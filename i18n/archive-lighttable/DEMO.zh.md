# 档案灯台 — 我们的示范片

这只是众多可能中的一个例子。不要照搬它的故事、结构、镜头、道具或时间安排。

示范片：*Two Seconds Short* 《差两秒》（40.0 s）· `archive-lighttable.mp4` · 源文件见 [`demo/`](demo/)

1903 年 12 月 17 日 Wright 兄弟的飞行，摆在一张灯台上，通过五件 Library of Congress（美国国会图书馆）藏品来讲述：两张玻璃底片、一封电报、一份剪报，以及作为道具的第三张底片。这是一部关于真实事件的非官方影片，只用公有领域的扫描件制作。画面上是中文，旁白是英文，字幕双语（中文在上，英文在下）。每一条事实及其出处都记录在 [`demo/FACTS.md`](demo/FACTS.md) 中。

## 故事与结构

一句话梗概：电报上说最长的一次飞行持续了 57 秒，第二天的报纸也照登了；而玻璃底片和图书馆的档案记录说的是 59 秒。

结构：说法（灯台亮起；放大镜落在 Orville 的电报上；镜片里的文字行逐行亮起，"57" 作为读数浮出）→ 回声（镜头升起，滑向 Dayton Herald 剪报，同一句话被加上下划线，其中的 57 被圈出）→ 证据，也是情感的高潮（放大镜落在首飞底片上，底片在镜片里由负像转为正像，镜头穿过镜片落进照片中，飞行者号从地平线上分离出来并向前飘移；12 s，120 ft）→ 测量（第四次飞行的底片：一把标尺铺在地平面上，从镜头一直延伸到地平线上那架小小的机器；852 ft，59 s）→ 裁定（57 和 59 并排，静止停留 2.7 s，然后 57 被划掉："差 2 秒"）→ 结尾（拉回到整张灯台；每件物品的标签飞进一份档案索引；片尾卡）。

用到的原生手法：电报和剪报上的*文字行亮起*；首飞用的*放大镜下由负转正*和*进入照片*（标志性手法，放在高潮处）；第四次飞行用的*在照片上测量*；裁定用的*两份记录并排停留*；结尾用的*灯台变成索引*。

## 配乐结构

90 BPM，4/4 拍；每个关键动作都落在一拍或半拍上（`demo/tools/cuecheck.mjs`），只有两次换气（17.6、32.8）是故意放在各自强拍之前的。B 小调转 D 大调。

| 段落 | 时间 | 音色 | 备注 |
|---|---|---|---|
| 亮灯 | 0–2.7 | 钢琴 D5 随灯光响起；电流嗡鸣和启辉器咔嗒声 | |
| 电报 | 2.7–10.7 | 弱音钢琴八分音符分解和弦，Bm–G–D–A；每一行亮起时一声纸张掠过声和一声玻璃余韵；大提琴 D3 和中提琴 A3 在 57 下方进入 | |
| 剪报 | 10.7–13.3 | 同样的分解和弦，更轻（Bm, G） | 回声 |
| 首飞 | 13.3–23.6 | 滑动时为 D；弦乐从显影处渐强（起音 1.6 s），钢琴以八分音符从 D4 爬升到 A5，一个噪声上升音效贯穿推镜；17.6 时一切切断；18.0 时完整的 D 和弦（钢琴 D2–A4、弦乐、低音提琴 D2、玻璃 D6、一记轻柔的镲），随后是一条下行旋律 A4–F♯4–D4–E4–F♯4 | 在照片里，风声和浪声取代了电流嗡鸣 |
| 测量 | 26.3–32.8 | 钢琴八分音符在 A 大调持续音上，略微渐强；下方是大提琴 A3 和中提琴 E4；每 100 ft 一声滴答；852 时玻璃 A5，59 时 E6 | 靠密度而非速度加速 |
| 裁定 | 32.8–33.3 | 寂静（只有嗡鸣） | |
|  | 33.3 | 笔划声，钢琴 D2/D3/A3，玻璃 D6，轻柔的定音鼓 D3 | |
| 结尾 | 35.7–40.0 | D 调的主题（F♯4–A4–D5–C♯5–A4），索引行落定时配滴答声；36.33 时最后的 D 和弦，带弦乐和弓擦颤音琴 | |

混音（在 `mix.py` 中）：闪避压低之前，音乐比人声低约 11 dB，旁白说话时再压低约 5 dB；拟音比人声低 9 dB，声底低 24 dB；除人声外一律加 38 Hz 高通；母带限制器把峰值与 RMS 之比保持在 11.5 dB 左右，使 `mux.sh` 能在 −1.2 dBTP 以下达到 −14 LUFS。

## 色板与道具

- 灯台 #F7F9FB，拉丝铝边框，深色书桌（#0E0F11）；墨色 #15171A；信号橙 #FF5A1F；说明牌 rgba(14,15,17,0.74)。
- 道具（全部来自 Library of Congress，真实比例，5000 世界单位 = 7 in）：电报（LC-USZ62-65459 / mcc.061）、Dayton Herald 剪报（LC-USZ62-70686）、首飞底片（LC-DIG-ppprs-00626）、第四次飞行底片（LC-DIG-ppprs-00629）、12 月 14 日底片（LC-DIG-ppprs-00610）。
- 放大镜：2.5×，镜片半径 1000 世界单位（约 1.4 in）。
- 旁白：Kokoro `bm_george`，语速 0.92–1.0。

## 片尾卡

在拉远后的灯台上方，左下角：差两秒（Noto Serif SC）、*Two Seconds Short*、一条信号橙色细线、`ARCHIVE LIGHT TABLE` 档案灯台、`LemoLab × Claude Opus 5.5`；右侧是档案索引。3.7 s。"LemoLab × Claude Opus 5.5" 的署名只属于本库的示范片；用户的影片不带任何 LemoLab 署名，也不要照搬这张片尾卡。

## 构建说明

```
demo/
  build.sh          one command: (FETCH) scans + textures + fonts → voice → speech check → cues → cue grid →
                    video → mix → master → .srt → subtitle widths → readcheck → poster + style frame
  index.html        two canvases (WebGL2 picture, 2D marks), fonts
  film.js           the table, camera keys, the three dives, the shader, every mark, readouts, index, end card, subtitles
  timeline.js       beats, key actions, narration, subtitle cues (single source; tools/export.mjs → out/timeline.json, out/cues.json)
  mix.py            score, foley, beds, voice, mix → out/mix.wav + out/stems/
  tools/            prep.py (masks, layers, fill), fonts.py, sru.py (LoC catalogue lookups), export.mjs,
                    cuecheck.mjs, subcheck.mjs
  sources/          the Library of Congress catalogue records (MARCXML) behind FACTS.md
  assets/           raw/ (downloads), tex/ (textures the page reads)
  FACTS.md, CREDITS, stills/styleframe.jpg
```

- `sh demo/build.sh` 在 Apple silicon 上约需 4 分钟（画面用 4 个 worker 约 40 s 渲染完；母带处理是最慢的一步）。从干净的克隆开始时，它会先获取 git 中没有的内容：来自 Google Fonts 的字体（`tools/fonts.py`）、Kokoro 模型以及 salamander、vsco2ce 和 vcsl 采样库（`tools/fetch.sh`），还有约 100 MB 的 Library of Congress 扫描件，由 `tools/prep.py` 转成纹理（约 25 s）。`FETCH=1` 会强制重新获取字体和扫描件。
- 它运行的检查：用 `small.en` 运行 `asr_check.py`（有两句台词带 `asr` 字段：Whisper 会把念出的日期写成 "17th, 1903"，并把 "four flights" 听成 "for flights"）、提示点网格、用真实字体测量的字幕单行宽度（最宽 648 px，上限 1500 px）、`readcheck.mjs`。
- 本示范片特有的坑：loc.gov 的藏品页面挡在 Cloudflare 验证之后，因此目录记录取自图书馆的 SRU 服务器（`lx2.loc.gov:210/lcdb`），文件取自 `tile.loc.gov`；在首飞底片中，天空可以对着平滑的乳剂膜精确分离出来，但沙地不行，所以地平线以下只抠出明显的部分（下翼、滑橇、支柱；用一个竖线滤波器捕捉细支柱），其余部分留在地面上；第四次飞行的扫描件对比度低，在正像中单独调整色阶；剪报是低分辨率副本，所以镜头在它上面的缩放从不超过约 0.66。
