## 5. 运动质感

- **角色一拍二（12 fps）**；摄影机、灯光、灯泡、金线描绘和扫光一拍一（24 fps）。逐格跳动的摄影机看起来像卡顿。
- **一切从中心展开**：一个点 → 一条细线 → 横条对称打开 → 文字升起 → 两翼与闪光。
- **描绘跟随音乐**：金线以其下方乐句的速度生长，并落在重音上。
- **灯泡有点亮过冲**（约 1.6× 的闪亮，在约 0.18 s 内回落）和一声继电器“咔哒”；招牌一旦点亮，可以有一串快速追光跑过它。
- **机械式缓动**：门、表盘和指针以坚定的缓入缓出加一点回弹移动，像机器一样；没有任何东西是飘浮的。
- **表演节拍要有预备动作**，并以三次递进（一下、两下、猛按）。
- 永远不动的：构图的中轴线。对称可以旋转或打开，但绝不偏离中心。



## 6. 镜头语法

这是一套词汇，而不是一条路线。开场和结尾由题材决定。

| 运镜 | 表达什么 | 可用于 |
|---|---|---|
| 对称分开（两扇在边缘铰接的门扇；或旋转门式划过） | 跨过一道门槛 | 一个新地方；新的一章；揭开立面背后的东西 |
| 门扇在实拍画面上滑动合拢 | 门在某个时刻上关闭 | 离开；做出决定；一个时代的终结 |
| 极低角度的 Cassandre 式俯仰 | 尺度与抱负 | 高高在上的目标；一座塔、一枚火箭、一座纪念碑 |
| 建筑剖面（拉远成整栋建筑的剖面图） | 在结构中前进 | 攀升、下降、分阶段的流程；一家公司的各个楼层 |
| Busby Berkeley 式俯拍，镜像并旋转 | 人变成图案 | 一个团队、一次发布、一场庆典、由部件组成的系统 |
| 对表盘、徽章或时钟推镜 | 数字就是情节 | 截止时间；计数；里程碑 |
| 形状匹配剪辑（圆 → 圆，光芒 → 光芒） | 两个地方，一个韵脚 | 在部门、城市、时代之间跳转 |
| 沿招牌或跑马灯低角度斜拍 | 光逐字传递 | 揭晓一个名字；一次发布；计分 |
| 从细节拉远到天际线 | 这一刻在世界中的位置 | 余波；全城范围的影响；尺度 |

构图：中轴线神圣不可侵犯；不对称的画面必须在镜头内回归中轴。在情绪高峰处，主角应占画面高度约 ≥ 1/3（再小的话，脸就像装饰中的一个道具）。转场：分开、旋转、拱门打开、形状匹配；绝不用普通的叠化或滑动。



## 8. 原生招式

这是一份菜单：按故事需要取用。

- **数出来的光。** 灯泡招牌每一拍或每个事件点亮一个字母，让观众能数出来。*适合的内容：* 产品发布倒计时；火车进站时城市名的字母逐一亮起；票数累计出胜者。
- **门槛之门。** 每次换场都是一扇沿中缝分开的门。*适合的内容：* 一家公司的各个部门；博物馆的各个展厅；职业生涯的各个阶段。
- **机械万花筒。** 人或物体变成镜像旋转的图案，最后锁定成一个符号。*适合的内容：* 团队变成一个标志；供应链的齿轮；合唱团变成一座钟。
- **表盘承载情节。** 用楼层指示器、时钟或仪表的移动代替旁白。*适合的内容：* 筹款温度计；登山的海拔；开盘钟声时的股票行情。
- **建筑剖面图。** 拉远直到建筑成为剖面、主角成为带速度线的彩色小点。*适合的内容：* 数据在服务器机架中流动；一封信穿过邮局；滑雪者从度假村滑下。
- **扫光 / 描绘。** 光在重音上掠过金色物体；金线以滑音的速度自行雕刻出来。*适合的内容：* 揭幕一座奖杯；地图上的路线；条约上的签名。
- **唯一的颜色。** 在金色世界里，一个元素保留自己的颜色。*适合的内容：* 众多竞品中的那一个产品；医生群中的那位病人；老牌公司里的新点子。
