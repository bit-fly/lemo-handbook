## 5. 运动质感

- **字符永远不离开网格，除非在一个明确声明的变形时刻。** 打字、滚动和计数器都是从一个单元格跳到另一个单元格。滚轮数字离散地翻动，先快后慢。
- **只有三样东西连续运动**：网格缩放（即镜头）、CRT 物理效果，以及变形中的粒子。
- **打字速度就是表演**：机器输出均匀而快速（约 10–40 ms/字符）；戏剧性的句子放慢到配乐的音符时值；人类打字手工设定时间，不均匀，有停顿和爆发。
- **粒子**从源字形内部的随机点生成，起初很小，淡入，缓动到它的单元格，落地时短暂闪光，因此永远不会堆叠成亮条。
- **推进到一个字符**：先在整个字形可读的位置停留，再推进到其内部文字可读；内部文字全亮度，外部文字只有几个百分点，相邻字形变暗，这样先读出形状，再读出文字。



## 6. 镜头语法

唯一的镜头就是网格缩放，再加上 CRT 的开关机状态，以及至多一个屏幕之外的镜头。

| 运动 | 表达什么 | 可用于 |
|---|---|---|
| 静止的 80 列终端 | 等待、流程、机器时间 | 倒计时；排队；正在被阅读的日志 |
| 推镜（单元格变大） | 注意力、亲密 | 一句对白；一个名字；一个被打出的决定 |
| 拉镜（单元格变小） | 背景、尺度 | 片名变成列表的第 1 行；千万条记录中的一条 |
| 推进到单个字形里 | 隐藏的深度；一个符号由什么构成 | 由消息组成的字母；由人组成的像素 |
| 滚动（缓冲区移动） | 积累、时间流逝 | 多年的记录；一份更新日志；一条信息流 |
| 清屏 / 硬重绘 | 一次剪切；一个新状态 | 重启；新的章节；一次崩溃 |
| 文字变成图像（字形下落时网格缩小） | 文字化为世界 | 一封信变成一张脸；数据变成一幅地图 |
| 开机 / 关机、消磁 | 诞生、死亡、睡眠、震动 | 一台机器苏醒；一个结局；一次冲击 |
| 从玻璃屏拉远到一个绘制的房间 | 屏幕是世界里的一件物体 | 谁在阅读；机器在哪里 |

开场和结尾由题材决定。构图：文字保持在弯曲屏幕内的安全区域；LOG 条区域保持干净。转场发生在屏幕上（清屏、重绘、滚动、开关机），绝不在两个屏幕之间交叉淡化。



## 8. 原生手法

这是一份菜单：按故事需要选用。

- **画面由文字构成。** 一句话分崩离析，它的字母按墨量密度排序，变成一幅只包含这些字母的图像。*适合的内容：* 一份宣言变成一群人；一份食谱变成那道菜；一首诗变成一片风景。
- **字号 = 镜头。** 推进直到一个字符填满屏幕，而它本身由更小的文字构成。*适合的内容：* 由员工姓名组成的公司名；由当年头条组成的年份；由消息组成的心形字符。
- **打字节奏 = 剪辑节奏。** 均匀的机器打字对比不均匀的人类打字；闪烁的光标就是一段表演。*适合的内容：* 一份求职申请；一次道歉；一个被想起的密码。
- **CRT 物理特性。** 开机时点 → 线 → 画面，关机收缩成一个点；余辉、辉光、弯曲的玻璃。*适合的内容：* 医院监护仪；一个夜班结束；一份旧档案被重新打开。
- **唯一一次颜色变化。** 一种柔和的第二颜色只出现一次。*适合的内容：* 数据日志中的第一片绿叶；天气报告里的一抹血橙色日落；服务器机房里的一幅儿童画。
- **日志文件。** 时间戳、错误代码、进度条来讲述故事。*适合的内容：* 产品发布日；一次救援；一次迁移。
