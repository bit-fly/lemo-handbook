# ASCII / CRT 终端 — 我们的示范片

这只是众多示例之一。不要照搬它的故事、结构、镜头、道具或时间安排。

示范片：*TRANQUILITY.LOG*（59.8 s）· `ascii-crt.mp4` · 源码见 [`demo/`](demo/)


示范片的创作简报：一部 30–60 秒、ASCII / CRT 终端风格的短片。

## 故事与结构

一台被留在月球上的机器，已经连续 40 年记录着 `NO SIGNAL`。一条消息抵达；它回复 `I AM STILL HERE.`，而这条回复的字母变成了一幅地出画面。我们选了一个**文字是角色唯一行动方式**的故事：一台机器、一个远程操作员、一条跨越距离或时间的消息。媒介本色的运用方式如下：

| 媒介本色 | 在故事中的用法 |
|---|---|
| **画面由文字构成** | 高潮*就是*一句话变成一幅图像。回复 `I AM STILL HERE.` 分崩离析，它的字母按墨量密度排序，变成一幅地出画面。图像中**只包含这句话里的字母**。 |
| **字号 = 镜头** | 推镜直到一个字符填满屏幕。这个字符本身又由更小的文字构成，由此揭示尺度和意义。一个 `M` 由 40 年的 `NO SIGNAL` 日志构成。 |
| **打字节奏 = 剪辑节奏** | 机器打字均匀而快速。人类打字不均匀，有停顿、有爆发。光标闪烁三次，是全片最重要的一段表演。 |
| **CRT 物理特性** | 屏幕开机时先是一个点，再是一条线，然后是整个画面；关机时收缩回一个点。用于开场和结尾。 |
| **唯一一次颜色变化** | 地球用蓝白色 `#BFE4FF`，这是唯一不是琥珀色的东西，也是情感的顶点。在音乐的重拍上切换。 |

我们在创作时记下的改编思路（只是例子，不是规则）：产品发布可以变成一份规格表，拼合成产品的轮廓；一封情书可以变成它自己的文字如雨落下，汇成一张脸；一堂历史课可以变成一个日志文件，其中的日期拉远后变成一幅地图。

**情绪弧线（59.8 s）：** 黑暗中一个光标，然后苏醒（启动日志，一个日期跳变），然后扰动（握手噪声，一行文字），然后屏住呼吸（光标闪烁），然后挫折（`NOT FOUND` 在三个拍点上出现 ×3），然后决定（打出回复），然后**近乎静默 1–1.5 s**，然后高潮（字母变成图像，唯一的颜色出现），然后尺度揭示，然后等待，然后一个小小的回复，然后余响（拉出屏幕，关机收缩成一个点）。

## 镜头

| 节拍 | 镜头 |
|---|---|
| 开场 | CRT 关闭，然后一个点、一条线、整个画面。一个巨大的光标在空白中闪烁 3 次。 |
| 片名 | 片名就是机器打开的文件，以 20 列打出。随后它**拉远**到 80 列，成为启动日志的第 1 行。 |
| 悬念 | 静止的 80 列终端。唯一的运动是文字和光标。在闪烁上停留。 |
| 决定 | 围绕提示符从 21 px 单元格**推镜**到 80 px 单元格。回复以巨大字号居中打出。 |
| 高潮 | 网格边下落边缩小（80 px 的字母变成 8 px 的单元格）。在完成的画面上停留，在重拍上切换颜色。 |
| 尺度揭示 | 推进到一个字形里，直到它变成由文字构成的子网格，然后猛地弹回。 |
| 结尾 | **唯一**一个屏幕之外的镜头：拉远，直到屏幕画面位于一个暗室中由字符绘制的终端里。旁边是一个大舷窗，显示真实的地球（18–20 行高）。只有两样东西发光：那条小小的回复和那颗星球。然后关机收缩成一个点。 |

为什么这个故事走这条路线：把片名打成机器打开的文件，让机器成了叙述者；在回复上推镜，让决定变得私密；唯一的屏幕外镜头放在最后，于是房间和真实的地球成了一次揭示。每一项都只是从 STYLE.md §6 中做出的一个选择，而不是这个风格默认的开场或结尾。

### 字母下落（示范片的高潮，逐步拆解）

1. 句子停留 1.5 s，光标闪烁。
2. 分裂时，字母抖动并抛出一个残影副本。
3. 每个目标单元格从一个匹配的源字母内部的随机点生成一个粒子（色阶中只存在这句话里的字母）。粒子从 18 px 开始，缩小到网格尺寸，并在 0.2 s 内淡入，这样粒子永远不会堆叠成一条亮条。它的路径在 x 方向平滑缓动，y = u·(0.6 + 0.4u)。
4. 地面从下往上落定。
5. 地球的字母先全部落到*地平线之后*，然后从下往上升到各自位置，于是星球真的"升起"了。
6. 源字母在被用完时逐渐变暗。
7. 落地闪光为 1.9× 亮度，在 0.12 s 内衰减。

**分形推镜**：推到能看清整个 `M` 的构图并**停留 1 s**，然后继续推进，直到日志文字可读（单元格 450 px，子文字约 28 px）。字形内部的文字为全亮度，外部文字为 3–6%，相邻字形为 20%。

**使用的打字速度**：启动日志行 12 ms/字符，命令 38 ms，片名和回复 120–150 ms（100 BPM 下的十六分音符）。人类打字使用手工设定的时间偏移，带停顿。

## 声音结构

- **音乐**：一段原创的 Carpenter 风格模拟合成器配乐，用 numpy 和 numba 渲染。
  - **声源**：PolyBLEP 锯齿波和方波振荡器、截止频率移动的 4 极谐振梯形滤波器，以及滤波器包络。加入缓慢的磁带抖晃（±3 音分）、铺底音色上的长混响，以及重击上的门限混响。
  - **网格与调性**：D 小调，100 BPM，每个剪切都在小节或拍点上。
  - **配乐形态**：启动阶段下面是静默，然后在机器苏醒时出现一个持续低音和一个方波十六分音符音序。
  - **硬切**：握手时整个配乐降到数字零，包括混响尾音，持续五秒。
  - **高潮**：一个单独的锯齿波琶音随字母下落而增长，并在颜色变化时展开为 Bbmaj7。**唯一的大三和弦**（D 大调）落在回复上。
  - **绝不做成芯片音乐。**
- **静默是主要乐器。** 握手、消息和光标闪烁只垫着房间底噪，画面成形前有 1.5 s 的静默。
- **拟音**（全部合成）：
  - **继电器与消磁**：继电器咔嗒声，消磁嗡鸣（60 Hz 加谐波，在 0.35 s 内衰减，带一声闷响）。
  - **按键**：屈曲弹簧键盘（塑料咔嗒声、一声 3.4 kHz 的弹簧铮响、键帽的沉闷敲击声）。空格键更闷，回车键更重。远端字符用干涩的电传打字机滴答声。
  - **调制解调器**：一段原创握手音（带两次相位反转的 2100 Hz 应答音、一个双音、1200/2400 FSK、加扰的频带噪声，全部限制在电话线频带内）。
  - **蜂鸣**：一声方波错误蜂鸣，最后一次错误用更低的一声，回复用一声 1 kHz 的 BEL。
  - **粒子**：粒子落地用一簇簇 2–6 kHz 的细小滴答声。
  - **房间底噪**：一层风扇声，带 120 Hz 嗡声，以及一声**非常轻**的 15.7 kHz 回扫啸叫（响度归一化之前约 −50 dBFS）。
- **人声**：机器的日志，由 Kokoro `am_echo` 以 0.8 的语速朗读。处理方式：52 Hz、16% 的环形调制，6 ms 梳状滤波（0.22），140–7000 Hz 带通，以及轻度饱和。Whisper 仍能 5/5 正确识别。使用 4–6 句短台词。人声下音乐闪避约 −8 dB。母带 −14 LUFS，不加颗粒（噪声留在画面里）。

## 色板与道具

- **字体与网格**：VT323 字形图集，以 160 px、2.2 px 描边预渲染。使用的网格：片名 20 列（单元格宽 84 px），终端 80 列（21 px），画面 240 列（8 px），房间 213 列（9 px），分形推镜最大到 450 px 单元格，每个单元格内是一个 40 列的子网格。
- **色阶数值**：属性 暗 / 正常 / 粗 = 0.42 / 0.7 / 1.0；抖动幅度 0.7；亮度 < 0.05 的单元格保持空白。底片以每单元格 3×6 采样：R = 琥珀色亮度，G = 第二颜色亮度，B = 一个标志位，例如"夜面"。房间场景加 3×3 的局部对比度增强。
- **看起来像地球的地球**：用经纬度表示的大陆多边形（一次性栅格化为等距圆柱遮罩），而不是噪声。海洋反照率 0.14（稀疏的暗字形），陆地 0.96（密集的粗字形），云层 0.5（中等密度的旋涡）。晨昏线很窄（smoothstep −0.03…0.10），夜面只用稀疏的 `.`。选择轮廓清晰的角度：非洲和欧洲。
- **月面**：远处地面更暗更稀疏（×0.3），近处地面更亮更密集。地平线有一道细亮的边缘（10 px 衰减）。环形山：左侧内壁处于黑色阴影中，右侧内壁被照亮，环形山边缘明亮。前景有几个轮廓分明的大环形山。
- **CRT 后期**（`demo/crt.js`）：R 映射为琥珀色：暗 `#FF6605`，中 `#FFB000`，过曝趋向 `#FFEBB8`。G 映射为 `#B8E0FF`。四级辉光 0.55 加光晕 0.22。3 px 扫描线 0.3；桶形弯曲 0.045；未点亮的玻璃 `#090604`；左上角淡淡的反光，1.2% 的高压闪烁。
- **余辉**：τ = 0.12 s；在 t − 35 ms 处额外加一个拖尾采样 × 0.3。
- **LOG 条**：暗色虚线分隔线，反白的 `LOG` 标签，`> ` 加上大写的 VT323 45 px 文字行；该行完成后停留 1.4 s；空闲状态为 `TRANSMIT [#####.....] 40%`、`SENT … AWAITING REPLY`。
- **片名**：文件名，伴随按键声打出，外加一行暗色的小副标题。

## 片尾卡

在最后的房间镜头上打出（`ASCII / CRT TERMINAL`、`LemoLab × Claude Opus 5.5`），随后 CRT 关机。"LemoLab × Claude Opus 5.5"署名只属于本库的示范片；用户的影片不带 LemoLab 署名，也不要复制这张卡片。

## 构建说明

```
styles/ascii-crt/demo/
  term.js    glyph atlas, grid drawing, density ramps, image → cells
  art.js     continent texture, earth shading, lunar ground, craters
  crt.js     monochrome phosphor CRT post (WebGL2)
  main.js    the whole timeline: boot, handshake, message, reply, letter fall, fractal, room, end card, EV, SUBS
  voice_fx.py  AI voice processing      mix.py  synthesized foley + ducking + score
  music/score.py  original analog-synth score      tools/subs.mjs  export window.SUBS
```

1. `node core/render/still.mjs styles/ascii-crt/demo --range 33.4:37.4:0.2` 可渲染任意段落的帧；`?frame=earth|fractal|base|poster` 渲染单项测试；`?nosub=1` 渲染不带 LOG 条的画面。
2. `sh styles/ascii-crt/demo/build.sh` 从零开始生成完整影片：TTS、人声效果、whisper、配乐、事件、混音、SRT、渲染（3 个工作进程约 50 s 渲染 1435 帧）、封装、风格帧、海报。

与本示范片道具相关的坑：

- **离屏底片漂移**在 200 列范围内表现为星星重影和环形山边缘错位。
- **用噪声纹理做的地球看起来像一个带纹理的球。** 使用大陆剪影、暗而稀疏的海洋和只有点的夜面。
- **从 13 个字母中心迸发的粒子会堆叠成一条发光的亮条。**
- **地球的字母穿过仍然可见的句子升起，看起来很乱。** 先把它们全部送到地平线之后，再升起。
- **粗的（描边的）图集字形会把 `M` 的缝隙封死。** 分形遮罩要采样一张单独的*细*（仅填充）字形位图。
- **惰性构建的数据**：如果不先构建粒子时间表，下落部分的拟音就是无声的。
