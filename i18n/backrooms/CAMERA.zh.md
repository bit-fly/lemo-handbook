## 5. 运动质感

- **一个连续的手持长镜头。** 剪切只发生在磁带断裂处：开机卷入、循迹撕裂、REC 关闭。
- **手持** = 行走步态（头部起伏几厘米、摇摆、轻微滚转）+ 呼吸（约 0.27 Hz）+ 几个频率的颤抖噪声，其幅度跟随一条**恐惧**曲线。屏住呼吸时，**全部冻结**。
- **低头**只拍到鞋尖和地面，绝不出现腿。
- **自动对焦** = 带过冲的对焦距离动画：模糊 → 合焦 → 滑脱 → 合焦。模糊来自把焦点拉*近*。变焦收窄 FOV 并开大光圈。
- **灯光闪烁**表现为短暂的黑场（约 0.1 秒）；自动曝光滞后追上（约 0.45 秒），增益噪点随之起伏。
- 东西会自己缓慢移动（一扇门用时 >1 秒，带缓动），绝不瞬间到位。



## 6. 镜头语法

这是一套词汇，而不是一条固定路线。开场和结尾由主题决定。

| 运镜 | 表达 | 可用于 |
|---|---|---|
| 沿走廊行走的主观视角 | 例行公事，无尽感 | 建立空间；时间流逝 |
| 从一个细节缓慢摇开到整个空间 | 尺度；空间无穷延续 | 一次揭示；第一眼 |
| 低头瞥一眼脚下 | 服从，回避 | 遵守守则；不去看 |
| 蹲下并停留在印刷文字上 | 阅读；官僚气 | 一条守则；一处矛盾 |
| 向远处变焦 + 对焦搜寻 | 看见 / 看不见 | 某种存在；一个疑虑 |
| 撕裂之后完全相同的构图，只有 OSD 变了 | 时间被抹去 | 一次跳跃；一次丢失 |
| 转过拐角，静止停留 | 一道门槛 | 一个出口；一个抉择 |
| 无声的缓慢推镜 | 某种东西的牵引 | 一扇门；一个标志 |
| 边拍边后退 | 撤退，恐惧 | 离开房间；守则被打破 |
| 摄像机被放在某个平面上，静止，独自录制 | 被遗弃 | 摄像者消失；漫长的等待 |
| 朝声音甩镜，然后什么都没有 | 期待落空 | 一个找不到来源的声响 |

构图：文字可读且不被遮挡；任何存在都要小、远，并处在灯光熄灭的区域。转场：只用磁带事件。



## 8. 原生手法

一份菜单：按你的故事需要挑选。

- **自动对焦 / 自动曝光搜寻。** 某样东西只在对焦正确时才存在。*适合这类内容：* 酒店楼层里走失的宠物；空荡体育场里的一个人影；医院走廊尽头的一个形状。
- **磁带循迹损伤。** 一次撕裂就是宇宙做出的一次剪切；之后构图不变，但时钟跳了、电池耗尽了、一盏灯熄了。*适合这类内容：* 一份守夜日志；在商场里丢失的一个周末；在两盘磁带之间变老的房子。
- **OSD 就是情节。** REC、电量、日期和时间码都是证据。*适合这类内容：* 一份不在场证明；一次倒计时；一次标有日期的检查。
- **画面中的守则文字。** 告示和广播一开始很普通，然后走样、互相矛盾，最后直接对观众说话。*适合这类内容：* 泳池安全守则；学校消防演练；闭馆后的博物馆。
- **空旷与重复。** 同一张告示出现在另一个地方；同一个房间只改了一个细节；一条通向雾中的走廊。*适合这类内容：* 搬家日的巡视；凌晨 4 点的机场；裁员之后的办公室。
- **几乎像人的那个东西。** 一个"不对劲" 15–40 % 的远处剪影（头小、脖子长、肩膀窄而高、手臂长），在公告板上画成有机曲线，缓慢移动。*适合这类内容：* 一个其实不是假人的假人；一名夜班保安；一个慢半拍的倒影。
