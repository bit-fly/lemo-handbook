# 阈限空间录像 — 我们的示范片

这只是众多例子中的一个。不要复用它的故事、情节走向、镜头、道具或时间安排。

示范片：*Night Shift Orientation*（夜班入职引导）（59.7 秒）· `backrooms.mp4` · 源文件见 [`demo/`](demo/)


## 故事与结构

一名新来的夜班员工拍下了自己的入职引导巡视：他按照打印的守则和广播，走过一层无穷无尽的办公楼。以下是为这部示范片撰写的原始风格笔记：

一段第一人称的**摄录机录像**（1990 年代 VHS，4:3），走过一个**空无一人、似曾相识却又不对劲的室内空间**：芥末黄的墙纸、潮湿的地毯、装满嗡嗡作响的荧光灯板的吊顶，无限重复。没有任何东西在追任何人。恐惧来自**空旷、重复、官僚式的守则，以及摄像机自身的机械在错误的时刻失灵**。观众应该感到后颈发凉，而不是从座位上跳起来。

影片中**绝不**使用 "Backrooms" 这个词、wiki 的 "Level" 编号、社区里的实体名称，或任何现实中的机构/标志。类型名称只存在于本文件中。画面上的一切——守则、表格、公司口吻、那个"东西"——都是原创。

录制媒介就是讲故事的人。示范片用上了全部五种原生能力，并把对焦搜寻放在情绪的最高点：

| 原生能力 | 示范片如何使用 |
|---|---|
| **自动对焦 / 自动曝光搜寻** | 摄像机只有在对焦正确时才"找到"某样东西。第一次合焦时它在，第二次合焦时它不见了。断电黑场后自动曝光滞后，画面随增益噪点起伏。 |
| **磁带循迹损伤** | 一次循迹撕裂就是*宇宙做出的一次剪切*。之后构图完全相同，但 OSD 时钟跳了好几个小时 / 电池耗尽了 / 有一盏灯熄灭了。 |
| **OSD 就是情节** | REC 红点、电量、日期和时间码都是剧情内的证据。摄录机的字幕生成器可以把片名写在第一个镜头上。 |
| **画面中的守则文字** | 打印的告示，语气平静的公司广播。守则一开始很普通，然后逐渐走样；其中两条互相矛盾；最后一条直接对观众说话。 |
| **空旷与重复** | 同一张告示出现在另一个地方；同一个房间只改了一个细节；一条消失在雾中的走廊。空旷本身就是威胁。 |

我们如何框定这个主题（同样的技巧适用于其他主题）：把主题变成某人用磁带录下的**一次入职引导、一项流程或一份检查清单**——新工作的第一个班次、一次楼宇检查、一次搬家日的巡视、一次学校安全演练、一次酒店夜审。写 5–6 条守则。让媒介背叛这些守则。

**示范片情绪走向（59.7 秒）：** 无聊的正常（约 20 秒几乎什么都没有）→ 一个小小的不对劲（一处矛盾、一张重复的告示）→ 一条守则受到考验（灯光闪烁）→ 看见 / 看不见（对焦搜寻）→ 时间被抹去（循迹撕裂）→ 一条守则被打破（出口）→ 最后一条守则转向观众 → REC 关闭。一个主体（摄像者——只闻其声，画面中从不出现鞋子以上的部分），一个目标（遵循流程），一个转折（时间码证明他已不在"正常"之中）。

## 镜头

| 节拍 | 镜头 |
|---|---|
| 开场 | 磁带卷入，自动白平衡从蓝摆到黄，自动对焦找到墙上的一张告示；摄录机字幕压在上面 |
| 揭示空间 | 从告示缓慢摇开，露出一条隔板走廊，灯光向雾中退去 |
| 例行公事 | 行走的主观视角，低头瞥一眼潮湿地毯上的鞋子；约 20 秒没有任何事件 |
| 矛盾 | 蹲下看一张重复的告示；停留 ≥4 秒，文字不被任何东西遮挡 |
| 遵守守则 | 猛地低头看鞋；让地毯上的光线变化，而不是去拍天花板 |
| 高潮 | 沿走廊变焦 + 自动对焦搜寻；那个人影只存在于约 0.5 秒的正确对焦中 |
| 时间剪切 | 循迹撕裂，然后是*完全相同*的构图——只有 OSD 变了 |
| 打破守则 | 转过拐角看到红色的 EXIT；在彻底的寂静中静止停留；推镜；门自己打开 |
| 结尾 | 最后一张告示清晰对焦 ≥3 秒 → REC 关闭：定格、撕裂、黑场 |

**那个"东西"**从不给特写：一个 2.4 m 高的剪影（一个"不对劲" 15–40 % 的同事：头小、脖子长而歪斜、肩膀窄而高、手臂垂到膝盖），用 Canvas2D 画成有机的剪影，贴在一块始终朝向摄像机的公告板（billboard）上，位于约 33 m 外一段灯全灭的区域，只有远处背后有微弱的光。缓慢的小幅挥手（3.6 秒一个周期）。目标：*你能看出它在挥手，但数不清手指。* 要把这块公告板排除在 GTAO 预处理之外（`mesh.isPoints = true`），否则它会印出一个深色矩形。

示范片的运动数值：步幅 0.72 m，头部起伏 3 cm，摇摆 1.8 cm，滚转 ±0.8°，呼吸 0.27 Hz，1、3.5 和 9 Hz 的颤抖；低头时俯仰约 −1.2 rad，摄像机前推 0.2 m；变焦 FOV 52° → 27°，光圈 ×5；每次闪烁三次 0.1 秒黑场，自动曝光滞后约 0.45 秒；门在 1.3 秒内打开。原始的运动部分：

- **一个连续的手持长镜头。** 剪切只发生在磁带断裂处：开机卷入、循迹撕裂、REC 关闭。
- 手持 = 行走步态（步幅 0.72 m，头部起伏 3 cm，摇摆 1.8 cm，滚转 ±0.8°）+ 呼吸（0.27 Hz）+ 1、3.5 和 9 Hz 的颤抖噪声，其幅度随一条**恐惧**曲线上升。在"屏住呼吸"的时刻，**全部冻结**。
- 低头：俯仰约 −1.2 rad，摄像机前推 0.2 m——画面里只有鞋尖和地毯，绝不出现裤腿。
- 自动对焦就是带过冲的景深对焦距离动画：模糊 → 合焦 → 滑脱 → 合焦。模糊来自把焦点拉*近*（焦点过冲到无穷远时，远处目标几乎不会模糊）。变焦把 FOV 从 52° 收窄到 27°，并把光圈提高 ×5。
- 灯光闪烁表现为三次 0.1 秒黑场；之后自动曝光以约 0.45 秒的滞后提亮。
- 门自己缓慢打开（1.3 秒，带缓动）。

## 配乐结构

没有配乐。为示范片搭建的声音设计如下：

- **没有配乐。** 只有磁带本来会录到的声音。
- **荧光灯底噪**：120 Hz + 谐波（×1…×7 依次为 1、.55、.42、.22、.16、.06），一个嗡嗡的带通方波成分，一丝约 9 kHz 的镇流器啸叫，随机出现的坏灯管"滋滋"爆音；由与画面相同的灯光曲线门控；在小房间里近 +3 dB。
- **广播**：平静的公司口吻（Kokoro `af_bella`，语速 0.82–0.84），经过"天花板扬声器"处理：带通约 310–3500 Hz，约 1.3 kHz 的纸盆共振，tanh 饱和，房间混响——保持足够干，让 whisper 能转写（混响过多会把 "night shift" 听成 "my church"）。每条守则前一段原创的双音提示音（颤音琴 E5→C5）；时间跳跃之后，提示音和人声都随磁带抖晃而走音偏低。
- **摄像者**：3–4 句短台词（`am_michael`），音量低，近讲低频效应，一层跟随人声包络的呼吸/气声，做压缩。Kokoro 无法真正耳语——目标是"轻声说话"。近距离的呼吸声，频率随恐惧曲线变化；先屏住呼吸，然后一次长长的呼气。
- **剧情内的等待音乐**：一段原创的轻音乐循环（这里是 88 BPM F 大调，颤音琴旋律，干净吉他在 2、4 拍扫弦，指弹贝斯），带通处理并淹没在混响里，仿佛隔着墙传来，按逐渐变慢的带速曲线（1.00 → 0.97 → 0.89）读取，抖晃越来越大。黑场时它会中断，到静默处彻底消失，再也不回来。
- **拟音**：潮湿地毯上的脚步（60–85 Hz 闷响 + 0.9–2.6 kHz 的细小湿响）、转身时的衣物摩擦、REC 开/关时摄录机的咔嗒声和马达声、变焦伺服的嗡鸣、自动对焦马达的嘀嗒、每次闪烁时镇流器的"叮"声和电弧嗡鸣、头顶几乎听不见的拖拽声、门锁 + 黏滑摩擦的合页吱嘎声 + 气流推动声。
- **静默就是高潮**：出口出现时一整秒的数字零值（包括尾音）；字幕 `[SILENCE]`。唯一允许的惊吓是轻柔的：声音回来时所有镇流器同时重新点亮，伴随一声低沉的闷响。
- 低频嗡鸣（35–55 Hz 褐噪声 + 41/43.5 Hz 拍频）从时间跳跃一直上升到静默。人声下方底噪和音乐闪避约 −8 dB。响度 −14 LUFS，颗粒 0（噪点已经在画面里了）。

## 色板与道具

- **画幅**：4:3 画面以左右黑边嵌入 1920×1080。3D 以 **720×540** 渲染，交给 VHS 处理放大——低分辨率是这种质感的一部分，还能掩盖 CG 的干净感。
- **空间**：0.16 m 厚、沿坐标轴排布在 2.4 m 网格上的隔墙，随机留出缺口和断墙，偶尔有方柱；层高 2.70 m；吊顶板 0.6×1.2 m；每 2.4 m 一盏嵌入式格栅灯（0.6×1.2 m 棱镜灯板）。在程序化填充的办公室中手工编排一条路线（起始房间 → 长走廊 → 侧走廊 → 一个小房间），让每个门口都露出更多空房间。
- **照明 = 成千上万盏灯，没有阴影**：把每盏格栅灯的颜色/强度存进一张 128×128 浮点 **DataTexture**；每个片元累加最近的 5×5 块灯板（发光体余弦 × Lambert / (d²+0.3)），再加上同一邻域的反弹光项。没有遮挡——这种空间的光是平的。每盏灯的差异：冷暖 ±8 %，偏绿 +0–7 %，3.5 % 熄灭，2.5 % 闪烁。GTAO（半径约 0.55 m）压暗墙与地面的接缝。
- **雾随局部光照变化**：雾的颜色 × （局部反弹光 / 平均值）。灯熄灭的地方雾也是暗的，所以那里的剪影看起来像*光里的一个洞*。场景背景 = 雾 × 0.15，让走廊消融进黑暗，而不是撞上一堵亮墙。
- **色板**（反照率，sRGB）：墙纸 `#d5bd66`，带较深条纹 `rgba(140,112,40,.7)` 和一列菱形图案，每卷褪色程度各不相同；踢脚线 `#4d3d26`；地毯 `#8c763c` 带斑驳，潮湿处 ×0.6 并有微弱高光；吊顶板 `#d9d3b8`，龙骨 `#e6e1cf`；格栅灯扩散板 `#fbfaf0`，自发光 ×5；**唯一的饱和色是红色 EXIT 标志**（`#ff2a1a`，自发光 ×9 以产生泛光）。
- **克制的破败**（干净是这种风格的一部分——绝不要把它做成废墟）：*部分*墙脚有水渍痕，天花板下有一圈烟熏黄，偶尔有起翘的接缝（约 7 % 的墙纸卷，露出浅色纸背三角 + 阴影），少量小污渍，约 4 % 发黄的吊顶板，约 2 % 回风格栅，<1 % 缺失的吊顶板（黑洞），扩散板里有死虫。
- **告示**：发黄纸张上的办公室激光打印：IBM Plex Sans Condensed 标题（"FLOOR STAFF — PLEASE READ"、"FORM NS-01 (REV. 9)"），编号守则用 Plex Sans 600，"Thank you for your cooperation. — Management"。钉在软木板上或用胶带贴在墙纸上。拍特写时，**把摄像机降低，让镜头与纸面平行**——对着竖直的纸张向下俯拍，会把文字剪切成假斜体。
- **VHS 摄录机处理**（自定义着色器，*不是* CRT）：逐行时基抖动（幅度要小；低频晃动 ≤0.25 px，否则文字会歪斜），最底部 8 行的磁头切换带，按需触发的循迹撕裂；桶形畸变 0.07 + 暗角 0.42 作用于画面但**不**作用于 OSD；亮度带宽限制（720 下高斯 σ≈1.25 px）+ 边缘增强振铃（锐化 0.9）；色度在 ±10 px 范围内平均并向右偏移 1.6 px；亮光向右拖影；自动白平衡色偏漂移；AGC 噪点（条纹状，暗部更强）；每帧 0–2 条信号丢失线；黑位抬升 0.045，高光柔和截断。噪点以 30 fps（磁带速率）运行，尽管输出是 24 fps。没有扫描线，没有 RGB 荫罩。
- **OSD**：手工制作的 5×7 点阵字体，带黑色描边：左上 `● REC`，右上电量，右下 `PM 11:58` / `SEP.27.1996`。片名使用同一字体 ×2，就像摄录机的字幕生成器。

## 片名与字幕

- **CEA-608 风格的隐藏字幕**：IBM Plex Mono 600，42 px，每行白字配实心黑底框，每行 ≤32 个字符，在 4:3 画面内居中，位于 OSD 时钟上方。它们不受磁带噪点影响（由电视解码）。
- 说话人标记：广播用 `[PA]` 前缀；摄像者用斜体（第一句标注 `(whispering)`）；SDH 声音描述放在方括号里：`[FLUORESCENT LIGHTS HUMMING]`、`[LIGHTS FLICKER]`、`[TAPE NOISE]`、`[SILENCE]`。
- 告示上的守则*不*加字幕——它们就是画面。保证文字在 1080p 下可读，每张告示至少有 3–4 秒不被遮挡。
- 片名：摄录机字幕生成器的点阵文字，在第一个镜头上逐字打出。

### 我们踩过的坑

- 全亮的场景看起来像医院走廊。把墙打散成带缺口的隔板；让远处暗下去。
- 灯光会穿墙（没有遮挡）——一个"死区"需要 ±5 m 内的所有灯全部熄灭，它背后的走廊也要暗，否则人影会被框在一扇亮窗前。
- 场景背景在走廊尽头显示成一个亮矩形——把背景设为 雾 × 0.15。
- 均匀的雾色会把剪影抬成灰色；让雾跟随局部光照。
- VHS 处理中的低频行晃动会让文字歪斜；保持 ≤0.25 px。摄像机向下俯拍告示让文字看起来像斜体——改为降低摄像机。
- 用胶囊体搭的人形看起来像玩具 / 火柴人。把剪影画成公告板上的有机曲线。
- 用基本体做的腿看起来像管子；只露出鞋尖（挤出的鞋印轮廓加倒角，浅色鞋底，鞋带）。
- ×3 的红色自发光永远到不了泛光阈值（纯红的亮度很低）；用 ×9。
- 用*滤波前*的峰值来归一化滤波后的提示音，让广播总线爆了 16 dB——要用处理后的信号来归一化。
- 过重的广播混响会毁掉可懂度；用 whisper 检查每一句处理后的台词，也要检查完整混音。
- 压缩一条已完成的时间线：用"原始"时间写关键帧，再通过一个分段线性映射 `W()` 统一变换；记得把其他地方硬编码的时间也一起变换。
- VHS 噪点让文件很大：CRF 24 → 60 秒约 47 MB。
