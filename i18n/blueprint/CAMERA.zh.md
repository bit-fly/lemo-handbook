## 5. 运动质感

- **摄像机和逐步绘出都按一拍一帧（24 fps）。** 段落内连续运镜，段落之间在强拍上硬切；只有物理冲击（纸张拍下、盖章）才有微小的镜头震动。
- **逐步绘出**按弧长截断，笔头有发光笔尖；同一层内元素错开；每一层从一个节拍开始。
- **制图顺序**：中心线 → 轮廓线 → 细节 → 剖面线 → 尺寸 → 气泡 → 标签。
- **爆炸图**：零件在节拍的细分上依次离开，带缓动，回来时每个节拍组一个，伴随一声咔嗒。
- **机构在网格上步进**，像擒纵机构一样：齿轮每个细分前进一个齿，带短暂的 ease-out；啮合相位经过计算，齿真正咬合；链条随链轮运动。
- **机器表演**：角度、下垂、体积和仪表指针就是它的脸。失败 = 在约 1.5 s 内变慢、下垂、停转；喜悦 = 啪地立直，指针过冲（back 缓动）。



## 6. 镜头语法

一套词汇，不是一条固定路线。开场和结尾由主题决定。

| 运镜 | 表达什么 | 可用于 |
|---|---|---|
| 桌上的整张图纸 | 规模，文档作为一个物件 | 建立镜头；判决；一系列图纸 |
| 中景对准一个图形，主体约占 80 % 高度，一侧留空 | 设计正在被画出来 | 绘制；讲解一个零件 |
| 沿力的路径跟拍（链条、管道、电线、梁） | 因果关系 | 工作原理；一系列操作 |
| 在强拍上剪切到 2× 特写 | 机构的心脏 | 齿轮啮合；一个阀门；一个关节 |
| 固定机位，停留一个节拍 | 斟酌 | 一只手在修订；一个决定 |
| 斜轴深度系数 0 → 0.5 | 平面图纸"转动"起来并获得厚度 | 从平面到实物；揭示纵深 |
| 剖切线扫过 | 内部与外部 | 剖视；隐藏的结构 |
| 横向摇镜扫过图 1 → 图 2 → 图 3 | 版本、步骤、时间 | 修订；施工阶段 |
| 缓慢推镜，没有人声 | 惊奇 | 那唯一变成真的东西 |

讲故事的镜头要近；整张图纸的远景要少用。让主图形距离你会取景的任何图纸边缘至少 `960/zoom`。转场：在强拍上剪切，或在图纸上改写图号；不用叠化。



## 8. 原生手法

一份菜单：按故事需要挑着用。

- **制图顺序。** 物件像工程师那样把自己画出来，每拍一层。*适合的内容：* 一座桥；一把小提琴；一次厨房翻新。
- **实时标注。** 尺寸测量运动中的零件，数字随之变化；气泡跟着零件飞；剖切线揭示内部。*适合的内容：* 心脏瓣膜；折叠自行车；火箭级间分离。
- **用图号做转场。** "FIG. 1"被划掉，改写成"FIG. 2 · EXPLODED VIEW"。*适合的内容：* 一个产品的各个版本；一项工程的各个阶段；一道菜谱的步骤。
- **投影即摄像机。** 斜轴系数做动画；炸开的零件沿深度轴飞出。*适合的内容：* 平面图变成建筑；一块电路板；平板包装家具。
- **符号变成真的**（只用一次，或者不用）。某个制图规范离开了制图语言：尺寸箭头飞出去，剖面线变成雨，中心线变成道路，焊接符号迸出火花。*适合的内容：* 一项发明终于成功；城市规划变成街道；梦想变成计划。
- **蓝晒与水。** 水滴晕开，线条变柔。*适合的内容：* 一项防洪设计；悲伤；一道港口防波堤。
- **把标题栏当成故事。** 状态栏 = 判决；修订行 = 历史。*适合的内容：* 一份被驳回的许可；一座城市的 REV. 1–5；多年后终获批准。
