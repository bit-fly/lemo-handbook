# 蓝图 — 我们的示例片

这只是众多可能中的一个例子。不要照搬它的故事、结构、镜头、道具或时间安排。

示例片：*Patent Pending: The Cloud Catcher*（46.7 s）· `blueprint.mp4` · 源文件见 [`demo/`](demo/)


## 故事与结构

一位发明家为一台接云机器绘制的专利图：它被画出来、被炸开展示、完美运转，但天上没有云；那只手修订了图纸，修订云线变成了一朵真正的雨云，雨落在画出来的花园上，一朵花长了出来。以下是为这部示例片写下的、关于本风格叙事能力的原始笔记：

整部片子都发生在**一张蓝图纸上**，纸平铺在一张深色绘图桌上。一切都是不均匀的普鲁士蓝上的白色线稿：中心线、轮廓线、剖面线、尺寸线、带编号气泡的引线、一个标题栏和一栏注释。摄像机在图纸上移动，就像一只眼睛在读图。这是一种 **2D 线稿语言**。你可以使用正交投影和斜轴/等轴投影，但**绝不使用 3D 渲染**。

它的魅力来自**严谨的工程规范**与**奇思妙想**之间的张力。图纸干巴巴、精确无误。笑点藏在注释里（"10 · COUNTERWEIGHT (GRANDMOTHER'S IRON)"，配重（外婆的熨斗））。而每部片子里有一次，某个制图符号打破规则，变成了真的。

可以学习其语法，但绝不照抄：Prologue Films 为 *Iron Man*（2008）片尾字幕制作的动态技术图纸、达·芬奇的 *Codex Atlanticus* 手稿页、19 世纪的美国专利图（Fig. 1 / Fig. 2、零件气泡、细线明暗）以及 *Hugo*（2011）中的自动人偶图纸。不要出现漫威元素，不要用真实专利，不要用真实发明家的机器或签名。

机器（或物件、或规划）**就是角色**。零件会表演：吊臂满怀希望地抬起或耷拉下来，风向标精神起来或萎靡下去，风箱在呼吸，仪表指针在零点抽动。发明家只以一个**握着笔尖的手影**或一个签名的形式出现。

| 原生能力 | 示例片的用法 |
|---|---|
| **制图顺序** | 物件像工程师那样把自己画出来：中心线 → 轮廓线 → 齿轮/细节 → 剖面线 → 尺寸 → 气泡 → 标签。每一层都落在一个节拍上。 |
| **实时标注** | 尺寸线测量运动中的零件，数字随之变化。引线和气泡跟着炸开的零件一起飞。剖切线 A–A 扫过外壳，露出内部。 |
| **用图号做转场** | "FIG. 1"被划掉，改写成"FIG. 2 · EXPLODED VIEW"（图 2 · 爆炸图），再改成"FIG. 3 · IN OPERATION"（图 3 · 运行中）。 |
| **投影就是摄像机** | 把斜轴深度系数从 0（平面立面）动画到 0.5。线稿"转动"起来并获得厚度，不需要 3D 渲染器。炸开的零件沿深度轴飞出。 |
| **制图符号变成真的**（放在情感高潮处） | 一朵修订云线变成真正的雨云。其他候选：尺寸箭头变成真箭、剖面线图案变成雨、中心线变成道路、焊接符号迸出火花。规则：**这一个符号是整部片子里唯一离开制图语言的东西。** 它获得柔和的体积、渐变、辉光，以及一道投在图纸线条上的阴影。 |
| **蓝晒与水** | 雨落在图纸上：每一滴晕开成更深的蓝色，带一圈浅色水渍边，水渍内的白线变得柔和。一滴落在签名上，签名就洇开了。 |
| **标题栏** | 标题卡 = 图纸表头。状态栏 = 故事的判决（红色橡皮图章是片中唯一的非蓝色）。片尾卡 = 标题栏的最后一行被写上（STYLE / DRAWN BY）。 |

**我们如何改编这个话题**（同样的配方也适用于其他话题）：把话题变成**某种被设计出来的东西**，让图纸发现一个只有图纸才能修复的缺陷。一次产品发布会变成图 1、爆炸图、运行，然后一次修订补上了缺失的功能。一个爱情故事：一张图纸上的两台机器，一朵修订云线画出了它们之间的桥。一堂历史课：一份城市规划被一改再改（REV. 1、2、3）。

**示例片情感弧线（46.7 s）：** 好奇（空白图纸，物件被画出来）→ 自豪（爆炸图）→ 兴奋（它运转起来，踩在节拍上）→ 缺陷（它完美运转，但世界缺了点什么；音乐停止）→ 那只手修订图纸 → **符号变成真的**（挂留和弦，没有人声）→ 回报 → 回响（图章、签名、标题栏）。

## 镜头

| 节拍 | 摄像机 |
|---|---|
| 开场 | 深色桌面上的整张图纸。纸卷啪地展开，然后是丁字尺。仅作为建立镜头。 |
| 标题 | 推镜到表头字样。 |
| 绘制 | 中景对准图 1，机器约占画面高度的 80%，右侧是空旷的天空（字幕就放在那里）。 |
| 爆炸图 | 拉镜，让机器位于中间偏左，零件清单从右侧露出一角。 |
| 运行（最令人难忘的镜头） | 剪切到曲柄和齿轮的 2× 特写，然后**沿传动链跟拍**，顺着桅杆向上到吊臂，再跟随网的弧线。摄像机沿着力的路径走。 |
| 缺陷 | 中远景，留出大片空旷天空。空旷本身就是笑点。 |
| 修订 | 手影绘制时固定机位。符号画完后停留一个节拍。 |
| 符号活过来 | 缓慢推镜，没有人声。 |
| 回报 | 跟随物件向下落到目标处，推镜到结果上（那朵花）。 |
| 结尾 | 拉镜到整张图纸（揭示规模）。图章在远景中落下。推镜到标题栏作为片尾卡。 |

讲故事的镜头要近。只有开场和结尾的建立镜头是整张图纸。

示例片的运动数值：炸开的零件在八分音符上依次离开，每隔约 0.055 的进度离开一个，回来时每个八分音符一组，伴随一声黄铜咔嗒；齿轮每个八分音符前进 7.5°（一个齿），带 0.35 拍的 ease-out；风箱每拍呼吸一次；失败历时约 1.5 s（齿轮变慢、风箱泄气、吊臂下垂、风向标耷拉）；喜悦 = 风向标啪地立直，指针过冲到 1。原始的运动一节：

- 线条的**逐步绘出**按弧长截断，笔头有一个发光的小笔尖。同一层内的元素错开出现。每一层从一个节拍开始。
- **爆炸图**：零件按顺序离开，每隔约 0.055 的进度一个，踩在八分音符上，带缓动。摄像机拉远腾出空间。零件回来时**每个八分音符一组，伴随一声黄铜咔嗒**。
- **机构在网格上步进**：齿轮每个八分音符前进一个齿（7.5°），带 0.35 拍的 ease-out，像擒纵机构一样。啮合相位经过计算，齿真正咬合。链节随小齿轮运动。风箱每拍呼吸一次。
- **机器表演**：吊臂角度、风向标下垂、风箱体积和仪表指针就是它的脸。失败意味着齿轮变慢、风箱泄气、吊臂下垂、风向标在约 1.5 s 内耷拉下来。喜悦意味着风向标啪地立直，指针过冲（back 缓动）到 1。
- **摄像机按一拍一帧（24 fps）运动**，段落内连续，段落之间在强拍上硬切。两次微小的镜头震动：纸张拍下和盖章。

## 配乐结构

- **音乐**：G 大调、108 BPM 的二声部**巴洛克创意曲**。羽管键琴奏主题（一小节十六分音符的"齿轮"动机），巴松以断奏在低两个八度处模仿。
  - 运行段加入小提琴和大提琴的跳弓八分音符（"齿轮咬合"）。
  - 缺陷段：乐器依次退出，带写出来的渐慢，然后是真正的数字静音。
  - 修订段除了一个三音的疑问音型外全部静默。
  - 奇迹段停在一个 Dsus4 弦乐和弦上，带两次呼吸般的渐强，不解决。
  - 接住云的那一刻在强拍上解决到 G。
  - 雨用竖琴和羽管键琴的琶音。
  - 一个简短的完全终止落在盖章上，片尾卡时主题以增值形式回归。
  - 用 `core/audio/sampler.py` 渲染：VCSL 羽管键琴和竖琴，VSCO 2 CE 巴松、弦乐和跳弓。
- **拟音跟随材质**：
  - 纸张：纸卷展开的噼啪声和拍下声、丁字尺的木头滑动声、针管笔的刮擦声（2–6 kHz 颗粒，长度 = 笔画长度）、写字（一阵阵短笔画）、圆规的吱声、画剖面线（每秒 13 笔）。
  - 黄铜与木头：零件咔嗒声（3.1 / 5.2 kHz 共振）、擒纵滴答声、链条哗啦声、风箱呼吸声、按 ×1.35 逐渐变慢的停转滴答声。
  - 魔法时刻：两次呼吸时柔和的纸张"噗"声、一次噪声渐强，除此之外什么都没有。
  - 水：每滴一声柔和的闷拍，加一层轻柔的雨声底。
  - 橡皮图章的闷响，最后一刻笔帽的咔嗒声。
- **人声**：一位冷幽默的英国工程师朗读他自己的设计笔记，Kokoro `bm_daniel`，`lang en-gb`，语速 0.9。五六句短台词。高潮部分不要人声。
- **混音**：有人声时音乐闪避到约 0.36，拟音闪避一半。whoosh 声做 2.5 kHz 低通（它们在 whisper 中盖住了"bellows"这个词）。−14 LUFS。`mux.sh` 颗粒 4（纸张颗粒已经在画面里了）。

## 配色与道具

- **图纸**：3200 × 2200 单位，折成四折。蓝色由 WebGL 片元着色器在*图纸坐标*中程序化生成，所以任何缩放下都保持清晰。在 `#18336B` 和 `#2A58A6` 之间的低频 fbm、水平的涂布条纹、轻微的从左到右渐淡、纤维噪点、稀疏的纤维、折痕（亮边、暗边、沿折痕磨损发白）、不规则的漂白边缘和角落、细小斑点。图纸之外：深色绘图布 `#0D1116`，带投影。
- **线条**：浅蓝白色 `#E7F0F9`，略微柔和（mipmap 渗色），带由纸张纹理驱动的轻微墨迹断续。
  - 以图纸单位计的线宽：轮廓 3.2、细节 2.0、细线 1.25、发丝线 0.9。
  - **屏幕线宽 = 图纸线宽 × zoom^0.65。** 特写时线条不会变成香肠，远景时也不会消失。
  - 虚线：中心线 `[34,7,6,7]`，隐藏线 `[11,7]`，假想线（剖切面）`[30,6,5,6,5,6]`，全部随缩放调整，让图案始终贴在纸上。
- **遮挡**：每个实体在描轮廓之前先用"纸"填充（在墨迹缓冲区中为黑色），按画家算法排序。斜轴投影中的挤出用扫掠实现：在 N 个深度步长上以 2× 线宽描轮廓，然后在同样的 N 步上用纸填充。留下来的是一条干净的半宽剪影。正面和可见的顶点连线画在最上层。
- **合成**：墨迹 canvas 是灰度的（白 = 曝光的线条）。fx canvas 的 R = 阴影压暗，G = 湿润度，B = 图章油墨，以 `lighter` 方式叠加。overlay canvas 放字幕。阴影也会压暗线条，这正是一个被抬起的物体证明自己已经离开纸面的方式。为了不让物体被自己的阴影压暗，在 fx canvas 上把它所在区域乘以 `rgb(0,255,255)`。
- **剖面线**（细线明暗）用于剖面、土壤和配重，45°，间距 8–14 单位。
- **魔法物件**（仅限高潮）：圆的并集（15 个扇贝弧加 4 个内部圆瓣）。
  - 平面状态：一朵向外扇贝状的修订云线。
  - 鼓起状态：整个并集上一个统一的径向渐变（左上受光）加顶部圆瓣上的小高光、一层模糊的白色辉光、右下方的雕刻式月牙阴影（遮罩 = 并集减去向左上偏移的并集），以及阴影一侧更粗的轮廓线。
  - 它在原来被画的位置留下一个浅色的"未曝光印痕"。它的阴影偏移随抬升而增大（最多向下约 240 单位）。
- **配色纪律**：只用蓝和白。一种图章红 `#C23B2E`，恰好只用一次。
- **字体**（全部 OFL）：
  - Architects Daughter 用于手写字（表头、标签、注释、字幕）。
  - B612 / B612 Bold 用于标题栏字段和"PATENT PENDING"。
  - Allura 用于签名。
  - 文字由一个发光笔尖从左到右写出来。

## 标题与字幕

- **字幕就是图纸注释**：一个浅色框（rgba(12,28,62,.58)，1.2 px 外框和 0.8 px 内框白线，高约 110–150 px），一个 B612 Bold 的"NOTE / n"格，Architects Daughter 38 px 的正文在 0.35 s 内写出，左下角有一个小小的引线刻度。
  - **每个镜头放在空旷的天空处**，绝不固定在底部。画面底部是地面线、底座和标题栏所在的位置。
  - 约 880 px 处换行。
- 每条字幕也会被写进图纸的 **GENERAL NOTES**（总注）栏（在固定注释"ALL DIMENSIONS IN MILLIMETRES."和"DO NOT SCALE DRAWING."之下），所以最后的远景会把全部旁白显示为图纸注释。
- **标题**：图纸表头（Architects Daughter 132 单位，加大字距，双下划线），配 PATENT PENDING 和一行 B612 副标题。

## 片尾卡

**片尾卡**：标题栏。最后一行被写上：STYLE: BLUEPRINT / DRAWN BY: LemoLab × Claude Opus 5.5。"LemoLab × Claude Opus 5.5"这个署名只属于本库的示例片；用户的影片不带 LemoLab 署名，也不复制这张卡片。

### 我们踩过的坑

- **机器靠近图纸边缘**：远景镜头会拍到桌面。让主图形距离你会在远景中取景的任何图纸边缘至少 `960/zoom`，或者把图纸做大（我们从 3200×2000 改成 3200×2200，并把机器右移）。
- **向上炸开的零件会撞到表头。** 主要向上方和侧面炸开，并在爆炸期间把吊臂放平，让网向侧面伸展。
- **字幕放在墨迹 canvas 上**会在图纸外消失，也无法遮挡线条。使用单独的 overlay 纹理，最后合成（预乘 alpha）。
- **魔法物件被自己的阴影压暗。** 在 fx canvas 上把它的区域乘以 `rgb(0,255,255)`，只清零阴影通道。
- **逐个圆瓣做明暗会变成"葡萄"或气泡膜。** 在整个并集上用一个渐变，月牙阴影来自"并集减去偏移并集"的遮罩，弧线只画在上方的内部圆瓣上。
- **重叠的叠加式圆形填充会变成气泡。** 把并集作为一条路径用 `fill('nonzero')` 填充。
- **扇贝弧方向画反了看起来像爆炸星。** 选择包含圆瓣朝外角度的那个弧方向。
- **半鼓起的云看起来像甜甜圈。** 让内部圆瓣提前长大（`r × min(1, pf × 2.2)`）。
- **回报必须够大。** 第一版剪辑里，花只是下三分之一处的一小簇，大大削弱了情感回归。让回报物件占画面高度约 1/3，居中，一笔一笔画出来（茎 → 叶 → 每拍一片花瓣），周围有可见的水渍。字幕不要压在它上面。
- **接住的物体从网里透出来。** 不要整片把网画在它上面：先用物体的本体填充前沿下方的网兜，再在上面画网格和前沿，跳过后沿。
- `sfx.thump()` 长 0.35 s：加入更长的缓冲区前先补齐。
- Whisper 会把"Figure one"识别为"Figure 1"：在 `lines.json` 中使用 `asr` 字段。
- **仓库根目录出现多余文件**：始终在你的风格目录内用绝对路径写文件。
