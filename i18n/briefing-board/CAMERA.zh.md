## 5. 运动质感

- 24 fps 一拍一；没有任何东西是抽帧跳动的。
- 摄影机：相互重叠的缓动运镜，速度 ∝ u^a (1−u)^b（a、b ≈ 1.5–4），因此速度和加速度永远不会突变；b > a 带来惯性感。底层有一层手持般的呼吸感（≤ 3 px）；只有撞击时才震动。
- 重量感：照片从摄影机一侧放下，落下、弹一下、随着阴影收紧而停稳；磁铁咔嗒一声钉住它们；名牌晃动；被移除的磁铁朝镜头弹出；被划掉的东西一震再弹回。摄影机可以在物件落下时短暂凑近，对准它最能说明问题的细节，然后拉出。
- 运动时模糊，读字时清晰。每 1–2 拍就有东西落下、画出或摆动；只有静默和评判停留时画面才静止。
- 墨线以手写的速度画出；尺寸线以箭头一点落定。
- 绝不使用：叠化、文字缩放弹出、弹跳式 UI 缓动、文字自己淡入。



## 6. 镜头语法

| 运镜 | 表达什么 | 可用于 |
|---|---|---|
| 沿一条线运镜（跟着笔或尺寸线） | 测量；“它能延伸多远？” | 长度比较；一条路线；一条时间线 |
| 沿投影线俯仰 | 同一个量在另一个视图中 | 平面 → 立面；总数 → 各个部分 |
| 缓慢推镜，轻微荷兰角倾斜 | 紧张，一个正在逼近的问题 | 一次碰撞；一个截止日期；一次超支 |
| 向后并侧向拉镜 | 退后一步，宣布一条规则 | 一个约束；论证中的转折 |
| 随线甩镜，冲过头，再稳住 | 一个超出预期的结果 | 一项纪录；一个离群值 |
| 沿引线上升 | 从证据到结论 | 一个结论；一条建议 |
| 阶梯式取景（每个新项目都带上前一个结果） | 按顺序比较 | 排名；测试；方案 |
| 评判画面：完整项目、限值和判定，停留 ≥ 2.5 s | 观众自己也能核对的检验 | 对照阈值的通过 / 失败；对照上限的预算 |
| 长拉镜到整面墙 | 尺度；一切同时呈现 | 论证的终点；一段总结 |

取景：偏离中心、裁切、贴近。第一帧就有一个可读的主体；第一个强动作在 0.5 s 内出现。对照某个限值接受检验的项目各自得到一个评判画面（如果它们越来越大，就一次比一次宽）；判定在摄影机停稳后落下。揭示之前：画面宽度 ≤ 板宽的约 60 %，从不同时露出两侧边缘，从不露出揭示专用的区域。转场就是运镜；没有剪切、淡变或缩放适配全图。



## 8. 原生手法

- **整面墙揭示。** 先把墙当作一张海报来设计（层级、阅读路径、填满画面），再把每个镜头规划为它的一块裁切；留出一个区域（次要信息层、结论、标题卡）只在揭示时出现。*适合：* 一份产品路线图；一份家庭预算。
- **主体穿过答案。** 真实的事物穿过被选中的方案，声音先到。*适合：* 一个包裹沿选定的路线走；一列火车驶过新高架桥。
- **沿尺寸线运镜。** 把一个数量按同一比例画成真实的长度；摄影机跟着线头走。*适合：* 四款车的续航里程。
- **投影线。** 虚线把一条边从一个视图引到另一个视图，让两张图共用同一比例。*适合：* 一张步道地图，下方是它的高程剖面。
- **可数的磁铁。** 一个个单位按节奏咔嗒贴上，被规则移除时弹掉。*适合：* 一次投票中的席位。
- **擦成残影。** 被否决的想法被擦掉，但仍隐约可见。*适合：* 今年的计划下面压着去年的计划。
- **印章。** 判定伴着一声闷响和一震落下。*适合：* 通过 / 未通过的测试。
- **实物答案。** 放下一件真实道具作为解决方案。*适合：* 用一根线缆代替五根。
- **引线指向结论。** 一支箭头从决定性的数字指向结论。*适合：* 流程中的瓶颈。
