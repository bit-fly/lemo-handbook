# 蜡笔童书 — 我们的示范片

这只是众多可能中的一个例子。不要照搬它的故事、结构、镜头、道具或时长。

示范片：*The Moon Can't Sleep*（月亮睡不着）（52 s）· `crayon-book.mp4` · 源文件见 [`demo/`](demo/)


## 故事与结构

一页纸上的睡前故事：月亮睡不着；她试着数羊，失败了；亮着灯的窗口里，一个小女孩看见了她，爬上一架一级一级自己画出来的梯子，一笔水彩扫过，揭开了一直用白色蜡笔画在那里的星星。月亮被盖上被子；镜头拉回到桌上的书，翻页到 "The End"。

这部示范片是按照"画和涂色的过程就是情节"这条规则写的，六个原生动作全部用上，最强的那个（蜡笔防染）放在情感高潮：250 颗白蜡星星从第一帧起就在纸上，在歌声中被水彩揭开。

弧线（45–55 s）：空白的纸 → 一个角色被画出来并醒来（3 s 内的开场钩子）→ 一个小小的滑稽难题（数羊失败）→ 第二个角色（小女孩）→ 一个小小的勇敢举动（梯子）→ 歌声中的水彩揭晓（高潮，无旁白）→ 大家都睡了 → 拉回到书，翻页。

旧版指南是如何把原生动作对应到这个故事上的：

| 原生动作 | 示范片的用法 |
|---|---|
| **蜡笔防染** | 从第一帧起就把回报（星星）藏在眼皮底下；高潮时一笔水彩把它揭开。 |
| **现场画出** | 以一张空白的纸开场；梯子在小女孩手下一级级长出来。 |
| **涂色就是动作** | 拉上被子 = 在月亮身上涂出一床被子；夜幕降临 = 水彩。 |
| **线条抖动** | 故事入睡时，抖动平静到一半幅度。 |
| **孩子的逻辑** | 月亮上有一张脸；数羊时数字写在天空里。 |
| **这是一本书** | 结尾拉回到桌上的实体书，旁边放着蜡笔，翻到 "The End"。一页纸上的一镜到底，由这个揭晓得到解释。 |

旧版指南中的改编示例（一件用轮廓画出的产品，水彩揭开隐藏功能；一页历史逐个事件涂上颜色；一部用白色蜡笔写着名字的致谢片）现在是 STYLE.md §8 中的"适合的内容"条目。

## 镜头

一页纸上一个连续的镜头（世界 3200×1800；整页 = 缩放 0.6）。

| 节拍 | 机位 |
|---|---|
| 开场 | 固定整页，平视：观众在任何东西被画出来之前先看到纸 |
| 标题离场 | 推镜到月亮上，而不是让标题淡出（蜡笔没法淡出） |
| 滑稽节拍 | 固定中近景；替换姿势负责搞笑（辗转反侧 = 一张皱起的脸旋转 35°，踩在拍子上） |
| 发现 | 沿着月亮的视线俯仰（镜头*就是*往下看的月亮） |
| 双人镜头 | 月亮从画框边缘探进来，小女孩小小地站在亮着灯的窗口里 |
| 勇敢举动 | 紧跟着的俯仰；梯子就在她前方自己画出来；攀爬时每一级交替两张关键画面 |
| 水彩揭晓 | **保持全景。**画笔和音乐负责运动。小小的人物，巨大的天空 |
| 收束 | 缓慢推镜到正在入睡的月亮，然后俯仰到小女孩 |
| 结尾 | 一直拉出，直到这页纸变成桌上的一本书；翻页；滑到 "The End" |

为什么这个故事走这条路线：睡前故事需要一页不被打断的纸；固定的空白页让纸先于画出现；揭晓时保持全景，让材质本身成为运动；拉镜解释了一镜到底。每一项都是从 STYLE.md §6 中做出的一个选择，而不是这种风格的默认做法。

月亮身上用到的入睡语法：眼皮以黄色涂鸦的方式垂下，画上一顶睡帽，被子从下往上涂出来，折边先出现，一只小手把它掖好。

## 配乐结构

音乐优先，**3/4 拍，72 BPM**（一小节 = 2.5 s）。八音盒（主旋律），玩具钢琴（滑稽圆舞曲，每只羊 / 每级梯子一个音），长笛作为歌唱声部，单簧管负责低音和幽默感，水彩揭开的每颗星星配一声钟琴（由 `glint` 事件驱动）。没有弦乐，没有三角钢琴。摇篮曲主题完整出现恰好一次，在水彩段；开场的八音盒动机是它的第一个乐句。结尾是八音盒**发条走完**（渐慢 + 音高轻微下垂）。

静默：数羊失败后整整一拍静默；歌声前 0.3 s 的一口气。

本片特有的拟音：羊落地 = 毛毡噗声；辗转反侧 = 毯子的嗖嗖声；翻页 = 掀起 / 呼的一声 / 拍落。夜晚 = 非常微弱的蟋蟀声；书桌 = 温暖的房间底噪和远处的钟声。

混音：旁白下音乐 −7 dB，无词的歌声段 +4 dB；八音盒和钟琴分轨 +3 dB，并在 3–7 kHz 做轻微提升。

人声：Kokoro `af_heart`，语速 0.86–0.90（v3 重新配音：`bf_emma` 读得太亮、太硬），6–8 句短句。处理链：高通 75 Hz → **先压缩**（thr 0.2，2.5:1，8 ms / 140 ms）→ 低架 +1.5 dB @220 Hz，−2 dB 凹陷 @3.2 kHz，**高架 −4 dB @6 kHz** → 分频段齿音消除（4.8–10 kHz，4:1）→ 逐句 RMS 匹配 → 温暖的近场混响（12 ms 预延迟、早期反射、0.7 s 低通尾音，湿声约 −17 dB）。人声下音乐压低约 7 dB、拟音约 4 dB；人声比铺底高约 7–10 dB。避免使用 "Goodnight, Moon" 这句名著用语（改用 "Night, night."）。

## 色板与道具

- 纸 `#f4efe3`；纸纹八度 1.35 / 2.9 / 6.3 px 加纤维项（x/10, y/1.9），对比度 `smoothstep(.16,.86)`；压印强度约 0.55。
- 蜡附着阈值 `tooth > 1 − 1.22·pressure`（软边 ±0.07）；加深 ×(1−0.1·p²)。
- 轮廓抖动约 1.7 px；角色轮廓宽约 7 px，建筑 8 px，精细物件 4–5 px。排线间距约 10.5 px，宽约 11 px，压力 0.72–1.14×，出界 0–7 px；交叉排线在 40–50 %。
- 抖动：偏移 ±0.8 px，摆动 ±0.9 px；背景线条 ×0.6；角色入睡后 ×0.5。
- **12 支蜡笔**：墨蓝/靛蓝 `#2d3263`（所有轮廓）、黄 `#f5c63c`、橙 `#ec8a3c`、红 `#d4483c`、粉 `#ee8ea4`、肉桃 `#f4c7a4`、棕 `#7a4b31`、赭黄 `#e7b867`、绿 `#62a24c`、天蓝 `#79acd9`、紫 `#6a5aa6`、白 `#fbfaf4`（蜡笔防染）。一种水彩：群青，透射率 `(0.15, 0.19, 0.44)`。水彩防染 `density × (1 − 0.93·smoothstep(.12,.55, waxCoverage))`。
- 小女孩：约 2.6 头身，波浪形刘海，一枚黄色星星发夹呼应星星。月亮：大眼睛、眼皮、眼袋、睡帽、拼布被子。羊。房子（山墙 + 倾斜的侧墙 + 大屋顶），一棵带红点的圆树，梯子，250 颗白蜡星星，3 条水彩带。

## 片尾卡

标题：在纸的一角分两行手写（Gaegu Bold），在涂颜色的同时逐字写出。字幕：Patrick Hand 54 px，靛蓝蜡笔。

片尾卡：书的下一页——"The End"（Gaegu Bold），一个小小的月牙涂鸦，用 Patrick Hand 写的风格名和署名。"LemoLab × Claude Opus 5.5" 署名只属于本库的示范片；用户的影片不带 LemoLab 署名，也不复制这张片尾卡。

## 制作笔记

```
styles/crayon-book/demo/
  gl.js      WebGL2 compositor: paper, wax adhesion, knock-out, watercolour + resist, image pass, final emboss/vignette/lamp
  crayon.js  stroke engine: line (ribbons, taper, streaks, boil), fill (zig-zag hatching, overshoot), text, shapes
  rig.js     parts with occlusion + knock-out, limb tubes, curves
  chars.js   the girl (views × expressions × poses), the sheep, the moon (expressions, nightcap, quilt, crescent face)
  world.js   the page: house, tree, grass, ladder, 250 white-wax stars, 3 wash bands
  film.js    timeline, one-take camera, events, subtitles     end.js  book on a crayon desk, page turn, The End
  sheet.js   model sheets (?test=model&page=girl|moon)        lines.json, mix.py, music/score.py, build.sh
```

1. `node core/render/still.mjs styles/crayon-book/demo 0.5 --q 'test=model&page=girl'` —— 先做角色设定图；在做任何镜头之前先把角色迭代好。
2. `core/tts/tts.py lines.json voices` → `asr_check.py`，直到全部 OK。
3. 在 `film.js` 中搭建时间线；用 `still.mjs --range 0.5:51.5:1` + `sheet.py` 检查（至少两轮）。
4. `node core/render/events.mjs` → `music/score.py`（提示点落在 72 BPM 网格上，钟琴来自 `glint` 事件）→ `mix.py`。
5. `node core/render/video.mjs styles/crayon-book/demo --fps 24 --workers 3`（1248 帧，在 M 系列 Mac 上约 80 s）。
6. `CRF=26 sh demo/tools/mux.sh out/video24.mp4 mix.wav crayon-book.mp4 24 0` —— 不加颗粒（纸就是颗粒）；本地的 mux 副本开放了 CRF 参数。`demo/build.sh` 运行从 TTS 到成片的整条流程。

文件大小：固定在屏幕上的纸纹让影片达到 190 MB；把纸纹锚定到纸面、背景填色不抖动、不加额外颗粒、CRF 26 → 74 MB，看不出画质损失。

与本示范片道具相关的坑：

- **水彩带之间的白缝**，以及停在地面上方的天空：最后一条水彩带必须一直延伸到草地线；有纸的地方就有天空。
- **用轻压力涂色的墙，在水彩下变成了浑浊的蓝色。**
- **写在天空里的标题和数字在水彩之后仍然留着**（数羊的数字）：标题被放到了全景镜头看不到的角落。
- **画在小女孩头发上的轮廓线看起来像发箍。**
- **画成一块扁平紫色半圆的毯子，看起来像月亮的暗面。**它需要被子的特征：拼布方块、缝线、星星贴布、浅色的翻折边、垂过圆盘边缘的下摆，以及一只把它拉上来的手。
- **转到书本时出现双重暗角/压印**：书桌的暗角、压印和台灯光从 0 渐入。
- **女主角消失在夜色里**，因为水彩渗进了她涂色的空隙；她在水彩之后再合成。
