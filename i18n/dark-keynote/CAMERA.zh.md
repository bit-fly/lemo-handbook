## 5. 动态质量

- 24 fps 逐帧动画（on ones），没有跳帧，没有线条抖动：这是精密，不是手作感。
- **一切都落在网格上、落在节拍上。**动作提前一拍开始，正好落在拍点上。缓动是快出加一次小过冲（`back`，s ≈ 1.3），然后立即落定。没有飘忽的正弦漂移。
- **生成动作短促且按类型区分**（下落 + 回弹、甩入、滑入、弹出；0.2–0.3 s），每种元素类型一种动作。紧张感可以用几个像素的颤动表现。
- **飞行**沿弧线进行，沿最终切线过冲；同类元素朝同一方向弯，永不交叉。
- **活的元素可以表演**：挤压、拉伸、预备动作（≥ 8 帧的蓄力）、2 帧的接触、弹性跟随动作。光标的闪烁天然就是节拍器。
- **消失是设计出来的**（每拍收回一个部分，像 CRT 关机那样压扁成一个点）；没有东西是简单淡出的。
- 舞台和网格从不自己移动；只有镜头带动它们。



## 6. 镜头语法

这是一套词汇，而不是固定路线。开场和结尾由题材决定。

| 运镜 | 表达 | 可用于 |
|---|---|---|
| 固定机位，大特写一个微小的 UI 元素 | 亲密感，屏幕上唯一活着的东西 | 单个动作；一个正在成形的念头；一个安静的状态 |
| 连续拉镜，在对数空间按小节设关键帧 | 堆积，规模从一个点生长出来 | 负载扩散；网络增长；团队加入 |
| 穿过冻结画面推镜 | 时间停止，焦点收窄 | 一个决定；提交前的一瞬；发现一个 bug |
| 一拍之内甩镜拉出 | 同时看到因与果 | 同步完成；部署落到各处 |
| 钻进一个小 UI 元素（对数缩放）+ 匹配剪辑 | 进入细节内部 | 一个重要的计数器；一行日志；一项设置 |
| 从来源处展开的半秒插入镜头 | 过载，多到读不过来 | 通知风暴；报错；选择过载 |
| 近乎固定的画面，物体转动、光扫过 | 呈现，产品作为主角 | 揭晓；新版本；功能名称 |
| 缓慢横移扫过一个 UI 平面 | 视线读出的秩序 | 时间线；流水线 |
| 网格上方的正俯视平面图 | 系统视角、结构 | 架构；权限；工作流图 |
| 回到之前的构图 | 押韵：什么变了 | 前后对比；闭环；回响 |

构图：大量留白，一个视觉焦点，强调色放在焦点上。倾斜构图和晃动只用于表现失序。

**转场 = UI 展开 / 收拢**：每次换镜都是一个界面元素展开铺满画面，或画面收拢进一个元素。没有淡入淡出，没有空白帧。落在拍点上的展开要提前一帧开始，让拍点那一帧已经展开约 80 %。



## 8. 原生动作

这是一份菜单：只用你的故事需要的。

- **生成式堆积。**按规则生成 UI，越来越快，多达数百个；混乱不是画出来的，而是生成出来的。*适合的内容：*越积越多的未读工单；悄悄上涨的云成本；爆炸式膨胀的依赖树。
- **吸附网格。**一个动作说完整个承诺：所有东西在一拍之内飞进网格；在那之前网格一直不可见。*适合的内容：*CMS 一键发布到所有渠道；排程器填满一周；审计全部变绿。
- **活的元素。**光标（或产品中最小的活元素）是主角，也是品牌标志。*适合的内容：*一个越来越有野心的搜索框；一个不肯走完的进度环；一个状态圆点。
- **冻结。**一切停在半空，声音降到数字零电平；只有屏幕能这样让时间停止。*适合的内容：*拦截到的安全入侵；失败的部署；按下"发送"前的一秒。
- **光照揭晓。**一道柔和光带扫过，只有被照亮的像素才亮起（柔和前沿，高光 ≤ 20 %，≤ 约 1.3 s，不让任何东西一直暗着）。*适合的内容：*一次改版；新的定价页；一个 API 控制台。
- **数字从字符噪点中滚出。**数字乱码滚动，每个十六分音符锁定一位，带一个小回弹。*适合的内容：*降低的延迟；用户数；价格。
- **类型流。**元素沿彩色弧形光迹飞到各自的行，让类别读成一道道流。*适合的内容：*分拣过的收件箱；按严重级别分流的日志；按设备同步的文件。
- **收起。**UI 每拍拆掉一部分，直到只剩一个元素。*适合的内容：*"少即是多"的功能；离职交接；专注模式。
