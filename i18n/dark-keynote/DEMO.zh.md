# 暗色科技发布会 — 我们的示范片

这只是众多可能中的一个例子。不要照搬它的故事、结构、镜头、道具或时长。

示范片：*Room to Think*（42 s）· `dark-keynote.mp4` · 源文件见 [`demo/`](demo/) · 为 **Tidy** 制作的发布片，Tidy 是一款虚构的 app，一键整理你的桌面、照片和收件箱。


## 故事与结构

我们给自己定的任务：为一款软件产品做一支 30–45 秒的发布片（题材 → 故事、镜头、声音、音乐、字幕 → 成片）。

原生能力在这个故事里是怎么用的：

| 原生能力 | 在示范片中的故事用法 |
|---|---|
| **UI 可以无限生成** | 把问题表现为堆积：通知、文件、标签页和照片越生越快，多达数百个（264 个元素）。 |
| **吸附网格** | 把整个产品承诺浓缩成一个动作：所有东西在一拍之内飞进网格。在那一刻之前，网格一直不可见。 |
| **光标是屏幕上唯一活着的东西** | 光标是主角。它踩着节拍闪烁，被打扰推搡，犹豫、蓄力、按下。它同时也是 Tidy 的品牌标志，所以揭晓时收获双重回报。 |
| **屏幕可以暂停** | 一切在半空中冻结，声音切到数字静音。 |
| **暗色舞台 + 柔光** | 产品由一道扫过的光带揭开。 |
| **数字从字符噪点中滚出** | 唯一的数据（"0.8"）独占一屏，逐位乱码滚动到位，每个十六分音符锁定一位。 |

**弧线：**平静的开场钩子（光标在静默中打出标题）→ 打扰（3 s 处第一条通知）→ 在一个连续拉镜中不断堆积（每小节加一层）→ 过载插入镜头 → **冻结 + 静音** → **那一个动作**（所有层重新对齐成一个和弦）→ 光照揭晓产品 → 大数字 → 一口气的停顿，UI 自行收起，音乐逐层减去 → 回响（光标写完它开头那句话）。

**核心导演思路——声音和画面共享一条时间线。**每个 UI 元素都*在配乐的某个音符上*生成。两支马林巴演奏同一个 12 音型；第二支慢慢加速，逐渐错相。文件和照片出现在对齐网格的声部上，通知出现在漂移的声部上，所以视觉上的混乱*就是*听得见的错相。按下的那一刻，两个声部重新对齐成一个和弦。我们先写了音符表（`timeline.js`），再让画面去读取它。

我们为这个题材遵循的配方：挑出产品做的那一个动词（这里是：整理）。把它的缺席表现为与错相配乐绑定的生成式 UI 噪声。把动作交给光标。用光揭晓。一个数字。把一切收起。以空屏上最小的那个东西结尾。这只是一条路线，不是这种风格的固定形态。

## 镜头

| 节拍 | 机位 |
|---|---|
| 开场钩子 | 固定机位，光标和一行文字的大特写（文字约 150 px）。几乎察觉不到的推镜（×1.04）。 |
| 堆积 | 4 小节内从 ×5 到 ×1 的**一个连续拉镜**，在对数空间按小节设关键帧，单调插值（每小节一个"档位"，速度连续）。前景卡片模糊地掠过镜头。从 10.5 s 起，逐渐加入 1–2° 的倾斜构图和手持晃动。 |
| 过载 | 三个半秒的**插入镜头**，各自从来源位置展开（UI 展开转场）：999+ 角标 / 148 个窄标签页 / 红色存储条。 |
| 冻结 | 无声地穿过冻结的混乱推镜到光标上（×0.8 → ×2.6，ease-in-out）。 |
| 按下 | 一拍之内**甩镜拉出**（×2.6 → ×0.78，cubic ease-out），让观众同时看到按下点和整个网格落定。 |
| 揭晓 | 窗口在 4.5 s 内从 3/4 角度转正（−24° → 0°），同时光扫过。镜头几乎不动：只有光和产品在动。 |
| 数字 | 钻进状态栏计数器（对数缩放到 ×16），然后匹配剪辑到全屏数字。再以同样方式退出。 |
| 停顿 | 缓慢推镜（×1.08），同时 UI 自行收起。 |
| 回响 | 与第一个镜头完全相同的构图。光标停在同一个像素上。 |

每次换镜都是一次 UI 展开 / 收拢；没有淡入淡出，没有空白帧。

### 示范片中使用的动态数值

- **生成动作**（混乱段落）：文件下落 34 px，回弹 6 px（0.22 s）；照片从画外带旋转甩入（0.3 s）；通知从右侧滑入 90 px（0.24 s）；窗口从 0.94 弹到 1.0（0.22 s）。冻结前最后一秒，一切以 ±2.4 px 颤动。
- **收拢（本示范片的招牌动作）**：一个圆环以 2600 px/s 的速度从光标向外扩张。圆环前沿经过时，每个元素沿弧线飞向**自己类型的那一行**（文件 → 桌面行，照片 → 照片行，通知 → 收件箱行）；同一类型的弧线朝同一方向弯，因此屏幕上出现**三道彩色的流**。在一组之内，按元素的 y 顺序和 x 顺序填充各行，所以路径不会交叉。飞行时长按距离为 0.26–0.40 s，在前三分之一变形为统一的方块，沿最终切线过冲后落定。光迹为流的颜色，9 段，叠加混合。网格槽位轮廓在圆环前沿稍后亮起强调色。
- **光标表演**：闪烁 = 亮 0.5 s / 灭 0.5 s（它就是节拍器）。被打扰：推开 8 px + 压扁 10 %，0.25 s 衰减晃动，然后保持常亮（"僵住"）。蓄力：高度 ×1.35、宽度 ×0.8，12 帧 ease-in（≥ 8）。按下：2 帧，高度 ×0.3、宽度 ×2.4。跟随动作：0.6 s 内带过冲回弹。
- **光照揭晓**：亮区落后于光带前沿 700 px，一道 360 px 的柔和高光以 20 % 骑在前沿上，未照亮区域保持 7 %。耗时 1.3 s。
- **数字乱码**：字符以 24 fps 循环，带 3 份垂直拖影；数字在十六分音符上从右到左锁定，每一位落下时带一个小的阻尼回弹。
- **收起**：每拍收回一个元素（侧边栏、状态栏、标题栏、表头），然后窗口边缘亮起强调色，接着窗口像 CRT 关机一样纵向压扁（ease-in，0.22 s），缩进光标里。

## 配乐结构

- **音乐优先**：`timeline.js` 保存节拍网格（**120 BPM**）、12 音型以及所有声部的音符表（错相在这里以时间扭曲计算）。画面从同样的表中生成元素。`tools/cuecheck.py` 检查关键提示点，以及每个生成的元素是否都落在一个配乐音符上。
- **配乐（原创，极简主义）**：马林巴（声部 1，对齐网格）+ 硬槌颤音琴（声部 2，先齐奏，再领先错相；高潮处略微失谐、更亮）+ 钟琴（声部 3，向相反方向漂移）+ numpy 合成的铺底音色（A 持续音，逐渐加入 G#/D# 不协和并升高）+ 低音正弦脉冲（八分音符 → 十六分音符）+ 安静的噪声沙锤。按下时，所有声部落在**一个 A 大九和弦**上，弓奏颤音琴把它带进揭晓段（L 剪切），随后奏一遍干净的音型；在停顿段，音型逐小节减音，直到只剩一个四分音符。采样：VCSL（CC0）。
- **声音家族**：混乱的声音是分散的（每条通知音高偏离 ±45 音分，随机声像，每个来源不同音色）。Tidy 的声音是同一家族：毛毡滴答声和玻璃轻敲声，全部在 A 大调五声音阶上，居中。264 次落定轻敲构成一片合调的闪烁音。
- **声音层**：环境声（安静的房间 + 电脑风扇和 6.8 kHz 的电感啸叫，在混乱段落中逐渐增强，**压到最后一句旁白结束后才放出**）；拟音（光标滴答、矮键程键盘、回车、通知玻璃音、文件落下的噗声、照片弹出、窗口呼啸、故障点缀、存储嗡鸣、堆叠闷响、按下的"咚"= 毛毡槌 + 55→40 Hz 正弦下滑、网格滴答、毛毡滴答、扫光闪烁音、数字颗粒声、CRT 关机声）；音乐。
- **静音**：15.0–16.0 s 是**所有轨道上的数字零电平**（屏幕暂停）；之后的第一个声音是按下。33.0–34.0 s 接近静音（−60 dB 房间声）；之后的第一个声音是光标滴答，与第 1 帧的声音相同。
- **J / L 剪切**：在拉镜之前的特写下，一片闷住的通知声渐入（J）；按下的和弦一直响进揭晓段（L）；光的闪烁音比光早 0.4 s 开始（J）；数字的和弦一直响进停顿段（L）。
- **人声**：Kokoro `af_kore`，语速 0.95，自信而克制：简短的陈述句。人声下音乐压低 −8 dB、拟音压低 −4 dB。

## 色板与道具

**舞台**：底色 `#0A0B0F`，上方中央径向提亮到 `#151822`，右上角一团 8 % 的大面积冷色辉光 `#3B4CCA`，四角暗角 50–55 %。发丝细网格 `rgba(255,255,255,.032)`，每 48 px 一条，每第 4 条为 `.06`。颗粒：无（`mux.sh` grain 0）。

| 角色 | 数值 |
|---|---|
| 窗口表面 / 凸起 / 凸起-2 | `#12151C` / `#1A1E28` / `#222734` |
| 边框 / 内部顶部高光 | `rgba(255,255,255,.08)` / `rgba(255,255,255,.07)`（1 px） |
| 文字 / 次要 / 标签 | `#E8EAF0` / `#8A90A0` / `#5C6272` |
| **品牌强调色（唯一的颜色）** | 青柠绿 `#B7F34A`，辉光 `rgba(183,243,74,.35)` —— 光标、"Tidy up" 胶囊按钮、勾选标记、"0.8" |
| 噪声红（仅限问题段落） | `#FF5A5F` 角标。按下之后，红色再也不会出现 |
| 三种流的颜色（收拢光迹） | 文件 `#C9D3E6`，照片 `#F2A65A`，通知 `#7E95FF` |

**道具**：Tidy 品牌标志（圆角方形 + 光标）和文字标；窗口（圆角 14，40 px 标题栏）；带 "now" 的通知卡片；带等宽文件名的折角文件图标（`final_FINAL_2.pdf`、`Untitled 38.txt`）；程序生成的风景照片缩略图；带未读圆点的收件箱行；不断分裂的标签栏（148 个标签页）；999+ 角标；红色存储条；统一的吸附方块（60–64 px，圆角 20 %）。产品镜头最多旋转 24°。

**字幕的实际用法**：提示气泡为 `rgba(12,14,19,.72)` 胶囊（混乱段落中为 `.88`），1 px `rgba(255,255,255,.09)` 边框，Inter 500 40 px `#E8EAF0`，8 px 强调色圆点，0.16 s 内上浮 12 px 并淡入。标题和最后一句由画面中的光标打出（只出现在 .srt 中）。字幕出现时，产品窗口上移 25 px。

## 片尾卡

**片头卡** = 光标在特写中打出片名，上方有一行小号等宽字 `TIDY · A LAUNCH FILM`。**片尾卡** = 打出的口号，下方左对齐：片名、"a launch film for Tidy, a fictional app"、风格名、`Lemo-Opuscar`、`LemoLab × Claude Opus 5.5`、演职员信息。然后除光标外一切淡出，光标闪烁两次后熄灭。

"LemoLab × Claude Opus 5.5" 署名只属于本库的示范片；用户的影片不带 LemoLab 署名，也不复制这张片尾卡。

## 版权

Tidy 是虚构的。每个界面元素都是原创并用代码绘制；没有使用任何真实的操作系统界面、app 布局、字体、标志，也没有使用参考影片中的旋律。采样：VCSL（CC0）；字体 OFL（见 `demo/CREDITS`）。

## 制作笔记

```
styles/dark-keynote/demo/
  engine.js     the style engine (see Engine reference)   timeline.js  tempo grid + pattern + phasing note tables + key times
  world.js      the mess: 264 elements generated from the note tables, spawn poses, freeze, type-row snap targets
  film.js       scenes: mess / inserts / collapse / product reveal / number / breath / echo, captions, event list
  frames.js     engine demo scene          main.js / index.html   page (window.render(t), window.EV)
  music/score.py   original score (sub-agent), stems, score.json      mix.py   foley + voices + ducking + silences
  tools/        dump_timeline.mjs export.mjs cuecheck.py
```
1. 写 `timeline.js`（网格、音型、声部、关键时间点）→ `node tools/dump_timeline.mjs` → 把 `timeline.json` + 提示点表交给配乐子代理。同时并行绘制画面。
2. 先构建引擎和产品窗口（它们就是风格样帧），再根据音符表写混乱生成器，最后做收拢。
3. `sh demo/build.sh` 重建一切：TTS → whisper → 配乐 → 事件 → 提示点检查 → 混音 → srt → 渲染 → 合成（−14 LUFS，颗粒 0）。
4. 用 `node core/render/still.mjs demo --range 0.5:42:1` + `sheet.py` 至少检查两遍，另外检查收拢和按下的帧条。

与本示范片道具相关的坑：
- 让 264 个元素吸附到最近的槽位，看起来像闪烁；改成让每种类型沿带光迹的弧线飞到自己的行（桌面 / 照片 / 收件箱）后解决。
- 第一版生成器在网格里留了空洞；我们把每组裁剪或补齐到正好等于其槽位数。
- "窗口关闭"最初用的是一个平涂着色的矩形；现在是真实窗口被压扁，只在最后 45 % 着色。
- 风扇和电感啸叫（300 Hz–7 kHz）盖住了人声；它们被压低，直到该段落最后一句结束。
- 字幕气泡裁到了产品窗口底部；字幕出现时产品上移 25 px。

## 引擎参考

`demo/engine.js` 是一个普通的 ES 模块（Canvas 2D，除 `core/lib.js` 外无依赖）。所有绘制函数的第一个参数都是 context。坐标是当前生效变换下的像素。

| 函数 | 作用 |
|---|---|
| `setAccent(hex)` | 设置唯一的品牌色（默认 `#B7F34A`）。所有由强调色驱动的东西都会跟随：光标、提示气泡圆点、`litShape({accent:true})`、`trail`。 |
| `bg(g, {lift, cool, dark})` | 带径向提亮和冷色辉光的近黑舞台。 |
| `grid(g, {ox, oy, scale, module, alpha, rect})` | 可以跟随镜头的发丝细网格。 |
| `glow(g, x, y, r, color, a)` · `vignette(g, a)` | 柔和光池、四角衰减。 |
| `panel(g, x, y, w, h, {r, fill, shadow, cheap})` | 圆角 UI 表面：柔和阴影、顶光填充、1 px 边框、内部高光。`cheap` = 偏移阴影，用于数百个元素。 |
| `litShape(g, path2d, {accent, color, glowR, sweep, bbox})` | **以这种风格绘制任何形状**：带轮廓光的暗色受光表面，或（加 `accent`）发光的强调色填充；`sweep` 0..1 加一道移动的光带。 |
| `sparklePath(cx, cy, r, k, rot)` | 四角星路径（用于闪光、"新"标记）。 |
| `trail(g, pts, {color, width, caretH})` | 沿一串点的渐隐光迹，末端可选带光标。 |
| `caret(g, x, y, h, {sx, sy, on, glow, color})` | 带挤压/拉伸和闪烁的光标。 |
| `tidyMark(g, x, y, s)` · `wordmark(g, x, y, px)` | 品牌标志（圆角方形 + 光标）以及文字 + 光标。按你的产品改名。 |
| `windowBox` / `windowContent(kind)` / `notif` / `fileIcon` / `photo` / `badge` / `appIcon` / `storageBar` | UI 套件。`windowContent` 的类型：note、inbox、browser、sheet、chat、viewer、code。 |
| `flyPose(from, to, p)` · `motionBlur(p, span, n, draw)` | 带过冲、弹簧旋转和变形的吸附飞行；多重采样运动模糊。 |
| `lightReveal(g, src, x, y, w, h, p, {base, soft, band, glint, angle})` | 对任意 canvas 做扫光揭晓。 |
| `perspective(g, src, cx, cy, w, h, rotY, {slices})` | 以条带渲染平面 canvas 的 Y 轴旋转；返回到屏幕的 `map(u,v)`。 |
| `scramble(g, text, x, y, t, locks, {px, fam, color, tracking})` | 从字符噪点滚到数字，每个字符有自己的锁定时间。 |
| `toast(g, text, a, {dense})` | 字幕组件。 |
| `camera({x, y, zoom, rot, sx, sy})` | 2.5D 摄像机：`.apply(g, z)` 变换到深度 z；`.proj(x, y, z)` 返回屏幕位置和缩放。 |
| `buf(name, w, h)` · `rr(g, …)` · `font(px, wt, fam)` · `rgba` · `mix` | 辅助函数。 |

**最简示例：以这种风格绘制一个暖橙色四角火花，带光标尾巴。**
```js
import * as E from './engine.js';
const g = document.querySelector('canvas').getContext('2d');
E.setAccent('#D97757');                       // the one colour
E.bg(g); E.grid(g, { ox: 960, oy: 540 });
const pts = []; for (let i = 0; i <= 40; i++) { const u = i / 40; pts.push([360 + u * 1100, 640 - Math.sin(u * Math.PI) * 260]); }
E.trail(g, pts, { width: 8 });                // the cursor's path as a fading light trail
E.litShape(g, E.sparklePath(1480, 380, 90, 0.2), { accent: true, glowR: 40, bbox: [1390, 290, 180, 180] });
E.caret(g, 1560, 380, 120);                   // a cursor riding the spark
const card = new Path2D(); card.roundRect(300, 200, 420, 160, 28);
E.litShape(g, card, { sweep: 0.5, bbox: [300, 200, 420, 160] });   // any shape as a lit dark UI surface
E.vignette(g);
```
用 `?scene=engineDemo` 渲染它（见 `frames.js`）。如果想在一个整体中性的画面里只让一个元素保留颜色，就用默认的 `litShape` 绘制所有东西，只对那个元素使用 `{accent: true}`。
