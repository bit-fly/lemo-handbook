## 5. 运动质感

- **数据的节奏就是影片的节奏。** 把标记映射到音乐网格上；要加速，一种做法是**细分节拍而不是改变速度**。选一个最细分音符能落在整数帧上的速度（24 fps 下一分钟有 1440 帧；每分钟最细音符的个数必须能整除它），这样画面和声音永远不会漂移。
- **铅笔的表演**：每次落笔前先抬起，落下时阴影与笔尖相接，有一个微小的回弹；数据变密时变得急促，到峰值时像地震仪指针一样颤抖。它可以**退缩**（后撤并定住）、**犹豫**（在一个标记上方悬停）和**退场**（把故事交给观众）。
- **重新缩放**要像棘轮咔嗒（分步进行，每步缓动）；平静的重新缩放则是平滑的。
- **变形**：错开的扫过，每个标记缓动到新形态；注记在扫过时淡出，再以细小记号的形式回来。
- **不要淡出到空白，也不要叠化。** 转场都是图表操作：坐标轴生长、拉回、重新缩放、变形、一个格子扩展成下一个画面。



## 6. 镜头语法

一台 2D 摄影机 `{x, y, zoom, roll}`，在**一张纸**上运动。一部片子就是一个长镜头；硬切罕见且有意义。下面的运镜是一套词汇，而不是一条固定路线。开场和结尾由主题决定。

| 运镜 | 表达 | 可用于 |
|---|---|---|
| 对一个标记的极致特写，跟随它的引线 | 一个事实，一个人生 | 单个案例；一个有名有姓的人 |
| 先看全景，再潜入某一个标记 | 先看规律，再看个案 | 一个熟悉的趋势；一个需要纠正的误解 |
| 随坐标轴从标记中长出而拉回 | 框架随单位一起到来 | 说出度量单位；扩大一个论断 |
| 跟随铅笔，最新的标记位于宽度约 60 % 处 | 进程：过去在身后，未来在前方 | 时间序列；比赛；排队 |
| 随数据上升做升降镜头，荷兰角悄然出现 | 升级，不安 | 失控的增长；一笔债务 |
| 2 帧内急推，衰减的震动，重新缩放时的顿挫 | 意外，画框被冲破 | 一个离群值；一次崩盘 |
| 快速拉回，滚转，持续的微小颤动 | 一阵冲刺 | 一波繁荣；连锁反应；恐慌 |
| 固定机位 | 变形本身就是运动 | 一次变形；缓慢的解读 |
| 停留在一个标记上，然后拉回 | 整体中的局部 | 一个结论；背景语境 |
| 拉镜加摇镜，接入更多真实数据 | 尺度切换 | 更长的记录；名单的其余部分 |
| 在记忆区的注记间横向摇镜 | 回忆 | 一段传记；一条事件时间线 |

构图：关键时刻主体占画面高度 ≥ 1/3。当真实坐标轴滚出画面时，把它的刻度标签钉在画面边缘的一条纸带上（冻结窗格）。



## 8. 原生手法

一份菜单：按你的故事需要挑选。

- **一个标记 = 一个事实。** *适合这类内容：* 一家连锁店开的第一家门店；一项试验的第一位患者；发射的第一颗卫星。
- **坐标轴随故事生长。** y 轴在旁白第一次说出单位时出现。*适合这类内容：* 营收；一座城市的人口；疫苗接种率。
- **钉住的注记。** 它们的内容和颜色承载着情节走向。*适合这类内容：* 一位运动员的赛季；一个家庭的迁徙；使用量曲线上的各个版本发布。
- **冲破画框。** 图表必须腾出空间；撕破的边缘作为伤疤留下。*适合这类内容：* 一次爆红的峰值；价格泡沫；破纪录的洪水。
- **编码变形。** 柱状图变成华夫图，地图变成排名，折线变成斜率图：揭示整体。*适合这类内容：* 以人数为单位的预算；国家变成排名；每日步数变成一年的条带。
- **尺度切换。** 一个值 → 一条序列 → 更长的真实记录，绝不外推。*适合这类内容：* 一天的能耗 → 一年；一个物种的数量 → 一个地区。
- **空着的下一格。** 一个虚线空位，留给还没人知道的数值。*适合这类内容：* 明年的选举；下一次发射；明天的读数。
