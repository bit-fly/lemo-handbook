# Desktop Flythrough 桌面穿梭 — 我们的示范片

这只是众多例子之一。不要照搬它的故事、结构、镜头、道具或时长。

示范片：*叮之前 · Before the Ding*（59.95 s）· `desktop-flythrough.mp4` · 源文件在 [`demo/`](demo/)

## 故事与结构

你给朋友发了一张猫的照片，对方手机立刻"叮"了一声，但这张照片并不是直接飞过去的。影片跟着它走：第 1 步，App 把它压小（4.2 MB → 300 KB，示意数字）；第 2 站，它在聊天软件的服务器上等待；第 3 步，服务器发出一条通知；然后朋友的手机去取回照片，网速慢时它先模糊地出现，再变清晰。结尾：除非你勾选了"原图"，否则朋友拿到的是一份压缩副本；原图从未离开你的手机。

一张桌子上的四个站点：你的手机、压缩卡片、服务器塔、朋友的手机（小林，虚构人物），由一条钴蓝色虚线路线串起来。主角就是那张猫照片本身，一个 16×16 的体素玩偶，会眨眼，会踩着节拍等待，会被压扁成 8×8 的副本，并跳完整条路线。开场和结尾的标题都是桌上的物件。每一个说法及其出处都在 [`demo/FACTS.md`](demo/FACTS.md) 中；片中没有点名任何 App 或公司。

## 配乐结构

120 BPM，D 大调，从 0.0 起一小节 = 2 s，每小节一个和弦。旁白之下：弦乐铺底，低音提琴在第 1、3 拍拨奏，一个柔和的合成底鼓，八分音符沙锤，一个取自和弦的两音马林巴音型；有人说话时音乐压低 16 dB，在空隙处回升。马林巴主题（F♯–A B–D'–C♯'）开启全片，并在拉镜和收尾镜头下伴着拍手回归，最终落在一个由圆号和颤音琴持续的 D 和弦上；谢幕时的四次跳跃配四个钢片琴音。重音：猫弹起、徽章出现、响铃和照片变清晰时用钢片琴；压板和收尾时用定音鼓；标题落地时一声闷响加两个铃音。拟音来自页面的事件（音高取自 `music/harmony.json`）；呼啸声来自测得的镜头速度。母带处理前的混音：−16.0 LUFS，真峰值 −3.1 dBFS；`mux.sh` 之后：−14 LUFS，真峰值 −1.2 dBTP。

## 色板与道具

浅色橡木桌上铺着纸垫 #e2e8f5，点阵 #c4cde3；卡片和屏幕接近白色，墨色 #171c2e，强调色钴蓝 #2f5bff（路线、徽章、发送按钮、亮起的窗户、抽屉），铃铛和数据方块用芥末黄，照片保留它自己的橙、蓝、绿，红色只用于弱信号格。字体：IBM Plex Mono（标签、尺寸数字），Instrument Sans（胶囊标签、标题、字幕），Noto Sans SC（中文，也是前两者的后备字体）。角色：猫 16 × 16，每像素 0.0062（宽约 0.10，相当于 0.30 宽手机卡片的三分之一），它的副本 8 × 8，每像素 0.0074（约 0.06）；在收尾全景中宽约 63 和 37 px。布景：两张带完整聊天界面的手机卡片，带压板的压缩卡片，一座带抽屉和天线的四层服务器塔，一个标题立牌，名牌（在全景中），收尾标题卡；道具：一支笔、一本便利贴、一杯咖啡、一副带线耳机、一块橡皮。

## 结尾卡

在收尾全景之上、桌子中央的标题卡下方，从 57.0 s 开始：LemoLab × Claude Opus 5.5 显示在字幕位置的浅色底板上，一直持续到结束，覆盖在持续的最后和弦之上。"LemoLab × Claude Opus 5.5" 的署名只属于本库的示范片；用户的影片不带 LemoLab 署名，也不复制这张卡。

## 制作说明

- `sh styles/desktop-flythrough/demo/build.sh`（中文配音，本库示范片）或 `… build.sh en`（英文配音）：字体（从 Google Fonts 下载并子集化）→ 配音（`core/tts/tts_zh.py`，用 `core/tts/asr_check.py` 检查）→ `audio/vo_timeline.py`（写出 `src/vo.js` 和 `vo/timeline.json`）→ 事件和镜头速度 → `audio/compose.py` → `audio/foley.py` → `audio/mix.py` → `core/render/video.mjs` → `core/render/mux.sh` → `readcheck.mjs` → 海报和风格帧。配音步骤需要联网（edge-tts）。这里 `tools/subset.py` 之所以在配音之前运行，只是因为 `src/vo.js` 已提交；新影片应在 `vo_timeline.py` 之后再做子集化。
- 代码：`index.html` → `src/main.js`（页面契约、限速快门、`TEXTS`）→ `src/film.js`（卡片、塔、道具、角色、按旁白提示的时间线、声音事件、阅读框）和 `src/shots.js`（镜头关键帧）；`src/captions.js`（字幕、署名，`?nosub=1` 用于干净的静帧）。
- 阅读时间：`TEXTS` 报告标题立牌、压缩卡片上的两个尺寸数字、服务器的名字、通知横幅、网慢、两个尺寸标签、收尾标题和署名；字幕条目跟随旁白。
- 这些道具的陷阱：名牌只在全景中显示；徽章停留 3.4 s，并在镜头移走之前离开；猫在照片气泡旁边等待，而不是在字幕条下方；橡皮要远离收尾标题卡。
