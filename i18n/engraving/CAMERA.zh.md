## 5. 运动质感

- **刻画顺序就是动画**：轮廓 → 第一遍排线扫过每个形体 → 交叉排线 → 暗部、绒毛、点刻。笔画以恒定的刻刀速度运行，许多笔同时进行（轮廓只有几笔，排线则有几十笔）。
- 一条长的单笔可以由摄影机跟随；让它开始时已部分刻出，避免出现空帧。一次完整的逐层刻画控制在几秒之内。
- 圆框沿缓动弧线飞行，带一点升起，按对数线性长到目标大小。颜色从一点晕开，前沿参差，湿边随后变干；各区域错开时间。
- 任何东西都不像 UI 那样淡入淡出或滑动：线是刻出来的，文字是刻出来或写出来的，颜色是晕开的，纸张是压印、揭起或铺下的。



## 6. 镜头语法

摄影机是**悬在纸面上方的放大镜**。这是一套词汇，不是一条路线。开场和结尾由题材决定。

| 运镜 | 表达 | 可用于 |
|---|---|---|
| 放大镜跟随刻刀尖 | 唯一的注意点；正在制作 | 第一笔；一个签名 |
| 对数缩放拉镜 | 这条线是某个更大事物的一部分 | 尺度揭示；交代背景 |
| 推镜到某个部位，随其圆框移动 | 在哪里 → 是什么，一镜完成 | 肉眼看不见的细节；一个机构 |
| 以阅读缩放沿纸面俯仰/摇镜 | 按顺序读标签 | 零件清单；一段海岸线 |
| 在某物飞行时拉回 | 所有元素就位并建立关联 | 加速；总结 |
| 固定画面，或 ≤ 2 % 的呼吸式推镜 | 图版作为文献 | 阅读时间；颜色在动 |
| 斜掠铜版的视角 | 刻槽即深度 | 手艺的代价 |
| 从镜像的铜版剪切到正向的样张 | 反转 | 隐藏的真相；前后对比 |

构图：主体在版痕之内，标签和圆框放在页边；安排细节的顺序，让推镜永远不会过早裁掉某条注释。转场只用版画中的方式（拓印出样张、覆上拷贝纸护页、某区域被刮光后重刻、新纸放上印床）；不用叠化或划变。



## 8. 原生动作

一份菜单：按故事需要选用。

- **刻刀。** 刻刀正在运刀，铜屑升起，别无他物。*适合：*一份条约的第一行；钟表匠的划线；一条正在被测绘的海岸。
- **三遍刻画。** 形体一遍一遍获得体积。*适合：*从平面图长出的建筑；逐渐浮现的肖像；一项不断进步的技能。
- **放大圆框。** 刻出圆环、刮光、放大重刻，带着引线飞到页边，落定时刻出标签。*适合：*钟表里的一个齿轮；一粒花粉；海图上的港口插图。
- **样张。** 纸张揭起；镜像的铜版变成正向的纸面。*适合：*秘密揭晓；草稿定稿；硬币的模具与压印。
- **图版的状态。** 某个区域被刮光后重刻。*适合：*重划的边界；前后对比；设计修订。
- **手工上色。** 印刷之后颜色晕开。*适合：*点亮一个器官；历史地图上的一面旗帜；一颗正在成熟的果实。
- **实际大小。** 雕版旁边一个按真实比例绘制的小图形。*适合：*种子与它的树；芯片与它的电路；邮票与它的放大图。
- **完成的图版。** 所有标签和署名，定格。*适合：*博物馆展品说明牌；卷首插图；一张证书。
