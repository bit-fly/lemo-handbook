# 铜版雕刻 — 我们的演示片

这只是众多可能中的一个示例。请勿照搬它的故事、结构、镜头、道具或时间安排。

演示片：*The Honeybee, Plate VII*（蜜蜂，第七图版）（40.0 s）· `engraving.mp4` · 源文件见 [`demo/`](demo/) · 所有文字来自 [`demo/content.json`](demo/content.json)


## 故事与结构

这是一段场景演示，而不是一个故事：一块放在展柜旁屏幕上的**博物馆展品说明牌**。一件展品（蜜蜂）、它的名字、三件你不知道的事，以及去哪里看真品（"see the living hive in Gallery 4"，到 4 号展厅看活体蜂巢）。

结构（40 s）：铜版大特写 → 拓印出样张 → 拉镜到整块图版 → 三处放大细节（复眼、翅钩、花粉篮），各自飞到指定位置 → 静默 → 手工上色 → 定格的最终图版 → 拷贝纸护页片尾卡。

在这部演示片中，原生动作是如何服务于信息的：

- *刻刀本身*就是钩子：第一帧是刻刀正在铜版上运刀，铜屑卷曲着从刀尖前方升起。画面上别无他物，所以视线只有一个去处。
- *逐层刻画*（轮廓 → 第一遍排线 → 交叉排线 → 暗部与绒毛）是"这是一件严肃的、手工制成的东西"的节拍，控制在 5 s 以内，并压在标题之下。
- *放大圆框*是信息的载体：先在部位周围刻出一个圆环，圆内被刮光，再以放大比例重新雕刻，然后圆框拖着引线飞到它的位置。观众一个动作就同时看到细节*在哪里*、*长什么样*。它的标签（罗马大写字母、斜体术语、手写体注释）在落定时刻出。
- *手工上色*是高潮，安排在一段真正的静默之后、所有信息都已上版之后，因此它读起来是奖赏，而不是新信息。
- *最终图版*就是海报：所有标签、行动号召和雕版师署名一次呈现，定格不动。

为这部演示片最初写下的用途表，以及我们为每种用途设想的镜头结构（是示例，不是配方）：

| 用途 | 镜头结构 |
|---|---|
| 博物馆展品说明牌（本演示片） | 铜版大特写 → 拓印出样张 → 拉镜到整块图版 → 1–4 处放大细节，各自飞到指定位置 → 静默 → 手工上色 → 定格的最终图版 |
| "一分钟了解……" | 同上，由旁白承载注释；以图版作为缩略图收尾 |
| 教科书插图 | 不用铜版开场；以 1× 从纸面开始，刻出图形，然后用引线逐一标注各部分；不上色，或只给正在讲解的部分上色 |
| 手工艺传承（一块表、一把小提琴、一把刀） | 刻刀沿物件轮廓运刀的大特写 → 逐层刻画 → 圆框聚焦机构 → 只给关键材质上色（金、清漆） |
| 地图或场地平面图 | 刻出海岸线或平面图，圆框变成插图（一座建筑、一处港口） |

## 镜头

摄影机是一只悬在图版上方的放大镜。演示片中逐个节拍如下：

| 节拍 | 摄影机 | 原因 |
|---|---|---|
| 钩子（0–2.5 s） | 铜版上 4.2×，**跟随**刻刀尖，3° 滚转 | 只有一个注意点；刻刀本身就是钩子 |
| 拓印出样张（2.5–3.2） | 固定不动，纸张横向揭起 | 这一媒介自身的转场 |
| 逐层刻画（3.2–6.2） | **拉镜** 4× → 1×，对数缩放，带屏幕线性的移动镜头手感 | 尺度揭示：那条曲线原来是蜜蜂的腹部 |
| 细节 1（9.4–15.0） | **推镜**到复眼 4.3×；圆框升起并飞向其位置时**随之移动**，缓出到 1.45× 的阅读画面 | 标志性的一镜到底：在哪里 → 是什么 → 标签 |
| 细节 2（15.0–19.4） | 以 1.45× 从左上**向下俯仰**到左下，让细节 1 的注释留在画内 | 更快，语法相同 |
| 细节 3（19.4–23.75） | 圆框飞行时**拉回**到整块图版，然后**推镜**阅读（在细节 2 的注释获得足够时间之后） | 加速；尊重阅读时间 |
| 汇集、静默、上色 | 整块图版；上色期间 2 % 的呼吸式推镜 | 动的是颜色，而不是摄影机 |
| 最终图版 | 定格不动 | 海报 |

本演示片的运动时间：第一条线是摄影机跟随的一笔，长 5.4 s，所以在第 0 帧时它已经刻出三分之一；同时运行 6–90 笔；圆框在飞行中途升起 30 px，并长大到半径 120；每个颜色区域在 1.25–1.6 s 内晕开，相邻区域间隔 0.42 s 开始。

## 配乐结构

三层：环境底噪（安静的工作室，铜版上方有隐约的钟声；之后换成纸张房间）、与画面事件对齐的拟音，以及一首巴洛克室内乐配乐。

- **配乐**：羽管键琴 + 弦乐四重奏，96 BPM，D 大调。`music/score.py` 读取 `events.json`：每个细节段落（A 长段 / B 俯仰 / C 拉回）只写一次，放到影片安排它的位置；尾声随细节结束的时间移动，所以任何数量的细节都能得到相匹配的配乐。旁白之下，旋律提高一个八度，避开人声频段。雕刻段落**全部是拨弦**（刻刀细小精准的切削），密度一遍比一遍增加；每个圆框 = 刻环时一声高音"叮"、飞行时一条上行线、落定时一声低音拨弦。上色之前：一段急停的快速音阶，然后是**真正的静默**（1.25 s）。上色是弦乐第一次用弓拉奏。最终图版落在 V–I 终止式上。
- **静默**：2.0–2.5 s（刻刀抬起，在印刷机的重击和强拍之前）以及 25.0–26.25 s（在第一滴水落下之前）。
- **实际制作的拟音**：刻刀 = 带通嘶声（2.6–9 kHz），加上颤动的咔嗒声和微弱的铜版共鸣（1.18/2.31/3.47 kHz）；铜屑 = 细小的 5–9 kHz 叮声；抬刀 = 金属嗒声；印刷机 = 低沉的滚筒隆隆声（提前 0.35 s 的 J-cut）和一声重击；揭纸 = 密集的纸张噼啪声；排线 = 颗粒状微刮擦声，密度随每一遍增加；刻环 = 圆形划刻声；刮光 = 轻柔的摩擦声；圆框飞行 = 纸张呼啸声；落定 = 纸张轻拍声；字母 = 点状嗒声；注释 = 约 4 Hz 笔画的笔尖刮纸声；上色 = 一声下落的水滴"噗"，然后每个区域一下湿笔刷扫过声；片尾卡 = 拷贝纸窸窣声（J-cut）。
- **旁白**：Kokoro `bm_fable`（en-gb），语速 0.92，一位温和的博物学家；他说话时音乐压低到约 50 %（弓拉弦乐压得最少）。

### 配乐曲式，逐小节

原创，用代码写成（`music/score.py`，确定性的：重新构建得到字节完全一致的 `score.wav`）；不使用任何现有或公有领域的曲调。D 大调，96 BPM，4/4 拍（一拍 0.625 s，一小节 2.5 s，16 小节 = 40.0 s）。编制：羽管键琴（通奏低音与独奏音型）和弦乐四重奏（独奏第一小提琴、第二小提琴合奏、中提琴、大提琴、低音提琴）；弦乐在 25.0 s 之前演奏拨弦，从 26.25 s 起才用弓。在仓库根目录用 `.venv/bin/python styles/engraving/demo/music/score.py` 重新构建（约 5 s；写出 `score.wav`、`stems/`、`cues.json`、`CREDITS_music.txt`）。响度 −18.0 LUFS 整合（BS.1770），峰值 −1.2 dBFS，48 kHz 立体声 24-bit。分轨 `harpsichord.wav`、`pizz.wav`、`bowed.wav`（各 40.0 s，增益与混音相同，所以在限幅器之前相加即为混音，有两处击打约有 1 dB 的峰值限幅）。

曲式是三重奏鸣曲织体：先是雕刻的语法，然后是色彩。时间对应演示片的三个细节。

| 小节 / 时间 | 和声 | 发生了什么 |
|---|---|---|
| 1（0–2.5） | — | 静默，留给刻刀拟音。**1.875 / 2.1875** 羽管键琴弱起 A4 → C#5，短促制音（到 2.3 时低于 −28 dBFS）。 |
| 2（2.5） | D, A/C# | **拓印出样张：**全奏强拍重音（羽管键琴 D 和弦，大提琴、低音提琴和中提琴拨弦）。大提琴以拨弦八分音符走低音线，中提琴同样以拨弦八分音符伴奏。 |
| 3（5.0） | Bm, G, A7 | **5.0** 第二小提琴以十六分音符拨弦进入，分解和弦式的"交叉排线"。**6.25** 羽管键琴三十二分音符琶音花奏（G，然后 A7）上行进入 **7.5**。 |
| 4（7.5） | D, G | 完整织体。**9.375** 变薄为大提琴拨弦 A 持续音加上高音区羽管键琴八分音符音型（属音，"好奇"）。 |
| 5（10.0） | A 持续音 | **10.425** 刻环的"叮"：独奏小提琴拨弦 A6 配羽管键琴 A5。**11.275–12.5875** 上行的拨弦与羽管键琴音阶 A4 → A5（8 个音，间隔 0.1875 s）。**12.775** 落在低音 D 上（大提琴、低音提琴和羽管键琴的 D）。 |
| 6（12.5） | D, Bm | 拨弦织体回来，更轻（在 13.125 重新开始）。 |
| 7（15.0） | Em7, A7, D | **15.0** Em7 强拍。**15.5** 叮（B6）。**15.8–16.66** 更快的上行（7 个音，间隔 1/7 s）。**16.8** 落在 D 上。 |
| 8（17.5） | Bm, G, A | 更饱满的织体。**19.375** 变薄为 A 持续音（第三个细节）。**19.875** 叮（A6）。 |
| 9（20.0） | D, G | **20.0** 第一小提琴拨弦旋律，全片最有旋律感的时刻：A5 F#5 D6 · B5 G5-A5 B5 C#6-D6 · E6 G5 F#5。**21.475** 落在低音 G 上。**22.19** 托起：第二小提琴十六分音符渐强加上羽管键琴滚奏。 |
| 10（22.5） | Em, A7 | **23.75** 羽管键琴下行十六分音符快速音阶 A5 → A4（八度齐奏），停在属音上。最后一个音长 90 ms，所有声部在 25.0 处被门限归零。期待中的主音始终没有到来，这正是笑点所在。 |
| 11（25.0–26.25） | — | **完全的数字静默**（−inf dBFS，包括混响尾音）。 |
| 11b–13（26.25） | D, Bm, G, Em7, A7 → **D** | **26.25** 全片第一个弓拉音。大提琴、中提琴和小提琴以 pp 在 D 上进入，到 27.6 增强到 mp。高音声部旋律 A5 B5 · D6 C#6 → D6，低音线按三度下行 D-B-G-E，然后 A → D。羽管键琴稀疏而居高：在 27.5、28.75 和 30.0 处的缓慢分解和弦。**31.25** 完全终止 V7 → I：羽管键琴一个低音 D（不滚奏），上方和弦随后滚奏，低音提琴拨弦，以及弓拉 D 和弦。随后主音持续鸣响。 |
| 14（32.5） | D | **33.75** 眨眼：一声轻柔的独奏小提琴拨弦 D6。 |
| 15–16（35.0–40.0） | D | **35.625** 为片尾卡奏出一个非常轻柔的羽管键琴 D-A-D 滚奏。从 36.6 开始淡出，到 38.9 归零。39.0 到 40.0 为数字静默。 |

**旁白窗口。** 在 6.4–9.6、9.8–14.9、15.3–19.2 和 19.7–23.3 之内，拨弦短而干，使 300 Hz–3 kHz 保持为瞬态而非持续音。在 26.9–30.9 期间，弓拉和弦主要位于低音区（大提琴和低音提琴低于 300 Hz）和 900 Hz 以上（小提琴在 A5–D6），只有中提琴和第二小提琴以 pp 处在人声频段内。羽管键琴在此只弹四个轻柔的分解和弦。

**混响。** 每条分轨使用 `S.room`，在静默门限之前施加，因此没有尾音漏进 25.0–26.25：羽管键琴 size .28 / mix .16，拨弦 .30 / .18，弓拉 .42 / .24。每条分轨都有 35 Hz 高通。

**时间校验。** `music/cues.json` 中的每个重音都在其自身渲染出的分轨上测量（混响之后）：在 [t − 60 ms, t + 120 ms] 内，从局部谷值到局部峰值首次上升 30 % 的位置；低音落定在 300 Hz 以下测量，"叮"在 2 kHz 以上测量；容差 ±42 ms（24 fps 下的一帧）。对于弓拉进入，取第一个高于 −100 dBFS 的弓拉采样点。

## 色板与道具

**纸张**：1920×1080 世界单位，直纹纸 `#f1e8d2`，世界空间纸张纹理（纤维、帘纹、稀疏的霉斑 `#9a6a34`）。版痕（压出的带斜边矩形）位于 (70, 44)–(1850, 1036)：内部版色 `#e8ddc2`，55 %；斜边在上/左壁偏暗，在下/右壁偏亮（光从左上方来）。界框：2.4 px 粗线 + 内侧 9 px 处一条 0.8 px 细线，(100, 72)–(1820, 1008)。

**油墨**：`#1c1510`。1× 缩放下的世界线宽：轮廓 1.8–2.4（粗细变化 ×0.45–1.35），第一遍排线 0.18–2.0，交叉排线 ×0.78，第三组 ×0.6，绒毛与点刻 0.6–0.9。600 px 图形上的排线间距：3.1–3.7 px（第一遍），×1.1（交叉），×1.25（第三组）。0–1 色调上的排线阈值：第一组从 0.14 起，交叉从 0.46–0.5 起，第三组从 0.74–0.78 起。

**光线**：`{x: −0.55, y: −0.62, z: 0.56}`。

**字体**：Bodoni Moda（标题 50 px，字距 0.16；标签 17 px，字距 0.14），拉丁文用斜体（20–24 px），注释用 Pinyon Script（29 px）。字幕：Pinyon Script 38 px，`#2b1e14`，放在底部居中的毛边纸条上（`#f4eddb`，柔和阴影），最大宽度 860，最多两行；在台词前 0.1 s 出现，台词后 0.6 s 消失；绝不压在行动号召上。

**圆框**：半径 120，双线（2 px + 0.75 px，内侧 4 px），底纹为每 11 个局部单位一条的水平线；内容按 500 单位半径绘制后缩放进来。位置依次为：左上 (300, 300)、左下 (300, 700)、右下 (1620, 700)、右上 (1620, 300)。未使用的位置显示标本的**实际大小**（图版约 20 cm 宽，所以一只 13 mm 的蜜蜂是主图的 0.19×）。

**引线**：0.95 px，从部位上的一个圆点连到圆框边缘，绕开翅膀和身体，留出 ≥ 34 px 的间隙（一个转折点），根部附近有一个小号斜体图号。

**手工上色**：腹部琥珀色 `#d9962a`，胸部赭色 `#a8743e`，头部 `#8a6242`，眼睛 `#6e4a3c`，翅膀浅蓝灰 `#a9c3cf`（alpha 0.5），腿 `#7a5a3c`，花粉 `#eaa21a`（alpha 0.95）。以正片叠底覆盖在纸上；3.5 px 溢色，2/1.5 px 套色错位，湿边处有水痕线，低频密度提升（0.55），大区域里有 1–2 处回流水渍，颗粒感。

**铜版（仅开场）**：底色 `#5e2a12 → #94502c → #4e220e`，一圈抛光细纹（叠加），一扇柔和的工作室窗户倒映在版面上（四格窗，模糊 14 px，叠在 90 px 的室内光晕上），画面边缘趋向暗室。刻槽：暗色槽底 `#240c05`，偏向光源一侧的亮色毛刺 `rgba(255,226,186)`，远壁上一道暖色闪光。刻刀：受光面 `#d9e0e6`，背光面 `#262b30`，锐利的棱线高光，黄铜箍，带木纹的蘑菇形木柄；旋转 0.22 rad（≤ 15°）；铜屑是一条细长、渐窄的铜带，不规则地卷曲（随着长大卷圈逐渐张开，偶尔扭转）。

**主题**：蜜蜂（`subjects/bee.js`），配三幅绘制好的放大图——复眼、翅钩（hamuli）、花粉篮（corbicula）——位于 `subjects/details.js`；第二个内置主题是大扇贝（`subjects/scallop.js`），由 `content_alt.json` 使用。

## 片尾卡

标题是图版的一部分（雕刻上去的，而不是单独的卡片）。片尾卡：一张半透明的拷贝纸护页落在图版上；上面雕刻着：影片标题、风格名称、`LEMO-OPUSCAR`、`LemoLab × Claude Opus 5.5`、三行署名。"LemoLab × Claude Opus 5.5" 落款只属于本库的演示片；用户的影片不带 LemoLab 署名，也不复制这张卡片。

## 构建说明

```
sh styles/engraving/demo/build.sh              # voice → check → score → events → mix → cue check → srt → frames → mux → stills
```
- `demo/engine/`：`burin.js`（线条）、`plate.js`（纸张、字体、圆框）、`wash.js`（颜色）、`copper.js`（铜版、刻刀、铜屑）、`index.js`（公共入口 + `engraveShape`）。
- `demo/subjects/`：`bee.js`、`details.js`（复眼、翅钩、花粉篮的圆框图）、`scallop.js`（第二个内置主题）。
- `demo/film.js`：时间线（96 BPM 网格）、摄影机、渲染；读取 `content.json`。`demo/mix.py`：拟音 + 人声 + 压低的分轨。`demo/music/score.py`：配乐，依据画面事件的提示点图谱写成（逐小节曲式见"配乐结构"）。`demo/tools/cuecheck.py`：配乐重音与画面事件的对照（全部在 1 帧以内）以及静默电平。
- 用 `core/render/video.mjs --workers 2` 渲染；每帧耗时 60–500 ms（铜版帧和上色帧最慢）。

与本演示片道具相关的陷阱：

- **翅脉必须闭合成翅室。** 随机的翅脉笔画看起来很假；把长翅脉定义为曲线，再把横脉吸附到长翅脉上（`bee.js`，`FX`）。
- **腿关节画成完整的胶囊形会像一串珠子。** 排除前一段，只显示远端的端帽。
- **同一演示文件夹的两次渲染会冲突**：`video.mjs` 把分段写到 `<demo>/out/`，所以主片和备选片要先后依次渲染。
- **刻刀倾斜**：30° 看起来像在线旁边戳；改为 0.22 rad 后解决。
- **引线**贴着翅膀走会被看成穿过翅膀，直到以 ≥ 34 px 的间隙绕行才解决。
- "Apis mellifera"：Kokoro 读得还可以，但 whisper 无法转写；这一句使用 `asr` 字段。

## content.json 字段

`demo/content.json` 驱动每一个文字、数字和颜色。

| 字段 | 类型 | 范围 | 超出范围时 |
|---|---|---|---|
| `title` | string | ≤ 22 个字符 | 更长的标题会超出拉丁文行的宽度；缩短，或在 `film.js` 中降到 44 px |
| `latin` | string | ≤ 30 个字符 | 阅读时间变长（chars/12 + 1 s 必须在 9.4 s 的第一次推镜之前容纳得下） |
| `plate_no`, `series` | string | ≤ 10 / ≤ 48 个字符 | series 超过约 48 个字符会与上方标题相撞 |
| `subject` | `"bee"` \| `"scallop"` | 内置主题 | 未知 → `bee`；新主题是一个返回 `{ink, regions, focus}` 的模块，首笔为 `ol0`（见 `subjects/scallop.js`） |
| `details[]` | `{name, latin, note, focus}` 的数组 | 1–4 | 超过 4 个会被忽略；较少时会留下空位 → 第一个空位显示实际大小的图形；时间线重新排布（第一个 9 拍，其余各 7 拍） |
| `details[].focus` | string | bee：`eye`、`hamuli`、`corbicula`（已绘制的放大图）；任意主题：其 `focus` 键 | 没有绘制放大图的键会得到图形本身的实时放大 |
| `details[].note` | string | ≤ 60 个字符（29 px 下 2 行） | 第三行会开始碰到下一个圆框 |
| `colors[]` | `{region, color}` | 主题的区域（bee：abdomen、thorax、head、eyes、wings、legs、pollen；scallop：shell、bands、ears） | 未知区域被跳过；顺序 = 上色顺序 |
| `caption` | string | ≤ 50 个字符 | 必须在 4.4 s 的最终图版内保持可读 ≥ chars/12 + 1 s |
| `signature.left/right` | string | 简短 | — |
| `nat_size_label` | string | ≤ 16 个字符 | — |
| `voice.voice`, `voice.speed`, `voice.lines[]` | Kokoro 音色，0.8–1.0，`{id, text, asr?}` | id：`title`、`d1`…`dN`、`close` | 比所在段落更长的台词会与下一段重叠；d 行保持 ≤ 4.5 s |
| `end.film_title`, `end.style_name`, `end.credits[]` | strings | 署名 ≤ 3 行，每行 ≤ 35 个字符 | 更长的行会破坏片尾卡的阅读时间 |

步骤：编辑（或复制）JSON → `sh styles/engraving/demo/build.sh my_content.json`（TTS + whisper 校验、事件、按事件重新放置配乐、混音、提示点校验、字幕、帧）。如需保持主片不变，`sh styles/engraving/demo/tools/build_alt.sh my_content.json` 会把所有内容构建到 `demo/out/alt/`（演示片的 `content_alt.json`，2 个细节，35.6 s，通过提示点校验）。

## 引擎参考

```js
import { B, engraveShape, Wash, drawSheet, engraveText } from './engine/index.js';

// 1. any shape + a light direction → an engraved figure (contour lines follow the form), cut in order
const { ink, shape: spark } = engraveShape(
  'M0 -120 C12 -40 40 -12 120 0 C40 12 12 40 0 120 C-12 40 -40 12 -120 0 C-40 -12 -12 -40 0 -120 Z',  // a four-pointed spark
  { at: B.xf(860, 560, 1.9), light: [-0.6, -0.7], spacing: 4.2, style: 'contour' });               // or style: 'hatch'
engraveShape('M0 0 H150 V26 H0 Z', { at: B.xf(1140, 740, 1), ink, g: 't' });                        // its cursor tail, same ink
ink.schedule(['ol', 'tol'], 0, 1.1, { conc: 2 }); ink.schedule(['h1', 'th1'], 0.8, 2.2, { conc: 40 });
ink.schedule(['h2', 'th2'], 1.6, 2.7, { conc: 40 }); ink.schedule(['h3', 'th3'], 2.2, 3.0, { conc: 40 }); ink.build();

// 2. the "only colour": hand-colour one element and leave everything else in black ink
const w = new Wash({ scale: 1.5 });
w.add({ path: spark.path, polys: spark.polys, color: '#D97757', origin: [860, 560], t0: 3.0, dur: 1.2, alpha: 0.85 });

window.render = t => {
  drawSheet(ctx);                 // paper, plate tone, plate mark
  w.draw(ctx, t);                 // colour under the ink (omit for pure black-and-white)
  ink.draw(ctx, t);               // everything cut by time t; lines being cut grow
  engraveText(ctx, 'THE SPARK.', 960, 170, { size: 50, weight: 600, track: 0.16, p: t - 1.5 });
};
```
可作为 `demo/example/index.html` 运行（`node core/render/still.mjs styles/engraving/demo/example 4.5`），输出在 `demo/stills/engine_example.jpg`。

主要函数：

| 函数 | 作用 | 关键参数 |
|---|---|---|
| `B.shape(d, xf)` | SVG 路径 → 世界坐标环 + Path2D | `xf(x, y, scale, rot, flip)` |
| `B.Ink` | 有序的、按线宽分桶的笔画存储 | `group(name)`、`schedule(group, t0, t1, {conc})`、`instant(group)`、`draw(ctx, t, {color, wScale, dx, dy})` → 正在刻的刀尖 |
| `B.hatch(ink, polys, o)` | 一组顺着形体弯曲、粗细变化的线 | `angle, spacing, bend, tone(x,y), thr, wMin, wMax, swell, excl` |
| `B.engraveTone(ink, polys, o)` | 雕版师的三遍刻画 | `angle, cross, third, t2, t3, g` |
| `B.formTone(polys, {light})` | 任意形状 → 枕形打光的色调场（+ `.df` 距离） | `light, lz, base, radius, rim` |
| `B.contourHatch(ink, polys, o)` | 顺着形体走的线（等距轮廓线） | `spacing, tone, thr, wMax` |
| `B.outline / B.stroke` | 粗细变化的轮廓 / 开放的刻刀笔画 | `w, light, vary, run, pinch, swell, excl` |
| `B.stipple`, `B.fur` | 按色调分布的点；梳理过的绒毛笔触 | `density, r, tone` / `len, dir(x,y), curl` |
| `B.sphereTone`, `B.cylTone`, `B.linTone`, `B.blobTone` | 解析式色调场 | 光源来自 `B.LIGHT` |
| `Wash` | 手工上色，按区域缓存 | `add({path, polys, color, alpha, origin, t0, dur, spill, offset, lift, pool})`、`draw(ctx, t)` |
| `drawSheet`, `borderInk` | 纸张、版色、斜边；以油墨绘制的界框 | `plate: [x0, y0, x1, y1]` |
| `engraveText`, `writeScript`, `wrapLines` | 刻出罗马字母；书写手写体；固定字号的均衡换行 | `size, weight, italic, track, align, p` |
| `roundelFrame` | 按 `p` 刻出的双线圆 | `x, y, r, p, w` |
| `Copper.drawCopper / copperLight / drawGrooves / drawBurin / drawSwarf` | 铜版特写 | `zoom, lift, skew, s` |

整套流程的一个最小可运行示例是 `demo/film.js` 配合 `content_alt.json`（不同的主题，两个细节）。
