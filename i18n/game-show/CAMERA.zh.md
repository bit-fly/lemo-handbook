## 5. 动作质感

- **待机 = 踩拍跳动**：每拍一条抛物线（8–30 px）；相邻角色在反拍上跳，让人群像波浪一样起伏。
- **击打 = 挤压**：每次击打后一段阻尼摆动（约 30 rad/s，约 0.35 s）；每个强拍都有一个小挤压。
- **入场从天而降**，用缓入加速，正好落在自己的拍子上，让声音和落地同步。人群每拍或每半拍落下一个。
- **弹出用回弹缓动**，适用于一切出现的东西（卡片、贴纸、印章、文字）；退出用缓入。没有任何东西慢慢淡入：要么就在，要么弹出来。
- **喊叫姿势**：举起双臂 + 张开嘴，持续约半拍。
- **打字机**按拍子的细分逐字显示，每隔几个字一声按键音。
- 场景切换是**落在小节线上的硬切**，配一道极短的白闪。淡出只留给最后，甚至可以不用。
- 没有任何东西脱离网格运动：落在两拍之间的事件要放在细分拍上。



## 6. 镜头语法

舞台是正面、对称的舞台框；动的是画框本身。这是一套词汇，而不是一条路线。开场和结尾由题材决定。

| 运镜 | 表达什么 | 可用于 |
|---|---|---|
| 节拍冲击缩放（围绕中心缩放 0.8–5 %，约 0.16 s 内衰减） | 击打感，在画框里感受到 | 任何重音；一次重击；数拍 |
| 一小节内多次冲击缩放 | 画框随音乐呼吸 | 合唱；逐步升级的节奏型 |
| 锁定正面全景 | 整个舞台就是一张游戏棋盘 | 建立节奏型；人群；记分板 |
| 小节线上硬切 + 白闪 | 新一轮、新布景 | 章节切换；前后对比 |
| 分屏舞台（两半，两个布景） | 双方一呼一应 | 对手较量；人类对机器；新旧对比 |
| 缩成缩略图（完成的段落缩进一个槽位） | 记忆、积累 | 回顾；“然后这一切都发生了” |
| 布景纵向滚动（从地面到天空） | 赌注或规模不断升高 | 排行榜；增长；一座物品之塔 |
| 突然放大到某个道具（硬切到 2× 构图，下一小节切回） | 这个细节就是笑点 | 一个价签；一个数字；一张有反应的脸 |

同时叠加的冲击缩放总和保持在约 0.06 以下，这样画框边缘永远不会露出来。角色站在地面带上；横幅在左上，判定词在中上。只用硬切；不用叠化。



## 8. 招牌手法

一份菜单：按故事需要选用。

- **带标题卡的回合。** 一张 1 小节的标题卡（回合编号 + 名称 + 一个标签，如年份或步骤）伴着小调飞入，然后开始游戏。*适合这类内容：* 菜谱的步骤；创业公司的各个阶段；博物馆导览的各个章节。
- **成绩单。** 打字机打出的回顾，配一个评级印章。*适合这类内容：* 季度复盘；旅行总结；最终得分。
- **一呼一应。** 任何有来有回的东西都能变成节奏型；加快节奏型（四分 → 八分）*本身*就是剧情。*适合这类内容：* 老师提问、全班回答；顾客点单、咖啡师回应；两个谈判者之间的来回拉锯。
- **下一关预告。** 有东西孵化或解锁。*适合这类内容：* 下一个版本；下一季；下一个年级。
- **判定词。** 在回合最后一击时，一个带描边的大字斜着弹出。*适合这类内容：* 物流环节上的“已送达！”；许可证上的“已批准！”；训练计划里的“个人最佳！”。
- **Remix 面板。** 一个布景加一条时间线丝带；每个条目在舞台中央占几小节，然后缩进底部的一个槽位；到高潮时所有槽位一起弹跳。*适合这类内容：* 年度回顾；团队的发布清单；音乐节阵容。
- **把数据做成游戏 UI。** 数字变成领奖台分数、冲向目标的计数器、被锤下去的价签、按拍增长的柱状图。*适合这类内容：* 筹款进度；每道菜的卡路里；一个 App 的下载量。
- **人群降落。** 许多选手每拍落下一个，各配一声带音高的 pip。*适合这类内容：* 俱乐部的每位成员；行星；一道菜的配料。
