## 5. 运动质感

- **一切都逐帧运动**（24 fps），带缓动：镜头环绕用缓入缓出，零件减速进入漂浮用缓出，咔地合拢用缓入。
- **镜头始终在漂移**：缓慢环绕或推镜；绝不锁定机位，也绝不手持，只有撞击时会有几帧微震。
- **爆炸视图**：零件沿轴线散开（约为产品尺寸的 2×），每个都有一个小而确定的倾斜，以及与其偏移量成正比的旋转；长时间缓出分开 → 短暂的漂移悬停 → 在强拍上**极短的缓入合拢**。
- 物体从槽位中抬起时朝镜头倾斜，然后直立落定；盖子在后方铰接，立在物体后面形成背光光晕。
- 光脉冲和扫光是节拍网格上的事件，而不是自由动画。



## 6. 镜头语法

这是一套词汇，而不是一条路线。开场和结尾由题材决定。

| 运镜 | 表达什么 | 可用于 |
|---|---|---|
| 扫光掠过黑暗中的物体，缓慢推镜 | 先见轮廓，后见内容 | 一个未知的东西；"之前"的状态 |
| 缓慢的高角度 3/4 环绕 | 一个运镜看全整个物体 | 一个机构打开；不同款式 |
| 微距，焦点从表面移到内部零件 | 毫无隐藏 | 一种成分；一个传感器 |
| 侧面微距环绕 | 材质对比 | 层次；一道接缝 |
| 爆炸视图，轴线与视线约成 40°，环绕 | 技术之美，悬停 | 结构架构；转折前的停顿 |
| 正面平视，轻微推镜 | 宣告 | 一个数字；一个名字 |
| 俯拍微距 | 以原尺寸呈现图案 | 通道；一块电路 |
| 俯拍地面 | 效果离开物体向外扩散 | 覆盖范围；扩散的能量 |
| 在物体下方低角度环绕 | 纪念碑感，分量 | 耐用性；旗舰产品 |
| 缓慢拉镜进入负空间 | 为文字留出空间 | 一句宣言；一个问题 |

构图：一个主角，居中或位于强有力的对角线上，在全景中绝不被画面边缘裁切。只在节拍上剪切（尽可能在小节线上）。产品片的镜头之间**不需要空间连续性**：每个镜头都是独立的展示舞台，所以把任何不为它服务的东西藏起来或挪开。转场是节拍上的剪切，或一道穿过黑场的扫光；绝不用叠化或擦除。



## 8. 原生手法

一份菜单：按故事需要挑选。改编任何题材：找到**产品所做的那件看不见的事**，把它变成玻璃里的光，让人看见。

- **透明。** 内部才是主角；焦点从外壳移到里面的零件。*适合的内容：* 榨汁机的刀片；手表机芯；保健品胶囊的分层。
- **透镜效果。** 厚厚的玻璃穹顶会放大并弯曲其后方的东西；透过它拍微距，就像在凝视一颗宝石。*适合的内容：* 相机模组；放大工具；滤水器。
- **色散。** 扫光划过厚边缘时，变成一道流动的光谱。*适合的内容：* 棱镜灯；显示屏的色域；护肤品瓶子。
- **在内部流动的光。** 能量（电量、数据、热量、声音）化作光在通道中奔流。*适合的内容：* 电池充电；路由器的数据光丝；水壶加热。
- **焦散。** 内部的一次脉冲变成在地面上扩散的光环。*适合的内容：* 音箱的覆盖范围；香水的余香；无线充电器的感应范围。
- **爆炸视图与合拢。** 零件漂浮着分开，在强拍上咔地合拢。*适合的内容：* 模块化背包；钢笔的换芯系统；可维修的手机。
- **由磨砂变透明。** 磨砂外壳变得透明（粗糙度和色调动画归零），内部显现出来。*适合的内容：* 一项隐私功能；冰箱里的东西；一份诚实的价格明细。
