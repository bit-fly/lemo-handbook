# 玻璃质感产品 — 我们的示范片

这只是众多可能中的一个例子。不要照搬它的故事、结构、镜头、道具或时间安排。

示范片：*Aura — Hear the Light*（Aura — 听见光）（32 s）· `glass-product.mp4` · 源文件见 [`demo/`](demo/)


## 故事与结构

一副虚构的无柄、透镜形玻璃耳机，装在鹅卵石形的玻璃充电盒里。在黑暗中，它们只反射别人的光；被拆开、又在贝斯重拍落下时咔地合拢之后，它们从内部亮了起来：声音变成了在玻璃里奔流的光。主题：透明 = 毫无隐藏；声音 = 光。

让看不见的东西变得可见：声音化作导光件里的光脉冲。（同样的手法可用于其他产品：电池 → 电量充满一个玻璃电芯；手表 → 时间化作一圈光环；路由器 → 数据化作光丝；香水 → 香气化作焦散光斑。）

结构（30–40 s）：在黑暗中被外部光照亮（神秘）→ 打开（好奇）→ 被看透（亲密，微距）→ 被拆开（悬停，完全寂静）→ **在重拍落下时咔地合拢，从内部亮起**（释放）→ 自信的节奏 → 回到原位（落定，呼应）。一个物体，一个目标（发出自己的光），一个转折（重新组装）。

首尾呼应：开场是一道扫光揭示出黑暗中的物体，结尾是*同样的*扫光掠过这个如今自己发光的物体；两只耳机落回各自的槽位（磁吸的咔嗒声），充电盒的磨砂底座像在充电一样亮起。

在旧版指南中，示范片的规则是"六种原生能力至少用四种"；示范片六种全用上了（透明、透镜效果、色散、内部发光、焦散、爆炸视图）。

## 镜头

| 节拍 | 镜头 | 为什么 |
|---|---|---|
| 开场（0–4 s） | 低角度 3/4 侧面，极慢的推镜，环境光接近于零；两次扫光 | 只有轮廓，没有内容：引起好奇。3 s 内抓住观众。 |
| 揭示结构 | 高角度 3/4，盖子打开时缓慢环绕 40° | 用一个运镜讲清这个物体 |
| 微距 | 距离 25–45 mm，焦点从玻璃表面移到内部零件；每拍一次短扫光 | 把观众拉*进*玻璃里 |
| 侧面 | 侧面微距环绕 | 材质对比：透明 / 金属环 / 磨砂 / 柔软耳塞 |
| 爆炸视图 | 3/4，轴线与视线约成 40°，让零件形成一条有纵深的对角线（近大远小），占画面约 80 %，缓慢环绕产生视差 | 技术之美；视差让纵深感成立 |
| 主角正面 | 正面平视，轻微推镜 | 宣告：光环完整了 |
| 图案微距 | 俯拍导光通道的微距 | 把概念放到最大 |
| 一对 | 中景双人镜头，第二只耳机在强拍上飞入 | 立体声 = 左右交替 |
| 焦散 | 高角度俯拍地面 | 最令人难忘的镜头：声音在地面上扩散 |
| 主角结尾 | 低角度 3/4，居中在片名下方，缓慢拉镜，为演职员信息腾出空间 | 名字 + 标语 + 产品 |

爆炸视图镜头被延长到 17.0 s，让零件飞回、在 16.0 咔地合拢，光的图案在同一帧里首次亮起——因与果在同一个机位里——然后才剪切到正面。28.0 时磁吸咔嗒一声落回槽位。

实际使用的运动参数：每个镜头的环绕 0.2–0.4 rad；爆炸零件倾斜 `sin(i·1.7)·0.32`、`cos(i·2.3)·0.28`；时序为 3 s 缓出分开 → 0.75 s 悬停（漂移 +3 %）→ **0.25 s 缓入合拢**，正好落在重拍的强拍上；合拢后 0.9 s 内镜头推进约 40 %；合拢时两帧微震。磁吸抬起 1.2–1.4 s（`eio`）。悬停的耳机朝镜头转成 3/4，让透镜面和光环可见；盖子在充电盒后方立成约 100°，形成背光光晕。

## 配乐结构

原创 numpy 配乐（`demo/music/score.py`），**120 BPM，小调**。黑暗的开场用超低音持续音 + 玻璃微光音色；铺垫段用 FM 玻璃拨弦琶音，低通滤波逐渐打开；在微距扫光下每拍一记柔和的短底鼓；爆炸视图上叠加噪声 + 锯齿波上升音效；重拍前**半小节完全寂静（混响尾音也切掉）**，其中有一段长长的反向呼啸；**808 重拍**，带切分节奏型（每小节 [0, .75, 1, 1.5]），光脉冲严格跟随；第 2、4 拍拍手；一个四音的玻璃钟动机；揭示段用小九和弦铺底；最后落定时一声高音玻璃"叮"。配乐和渲染器共用同一份底鼓列表（`story.js`、`cues.json`）。

实际使用的拟音：每次扫光一声微光音、盖子的摩擦声、磁吸咔嗒声、每个爆炸零件一声气流"噗"，合拢时是六声相隔 15 ms 的咔嗒簇 + 非谐波的玻璃和弦。

人声：Kokoro `am_michael`，语速 0.86–0.88，3–4 句非常短的台词。单独一句 "Aura." 被误听为 Laura / Dora，所以台词改成了 "Meet Aura."。音乐在人声下压低 −12 dB，拟音 −6 dB。808 的峰值没有留下余量，loudnorm 退回到动态模式（−13.7 LUFS）；在混音中把重拍峰值限制约 3 dB 就解决了。封装时颗粒为 0。

## 色板与道具

- 强调色：冰蓝 `#62DCFF` → 柔紫 `#A98BFF`；其他一切为中性色。
- 灯条套件（尺寸单位 mm，强度）：左右高灯条 22×170，×3.2；地平线灯条 260×14，×1.4；顶部柔光箱 160×70，×1.1；低位前方反光卡 ×0.18（凹面充电盒朝向镜头时为 0）；顶前主光 150×60，×2.5，仅用于爆炸视图；扫光灯条 26×240，在镜头后方 ±1.35 rad 的弧线上；强调色反光卡按导光件颜色着色，由光脉冲驱动。
- 透明玻璃：粗糙度 0.015，IOR 1.52，厚度 3–4.5，色散 5，衰减 `#f3f8fb`，距离 160 mm。磨砂玻璃：透射 0.82–0.9，粗糙度 0.4，色调 `#eef2f5`，厚度 7–14，内部一个不透明的自发光圆盘。
- 金属：缎面钛环（粗糙度 0.16）、镜面铬磁铁（0.14；0.05 时会过曝成一个白色圆盘）、拉丝钢和带同心拉丝粗糙度贴图的香槟色振膜、带金色走线的石墨色 PCB。
- 导光件：抛光亚克力 `#15181b`，清漆 1；彗星脉冲头部 σ = w/2，拖尾长度 4w、强度 55 %，白热核心 head³ × 0.35，色相随时间从蓝变紫。
- 背景扫光 `#34383d → #16181b → #000`，范围 0–1.1；地面 Reflector 带 12 抽头模糊，×0.32，径向淡出。
- 后期：景深光圈微距 700–900、爆炸视图 70、全景 160–300；辉光强度 0.16–0.3，阈值 1.1 以上；Neutral 色调映射，曝光 1.1。微距距离 25–45 mm。
- 字幕条：高 76 px，圆角 38，`blur(18px) brightness(1.25)` + 10 % 冷白，1.2 px 渐变描边，顶部一条蓝 → 紫的细线；Inter Tight 300，40 px，字距 1 px；停留 ≥ 1.9 s 且 ≥ 语音时长 + 0.7 s。
- 片名：Inter Tight 200，112–132 px，字距 56–64 px；引题 18–20 px，字距 8–10（"A GLASS PRODUCT FILM"、"MEET"）。

## 片尾卡

片名保留；镜头拉远腾出空间的同时，演职员信息（风格名、`LemoLab × Claude Opus 5.5`）在底部柔和的暗色渐变上淡入；最后 0.6 s 淡入黑场。"LemoLab × Claude Opus 5.5" 的署名只属于本库的示范片；用户的影片不带任何 LemoLab 署名，也不要照搬这张片尾卡。

## 构建说明

```
styles/glass-product/demo/
  product.js   earbud + case geometry, glass/metal/guide materials, comet-pulse shader, explode()
  studio.js    strip-light env (PMREM per frame), sweep strip, background sweep, floor mirror + caustics + beat rings
  story.js     120 BPM timeline: shots, kicks, sweeps, VO, SFX events
  main.js      per-shot staging & cameras, light/pulse logic, frosted-glass subtitles, titles, end card
  music/score.py  original numpy score (stems + score.json self-check)
  mix.py       foley synthesis + voice + ducking → mix.wav
  lines.json · subs.py · check_mix.py · build.sh
```

1. 先写提示点表和 `story.js`（BPM 网格，配乐与渲染器共用的底鼓列表）。
2. `node core/render/still.mjs styles/glass-product/demo 9.3 14.6 26.8 [--q nosub=1]`：迭代静帧；用 `--range 0.5:31.5:1` + `sheet.py` 做整体审看。
3. `.venv/bin/python core/tts/tts.py demo/lines.json demo/voices` → `core/tts/asr_check.py`，直到全部 OK。
4. `python demo/music/score.py` → `node core/render/events.mjs demo` → `python demo/mix.py`。
5. `node core/render/video.mjs demo --fps 24 --workers 3`（768 帧，带 2× SSAA、透射、逐帧 PMREM 和镜面反射，在 M 系列 Mac 上约 30–45 s）。
6. `sh core/render/mux.sh out/video24.mp4 mix.wav glass-product.mp4 24 0`，然后运行 `python demo/check_mix.py glass-product.mp4`。
7. 或者直接运行 `sh styles/glass-product/demo/build.sh`。

与本示范片道具相关的坑：
- 最初放在磨砂充电盒底座里的青色灯条，在整个充电盒上抹了一层蓝绿色调；后来改成一个冷白色的暗圆盘。
- 光环的待机微光被透镜穹顶放大成一团淡蓝色的光斑。
- 正面看悬停的耳机像蘑菇；平躺在充电盒后面的盖子像锅盖。
- 第二只耳机最初是"从下面"穿过可见的地面升起来的；现在改为从侧面飞入。
- 单独一句 "Aura." 被 ASR 误听了。
