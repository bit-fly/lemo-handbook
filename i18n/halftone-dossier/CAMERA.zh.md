## 5. 运动质感

- 变换以 30 fps 运行；角色上的**线条抖动约 10 fps**，让画面在"呼吸"，同时位置保持平滑。
- **一切都带过冲入场**（back 缓动，0.3–0.45 s）：从画面下方升起，或从 0 缩放出现。没有任何东西是淡入的。
- 标题采用**逐字弹出**：每个字形下落 30–100 px 并挤压进入，错开 0.05–0.08 s（小字 0.02 s）。
- **印章盖下**：约 0.09 s 内从约 2.6× 到 1×（ease-in），然后一个小的阻尼回弹；摄像机抖动、闪光和盖章声落在同一帧。
- **压扁落地**保持体积不变（`scale(1/sq, sq)` 配合阻尼余弦）。
- **待机生命感**：呼吸、尾巴或头发摆动、在设定时间眨眼、闪烁、一个闪烁的 REC 圆点或时钟冒号。
- **网点擦除转场**：一张粗网格的圆点放大到完全覆盖再缩回（约 0.44 s），带对角线延迟；场景在被覆盖时切换。每个剪切可以有自己的擦除颜色。硬切是对比手段，用在大的冲击点上。



## 6. 镜头语法

一个 2D 摄像机组，覆盖在平面、正面的页面上。这是一套词汇，不是一条固定路线。开场和结尾由主题决定。

| 运镜 | 表达什么 | 可用于 |
|---|---|---|
| 锁定正面，带轻微的节拍脉动（约 0.6 %） | 页面像一张随节奏律动的海报 | 标题；清单；指控 |
| 缓慢推镜（1 → 1.05–1.08） | 审视，紧张感上升 | 档案介绍；判决前的总结 |
| 二次衰减的抖动（5–26 px） | 冲击 | 印章；摔碎；落地 |
| 闪光帧（白色叠加层 ≤ 0.95 → 0，大冲击限制在 0.5） | 被拍照，真相揭晓 | 档案照；判决；发现证据 |
| 横摇扫过钉满证物的板子 | 证物之间的关联 | 时间线；嫌疑人；事件链 |
| 急推进半调细节，直到网点变得巨大 | "再看仔细点" | 指纹；签名；一个数字 |
| 翻页 / 文件夹滑入 | 下一份档案，下一章 | 第二个案子；闪回 |
| 拉镜露出整张桌子 | 这份档案只是众多之一 | 规模；"这种事每天都在发生" |

像印刷页面一样构图：标题在左上，主体在右侧居中，字幕条在底部居中，HUD 在四角。转场：网点擦除或硬切；不用叠化。



## 8. 原生手法

一份菜单：按故事需要挑着用。

- **指控框架。** 一个主题变成"X 案"：列出它的罪状。*适合的内容：* 审判一种认知偏差；一座城市的交通问题；一株停不下来疯长的植物。
- **编号证物。** 每个节拍背后衬一个巨大的半调数字。*适合的内容：* 一次停电的五个原因；合同的三条条款；一次召回的各个阶段。
- **印章。** 判决是一次实打实的盖章。*适合的内容：* 资助申请盖上 APPROVED；保单盖上 EXPIRED；谣言核查盖上 VERIFIED。
- **档案照。** 正面主体、身高标尺、姓名牌、闪光灯。*适合的内容：* 一个新物种；一次产品拆解；bug 报告里的"嫌疑人"。
- **证据板。** 证物钉在板上，用线连起来，然后一起抖动。*适合的内容：* 一条供应链；一棵家族树；一场劫案的时间线。
- **网点密度 = 情绪。** 网点膨胀成光晕，挤向边缘制造紧张，放射状绽放表达喜悦。*适合的内容：* 打破纪录；截止日期逼近；一次重逢。
- **涂黑。** 黑条压印在文字上，再一条条揭开。*适合的内容：* 一份泄露的备忘录；一个惊喜派对计划；剧透。
