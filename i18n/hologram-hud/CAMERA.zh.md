## 5. 动态质量

- **24 fps 下一切都逐帧动画（on ones）。** 只有字符乱码滚动是逐帧跳变的。
- **目标锁定**：框先放大、旋转 45°、半透明；约 0.2 s 内吸附到位（cubic ease-out），在强拍上闪白 3 帧。
- **爆炸图**沿每个组件的装配轴展开：外壳*沿自身轴线*滑动，内部构件留在原位并发光。用一两拍打开，快速关闭。
- **引线**：锚点圆环 → 斜线 → 水平线连到卡片，约 0.5 s。**滚动数值**：字符从右到左依次锁定，在强拍上变成强调色，并闪一帧。
- **标签入栏**：完成的数值滑进侧栏，一直保留到结尾。
- **机位跟随目标框**：cubic 缓动，在下一次锁定*之前*开始；**真实运动模糊**只用在甩镜里（子帧，180° 快门）；HUD 始终清晰。
- **场景内不用剪切或淡入淡出**：只有扫描平面（扫描入场或擦除）和放大镜光圈。**故障效果**最多出现一次，最长三帧，用在最大的变化上。



## 6. 镜头语法

一个环绕机位（偏航、俯仰、距离、窄 fov），并为目标设定屏幕位置，让主体可以与文字并排。这是一套词汇，而不是固定路线。开场和结尾由题材决定。

| 运镜 | 表达 | 可用于 |
|---|---|---|
| 高位 3/4，缓慢环绕并降镜 | 审视；扫描平面读成椭圆 | 扫描入场；整体概览 |
| 正上方平面俯视 | 布局、秩序 | 零件清单；装配顺序 |
| 平视侧面，固定机位 | 物体在使用中的样子 | 高度；前后对比 |
| 推镜后漂移，3/4 角度 | 这个部件很重要；内部结构朝镜头靠近 | 关键参数；缺陷 |
| 跟随目标框甩镜 | 注意力跳到下一个部件 | 一串部件 |
| 绕部件自身轴线环绕 | 轴向结构只有在旋转中才看得懂 | 转子、叠层、铰链、镜片 |
| 沿长部件横向移动镜头 | 长度、路径 | 一根梁；一段线缆走向 |
| 拉镜 + 放大镜（画中画） | 在哪里（全景）和是什么（放大镜） | 小零件；传感器 |
| 升降到平视或再升回去 | 状态变化：物体站起来或安定下来 | 变形；尺度 |
| 转台 360° | 每一面 | 完整物体；对称性 |
| 几乎静止，缓慢移动镜头 | 留出阅读时间又不出现死帧 | 参数表；检查清单 |

构图：在每个关键时刻，主体都占画面高度的 ≥ ⅓。卡片在一侧，标签栏在另一侧，字幕在底部居中，放大镜在字幕上方：永不碰撞。宁可缩短爆炸向量，也不要让零件飞进文字里。



## 8. 原生动作

每个动作服务于信息，而不是故事。这是一份菜单：只用你的影片需要的。

- **扫描生长 = "这是真实数据。"** *适合的内容：*一台咖啡机；一颗卫星；一个建筑模型。
- **目标锁定 = "现在看这里。"** 目标框就是镜头。*适合的内容：*汽车的传感器；笔记本电脑的接口；机械臂的关节。
- **局部爆炸图 = "为什么这个数字成立。"** *适合的内容：*磨豆机的刀盘组；跑鞋鞋底的分层；相机镜头的镜片组。
- **滚动数字 = 回报节拍。** *适合的内容：*冲煮温度；以微米计的公差；价格。
- **标签累积 = 阅读时间。** *适合的内容：*3–5 个必须全部读到的事实。
- **放大镜 = 同时呈现两种尺度。** *适合的内容：*手表里的一颗螺丝；电路板上的一颗芯片；发动机里的一个气门。
- **实体全息 + 光束 = "整体已就绪。"** 最多一次。*适合的内容：*发布揭幕；完成的装配；v2 取代 v1。
