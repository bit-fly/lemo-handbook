# 油画厚涂 · 画刀 —— 我们的示例片

这只是众多可能中的一个例子。不要照搬它的故事、结构、镜头、道具或时间安排。

示例片：*The Colour of Rain*（39.7 s）· `impasto.mp4` · 源文件在 [`demo/`](demo/)


## 故事与结构

雨中一片灰色的广场。一位街头大提琴手在演奏，没有人停下来；拉到一半，他放弃了。一个小女孩在他面前撑开一把红伞：全片的第一抹颜色。大提琴重新响起，变成一支圆舞曲，一把又一把伞踩着节拍变成彩色。从正上方看，人群的圆舞在鹅卵石地面上画出一幅彩色曼陀罗。最后一个和弦落下，雨停了，颜色填满整个广场。

弧线：孤独（灰色）→ 放弃（静默）→ 一点颜色（红伞）→ 被听见（圆舞曲）→ 人群（俯拍编舞）→ 回响（同一机位，灰色变成彩色；开头在 E 上中断的乐句最终解决到 D）。

为什么适合这种媒介：颜色就是故事，而画刀可以用新的颜色重新铺下任何一笔。这是一部没有旁白的音乐短片：标题用画刀铺在灰色天空上，再被雨水冲掉（向下流淌并淡去）。

用上的招牌手法：画刀重新铺色（伞撑开、大提琴手重新振作、最后的和弦铺满广场）；唯一有颜色的东西（前半段红伞是唯一的颜色）；运动作画（俯拍时，每把伞沿路径滴下自己的颜色，拉镜后露出一幅曼陀罗）；侧光（最后一个和弦时阳光擦过地面，然后回落）；画刀刮擦声配合的覆盖式转场。

## 镜头

| # | 时间 | 镜头 / 镜头运动 | 为什么 |
|---|---|---|---|
| 1 | 0–2.65 | 大提琴琴身 + 琴弓特写，轻微推镜 | 3 s 钩子：灰色世界里唯一的颜色是那个音符（一条琥珀色的丝带），很快被雨水冲淡 |
| 2 | 2.65–7.15 | 大远景，缓慢横移 + 推镜，覆盖式转入 | 这个世界：灰色广场，行色匆匆的人。标题用画刀铺上，然后被雨带走 |
| 3 | 7.15–12.4 | 中景，穿过静默的一个连续推镜 | 没有人停下：路人从镜头近处穿过挡住他；在他放弃时推到他的脸 |
| 4 | 12.18–16.66 | 水洼低角度特写 → 向上俯仰，硬切 | 一只靴子踩进水花；向上摇到她、他、伞；预备、撑开（POP）、冲击缩放 |

| 8 | 31.66–35.75 | 大远景（与镜头 2 同一机位），向拱门推镜 | 呼应开场：灰变彩、侧光、伞纷纷合上、鸟鸣 |

## 配乐结构

`demo/timeline.js` 保存所有网格；画面和配乐都读取它。

- **A 部分**：大提琴独奏，D 小调，3/4 拍，80 BPM，从 0.4 s 开始。乐句在 10.15 s 停在一个未解决的 E3 上；0.3 s 后琴弓离开琴弦。
- **静默** 10.45–12.4：雨声几乎消失，11.15 一滴水声，11.5 / 11.95 两声小脚步先于画面进入（J 形剪辑），12.4 一声大水花是静默之后的第一个声音。
- **B 部分**：街头缪赛特圆舞曲，D 大调，3/4 拍，132 BPM。
  - 15.3 撑开（POP，弱起小节）：钟琴 + 上行竖琴刮奏。
  - 16.66 伴奏进入：拨奏贝斯 + 手风琴的“嘭-恰-恰”。
  - 18.03 大提琴旋律进入。
  - 19.39–23.03 九把伞，每拍一把；钟琴音高逐级上升 G→B→D / A→C#→E / D→F#→A。
  - 23.48–31.21 俯拍，六小节编舞；手风琴高八度重复旋律，每小节一个竖琴琶音。
  - 31.21 全体休止，数字零电平；雨滴凝在空中。
  - 31.66 最后的和弦（全奏 + 定音鼓 + 吊镲）。
  - 尾声 F#→E→D 解决了开头中断的乐句。
  - 35.75 最后一个拨奏，片尾卡。
- 其他声部：小提琴拨奏、沙锤。

逐段声音设计：

| 段落 | 环境底层 | 拟音 | 音乐 |
|---|---|---|---|
| 特写 | 雨声（略远） | 琴弓松香声、雨滴落在上漆木头上 | 独奏的第一个音 |
| 灰色广场 | 满雨声 + 排水沟细流 | 湿鹅卵石上的脚步声（由行走算法放置并定位声像）、画刀刮过标题 | 独奏 |
| 中景 | 拱廊下的雨声（低通） | 近处路人脚步 + 伞布擦过 | 独奏，中断 |
| 静默 | 几乎什么都没有 | 一滴水声、小脚步（J 形剪辑）、大水花 | 无 |
| 女孩 | 雨声 | 尼龙沙沙声、伞骨咔哒、伞撑开的“噗”、颜料点落下 | 撑开（POP） |
| 反应 | 闷住的雨声 | 举弓时的气流声 | 伴奏，然后大提琴 |
| 街道 | 雨声（降低） | 每把伞的“噗”+ 丝带到达时一声轻柔的嘶声 | 圆舞曲 + 钟琴琶音 |
| 俯拍 | 雨声 | 人群踩水的脚步合着圆舞曲（第 1 拍最重） | 全奏 |
| 全体休止 | 数字零电平 | — | — |
| 结尾 | 雨停了 | 滴水声、伞合上、鸟鸣 | 和弦 → 尾声 |

每次重新上色都配有画刀刮擦声。

## 色板与道具

- 雨后夕阳天空：钴蓝 `#34507e` → 桃色 `#d99a78` → 金色 `#f7dca0`。建筑立面赭石 `#dca064` 和玫瑰色 `#c98d7e`，百叶窗绿 `#3f7a6c`，遮阳篷红 `#b8342a`。
- 伞为全饱和度：镉红 `#dc2f28`、黄 `#f4bc2a`、钴蓝 `#2f62c0`、翠绿 `#23906c`、品红 `#cc3a82`、橙 `#ee7a2a`、青绿 `#26aab4`、紫 `#6e4cc0`。
- 灰色世界 = 同样笔触的亮度，略偏冷，保留 5 % 的颜色残余；它的高光略高（潮湿）。
- 光照：`light [-.55,-.6,.7]`、`norm 3.2`、`amb .8`、`dif .28`、`spec .16–.3`、`ao 1.2`。
- 笔触尺寸：天空和墙面用 40–60 px 的大块面，只有边缘和脸部用 3–6 px。画刀笔触：倾斜 ±0.55，角度抖动 ±13°，明度抖动 ±6 %。人物和伞使用 `run: 0–0.25`，以保持实心。
- 人物：大提琴手（IK 持弓手臂，每个音符改变弓向）、女孩（伞先往下一沉再猛地撑开）、人群（每个强拍时圆圈涨大；伞在拍点上弹开，带缩放回弹和一簇颜料点，合上后向下摆动垂挂）。脸：眼睛、眉毛和嘴是分开的程序化笔触，所以能做表情。
- 湿地倒影：每盏灯和每扇窗下方叠着一摞短横笔触。

## 片尾卡

深群青底上用画刀画出的标题，一个红点（从上方看到的一把伞），署名用清晰的 DOM 文字（小字必须保持可读）：“an impasto palette-knife study”，然后是“Lemo-Opuscar · LemoLab × Claude Opus 5.5”，然后是采样和字体的致谢。“LemoLab × Claude Opus 5.5”署名只属于本库的示例片；用户的影片不带 LemoLab 署名，也不复制这张卡（这一行在 `demo/film.js` 中：如果改编该文件，请删掉它）。

## 构建说明

```
styles/impasto/demo/
  engine/impasto.js  WebGL2 knife-stroke renderer     engine/plate.js  reference illustration → strokes
  timeline.js        BPM grids, cut times, melodies (MEL_A, MEL_B), pops
  scenes/*.js        sets as reference illustrations (Ref.fill/line/text/tint) → paintRef()
  film.js            shots, cameras, transitions (EDIT table), post looks, end card
  music/score.py     sampler score (CC0 instruments)   mix.py  foley + ambience + ducking + true silence
  tools/dump_timeline.mjs  timeline → out/timeline.json    build.sh
```

1. 先写 `timeline.js`：BPM 网格、剪切时间、旋律、撑开点。`tools/dump_timeline.mjs` 为配乐写出 `out/timeline.json`。
2. 在 `scenes/*.js` 中搭布景 → `paintRef()`。
3. `film.js`：镜头、镜头运动、转场、后期。
4. `music/score.py`，然后 `mix.py`。
5. `sh styles/impasto/demo/build.sh` 渲染全部内容（952 帧约 30 s GPU 渲染），以颗粒 0 合成封装。

引擎层面的陷阱：`half` 在 GLSL ES 3.00 中是保留字；在笔触 VAO 仍处于绑定状态时绑定合成四边形，会悄无声息地重连属性 0（下一帧报 “vertex buffer not big enough”）：先解绑 VAO。

与这部示例片道具相关的坑：
- 伞的半径取身高的 0.46 倍时看起来像遮阳桌伞；0.34 才像一把雨伞。
- 用普通矩形画的外套看起来像路桩：要 A 字形收窄 + 受光边缘 + 肩部一笔 + 头发一笔。
- 在逐镜头的丝带循环中使用全局索引，把控制点甩出了画面（天空里出现一道条纹）。
- 在建筑之后再画地面，会盖住建筑的底部。

## 引擎参考

`demo/engine/impasto.js`（渲染器）和 `demo/engine/plate.js`（参考图 → 笔触）。

| API | 作用 |
|---|---|
| `new Impasto(canvas, {W, H, ss})` | WebGL2 渲染器，超采样的颜色 + 高度缓冲 |
| `E.begin()` / `E.finish(post)` | 开始一帧 / 光照 + 调色（`light, norm, amb, dif, spec, ao, expo, sat, vig…`） |
| `E.batch(Float32Array)` → `E.draw(batch, o)` | 静态笔触集。`o = {M, cam:{x,y,zoom,rot}, t, grey, reveal, revDur, appear, appDur, alpha, run, hgt}` |
| `E.drawNow(Float32Array, o)` | 临时笔触（人物、天气、丝带） |
| `E.texture(canvas)` + `E.under(tex, w, h, o)` | 薄底色层（支持 `revC:[x,y,speed]` 揭示波） |
| `new Strokes().push({x,y,ang,len,wid,c,c2,type,taper,bend,skew,alpha,hgt,rev,app,seed})` | 构建笔触；`type`：`KNIFE`、`BRUSH`、`DAB`、`LINE` |
| `new Ref(w, h, scale)` + `.fill(path, fill, props)` / `.line` / `.text` / `.tint` | 参考插画；props 为 `{dir, maxR, detail, group, type, hgt, jit, len, wid, aj, fallback}` |
| `paintRef(ref, {R:[radii], T, rev(x,y), app(x,y,level)})` | 由粗到细、限定在形状分组内的画刀笔触 |
| `strokePath(out, pts, {wid, c, type, step})` | 沿折线生成笔触 |
