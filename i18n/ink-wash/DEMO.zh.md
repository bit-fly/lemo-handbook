# 中国水墨 —— 我们的示例片

这只是众多可能中的一个例子。不要照搬它的故事、结构、镜头、道具或时间安排。

示例片：*The Swordsman and the River*（48 s）· `ink-wash.mp4` · 源文件在 [`demo/`](demo/)


## 故事与结构

一位剑客踏水过江，一剑劈开一道滔天巨浪。一个角色，一个目标，一个转折。笔本身就是事件：劈开巨浪的那一笔，同时也是凌空写下的“水”字。

弧线（48 s）：空无 → 一滴墨（创生）→ 广阔空间中的一个小人影 → 轻盈与欢快（踏水而过的轻功奔跑）→ 一道以墨块画出的压倒性障碍（一泼湿浓墨化作巨浪）→ 静默 → 决定性的一笔 → 释放 → 尺度揭示（人影只是整幅画中一个小小的墨点）→ 落印。结尾一句是哲思而非胜利宣言（“cut water with a sword and it only flows on”，即抽刀断水水更流）。

用上的招牌手法：一笔即一切（开场那滴墨）、笔即手势（写下的“水”字）、飞白（彻底静默之后的那一劈）、劈开墨块（巨浪）、手卷（最后的拉镜和落印）。

## 镜头

| 节拍 | 镜头 |
|---|---|
| 开场 | 锁定在空白纸面上；墨滴落入其中。 |
| 建立镜头 | 从右向左缓慢摇镜（手卷展开），停在一个**高位远景**：人物高 150–180 px，江面是一大片留白。 |
| 行进 | 横向跟拍，人物在画面约 60 % 处，前方留出空间；远山极慢地视差移动；偶尔有深色芦苇从画面最底部掠过。 |
| 威胁 | **低角度**，地平线压低，巨浪高耸，人物小小地缩在一角；缓慢推镜，抖动逐渐加剧。 |
| 静默 | 硬切到大特写（斗笠帽檐，不露眼睛）；然后是一个**过肩**画面，把人物、写下的字和巨浪放在同一条轴线上。 |
| 释放 | 回到与建立镜头相同的高位远景尺度。 |
| 结尾 | 从人物连续拉镜到装裱在绫绢上的整幅手卷；落印；片尾卡在手卷下方。 |

为什么这个故事用这条路线：锁定的空白纸面把“无”放在“有”之前；结束于高位远景的手卷摇镜让人物显得渺小；静默中的大特写是全片唯一的硬切；释放回到建立镜头的尺度，让这种呼应显出变化；拉镜到装裱好的手卷，把整段旅程变成一幅画。每一项都是从 STYLE.md §6 中做出的一个选择，而不是这种风格默认的开场或结尾。

出剑前的停顿是一个缓慢的 5 % 推镜；随后那一笔用约 4 帧横穿画面，巨浪在它之后才开始裂开。

## 配乐结构

原创古琴配乐（`demo/music/score.py`），F 宫五声音阶（F G A C D），按段落提示而非循环。散板开场，山水段 60 BPM，行进段 90 BPM（脚步落在拍子上），威胁段鼓声滚奏，**数字静默**，三个清透的泛音对应写下的三笔，再次静默，然后在劈开时鼓声 + 七弦扫弦；释放时主题回归；最后一个音 = 落印。

本片特有的拟音：拔剑（剑鞘摩擦 + 细长的金属鸣响，在第二次静默前切断）、劈开（撕裂空气 + 江水咆哮 + 低沉的轰鸣）。剑鸣和一声滴水是静默中仅允许出现的声音；环境声在第一次静默时硬切掉。

人声：沉稳的英式旁白，Kokoro `bm_george`，语言 `en-gb`，速度 .82–.86，4–6 句台词。人声下音乐压低约 8 dB，环境声也一起压低：有一句台词下方的江水咆哮让 whisper 把“Halfway”听成了“This way”。每句台词都用 whisper 检查，最终混音上再检查一次。

## 色板与道具

- 纸：底色 `#F2ECDE`–`#F3EBDD`（rgb .95/.925/.87），云状斑驳 ±7 %，三个纤维方向（+1.8 % 亮度），暗角约 .22。墨色从冷灰 `rgb(.52,.55,.58)` 到暖黑 `rgb(.075,.068,.062)`。朱砂 `#B02E22`：印章和主角的**剑穗**，它让人在远景中一眼找到主角，并与最后的印章呼应。
- 合成器参数：湿润洇染是 1:1 下约 5 px 的 12 采样带噪泊松模糊；边缘色素 = 小模糊 − 大模糊。
- 墨色实际用法：焦墨用于书法、剑、帽檐线、苔点；浓墨用于轮廓和斗笠；重墨用于衣褶和剑鞘；淡墨用于山体和袍子的渲染；清墨用于远山、面部、雾气。
- `ink.js` 中的笔触剖面：`brush`、`tip`、`nail`、`lens`、`fan`、`rise`、`robe`、`even` + 逐点压力；饱墨笔触使用 `darkDir`、`side`、`brWet`（它们的笔毛进入湿层）；笔身填充按 `(1-dry)^1.6` 衰减；`dry` .3 = 有纹理，.6+ = 飞白。
- 山（`land.js`）：逐像素计算一次并缓存，尖锐的指数型山峰带 3 个八度的粗糙度；远山色调 .12–.16，无纹理，近山 .4–.5，有纹理；山脉两端用水平 alpha 遮罩淡出，绝不靠让山脊倾斜（那样会穿过江面）。松：一根弯曲的饱墨树干、几根出锋的枝条、扇形的松针簇。芦苇：长长的出锋笔触 + 透镜形叶子，只用在前景。
- 水：每次落脚处一圈墨环，一笔画 1.86π，留一个开口，r ∝ age^0.6，约 2.4 s 淡出。
- 巨浪：一个淡淡的湿润主体 + 4–5 条在浪尖卷曲的巨大饱墨笔触 + 几条细浪线 + 不规则墨点构成的浪花。
- 主角（`hero.js`）：100 单位的骨骼（臀、胸、头、手臂、腿、衣摆点、飘摆、剑鞘、飘带）。斗笠 = 一块湿墨 + 两条干笔脊线 + 一条焦墨帽檐线；袍子 = 一块淡墨 + 两条饱墨笔触；腿和剑用焦墨；一条飘带在风中。脸始终藏在斗笠下；五官只出现一次（剑眉、丹凤眼睑、一条鼻线、下垂的胡须）。
- **轻功飞跃**：身体前倾约 30°，一膝收起，另一条腿拖在后面，袍子向后拉成一大块带深色后缘的淡墨，衣袖飘扬。步伐循环：点水（14 %）→ 腾起 → 滑翔（45 %）→ 下落；高度为 `sin(π·phase)`；每次点水一圈墨环。
- 写下的“水”：依 Ma Shan Zheng 字体描摹，`solid: true`，干度 .17，收笔出锋收窄到 .12–.18，45° 藏锋起笔。
- 稳定笔触：`gapLen` 为固定参考长度；抖动以 5 张画为一个循环。
- 被劈开的巨浪：上半部分升起并旋转，下半部分塌落并压扁，两条撕裂边缘都有卷曲的浪尖和淡墨块；墨点沿剑的方向飞溅并受重力影响。
- 墨晕：遮罩为 `d·(0.62 + 0.8·fbm)`；元素晕染使用 1/4 分辨率遮罩配合 `destination-in`。

## 片尾卡

标题：直接写在手卷上的两竖列（英文字母旋转 90°，Cormorant SC 600，宽字距）+ 印章；它从湿到干淡入，摇镜开始时蒸发消失。字幕：Cormorant Garamond 斜体 500，46 px，1 px 字距，约 0.35 s 内“晾干”。

片尾卡：整幅手卷放在深色桌面上，带绫绢镶边和轴头；下方用淡纸色写着 “CHINESE INK WASH”（Cormorant SC 600，44 px，14 px 字距）和署名行（斜体 30 px）。“LemoLab × Claude Opus 5.5”署名只属于本库的示例片；用户的影片不带 LemoLab 署名，也不复制这张卡。

## 构建说明

```
styles/ink-wash/demo/
  ink.js     brush engine (strokes, bristles, masses, blots)   comp.js    WebGL rice-paper compositor (bleed, edge, paper, bloom)
  hero.js    xieyi figure rig + poses                           face.js    close-up face (one use)
  land.js    mountains, cun, cliffs, pine, reeds, ripples       wave.js    gestural wave
  glyph.js   "水" traced from Ma Shan Zheng + the cut stroke    seal.js    vermilion seal
  world.js   the handscroll world, reveals, shots 1–2           cross.js   crossing + rising (shots 3–4)
  climax.js  silence, writing, the cut (5–6)                    passage.js parted river, bow, scroll, end card (7–8)
  story.js   timeline (single source of truth)                  shots.js   dispatcher, transitions, subtitle spots, sound events
  subs.js    inscription subtitles   music/score.py  original guqin score   mix.py  foley + voice + music   build.sh
```

1. 先写 `story.js` 的时间（人声时长来自 `core/tts/tts.py`），然后用同样的数字向配乐交代需求（作曲可以并行进行）。
2. 用 `node core/render/still.mjs styles/ink-wash/demo --range a:b:1` + `core/render/sheet.py` 生成总览图；用 `?test=sheet|pose|shui|frame` 页面做设计工作；`?nosub=1`、`?poster=1`。
3. `node core/render/events.mjs` → `mix.py` → `video.mjs --fps 24 --workers 3`（1152 帧 ≈ 60–130 s）→ `mux.sh … 24 0`（颗粒 0：纸张已在着色器中）。
4. 或者直接运行 `sh styles/ink-wash/demo/build.sh`。

与这部示例片道具相关的坑：
- 在摇镜镜头中，字幕继承了世界镜头的变换，滑出了屏幕。
- 用 `flip=-1` 画的悬崖把人物放到了半空中；悬崖多边形的背面露出一条笔直的竖边；一块岩石的底部被图层画布的下边缘截断 → 翻转后再计算屏幕范围，把背面画成斜的，用 `destination-in` 渐变淡出图层底部。
- 那一笔还在横穿画面时，巨浪就已经开始裂开。
- 某个场景偶尔有很重的逐像素步骤，可能超过 Playwright 默认的截图超时；重试静帧渲染即可（帧本身是确定的）。
