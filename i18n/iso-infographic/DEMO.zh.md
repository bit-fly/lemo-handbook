# 等距信息图 — 我们的示范片

这只是众多可能中的一个例子。不要照搬它的故事、结构、镜头、道具或时间安排。

示范片：*From Bean to Cup*（从咖啡豆到杯中）（58.8 s）· `iso-infographic.mp4` · 源文件见 [`demo/`](demo/)


示范片用 45–60 s 讲述一颗咖啡豆从农场到杯中的旅程：一张等距地图、一个连续镜头、一条横贯方形底板的 Z 字形路线。

## 故事与结构

整部片子就是**一张等距地图**：一块方形的微缩场景底板，投影后正好是一个接近 16:9 的菱形。流程中的每一步都是底板上的一个**站点**。一条虚线**路线**把各站点串起来。镜头从不剪切，而是沿着路线推镜、拉镜、摇镜和跟拍；每个站点都用同一种方式讲述：**一个动作、一个标签、一个由图标组成的数字。**

它为什么成立：
- **扁平、真正的等距。** 没有透视，没有描边。形体之间只靠每个面的三种色调来区分。
- **信息图的"家具"是画面的一部分。** 引线、标签图钉、剖切线、带阴影线的剖面、追踪圆环和图例都生长在地图上。
- **一个被追踪的主体。** 用一个"你在这里"的圆环，在整个系统中始终跟随同一个物体（一颗豆子、一个包裹、一滴水）。这就把一张图解变成了一个故事。

示范片如何运用这种媒介：

| 原生能力 | 故事用途 |
|---|---|
| **一镜到底的微缩场景** | 任何流程都能变成横贯一块底板的路线。把路线布置成**横贯方形底板的 Z 字**（远角 → 右侧 → 穿过中间 → 近角）。直条形底板会浪费最后的拉镜，而方形底板正好填满 16:9。 |
| **剖切** | 一个统一的动作：一条虚线**剖切线**画出，靠近观众的外壳**沿法线方向滑出并淡出**，留下**带阴影线的剖面边缘**。可用于水果、船体、集装箱、麻袋、建筑或机器。 |
| **Isotype 数字** | 每个站点都有一个用相同图标绘成的数字，每次排列方式都不同：3×7 的太阳日历、14 个集装箱图标（1 = 1,000）、昼夜图标一行、一支上升的温度计、70 颗豆子**排成咖啡杯的轮廓**，以及一条 11 格的距离条。 |
| **聚焦 + 背景** | 在情感高潮处，**让除主体之外的一切褪色**（引擎的"单色保留"钩子）。这是信息图自己说"就是这一个"的方式。 |
| **画中画** | 细节标注：一条引线从地图上长出，末端是一个展示特写的圆形插图。系统与个体同时出现在画面中。 |
| **尺度揭示** | 结尾拉回到整块底板。路线逐站点亮，所有标签同时出现在画面上，于是最后一帧就是一张完成的信息图。 |

**故事结构（已在示范片中验证）：**
1. 以主体落入一只手中的大特写开场，配一个标签：**0 km**。
2. 拉镜到第一个站点并出片名。
3. 数字逐站增长（2 颗种子 → 每袋 400,000 颗豆 → 14,000 个集装箱）。主体被淹没了。
4. 在最繁忙的地方，穿过层层嵌套的剖切潜入并找到它：寂静，以及仅剩的一抹颜色。
5. 全片最响的声音打破寂静，镜头猛地弹回。时间跳跃就藏在这次下潜里。
6. 加工转化的站点，第二次寂静，然后是温和的收尾。
7. **呼应：** 同样的特写构图，换了一只手、换了一个物体，标签现在显示的是总数。拉回到完整地图。

**数字必须对得上。** 这种风格靠可信度立足：400 + 10,500 + 100 = 11,000 km，Isotype 条也按同样的比例上色。把流程的真实顺序放到画面上（示范片中，豆子是以生豆形式运输、在目的地国家烘焙的）；如果你改动了某个设定，要在你的方案里说明原因。

## 镜头

镜头由一个世界中心点加上一个**对数插值的缩放** k（每单位像素数）构成。示范片的 k 从 3.75（整块底板）到 8,000（一颗豆子）。

| 节拍 | 镜头 |
|---|---|
| 开场 | 手的大特写（k ≈ 600），轻微漂移。镜头位于掌心上方 0.17 单位处，让枝条能放进画面上方。 |
| 片名 | 拉镜 ×35 到第一个站点（位置用 eio 缓动，缩放按对数线性），同时片名牌升起。 |
| 站点 | 停留在全景，并打开一个圆形插图展示细节。 |
| 转场 | 下降（升降镜头）或跟随一辆交通工具；下一站的声音先到。 |
| 繁忙站点 | 先锁定，然后随着系统被填满而拉镜。 |
| 喘息 | 在空旷水面上一段长长的横向跟拍。 |
| 快进 | 带着尾迹和一行昼夜图标跟拍。 |
| **下潜** | 穿过嵌套剖切的三次推镜，**慢 → 较快 → 最快**（0.9 s、0.6 s、0.6 s），让它读起来像坠落。每深入一层，就有一件乐器退出，低通滤波也收得更紧。 |
| 寂静 | 缓慢推镜（k 3,200 → 8,000），同时除主体外的一切逐渐褪色。 |
| 弹出 | 1.2 s 内拉镜 ×470，在对数缩放上做缓出。任何会在拉镜过程中扫过画面的高大物体都要渐显进入。 |
| 呼应 | 以完全相同的构图推镜到第二只手。 |
| 结尾 | 拉回到整块底板；片尾卡放在空出的奶油色角落里。 |

在关键时刻，让主体至少占画面高度的 1/3（双手、烘焙滚筒、带圆环的豆子），并保持底部 170 px 留给字幕。

- **没有线引导，就什么都不动。** 路线比故事稍稍先画出来，引线先长出来插图才打开，剖切线先画出来外壳才滑开。
- **剖切时序：** 剖切线 0.3 s → 外壳滑出 0.35 s（缓出，alpha 在 10 % 到 75 % 之间从 1 → 0）→ 带阴影线的剖面边缘在最后 40 % 中淡入。
- **Isotype 填充：** 图标以回弹缓动（过冲 2.2）弹出，每个十六分音符一个。递增计数的数字（km、°C）在同一时段内跑完。
- **累积 = 加速。** 示范片里，集装箱先在四分音符上落下（由起重机吊放），然后是八分音符，再然后是四波十六分音符，每波约 44 箱（下落 7 个单位并带一个小回弹）。眼睛能感受到系统正在接管一切。
- **主体要"表演"：** 落地时挤压（18 %）加两次小回弹；寂静段随船体摇晃而摆动（±0.09 rad）；在烘焙机里变色（绿 `#A9B27C` → 黄 `#D9C27A` → 肉桂色 `#B07A45` → 棕 `#6A3B22`）；一爆的噼啪声以放射状墨线短刻表现。
- **交通工具**沿折线路径以缓入缓出移动，并朝向切线方向。船转弯前，先把它移离码头；否则船尾会扫过起重机。

## 配乐结构

- **音乐优先。** `demo/timeline.js` 是时间的唯一可信来源。配乐、拟音事件和检查都读取它（`tools/cuecheck.py`：68 个提示点，0 ms 偏差）。
- **配乐：** 原创**原声世界律动**，约 100 BPM。尼龙弦吉他指弹（D–A–Bm–G）和卡林巴，接着是沙锤、邦戈鼓、卡洪鼓反拍和康加鼓，在港口和海上再加入立式贝斯（`jazz_bass`）。快进段带上 B 小调色彩。不用钢琴，不用弦乐铺底。卡林巴上一个三音**咖啡豆动机**（A4–F#4–D4）出现在第一次落地、最后的标签以及结尾的站点琶音中。咖啡馆段从 100 BPM 放慢到约 70 BPM 并停下；寂静之后，一把吉他以 80 BPM 重新开始。
- **两段真正的寂静：** 下潜段（30.0–33.6 s；只有线条和一声 −66 dB 的船体吱嘎）和第一滴咖啡落下前（45.3–45.9 s；数字静音）。每段寂静之后的第一个声音都是全片最重要的声音之一：**船的汽笛**（比其他一切高约 10 dB；D2 锯齿波叠加，带失谐和 2.8 s 尾音）和**一滴落进空杯的咖啡**。
- **三个层次：**
  - **环境声底**，每个站点一种，互相交叉淡化：山风、树叶和鸟鸣；港口、海鸥和起重机蜂鸣；海浪涌动；城市嗡鸣；咖啡馆低语；清晨麻雀（与山上相同的鸟声合成器，调高音高）。
  - **按材质分类的拟音：** 茎秆的纤维断裂声、果实落在掌心的肉质闷响、果实在筛网上的颗粒碰撞声、豆子倒进黄麻袋的声音、集装箱门和落地的非谐波钢铁泛音、麻布撕裂声、随旋转的滚筒隆隆声、干脆的爆裂声、磨豆机的尖啸加碾碎声、压粉的"咚"声、陶瓷的"叮"声，以及音高上升的倒水声。
  - **音乐**，在人声下压低约 8 dB。旁白说话时，环境声压低 7 dB，鸟声静音：一个词末尾的鸟鸣曾让 whisper 把 "travel" 听成 "travels"。
- **声音转场：** 港口出现前 0.6 s 先进港口噪声（J-cut），烘焙滚筒壁打开前 0.6 s 先进滚筒声，汽笛尾音延续进城市（L-cut）。最后拉镜时，每个站点奏响一个卡林巴音。
- **人声：** Kokoro `bf_alice`，语速 0.88–1.0，六句短台词，每一句都在干声和最终混音中各经过一次 whisper 校验。

## 色板与道具

- **投影：** 真正的等距，轴线 30°。`sx = (x − y)·cos30°·k`，`sy = ((x + y)·½ − z)·k`。世界坐标 x 指向右下，y 指向左下，z 向上。画家算法深度 = x + y + z。永远不要旋转或倾斜视角。
- **每个面三种色调**（顶面亮 / 左面 = +y 面中间调 / 右面 = +x 面暗），按各面的法线选取：
  - 咖啡红 `#CF5140 / #B3352B / #8C2620`
  - 叶绿 `#7BA75F / #5E8C4A / #476F37`
  - 海蓝 `#5A9BCB / #3C7FB1 / #2D6390`
  - 奶油色 `#FBF4E6 / #F2E6D0 / #D9C8A9`
  - 土壤色 `#A77850 / #8A5B3A / #6A432A`
  - 芥末黄（起重机、道路）`#E9BE5C / #D9A53A / #B0832A`
  - 墨色 `#2E2522`
  - 其他颜色由 `tri(c)` 生成：顶面向暖白混合 20 %，暗面向 `#231A2C` 混合 22 %，让阴影略微偏冷。
- **实体不加描边。** 墨线（2 px）只留给信息图元素：引线、图钉、剖切线、圆环、路线和标签。
- **底板：** 漂浮在奶油色 `#F2E6D0` 背景上，背景有一层淡淡的等距点阵和柔和的模糊投影。底板两个正面露出三层土壤和卵石，海与边缘相接处则是三种蓝的水柱。海岸堤岸只在面向观众的地方绘制。
- 需要在全景中被找到的**站点**，配一块**带墨色虚线轮廓的浅奶油色底牌**和一种强调色（砖红色的烘焙坊、红白条纹遮阳篷的咖啡馆）。站点周围的建筑要保持低矮。
- **人物：** Monument-Valley 式的极简广告牌人物，圆形的头、两种色调的锥形身体、一笔粗粗的手臂，用帽子或发型来区分身份。没有五官。以 12 fps 步进。
- **主角特写（手）：** 扁平的多面块状造型，三种肤色（掌心朝上为亮面，侧面中间调，底面暗），袖子用角色的颜色，手指是圆头的两节胶囊，朝观众方向弯曲。开场和结尾的手**姿势、机位、缩放和标签位置完全相同**。只有肤色、袖子和物体不同。
  两只手并排对比：[`demo/stills/frame_v2_hands.jpg`](demo/stills/frame_v2_hands.jpg)（3.4 s 和 50.9 s）。
- **标签（图钉）：** 一个圆点（墨色圆环、奶油色填充）→ 一条竖直引线 → 一条水平线 → 文字。标题用 Jost 600，全大写，字距 0.12 em。数字用 Jost 400，44 px，单位用 Jost 500，半号大小。文字带 7 px 的奶油色光晕，在任何颜色上都清晰可读。图钉可以朝上或朝下、朝左或朝右；按站点选择方向，让标签永远不遮住主体。
- **片名：** Jost 700 的单词被挤出成等距立体块，放在平躺于地面的奶油色底牌上（奶油色正面、咖啡红侧面），每个八分音符出一个词。
- **云：** 扁平的等距云，带伪视差（地面运动的 1.25×）。k ≈ 40 以上时淡出。

## 片名、字幕与片尾卡

- **字幕就是地图标签。** 一张奶油色 `#FBF4E6` 卡片，10 px 圆角，2 px 墨色边框，一个小小的咖啡红等距立方体作为图例色块，墨色 Jost 500，42 px。位于底部居中，距底边 64 px。边框先画出（0.2 s），文字从左到右擦出；退出时下滑 8 px 并淡出。
- 每行停留 ≥ max(1.8 s, 语音时长 + 0.6 s)。字幕行之间、与片名或片尾卡之间都不能重叠。
- **片尾卡 = 地图的图例**，放在空出的奶油色角落里：片名、风格名、带 Isotype 条的总数、"Lemo-Opuscar · LemoLab × Claude Opus 5.5"、演职员。"NOT TO SCALE"（未按比例）既诚实，又是个小玩笑。"Lemo-Opuscar · LemoLab × Claude Opus 5.5" 的署名只属于本库的示范片：用户的影片不带任何 LemoLab 署名，也不要照搬这张片尾卡。

## 我们踩过的坑（示范片记录）

- **Newell 法线与顶点顺序：** 一个盒子的 +y 面被当作背面剔除了。给每个面一个朝外的提示（`out`），并在剔除前翻转法线使之与提示一致。
- **组合物体的画家排序：** 梯田山坡上的灌木出现在了下一层梯田的前面。把整座山当作一个整体来画：每层梯田，然后是它后排的灌木，所有梯田画完之后再从上到下画前排。起重机的吊臂需要很大的深度偏移，才能位于船的上方。
- **半透明的下落箱子看起来像幽灵。** 只用运动，不用 alpha。
- **船头盖在沙滩上**会被读成"搁浅"，哪怕几何上它还在水里。每个船体周围都要留出可见的水面。离港时先平移离开码头再转弯。
- **下潜中的时间跳跃：** 当画面里只剩豆子时，船从大洋中部瞬移到目的地码头。把豆子场**画在屏幕空间里，锚定在被追踪的那颗豆子上**并按 k 缩放；这样它的布局就不依赖船的朝向，跳跃也就看不出来了。
- **主角特写后面的巨大世界几何体：** 在 k = 600 时，一丛灌木就是一个画面大小的绿色圆盘。k 超过 120 时跳过灌木，并在主角层后面画一个纯色背景，随主角层一起淡出。
- **拉镜穿过起重机**会出现一帧难看的巨大吊臂。按缩放让高大物体渐显（`alpha = clamp((80 − k)/40)`）。
- **whisper 与环境底噪：** 一个词之后持续的树叶沙沙声（2.5–7 kHz）会把 "travel" 变成 "travels"。在对白下面，高频声底要压得非常低。
- **画成白盒子加红屋顶的机器会被读成房子。** 用钢灰色、深色前面板，顶上放杯子，再加一个冲煮手柄。
- 在 zsh 中，失败的通配符会中断 `&&` 链，所以 shell 循环要通过 `bash -c` 运行。

## 构建说明

```
styles/iso-infographic/demo/
  timeline.js   tempo grid, cue times, subtitles, km numbers (single source of truth)
  engine.js     the style: projection, camera, 3-tone solids, labels, insets, cutaways, Isotype, people, any-shape extrusion
  world.js      the board: coasts, terraced hill, beds, roads, ports, ship, cranes, city, cutaway buildings, hold/containers/sacks
  hero.js       close-ups: palm, picking fingers, branch, cherry, cup, km tag
  film.js       camera path, story state, stations, overlays, subtitles, title/end card, sound events
  music/score.py   original score (sampler)      mix.py   ambience + foley + voice + ducking
  tools/        cuecheck.py subs.py final_asr.py review.sh      tests.js   hero + any-shape test scenes
```
1. 先写 `timeline.js` 和提示点表。用世界单位把底板画成正方形（S = 240）。先布置 Z 字路线，再布置站点。
2. 搭建各站点场景，用 `?k=…&cx=…&cy=…` 静帧在各自的缩放下逐一检查。单独渲染两个主角特写（`?test=hero`、`?test=hero&end=1`），直到二者一致。
3. `sh demo/build.sh` 大约 2 分钟重建全部内容：TTS → whisper → 配乐 → 事件 → 提示点检查 → 混音 → srt → 渲染（2 个 worker 约 35 s 渲染 1,411 帧）→ 封装（−14 LUFS，颗粒 0）→ 最终 whisper → 静帧。
4. 用 `bash demo/tools/review.sh out/revN 6 $(seq 0.3 1 58.3)` 至少审看两遍，并从封装好的 mp4 中截取下潜、弹出、落地和倒咖啡段的帧条。

## 引擎参考

`demo/engine.js` 是无依赖的 ES 模块代码，基于 Canvas 2D。所有内容都先入队并按深度排序，直到 `flush()`。

| API | 作用 |
|---|---|
| `new Iso(ctx, W=1920, H=1080)` | 引擎实例。`iso.cam = {x, y, z, k}` 设置屏幕中心对应的世界点和缩放（每单位像素数）。 |
| `iso.P(x,y,z)` / `iso.unP(sx,sy,z)` | 投影与反投影。 |
| `iso.push(ox,oy,oz,rot,s)` / `iso.pop()` | 局部坐标系（平移、绕 z 旋转、缩放），用于车辆和船只。法线也会一起旋转，因此任何朝向下明暗都正确。 |
| `iso.box(x,y,z,w,d,h,tri,{decal,bias,layer})` | 轴对齐盒子，三色调。`decal(I)` 在其表面上绘制（窗户、肋条）。 |
| `iso.prism(pts2d,z,h,tri)` | 挤出任意底面多边形。方向自动判断，每个侧面按其法线着色。 |
| `iso.cyl(x,y,z,r,h,tri,{axis:'z'|'x'|'y', n, spin, stripe})` · `iso.cone(...)` · `iso.roof(...)` · `iso.sphere(...)` | 圆柱（直立或横卧，带旋转条纹）、圆锥、双坡屋顶，以及带亮面顶盖和暗色月牙的扁平圆盘球体。 |
| `iso.flat(pts,z,color)` · `iso.line3(pts,color,px,{dash})` · `iso.bill(x,y,z,fn)` | 地面贴花、3D 折线，以及广告牌（随缩放变化的 2D 绘图：人物、手）。 |
| `iso.text3(str,x,y,z,{plane:'xy'|'xz'|'yz', size, extrude, tri})` | 世界平面上的等距文字，可选挤出。 |
| `iso.desat = 0..1`、`iso.keep = true` | **单色保留钩子：** 所有绘制内容都向暖灰褪色，只有以 `keep = true` 绘制的项目除外。 |
| `iso.sub(fn)` | 已排序的子队列，用于绘制在后墙与前墙之间的室内。 |
| `tri(hex)` · `PAL` | 三色调生成器和色板。 |
| `pin(iso,x,y,z,{title,num,unit,dir,up,len,a,icons})` | 标签图钉，带显现参数 `a`。`icons(g,x,y,dir)` 在其下方绘制一行 Isotype 图标。 |
| `inset(iso,ax,ay,cx,cy,r,a,drawIn)` | 带引线的圆形细节标注。 |
| `cutLine(g,pts,a)` · `hatch(g,pts)` · `ring(g,x,y,r,a,t,tag)` | 剖切线、带阴影线的剖面、带标签的旋转虚线追踪圆环。 |
| `ICON.sun/moon/box/sack/bean/cherry(g,x,y,size,lit)` · `iconGrid(g,x,y,n,lit,cols,gap,draw)` | 使用同一套三色调语言的 Isotype 图标；点亮数量 m 可以是小数（弹出中）。 |
| `person(g,{body,hat,hair,skin,arm,face,h,basket,apron,tool})` | 用于 `iso.bill` 的极简人物。 |
| `shape(iso, pts2d, [x,y,z], {color, depth, plane, scale})` | **用这种风格绘制任意形状：** 2D 轮廓变成按三色调规则着色的等距实体。`sparkPath(n,r,inner)` 和 `cursorPath(h,w,x,y)` 是现成的轮廓。 |

最小示例：一个暖橙色 `#D97757` 四角星芒，带一条光标尾巴，放在底座上并加标签（`?test=spark`，输出见 `demo/stills/engine_shape.jpg`）：

```js
import { Iso, PAL, shape, sparkPath, cursorPath, pin } from './engine.js';
const iso = new Iso(ctx); iso.cam = { x: 0, y: 0, z: 2.5, k: 70 };
iso.box(-6, -6, -1, 12, 12, 1, PAL.cream);                                          // plinth
for (let i = 0; i < 5; i++) iso.box(-5 + i * 2.2, 3.2, 0, 1.6, 1.6, .6 + i * .5, PAL.blue);
iso.keep = true;                                                                    // the one element that keeps its colour
shape(iso, sparkPath(4, 2.2, .22), [-1, -1, 5], { color: '#D97757', depth: .9, plane: 'xz' });
shape(iso, cursorPath(2.4, .45, 2.7, 0), [-1, -1, 5], { color: '#D97757', depth: .9, plane: 'xz' });
iso.keep = false;
iso.desat = 0;          // set 1 to grey everything except the spark (focus + context)
iso.flush();
pin(iso, 0, -1, 7.6, { title: 'ANY SHAPE', num: '#D97757', dir: 1, up: 90, a: 1 });
```
