# 等距绘本 — 我们的演示片

这只是众多可能中的一个例子。不要照搬它的故事、结构、镜头、道具或时间安排。

演示片：*Seventy-Two Seats*《七十二个座位》（59.8 s，中文旁白，双语字幕）· `isometric-picture-book.mp4` · `isometric-picture-book.srt` · 源码在 [`demo/`](demo/)

## 故事与结构

登机总是要很久，即使按排号顺序叫号也一样。影片先展示原因（只有一条过道：一个人停下来放行李，后面所有人都被挡住，而且被叫到的人都奔向同样的那几排），再给出另一种顺序（靠窗座位先上，排队时前后两人隔开一排），这样六个人可以同时放行李，客舱几乎只用一半的时间就坐满了。

两种顺序和两个时间都来自一次真实测试：Steffen & Hotchkiss（2012），一个 12 排、每排六座、只有一条 21 英寸过道的模拟客舱，72 名乘客；按区块后排先上用时 6:54，靠窗先上且隔排登机用时 3:36（来源和引文见 [`demo/FACTS.md`](demo/FACTS.md)）。B12 登机口、飞机及其涂装都是虚构的；没有出现任何航空公司。

结构：问题（为什么这么久？）→ 通常的答案（后排先上）→ 为什么会堵（一条过道；一人停下，全体等待；大家都奔向同一段）→ 6:54 → 如果换个顺序呢？→ 靠窗先上，隔开一排 → 六人同时 → 3:36 → 两个时间并排 → 真实测试和它的 72 名乘客 → 答案：不是人多，而是同一段过道 → 署名。

用到的天然招式：地面文字（标题、关键词、数字、署名）；多米诺起立；揭盖（两次）；顺序点亮；顺序箭头；编织式填充；地面上的条形；人即样本；被堵的那一段点亮为“站这里”。

## 配乐与声音结构

100 BPM，F 大调，垫在人声之下。开场 F → B♭；登机口处是队伍下方一段拨弦行进；机顶打开时一记竖琴刮奏；队伍等待时一记卡住的拨弦短促音和一个持续的大提琴 D；延时段用钢琴十六分音符，6:54 处一个低音 Dm；倒放时用一秒倒放的配乐，座位亮起时一串钟琴；第二个登机口处上行的颤音琴 F A C F；编织式填充中每一波一个六音颤音琴和弦，下面垫拨弦和沙锤；3:36 处 F 加钟琴；条形下 B♭ → Gm，括号处 C；72 名乘客下 F/A，呼应镜头下 Dm，署名下一个长 F。每个镜头下都有柔和的大提琴根音持续，并跨过每一次剪切。音乐在旁白下闪避 16 dB，在台词之间回升。混音：封装前整体 −16.0 LUFS，真峰值 −2.1 dBFS（英文版：−16.0 / −2.3）。

## 色板与道具

色板见 STYLE.md 第 3 节（纸、水泥、地毯、墨、柿红强调色、主体绿、姜黄色地标线）。道具：一架虚构的尾吊发动机支线客机，T 型尾翼，白色机身带两条绿色条纹；12 排 3 + 3 绿色座椅，奶油色头枕套，低靠背；剖切边缘上的行李架，近侧每排一个；一座 7.5 m 长的廊桥，远侧为玻璃墙，近侧为矮墙；一个登机口，有三条涂漆通道、分组标牌、一个服务台和三排浅绿色座椅；服务道路上的一列行李车；停机坪上的两根时间条和一个由 72 人组成的客舱形队列。人物：72 人，四种上衣，每人一只拉杆箱。

## 片尾卡

在机位上，"LemoLab × Claude Opus 5.5" 用地面文字的衬线字体逐词落下，停留 3 s，完全在画面之内。"LemoLab × Claude Opus 5.5" 署名只属于本库的演示片；用户的影片不带 LemoLab 署名，也不要复制这张片尾卡。

## 构建说明

- `sh styles/isometric-picture-book/demo/build.sh`（中文，`isometric-picture-book.mp4`）或 `build.sh en`（`isometric-picture-book-en.mp4`，复用已渲染的画面）：字体（从 google/fonts 下载，Noto Serif SC 由 `tools/subset.py` 子集化）→ 采样包 → 旁白（edge-tts，需联网）+ 语音校对 → `tools/vo_lengths.py`（中文人声必须仍与 `VO_DUR` 匹配）→ 事件 → `audio.py`（旁白、配乐、拟音、闪避、响度）→ 画面 → 母带 → readcheck → `tools/srt.py`（双语 .srt）→ 海报帧和图库静帧。
- 文件：`engine.js`、`kit.js`（风格套件，双行字幕）、`plane.js`、`places.js`、`film.js`（由旁白生成的时间线、排队模拟、14 个镜头函数、`texts()`、`events()`）、`main.js` / `index.html`、`audio.py`、`lines.json` / `lines_en.json`、`FACTS.md`、`tools/`。
- 检查：readcheck 对所有场景内文字都通过（字幕提示跟随旁白并输出到 .srt）；`tools/motion_check.mjs` 报告没有跳变、没有走走停停的步进，也没有两个站立的人距离小于 0.35 m。渲染约每帧 1080p 30–60 ms。
- 演示道具说明：在每个越过航站楼玻璃看过去的镜头里，玻璃都被切成一道矮墙；机身旁的文字保持在廊桥和机翼之间（单行，必要时缩小）；结论条形放在机头前方足够远处，使机头永远不会遮住客舱图标；登机口的座位号和分组标牌只在各自的镜头里出现。
