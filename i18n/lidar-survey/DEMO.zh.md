# LiDAR Survey — 我们的示范片

这只是众多可能中的一个例子。不要照搬它的故事、情节走向、镜头、道具或时间安排。

示范片：*The Fields Under the Forest* 《林下的田》（40.0 s）· `lidar-survey.mp4` · 源码在 [`demo/`](demo/)

从空中看，康涅狄格州 Ashford 的一片区域只有森林。一次激光测绘把照片变成点，一个切割平面一层层剥去树冠，剩下的地面凝结成一个表面，上面立着石墙：这是曾经在此的农场的田地系统，在 0.74 km² 内描出了 3.4 km 的石墙。其中一段墙被剖开测量；小镇的历史用两个数字讲完；森林又重新长回到墙上。屏幕上是中文，旁白是英文，双语字幕（上行中文，下行英文）。这是一部用公有领域的测绘数据和影像制作的非官方影片；U.S. Geological Survey、USDA 和 Ashford 镇并未制作或认可它。

## 故事与结构

一句话梗概：从空中看只有森林；去掉所有打在树上的回波，地面仍保留着田地的石墙。

情节走向：一个论断（一张 2016 年 7 月的航拍照片，满眼只有树冠）→ 媒介改变（一条扫描线把照片变成 2016 年春季的激光雷达点云；27.6 % 的回波到达了地面）→ 剥离（一个水平面随拍点从 30 m 逐级降到 0 m，其上方的回波升起并发光，一把附带树冠高度直方图的标尺跟随它）→ 在裸露的地面回波上几近静默 → 转折（第二次扫描把地面回波凝结成一个掠射光照亮的表面；一声撞击）→ 摄影机上升时石墙一段接一段亮起 → 测量（描出 3.4 km；用 1,451 个原始地面回波剖开一段墙：高 0.56 m，半高处宽 2.5 m）→ 历史（Ashford 1870 年：67.3 km² 开垦的农田；2006 年：80.2 km² 森林）→ 森林以幽灵般的形态在发光的石墙上重新生长；片尾卡。

用上的原生招式：开场的*照片变点云*；作为标志镜头的*树冠剥离*；转折处的*点云凝结*；细节部分的*剖面*；贯穿始终的*窗口*（测区作为昏暗、未剥离点云中的一座舞台）；作为结尾的*重新生长*。

每个数字及其来源都在 [`demo/FACTS.md`](demo/FACTS.md) 里；测得的数值在屏幕上标注为测量值或描绘值。

## 镜头

一个连续的摄影机运动（目标点、距离、航向、俯仰上随时间变化的 C1 样条）。时间单位为秒。

|---|---|---|---|---|

| 3 | 6.9–10.0 | 点云；读数 打到地面的回波 27.6 %（7.5 落定） | 升降下降到低角度斜视，105 m，俯仰 15° | 树冠作为地面回波之上的一层 |

## 配乐结构

96 BPM，4/4（一拍 0.625 s）；每个画面提示点都落在拍点或半拍上（`demo/tools/cuecheck.py`：17 个提示点均为 0 ms）。前半段干燥的部分为 D 小调，从转折处起为 F 大调。

| 段落 | 时间 | 音色 | 备注 |
|---|---|---|---|
| 树冠 | 0–3.75 | 森林底噪（经过滤波的林间风声、阵风、合成的两音鸟鸣），Dm 铺底 | |
| 激光 | 3.75–10 | 八分音符的 FM 提示音（D5 A5 F5 A5 …），扫描扫频 700 → 3800 Hz 带细碎噼啪声，从 5.0 起八分音符的脉冲贝斯 D2/C2 | 森林底噪在 5.2 前淡出 |
| 剥离 | 10–13.1 | 滴答声由八分 → 十六分 → 三十二分音符，每层一声 FM 提示音 D6 A5 F5 D5 A4，上行的闪烁扫频 | 通过细分来加速 |
| 静默 | 13.1–14.4 | 只有空气底噪（比节目中位电平低 −22 dB），从 13.4 起一段反向噪声渐强 | |
| 转折 | 14.4 | 底鼓 + 大鼓 + 定音鼓 F2，一段回落的扫频；弓奏颤音琴 A4/E5 | 在 −16 dB 的下沉之后，比最响的时刻低 −1.9 dB |
| 石墙 | 15.6–20 | 马林巴在半拍上走 F 大调五声音阶；铺底 F–Dm–B♭–C，脉冲贝斯回归 | 唯一的木质音色 |
| 测量 | 20–28.75 | 3.4 滚动时的棘轮咔嗒声，落定时 C6 提示音；24.1–24.4 声音被抽空，剪辑点上扫频 + 定音鼓 D2 + 底鼓，读数出现时 A5 提示音 | |
| 历史 | 28.75–35.6 | 每根条形配一段上行的正弦滑音，落定时配马林巴 | |
| 结尾 | 33.75–40 | 重新生长配颗粒音；从 34.4 起森林底噪 J 剪辑切入；F 大调和弦（马林巴、铺底、弓奏颤音琴、轻柔定音鼓） | |

混音（在 `mix.py` 中）：音乐比人声低 −10 dB，人声说话时再闪避约 5 dB，脉冲、拟音和底噪更低；只对音乐、脉冲、拟音和底噪做总线压缩；超低音做 38 Hz 高通（撞击时 46 Hz），62 Hz 以下 −5 dB 搁架；母带级处理到 −14.4 LUFS，真峰值限制器设在 −4.6 dBTP，让 `mux.sh` 保持线性。成片测得 −14.0 LUFS，峰值 −3.9 dBFS，LRA 2.4 LU（撞击和静默用 `demo/tools/audiocheck.py` 检查）。

## 调色板与道具

- 背景 #05080A；树冠按离地高度（0–28 m）渐变 #1F3F35 → #5C9A7A → #E2F3DC，强度映射到明度；地面回波 #C8B38C；表面 #BDB5A6，光源方位角 315°、仰角 26°；前沿 #D4FFF0；点缀色 #FFB347（石墙、读数、剖面）；图表绿 #83C495。
- 道具：2016 年 NAIP 照片覆盖在 1 m 树冠表面上；4,789,797 个回波；0.5 m 地面模型；22 段在局部起伏模型上手工描绘并吸附到墙脊的石墙（`demo/data/walls_traced.json` → `walls.json`）；C 墙的横截面（`data/profile_C.json`）。
- 测区窗口：x < 235 m（其东侧是一条碎石小路和房屋，保留为昏暗的未剥离点）。
- 旁白：Kokoro `bm_george`，语速 1.0。

## 片尾卡

在树冠重新生长时，位于压暗的田地系统上方的左三分之一处：林下的田（Noto Sans SC 500）、*The Fields Under the Forest*、一条短短的琥珀色横线、`LIDAR SURVEY · 点云测绘`、`LemoLab × Claude Opus 5.5`。4.1 s。"LemoLab × Claude Opus 5.5" 这一落款只属于本库的示范片；用户的影片不带任何 LemoLab 署名，也不要复制这张卡。

## 构建说明

```
demo/
  build.sh          one command: (data) → voice → speech check → cues → events → video → mix → master → .srt → checks → poster
  index.html        two canvases (WebGL scene, 2D overlay), fonts
  film.js           render(t): points / surface / photo shaders, camera spline, fronts, cutting plane, overlay, subtitles, EV
  timeline.js       beats, cues, peel steps, narration, camera keys (single source; tools/export.mjs → timeline.json, cues.json, voice/lines.json)
  mix.py            score, foley, beds, voice, mix → out/mix.wav + out/stems/
  data/             walls_traced.json (hand tracing), walls.json, profile_C.json, facts.json (all on-screen numbers)
  tools/            fetch_ept.py, terrain.py, load.py, walls.py, trace.py, profile.py, build_data.py, fetch_naip.py, fonts.py,
                    scout_dem.py (finding the site); export.mjs (voice/cues); cuecheck.py, subcheck.mjs, audiocheck.py, motioncheck.py (checks)
  assets/raw/       ept/ (EPT nodes), work/ (DTM, relief), build/ (points.bin, ground.bin, canopy.bin, naip.jpg), fonts/, .venv (laspy, lazrs, scikit-image)
  FACTS.md, CREDITS, stills/styleframe.jpg
```

- `sh demo/build.sh` 在 Apple silicon 上约需 5 分钟（画面用 3 个 worker 约 30 s 渲染完；Kokoro 和 Whisper 检查占去其余大部分时间）。如果还没有数据，或设置了 `FETCH=1`，它会先抓取并构建数据（约 3 分钟，`assets/raw/` 中约 350 MB）。
- 字体（Barlow Condensed、IBM Plex Mono、Noto Sans SC）不在 git 里：缺失时 `tools/fonts.py` 会从 github.com/google/fonts 抓取，并对 CJK 字体做子集化。数据工具运行在 build.sh 创建的私有 venv 中（`assets/raw/.venv`：laspy、lazrs、scikit-image、fonttools）。
- 它运行的检查：用 `small.en` 跑 `asr_check.py`（0 处不匹配）、根据真实人声时长检查提示点重叠、提示点网格、用真实字体检查字幕单行宽度（最宽 595 px，上限 1100 px）、`readcheck.mjs`、每秒运动量（没有超过 1 s 的静止段，没有像剪切一样的跳变）。
- 数据说明：EPT 副本是 Web Mercator；所有数据都转换到以 41.8875° N、72.1960° W 为中心的本地米制坐标系。数据提供方的 class 1 混合了植被和建筑；紧贴地面的低矮植被能在 0 m 的切割中留下来，所以平面最终降到 −6 m。地面模型由 class-2 回波（1.3 M）以 0.5 m 三角化生成。
- 本示范片特有的坑：落叶季的树冠从约 150 m 以上看像一张平坦的地毯，因此剥离要贴近低角度拍摄；东北方的一个池塘没有回波（窗口外的一个黑洞）；地面回波规则的扫描线条纹在掠射角度下最明显；第二次扫描必须从画面外稍远处开始，否则最初几帧会跳变。
