## 5. 运动质感

- 30 fps；界面逐帧运动（on ones）；吉祥物位置按其像素网格步进。
- **吉祥物表演**：跳跃时有预备下蹲、起跳拉伸、空中收腿、落地压扁并带阻尼回弹和扬尘。待机时随配乐的节拍呼吸（轻微压扁），并不规则地眨眼。行走靠双腿交替，改变方向时翻转精灵图。
- **眼睛承担表演**（平视 / 左 / 右 / 上 / 下 / 睁大 / 开心 / 闭眼 / 眨眼）：它们看向重要的东西。手臂：放下 / 举起（欢呼）/ 挥手。
- **光标**：平滑、弹簧缓动的路径，点击时轻微下压，绝不瞬移。
- **因果关系**：吉祥物的每个动作都会触发一次真实的界面状态变化；用户的每个动作都是一次光标移动、点击或按键，并显示在 HUD 上。
- 界面的动画与真实产品一致（它自己的菜单、浮层、diff 展开）；不要编造产品没有的花哨效果。



## 6. 镜头语法

录屏软件式摄影机：屏幕内的一个连续长镜头，缩放 ≥ 1，只在章节转场下剪切。开场和结尾由题材决定。

| 运动 | 表达什么 | 可用于 |
|---|---|---|
| 推镜到光标或输入光标 | “事情就发生在这里” | 输入提示；选择菜单项；一个设置 |
| 静止时缓慢漂移 | 我们听旁白时应用依然是活的 | 一句旁白；等待结果 |
| 在窗格之间甩镜（带模糊） | 这里是因，那里是果 | 发送消息 → 结果出现；代码 → 预览 |
| 推镜 + 暗角定格 | 需要记住的那一个承诺 | 一项安全保证；一个价格；一次撤销 |
| 在窗格之间转移焦点 | 注意力在移动，别的都不动 | 读取文件；聊天等待时日志滚动 |
| 拉镜到整个窗口 | 整个工作流尽收眼底 | 一个总结；并行任务；前后对比 |
| 沿列表跟随吉祥物 | 软件在逐项处理 | 扫描结果；一张清单；一次迁移 |
| 分屏重新构图 | 两件事同时进行 | 并行会话；对比两个版本 |

构图：正在讨论的东西和它的字幕绝不重叠；吉祥物绝不遮住要读的文字。转场：章节胶囊标签划像、像素划像、主题切换的揭示圆圈；绝不用叠化或截图。



## 8. 天然招式

一份菜单：按你的演示流程需要挑选。

- **匹配剪辑式起源。**吉祥物诞生于界面中已有的东西（logo 的方块字符、一个图标、一个加载转圈），并从里面爬出来，留下一个轮廓。*适合的内容：*聊天气泡变成向导；图标变成助手；加载转圈变成帮手。
- **剧中标题。**名称作为真实的界面元素出现；吉祥物在强拍上落在它上面。*适合的内容：*一个空状态；新建项目对话框；一封欢迎邮件。
- **移动的地面。**吉祥物搭乘输入光标、弹窗、发送出去的消息、进度条。*适合的内容：*一条飞进会话的消息；上传进度条；拖放操作。
- **带标签的延时。**耗时的工作以 N× 速度运行，配闪烁的标签和焦点转移。*适合的内容：*为资料库建立索引；数据导入；一次构建。
- **聚光定格。**推镜并用暗角圈出承载承诺的那个徽章。*适合的内容：*“已保存”；“已加密”；“在……之前不收费”。
- **影片改变状态。**一个开关的效果逃出预览、接管整部影片，之后再回来。*适合的内容：*深色模式；切换语言；离线模式。
- **细胞分裂。**一个新会话或新窗口把屏幕分开，吉祥物伴随像素迸发一起分裂。*适合的内容：*并行任务；多个账户；团队成员。
- **光标和吉祥物都是角色。**光标摸摸、戳戳或拖动吉祥物，它会有反应。*适合的内容：*采纳一条建议；撤销；新手引导中的小惊喜。
- **卡拉 OK 跳球式文字。**吉祥物随着口播在词与词之间跳跃。*适合的内容：*一句口号；一份快捷键清单；步骤名称。
