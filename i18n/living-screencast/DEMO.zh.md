# 实况录屏 — 我们的演示片

这只是众多可能中的一个例子。不要照搬它的故事、结构、镜头、道具或时间安排。

演示片：*Clawd Moves In*（59.4 s）· `living-screencast.mp4` · 源码在 [`demo/`](demo/) · Claude 应用中的 Claude Code，以 Clawd（Claude Code 的像素吉祥物）为主角。非官方同人片；Anthropic 未参与制作，也未为其背书。


## 故事与结构

Clawd，Claude Code 的像素吉祥物，从终端 logo 里爬出来，搬进了 Claude 应用，然后分四章演示四个功能：**01 Just say it**（直接说：带 @ 提及的自然语言提示，读取文件），**02 Plan first**（先规划：Plan 模式；在你说开始之前什么都不会改），**03 Review**（审阅：diff、一条行内评论、修改后的版本），**04 Checks its own work**（自检：预览、深色模式开关、并行会话）。由口号收尾："Say it. Plan it. Review it. Ship it."。每一个交互都对照官方桌面版文档核实过。

演示片据以制作的简报（旧版“六条规则”，现在分散在 STYLE.md 第 1–6 节）：

| 规则 | 原因 |
|---|---|
| **真实界面，重新绘制** | 每个标签、模式名称和快捷键都与真实产品一致。不用截图，不用 lorem ipsum 占位文字。演示用的代码、diff 和测试输出前后一致，“被测应用”确实会发生变化。 |
| **录屏软件式摄影机** | 屏幕内的一个连续长镜头。推镜到动作上，轻微漂移，在窗格之间甩镜。缩放绝不低于 1，所以我们永远看不到显示器之外。剪切只发生在章节转场之下。 |

| **重力 = 界面元素的上边缘** | 吉祥物永远只站在真实元素的上边缘：输入框、菜单、文件行、diff 行、按钮、CI 条、标题的字母。位置来自每帧**测量实时 DOM**，绝不手工摆放坐标。 |

| **信息层** | 章节胶囊标签（01–04）、按键 HUD、毛玻璃字幕胶囊，以及可选的“▶▶ 4×”延时标签。屏幕上不叠加任何其他东西。 |

### 导演工具箱，演示片如何使用（十项全部用上）

1. **匹配剪辑式起源故事。**终端 logo 的象限块字符（`▐▛███▜▌`）与吉祥物的像素 1:1 对应。每个高的象限块变形为一个方形像素，角色从终端里爬出来，身后留下一个虚线轮廓。
2. **剧中标题。**产品名称作为应用空状态的标题落下，吉祥物在强拍上落在它的字母上。
3. **在移动的地面上表演。**吉祥物跟着输入光标走，跳上 @ 提及弹窗，再搭着发送出去的消息飞上聊天记录。
4. **带标签的延时。**读取文件以 4× 速度进行，配闪烁的标签和焦点转移：聊天区虚化，窗格清晰。
5. **聚光定格。**在关键承诺（“在你说开始之前什么都不会改”）处，摄影机推镜，暗角把 *No files changed* 徽章单独圈出。
6. **方向性运动模糊只用于甩镜。**它由摄影机速度推导，作为各向异性高斯模糊施加在一个**未变换的外层容器**上。慢速运动保持清晰。
7. **影片本身改变状态。**深色模式开关的揭示没有停在预览里。圆圈继续扩大，覆盖整个应用和桌面，影片余下部分都是深色模式。结尾时，吉祥物最后一跺脚，让光从它自己脚下重新回来。
8. **细胞分裂。**新会话把窗口一分为二，吉祥物伴随一阵像素迸发分裂成两个。
9. **卡拉 OK 跳球式片尾卡。**吉祥物在口号的词与词之间跳跃，每个词被念到时正好落在上面。
10. **光标和吉祥物都是角色。**光标“摸摸”吉祥物的头：它被压扁、闭上眼睛，冒出一颗爱心。

演示片的精灵图是一个 **18×10** 网格，由终端 logo 的象限字符 1:1 展开而来；它的道具（铅笔、“!”、闪光、爱心、尘土）共享这个网格。

## 配乐与声音结构

- **两种分辨率的配乐。**高保真层（钢琴、低音提琴、架子鼓、钟琴，真实采样）是世界。芯片音乐（chiptune）方波是吉祥物的声音。
- **配乐结构：**
    - 吉祥物落在标题上时乐队进入。
    - 每次章节转场配一段通鼓加花和一记镲。
    - 最后一章去掉鼓，制造紧张感。
    - 深色模式那一跺脚，把整个乐队交叉淡化成一个低通滤波后的“夜晚”版本。
    - 分屏变成左右二重奏（左边钢琴，右边芯片音乐）。
    - 片尾卡上的词是芯片音乐音符；最后一跺脚在一个宏大的大九和弦上打开滤波器。
- **拟音：**键盘（一声闷响加一声咔嗒，带人性化的时间抖动）、触控板点击、窗格的嗖声、弹窗的啵声、CI 的滴答声、截图的快门声。吉祥物的脚步、跳跃和落地都是 8-bit 音效。
- **旁白：**平静，每句一个功能，产品名称用 whisper 核实。让音效避开词的起始：一个落在“Start”上的按键声把这个词盖住了。

速度约 104 BPM（处理方案中的设定）。片尾卡的词在 `sound.py` 中是芯片音乐音符 C5 E5 G5 C6。

演示片中吉祥物的时间参数：预备下蹲 0.14 s，压扁 0.28；行走每秒 9 步。完整的表演笔记：

- **跳跃：**预备下蹲（0.14 s，压扁 0.28），起跳时拉伸，空中收腿，落地压扁并带阻尼回弹，还有扬尘。
- **待机：**配乐的每一拍都有一次轻微压扁，让角色随音乐呼吸。它以不规则的间隔眨眼。
- **行走：**每秒 9 步的双腿交替。方向改变时翻转精灵图。
- **眼睛承担表演：**n / l / r / u / d / wide / happy / shut / blink。它们看向重要的东西：弹窗、光标、正在修改的那一行。
- **手臂：**放下 / 举起（欢呼）/ 挥手。道具在同一个网格上。

人声：Kokoro `am_michael`，speed 1.0（其他声音会把“Claude”读成“Clod”）。一个落在“Start”上的按键声把这个词盖住了，因此有了让音效避开词起始的规则。

## 色板与道具

Claude 应用的浅色主题（墨色 `#1F1E1C`，陶土色 `#D97757`，`--clay2` `#BD5D3A` 用于口号中被强调的词）以及切换开关后真实的深色主题（墨色 `#EEEAE2`，陶土色 `#E08565`），全部作为 CSS 变量写在 `demo/index.html` 中。Clawd 使用品牌陶土色 `#D97757`，阴影 `#B85F40`，眼睛 `#2A2622`；铅笔黄 `#F2C14E`，爱心 `#E0543A`，对勾 `#2F9E4F`（`demo/clawd.js`）。字体：Inter、Newsreader、JetBrains Mono（OFL）。“被测应用”是一个小小的番茄钟项目（`~/tomato-timer`）；界面上显示的模型名称与应用中出现的一致。

**版权。**非官方同人片：它使用了官方的 Claude Code 吉祥物，并高度还原地重绘了 Claude 应用的界面。片尾卡写明“Unofficial fan film”。用户的影片应该展示自己的产品和吉祥物，或一个原创的像素角色。

## 构建说明

- `demo/film.js` 是时间线。旁白台词放在固定时间点上，每个视觉节拍都挂在一个口播词上（`W(id, word)`）。它包含摄影机运动、`Actor`（吉祥物）片段、`Cursor` 以及声音事件。
- `demo/ui.js` 把状态转换成终端和 Claude 应用的 HTML。
- `demo/clawd.js` 包含精灵图网格、姿势和像素道具。
- `demo/main.js` 处理浅色和深色图层、DOM 锚点测量、运动模糊以及 HUD（字幕、按键、像素划像、聚光）。
- `demo/sound.py` 从 `events.json` 构建配乐、拟音和旁白，并带闪避。
- 用 `sh styles/living-screencast/demo/build.sh` 运行全部流程。完整渲染约需 30 s。

其他文件：`demo/lines.json`（旁白台词）、`demo/tools/asr_check.py`（whisper 校对 + 词时间戳，`sh demo/build.sh --vo`）、`demo/tools/mixcheck.py`、`demo/tools/subs.mjs`（字幕 → `.srt`）。`build.sh` 还会渲染风格帧（40.9 s）和海报帧（8.9 s）。
