## 5. 运动质感

- 以一拍一（24 fps）制作，流畅。魅力在于**到达曲线**，而不是阶梯式的抽帧。
- **从下方升起**：一个短促的三次缓动上升，然后是阻尼正弦过冲；在破水而出的那一刻出现水花环和飞沫。事件时间以落定的时刻为准。
- **落下与堆叠**（楼层、屋顶、圆环）：快速缓入下落，阻尼弹跳，落地时保持体积的挤压与拉伸。
- **弹出**（树木、灯、细节）：缩放 `1 − e^(−k s)·cos(ω s)`，约 25 % 的过冲。
- **生活气息**：风车转动、烟囱冒烟、鸟儿盘旋、船随着与水面相同的波浪函数起伏（在 CPU 上计算）。
- **按音乐网格排程生长**：每个最小时间格最多一件，这样每个事件都保有自己的音；靠密度加速（二分 → 四分 → 八分），而不是靠速度。
- 永远不动的：投影方式（不用透视，不改视场角）。



## 6. 镜头语法

`THREE.OrthographicCamera`。**视锥高度就是缩放**（特写几个单位，整个世界十几个或更多，尺度揭示可达几百）；把相机放在 ≥ 3 × 视锥高度的距离上，否则画面底部会看到海面以下。这是一套词汇，不是一条路线。开场和结尾由题材决定。

| 运动 | 表达什么 | 可用于 |
|---|---|---|
| 转台（方位角扫动） | 从各个侧面观看这件东西 | 建造；检视；一件组装好的产品 |
| 纯正交缩放（改变视锥） | 没有透视的尺度变化 | 细节放回背景中；渺小；众多世界中的一个 |
| 仰角变化 | 低（≈20–25°）让天空带变宽；高（≈50°）读起来像一张地图 | 夜晚与星空；扫过整个世界；一张平面图 |
| 锁定的 3/4 宽景 | 世界自己在生活 | 灯光亮起；延时；等待 |
| 对准一次到达的近景特写 | 弹跳和水花 | 一个关键部件；一个里程碑；一个笑点 |
| 侧面角度跟随一个移动物 | 横穿画面的行进，从不冲向镜头 | 一次投递；一次出发；一条路线 |
| 沿一排地块横移 | 一份清单，一个序列 | 流程的步骤；一条时间线 |
| 延时太阳扫过，镜头不动 | 光线就是时光机 | 一天；一个季节；一段历史 |

在拍点上交替剪切宽景和特写：宽景展示形状的生长，特写卖出弹跳。转场：在拍点上硬切、一天中时段的变化、穿过天空的缩放；不用叠化，不用透视甩镜。



## 8. 原生手法

这是一份菜单：按故事需要选用。

- **建造即作曲**：每一块落定的部件都奏出一个音；之后的一次扫过可以按空间顺序把它们重新奏成一段完整的旋律。*适合的内容：* 楼层就是音符的天际线；一个团队组装一件产品；花朵组成和弦的花园。
- **程序化生长**：地块升起、楼层堆叠、树木弹出。*适合的内容：* 一家初创公司的第一年；一片珊瑚礁的恢复；一个正在规划的街区。
- **纯缩放表现尺度**：一个物体填满画面，然后世界变成一个小点（或反过来）。*适合的内容：* 百万用户中的一个；大陆上的一个村庄；网络中的一个数据中心。
- **转台**：围绕正在制作的东西连续旋转。*适合的内容：* 一台正在组装的机器；一件博物馆藏品；一次房屋翻新。
- **光线即时钟**：阴影扫过，面片重新着色。*适合的内容：* 一家店的一天；一座农场的一年；医院的一个班次。
- **黑暗中的自发光方块**：灯光一盏盏亮起，一道光束像时钟指针一样扫过。*适合的内容：* 一张网络上线；夜幕降临的小镇；志愿者加入一项事业。
