# 低多边形等距岛屿 — 我们的示范片

这只是众多示例之一。不要照搬它的故事、结构、镜头、道具或时间安排。

示范片：*The Island That Grew*（53 s）· `lowpoly-island.mp4` · 源码见 [`demo/`](demo/)


## 故事与结构

一片空荡的海面上只有一个浮标，它只会一个音；地块、树木和房屋一个接一个从海中升起，每一样落定时都奏出一个音，于是岛屿和它的歌被一起写成——直到夜里，出海的船找不到回家的路，而最后一个"音符"是一座灯塔。

我们对创作简报的理解是：**一个不断生长的小世界，度过一天，遇到一个问题，由最后一块拼图来解决**——一个主体（一座岛），一个目标（成为一个家），一个转折（夜幕降临，船迷了路）。在旧版指南里，这被当作改编任何题材的方法；其实它只是这部片子的形态。

情绪弧线（53 s）：空无 → 第一个音 → 建造中不断加速的喜悦 → 生活气息浓郁的一天 → 黄昏的温暖 → 寂静的夜晚，少了一样东西 → 最后一块被点亮（高潮）→ 拉远展示尺度，并呼应开场。

用到的媒介本色：程序化生长（整个第一幕）、正交注视（最后的 ×25 缩放）、转台（生长镜头）、平面着色 × 光线（白天的延时）、自发光方块（黄昏的窗户、夜晚的光束）。

**"建造即作曲"，示范片是这样兑现的：** 每一个生长事件都从页面中带着一个 MIDI 音符导出，配乐的旋律声部就是由这些事件合成的。灯塔光束每 12 拍转一圈，每拍扫过一个环形格；立在这些格子上的八栋房子在光束扫过时依次亮起并发出钟鸣，于是以打乱的建造顺序落下的音符，被按**空间顺序**重新奏出，成为完整的主题。中心格周围的第二环正好有 12 个格子，间隔恰为 30°，这让与节拍同步的扫光成为可能。

## 镜头

| 节拍 | 镜头 | 原因 |
|---|---|---|
| 开场 | 近距离正交镜头（视锥 7.5）对着一个孤零零的物体，空荡的多面体海面，顶部一条天空带 | 不给观众任何可看的东西；于是第一块地块就成了一个事件 |
| 生长 | 转台（约 5 s 内方位角 +45°）配合缓慢拉远，并在拍点上**穿插**特写：一座山峰带着水花升起（仰角 23°，视锥 5.2），楼层堆叠（26°，6），码头木板和船落下（27°，6.6） | 宽景展示形状的生长；特写卖出弹跳和水花 |
| 白天 | 村庄中景，太阳在 2.5 s 内扫过 100°（延时阴影） | 光线就是时光机 |
| 出发 | 根据码头方向计算出的侧面角度，镜头跟在船后面 | 船必须横穿画面，而不是朝镜头驶来 |
| 黄昏 | 固定的 3/4 宽景，缓慢推镜，窗户每个八分音符亮起一扇 | 让灯光成为唯一的运动 |
| 夜晚 | 非常宽的景，仰角 21°，岛在左下，远处黑暗中一点微光 | 负空间 = 危险 |
| 高潮 | 高角度（50°）以光束速度的 0.22× 旋转，然后缓缓降到 25°，让星空"升起" | 必须看到光束扫过每一栋房子；然后天空打开 |
| 结尾 | 纯正交缩放 ×25；远处右下角一个呼应的物体 | 尺度揭示与呼应 |

使用的镜头设置：默认方位角 45°，仰角 **30°**（建造），**33–35°**（白天细节），**20–25°**（夜晚——更低的角度让天空带更宽，星星才能显现），**50°**（光束扫过时接近俯视）。特写的视锥高度 5–7，整座岛 12–16，最后的尺度揭示最高 420。

## 声音结构

- **事件驱动**：页面的 `EV` 条目带有 `note`；`music/score.py` 在每个事件的精确时间合成它（rise → 马林巴，pop → 卡林巴，floor → 木鱼，roof → 卡林巴+马林巴 = 旋律，window → 柔和的卡林巴，ring → 上行马林巴，beamhit → 卡林巴主奏 + 马林巴八度 + 钟声泛光）。底层：氛围铺底、一段轻柔的马林巴固定音型，只有白天和高潮段落才有沙锤/轻底鼓。**96 BPM，D 大调五声音阶的感觉。** 不用钢琴，不用弦乐。
- **一个音作为动机**：D5 上的浮标钟声开启影片（"大海唯一会的音"），结尾远处一声钟响奏出同一个音。
- **静默**：夜晚段落降为低沉的铺底持续音、海浪和蟋蟀声；高潮重拍之前的最后半拍，音乐总线为数字零。
- 生长按十六分音符网格排程：地块从二分音符 → 四分音符 → 八分音符。
- 船的应答钟声放在旋律的休止处，在光束找到它时填补空隙。
- **拟音**（`mix.py`）：同 STYLE.md §7，另加白天的海鸥（向下滑翔的 FM 鸣叫）、风车的吱嘎声、黄昏起的蟋蟀声；码头木板的敲击声和灯塔环的石块闷响、灯室的玻璃叮声、点亮时的轰响 + 嗡声。楼层：第一声敲击后 0.21 s 有第二声。
- **人声**：Kokoro `af_sky`（清亮、温柔的女声），语速 0.86–0.92，5 句短台词。在一部关于音符的片子里，"Sea"被听成了"C"，所以旁白改说"ocean"。
- **混音**：人声经压缩，比音乐高约 10 dB；人声下音乐闪避 −8 dB；−14 LUFS；颗粒 0。

## 色板与道具

- **地形高度**：沙地 0.36–0.42，草地 0.74–0.9，丘陵 1.1–1.4，岩石山峰 1.95；顶盖厚 0.16，侧柱下沉到顶盖以下 0.1；地块之间留 1.5 % 的缝隙；明度抖动 ±4 %；粗糙度 .88。
- **道具**：方盒房屋宽 0.92，每层高 0.62，人字形屋顶棱柱（出檐 0.08），山墙端用墙面颜色；窗户 = 小四边形，每栋房子有自己的自发光材质；圆锥松树（6 边），二十面体（细分 0）阔叶树，三边圆锥的棕榈叶；风车（6 边收分塔身，4 片叶片）；立在桩上的码头木板；一条由收紧的方盒船身 + 三角帆组成的船；灯塔 = 4 段收分的八边形环，红白相间 + 深色回廊 + 自发光玻璃 + 红色圆锥顶。三只海鸥盘旋；烟囱冒烟；风车在"岛屿完成"的和弦上转起来。
- **色板（sRGB）**：沙地顶面 `#f3dfab` / 侧面 `#e2c68e`；草地 `#93c96c`、`#7fbd62`；泥土侧面 `#c99c6e`；岩石 `#b4b8bd` / `#8f949c`；墙面 `#fbf3e6 #f5c2b0 #b5dccb #a9cbe8 #f7df8f #e9c9e6`；屋顶 `#d9644a #4f7fb8 #e0874f #6a5a8e #3f8f86`；松树 `#3f8a5a #4f9c63`；树叶 `#7fc36a #9ad06f`；暖色窗户 `#ffc676`；灯塔 `#f6f2ea` / `#d9544a`。
- **昼夜关键帧**（天顶 / 地平线 / 深海 / 浅海 / 太阳）：黎明 `#9fb6cf / #f3d2c4 / #4f8ea3 / #8fc9c4`；白天 `#88c8e8 / #eaf5f2 / #38a5bc / #86e2d4`，太阳 2.7；黄昏 `#6f6fa8 / #ffa888 / #5a6a9e / #b08aa6`，太阳 `#ff9a68`，高度角 8°；夜晚 `#12163a / #4a4478 / #23264a / #363a66`，月亮 `#a9b0e8` 0.9。夜晚的海面靠近镜头处更暗，向天空带方向逐渐变亮。
- **海面**：220×220 平面，200×200 分段，四个正弦波叠加（振幅 ≈ 0.2），粗糙度 0.55；下方 0.55 处还有一个粗糙的 5000 单位平面；潟湖贴图是一张 512² 的画布，在地块升起处画上柔和的斑块；浪花环 0.99–1.12 r，不透明度 ≈ 0.32。
- **到达数值**：升起 0.5 s 三次缓动，过冲 `sin(13 s)·e^(−7 s)·0.18`，在落定前 0.12 s 出现六边形水花环 + 14 颗水滴。落下：0.22 s 内下落 2.4 单位（缓入），弹跳 `|sin(15 s)|·e^(−9 s)·0.22`，Y 方向挤压 `1 − 0.16·e^(−12 s)·cos(26 s)`，保持体积。弹出：`1 − e^(−9 s)·cos(17 s)`。
- **后期**：GTAO 半径 0.7，尺度 1.5；移轴模糊在画面边缘最大半径 3 px；辉光阈值 0.95，强度白天 0.22 / 夜晚 0.5；调色饱和度 1.04–1.1，柔和对比，夜晚略微提升蓝色；渲染 3840×2160。
- **灯塔光束**：面向镜头的色带，光晕宽 2.4×、强度 0.32，向下倾斜 7°，在远处与海面相交；水面被光束方向周围的一条角度带照亮，再加上逐面片的闪光。光束：每 12 拍转一圈。
- **实际实现的字幕**：Quicksand 600，44 px，`#fffdf8`，海军蓝投影（模糊 14），居中，距底部 118 px；六边形图标（顶面 + 两个侧面）在黎明为粉色，白天为草绿，黄昏为橙色，夜晚为窗户黄。在台词开始前 0.05 s 显示。
- **片名**：Josefin Sans 600，全大写，78 px，16 px 字距；字母以 55 ms 间隔从一条细水线下方升起；300 字重的小写副标题（"a low-poly island film"）。

## 片尾卡

夜晚尺度揭示的画面，压暗；同样的片名区块（静态）、六边形图标、`LOW-POLY ISLAND · LEMO-OPUSCAR`、`LemoLab × Claude Opus 5.5`、演职员表，排版时让那座亮着灯的小岛在文字区块之间的空隙中保持可见。"LemoLab × Claude Opus 5.5"署名（以及 LEMO-OPUSCAR 这一行）只属于本库的示范片；用户的影片不带 LemoLab 署名，也不要复制这张卡片。

## 构建说明

```
styles/lowpoly-island/demo/
  story.js   timeline (96 BPM grid), VO, chords, day/night keyframes, shots
  world.js   hex layout, all props, growth schedule → EV (with notes), per-frame animation
  sea.js     faceted wave shader, shallow-lagoon map, beam-lit water
  post.js    ortho post: GTAO → sky/haze + stars → tilt-shift → bloom → grade
  main.js    renderer, lights, cameras per shot, HUD (title, subtitles, end card), EV export
  music/score.py   event-driven score (+ check.py: librosa onset/pitch check vs events)
  mix.py     foley + ambience + voice + ducking     subs.py  subtitle cues
  build.sh   one-command rebuild
```

1. `node core/render/still.mjs styles/lowpoly-island/demo --range 0.5:52.5:1` + `core/render/sheet.py` — 生成概览联系表，反复迭代。
2. `core/tts/tts.py lines.json voices` → `core/tts/asr_check.py`，直到全部 OK。
3. `node core/render/events.mjs styles/lowpoly-island/demo` → `music/score.py` → `music/check.py` → `mix.py`。
4. `node core/render/video.mjs styles/lowpoly-island/demo --fps 24 --workers 3`（1272 帧，2× SSAA + GTAO）。
5. `sh core/render/mux.sh out/video24.mp4 mix.wav lowpoly-island.mp4 24 0`。或者直接运行 `sh demo/build.sh`。

与本示范片道具相关的坑：

- 一个不可见的发光精灵在 GTAO 通道中变成了漂在海面上的一个黑色平行四边形。
- 船在 21 个单位之外——光束找到它时它已在画面外。我们根据光束的角速度推算船的位置，让光束在选定的拍点上找到它（旋律中的一个休止处，这样船的应答钟声正好填补空隙）。
- 太阳很低时海面上的阴影形成一道长长的黑色污迹；海面不接收阴影。
