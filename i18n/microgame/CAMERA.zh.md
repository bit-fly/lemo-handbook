## 5. 动态质感

- **帧率是阶梯的一部分**：前期角色以一拍二或 8 fps 步进，越往后越快，高潮时一拍一。镜头运动、转场和计时器火花始终逐帧运行。
- **每次加速时五样东西一起提速**：速度、游戏时长、舞台停留、指令停留、角色帧率。
- **计时器可见且踩在节拍上**：例如一根每拍一个绳结的导火索，火花恰好在节拍上经过每个绳结。回放时它会冻结。
- **通过"画中画"统一转场**：推进屏幕开始一个游戏（约 0.25 s），把游戏缩回屏幕里返回（约 0.33 s），并盖上 ✓ / ✗ 印章。没有淡入淡出，没有空白帧。
- **失败是表演出来的**：动作过冲、溅开、撞响或滚走；由媒介自身的物理特性来制造笑点。
- **即时回放**用于必须被看懂的失败：冻结、半速、推镜、加黑边，配一行用该媒介字体写的说明。
- 主舞台主持人每拍都有一下滴答；让它戛然而止是最强的情绪手段。



## 6. 镜头语法

这是一套词汇，而不是一条固定路线。开场和结尾由主题决定。

| 运镜 | 表达什么 | 可用于 |
|---|---|---|
| 从游戏内部开始，指令已经砸进画面 | 规则自己解释自己 | 把观众直接扔进去 |
| 从游戏屏幕里拉镜出来 | 尺度：这只是节目里的一块屏幕 | 第一次回到舞台 |
| 锁定的正面主舞台画面 | 不变量；只有记分牌在变 | 舞台节拍；主持人的反应 |
| 老虎机滚轴（舞台分裂成旋转的条带，滚过之前的画面，每拍停一条） | 加速，一次总结 | 一次加速；换一轮 |
| 对触发道具的大特写插入镜头 | 开始，能被身体感受到 | 一个在强拍上开始的游戏 |
| 灯光收成头顶一束追光，画面不变 | 风险；最后的机会 | 最后一条命；一个决定 |
| 方片翻转（过去游戏的最后一帧翻转成新画面的碎片） | 过去成为现在的材料 | Boss 关或终局；回顾 |
| 推镜到一个细节，停留 | 观众比主角先注意到 | 一条线索；一段静默 |
| 一拍之内猛地拉回全景 | 释放 | 解决方案绽开；一次救场 |
| 分屏，两种媒介并排 | 对比，较量 | 两个玩家；之前/之后；两种做法 |

构图：游戏屏幕占画面的固定比例（约宽度的 40 %）；在混合媒介画面中保留**一条焦点链**（A 引向 B 引向 C），把信息面板推到角落。



## 8. 原生手法

这是一份菜单：只用你的故事需要的。

- **每个游戏切换一次风格。**每个任务用最适合它的媒介来画。*适合的内容：*烤面包的步骤（面粉用蜡笔、烤箱旋钮用蓝图、面包皮用木刻）；一位护士的一天；一场劫案中的各个角色。
- **指令词。**一个动词同时是剧本、字幕和强拍。*适合的内容：*收银台的 SCAN!（扫码！）；瑜伽课上的 BREATHE!（呼吸！）；签约现场的 SIGN!（签字！）。
- **生命值即 UI。**计数器在没有旁白的情况下承载情绪；3 → 2 → 1（闪烁）本身就能制造紧张。*适合的内容：*手机电量；驾考的重考次数；问答节目剩余的机会。
- **SPEED UP。**一切一起提速。*适合的内容：*早晚高峰；截止日期前的最后一周；晚餐高峰时的后厨。
- **失败变成解决方案。**早先失败的材料在最后一个游戏里作为答案回归。*适合的内容：*一杯洒掉的咖啡后来染出了制胜的地图；一个 bug 变成了功能；一班错过的火车把人带到了对的会面。
- **Boss 混合规则。**最后一个游戏由之前各种媒介的碎片拼成。*适合的内容：*期末考试；发布日；音乐节的闭幕之夜。
- **即时回放。**用慢动作解释笑点。*适合的内容：*门线判罚；一个上线了的错别字；一只扑空的猫。
