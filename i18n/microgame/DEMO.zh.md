# 微游戏快闪 — 我们的示范片

这只是众多例子之一。不要照搬它的故事、结构、镜头、道具或时长。

示范片：*Five-Second Astronaut*（五秒宇航员，59.8 s）· `microgame.mp4` · 源文件在 [`demo/`](demo/)


## 故事与结构

一名太空学员在一档游戏节目上试图通过宇航员学校的考核。游戏节目由一连串**微游戏**组成。每一个都是**一个喊出的指令词 + 2.5–4 秒 + 一个动作 + 一个结果**（成功，或一次搞笑的失败）。游戏之间，影片切回**主舞台**：一位主持人、一块显示剩余生命的记分牌和一个关卡编号。每隔几个游戏，整部片就会 **SPEED UP（加速）**。最后，一个 **BOSS STAGE（Boss 关）**持续更久，混合了之前所有的规则，并决定故事的结局。

让这个风格成立的关键：**每个微游戏都使用不同的视觉媒介。**蜡笔、水墨、ASCII 终端、Risograph、像素画、蓝图、瑞士字体排印等等。每次风格切换带来的冲击既是笑点，也是节拍。主舞台是唯一固定的样貌，把整部片串在一起。

示范片如何使用这些原生手法：

| 原生能力 | 示范片中的用法 |
|---|---|
| **每个游戏切换一次风格** | 任何主题都能拆成 6–8 个小任务，每个用最适合它的媒介来画。喷嚏是一团墨迹。扣上卡扣是一个终端继电器。拉拉链是尺寸线上的刻度。跳跃是一个像素平台游戏。 |
| **指令词** | 一个动词就是整个场景：PUMP!（打气！）/ DON'T SNEEZE!（别打喷嚏！）/ ZIP!（拉上！）。它同时充当剧本、字幕和强拍。 |
| **生命值即 UI** | 头盔图标计数器在没有旁白的情况下承载情绪。从 3 → 2 → 1（闪烁）本身就能制造紧张感。 |
| **SPEED UP** | 五样东西一起加速：BPM、游戏时长、舞台停留时间、指令词停留时间和动画帧率。观众能感受到加速。 |
| **Boss 混合规则** | 最后一个游戏由之前每种风格的碎片拼成，所以高潮实实在在地由影片自己的过去构成。 |

**示范片的故事形态：**冷开场，第 1 帧就已经在一个游戏*之中*。第 1 轮的一次失败很好笑。第二次失败耗掉了最后一条备用生命。最后一条命时出现一个静默节拍。**转折：一次早先失败的材料，在 Boss 关里变成了解决方案。**在示范片中，那个让主角丢了一条命的水墨喷嚏，绽开成了一顶水墨降落伞。结尾的呼应：角色重做一次早先失败的动作，这次做对了（敬礼）。

我们如何改编主题：我们从主题中列出 7 个动词，给每个动词配上最自然的绘画媒介，让其中两个失败，并让 Boss 关重新使用失败的那两个。同样的配方用于另一个主题：一次产品发布会变成 UNBOX!（开箱！蜡笔）、PLUG IN!（插电！蓝图）、DON'T DROP IT!（别摔了！水墨），以此类推；Boss 关是 "SHIP IT!"（发货！）。

## 镜头

| 节拍 | 镜头 |
|---|---|
| 冷开场 | 第 1 帧就已在游戏之中，指令词正砸进画面。规则在 1 s 内自己解释清楚。 |
| 第一次回舞台 | 从电视里拉镜出来：尺度揭示。原来那个游戏只是节目里的一块屏幕。 |
| 舞台 | 永远是同一个正面、对称的"主舞台"画面。只有记分牌在变。 |
| SPEED UP（标志性镜头） | 舞台分裂成**三条老虎机滚轴**，带着运动拖影旋转过之前的游戏画面，每拍停一条，依次停在 SPEED \| UP \| !。 |
| 按钮 | 一个 Edgar Wright 式的**插入镜头**：红色按钮的大特写，一只手套在节拍上狠狠拍下它。 |
| 最后一条命 | 同一个舞台，灯光收成头顶一束追光；主持人一动不动。 |
| BOSS STAGE | 8 块方片（7 张之前游戏的最后一帧加一张 BOSS 卡）按八分音符翻入，然后再翻一次，变成 Boss 画面的组成部分。 |
| Boss 静默 | 推镜到舷窗特写；观众比主角先看到那粒灰尘。 |
| 高潮 | 水墨伞盖绽开时，一拍之内猛地拉回全景。 |
| 结尾 | 回到主舞台；主角第一次站上舞台并敬礼；随后镜头推进电视，进入结尾卡。 |

示范片中的运动方式：

- **速度阶梯**（示范片）：120 → 140 → 160 BPM。第 1 轮游戏为 2 小节（4.0 s），第 2 轮为 1.5 小节（2.57 s）。舞台停留从 1 小节 → 2 拍。指令词停留 0.75 s，之后 0.64 s。角色步进从 8 fps → 12 fps → 24 fps（Boss）。镜头运动、转场和导火索火花始终逐帧（一拍一）运行。
- **指令词**：Titan One，白色字，22 px 墨色描边，洋红色投影，背后一团金色爆炸，倾斜 −6°。它在 3 帧内**砸入**（1.9 → 0.92 → 1.0），停留，然后**在第一个动作之前缩成角落里的小标签**，因此结果永远不会被遮住。一次性的横幅（"BOSS STAGE!"、"PULL!"）则直接飞出，不变成标签。
- **导火索计时器**：底部一根编织绳，**每拍一个绳结**；火花恰好在节拍上经过每个绳结，最后烧到一枚小鞭炮火箭。即时回放时导火索冻结，在 Boss 特写中隐藏。
- **统一转场 = 电视边框**：舞台 → 游戏是镜头推进电视屏幕（0.25 s）；游戏 → 舞台是整个画面缩回电视里（0.33 s），同时 ✓ / ✗ 印章拍在屏幕上。没有淡入淡出，也没有空白帧。
- **失败是被表演出来的，而不只是展示**：水墨喷嚏糊住面罩，两只白眼睛从墨里眨出来。瑞士风格的敬礼手臂转过了 90°，并且*长得超过了它的模块长度*，一巴掌拍飞了红球，红球在基线上弹了两下，滚出了网格。
- **即时回放**用于对故事至关重要的失败：冻结 3 帧，然后以 0.5× 播放，配 1.4× 推镜、黑边，以及用该风格自己的字体写的 "instant replay"，然后恢复。它占用 2 拍；音乐配一声唱片刮擦并转为半速。

## 配乐结构

- **音乐先行**：在做任何动画之前先写好速度网格（`timeline.js`）。每一个击点都列在提示点表中（按段落：时间、BPM 和调性、叠在鼓和贝斯之上的乐器，以及画面必须落上的节拍，例如 10.5 s 全乐队停一拍半，11.0 s ACHOO = 底鼓 + 镲 + 墨迹飞溅），画面落在它们上面。`tools/cuecheck.py` 把 57 个画面事件与 `music/score.json` 对照检查（示范片最大偏差 4.7 ms）。
- **配乐**：原创的放克/流行融合。架子鼓配十六分音符踩镲和幽灵音，**合成的击勾贝斯**（加法合成拨弦 + 带通的拇指噪声 + 1.8–6.5 kHz 的勾弦爆音 + 八度跳跃和滑音），叠加的铜管短促重音（trumpet_stac + alto sax + trombone_stac），以及颤音琴+钢琴组成的"电钢琴"。鼓和贝斯贯穿全片。在其之上，**每种风格一件色彩乐器**：木琴（蜡笔）、古琴泛音和推弦（水墨）、方波哔声（ASCII）、颤音琴和萨克斯（Riso）、脉冲波琶音（像素）、弱音小号（蓝图）、响棒和干声钢琴（瑞士）。每次加速都有一段上行的铜管跑句，每一轮调性升高一个全音。
- **真正的静默**：第一次喷嚏之前 1 拍、最后一条命的舞台（只有心跳声），以及 Boss 特写（心跳 + 与第一粒灰尘相同的那个古琴音）。最大的击点紧跟在最长的静默之后。
- **拟音跟随媒介**：蜡笔打气配橡胶吱吱声 + 气流声，水墨配湿漉漉的啪嗒声和滴落声，ASCII 配电传打字机的咔嗒声和继电器声，Riso 配纸张的闷响和揉皱声，像素配比特压缩的噪声，蓝图配棘轮齿声和盖章的咚声，瑞士配空心的"咚"和小小的橡胶弹跳声。主舞台的声音：弹簧表冠的咔嗒声、丢命时的玻璃碎裂声加弹跳的叮当声、翻卡声、老虎机滚轴的呼呼声、稀疏的采样掌声。
- **人声**：主持人 = Kokoro `am_fenrir`（在测试过的声音中它的音高范围最宽），语速 1.05–1.15。主持人在铜管重音之后 0.1 s *才*喊出每个指令，这样铜管不会盖住词。主角 = `af_bella`，升高 +2.5 个半音，只说 "Oh no."，外加 "ah… ah…" 和喷嚏声，这些按音效处理，免于 whisper 检查。人声之下，音乐压低约 11 dB，拟音压低约 6 dB。
- **Kokoro 中的单词指令**："Pump!" 会念成 "Pompey"，"Zip!" 会念成 "Zipper"，因为它会加一个元音尾巴。生成 "Pump, now!"，再根据 whisper 时间戳在第一个词结尾处剪断（`tools/trim_cmd.py`）。

## 色板与道具

**主舞台（唯一不变的样貌）**：扁平卡通，**7 px 近黑色描边 `#1a1030`**，平涂填色，以及**一道硬边阴影**——做法是用暗色填满形状、裁切到形状内，再向左上偏移 9 px 重新填一次。色板：舞台紫 `#2a0f5c` / `#3d168f` 旋转的太阳放射线，洋红 `#ff2e88`，金色 `#ffc928` / `#e08a00`，青色 `#1fd1d1`，成功绿 `#3bdc5a`，失败红 `#ff3b3b`。固定道具：一块带追逐灯泡的跑马灯招牌（标题卡）、居中的 **16:9 金色电视**（屏幕 768×432，正好是画面的 1/2.5）、一块由头盔图标组成的生命值面板、一枚关卡编号徽章，以及一个带大红按钮的讲台。

**角色**（全部原创）：
- *主持人* = 一个金色的**秒表头**。表盘是脸，红色秒针是他的指针兼鼻子，他**拍自己的表冠按钮**来开始每个游戏。他的指针每拍走一格，兴奋时会转圈，最后一条命时彻底停住。
- *主角* = 一个 2.3 头身的学员：泡泡头盔、顶着橙色小球的弹簧天线（这是**情绪表**，每个动作时都会弹一下），以及编号 "05"。
- **转译规则：**在每种微游戏风格中，主角都从零重画，但**三个剪影标记始终保留**：圆头盔、天线球、"05"。同一角色的 8 种渲染见 `demo/stills/modelsheet_v2_styles.jpg`。
- **角色设定图：**[`demo/stills/modelsheet_v2.jpg`](demo/stills/modelsheet_v2.jpg) 中有两个角色的主舞台风格版本：转面图（正面、3/4、侧面、背面）、表情、关键姿势和色板色块（`?scene=frames.modelSheet`）。

**微游戏媒介（简化重绘，每种约 100–200 行代码）：**
| 风格 | 制作方法 |
|---|---|
| 蜡笔 | 画布中 RGB = 蜡笔颜色，**A = 压力**。着色器只在程序化纸纹 > 1 − 1.22·压力 的地方沉积蜡。靛蓝色抖动描边、越出边线的之字形排线，以及**挖空**：前景形状会擦掉它后面的蜡。8 fps，线条以 12 fps 抖动。 |
| 水墨 | 两个通道，**R = 湿墨**（模糊，边缘有颜料淤积）和 **G = 干墨**（被纸纹打断）。笔触是带鬃毛轨迹的压力曲线；墨迹是带噪声的圆盘；飞溅是甩出去的墨迹。唯一的颜色是一点朱砂：天线球，外加 "05" 印章。 |
| ASCII 终端 | **为主角手工制作的 ASCII 字符画**（用亮度阶梯会把小人物变成一团糊）。结构性字符 `/ \ | _ -` 撑起剪影。天线球是反白显示的 `@`。琥珀色荧光着色器，带辉光、3 px 扫描线和桶形弯曲。 |
| Risograph | 画布 **R/G/B = 蓝/黄/粉三个版的密度**。`lighter` = 叠印（黄+粉 = 橙，黄+蓝 = 绿）；`source-over` = 挖空。7 px 旋转网点，每个镜头固定的套印偏差，以及在关键动作上的一次色版**跳动**。主角周围有一圈纸白色光晕。 |
| 像素 | 240×135 索引色帧缓冲 ×8。精灵由基本图元构建，带**自动 1 px 墨色描边**；辉光和火焰用 Bayer 抖动。12 fps。 |
| 蓝图 | 程序化的蓝色图纸，加上 4 种粗细的白线、中心线 / 隐藏线虚线、尺寸线、手写字，以及一枚红色印章。 |
| 瑞士 | 12 栏网格，一套无衬线字体（Inter），黑白加信号红 `#e30613`。主角是一个黑色圆形、一个黑色矩形和一个**红色圆形**（天线球）。笑点在于有一个元素离开了网格。 |

**Boss 画面构图：**最多混合五种媒介，但**只保留一条焦点链**：降落伞引向太空舱，太空舱引向目标（这是审片时得到的教训）。去掉任何与故事无关的东西，比如装饰性的像素海鸥。把信息面板（ASCII 高度计）缩到角落。图层：蜡笔以 alpha 模式渲染（蜡的覆盖率 = alpha，在必须不透明的地方垫一层全压力的白底）。水墨和 Riso 在白底上渲染，并用 `multiply` 绘制。CRT 面板平面渲染并裁切到它的框内。

**水墨降落伞（高潮）：**它必须*读起来像降落伞*，而不是烟。它分三个阶段长出来：一股墨从舱门喷出（0.15 s），一滴**圆形**墨滴扩散（很短，0.3 s），然后 **9 片伞衣扇形展开**。伞衣填色是竖直渐变（伞顶浓、伞边淡），相邻伞衣色调交替 ±7 %，纸白色的细缝，以及扇贝形伞边（每片伞衣向下鼓出）。伞顶有一道饱蘸墨的弧形笔触，伞边是干笔飞白，几根细细的干笔伞绳连向舱门。

## 字幕与结尾卡

- **指令词就是字幕**：它不会被烧录两次，只列在 .srt 中。
- 其他台词使用一张**金色圆角卡片**，7 px 墨色描边加硬阴影，Lilita One 50 px，配一个小秒表图标（主持人）或头盔图标（主角），在游戏中放在导火索上方。它以 12 fps 分 2 步弹出。停留 ≥ max(1.8 s, 语音时长 + 0.6 s)，且绝不在大横幅出现时显示。
- 标题卡是主舞台的跑马灯招牌逐字点亮（FIVE-SECOND ASTRONAUT / A MICROGAME FRENZY）。

结尾卡位于电视里：片名、风格名和 "LemoLab × Claude Opus 5.5"，配上主角和主持人。"LemoLab × Claude Opus 5.5" 的署名只属于本库的示范片；用户的影片不带 LemoLab 署名，也不复制这张卡。

## 制作说明

```
styles/microgame/demo/
  timeline.js   tempo grid + segments (single source of truth)     film.js   assembly: stage, TV transitions, slot reels, boss tiles, end card, subs, events
  toon.js chars.js stage.js hud.js   home style, host & hero, stage, fuse/command/stamps/lives/subtitles
  glpass.js     WebGL2 material shaders: riso, crayon, CRT, ink, blueprint paper
  g_crayon.js g_ink.js g_ascii.js g_riso.js g_pixel.js g_blue.js g_swiss.js g_boss.js   one module per medium (scene + hero translation)
  frames.js     model sheets & style frames      music/score.py   original score      mix.py   foley + voices + ducking
  tools/        trim_cmd.py cuecheck.py subs.py final_asr.py review.sh mux.sh dump_timeline.mjs
```
1. 先写 `timeline.js`（速度网格），再写提示点表，然后把网格和提示点表交给一个音乐子代理。与它并行绘制画面。
2. 先构建主舞台风格和角色，然后**每种媒介写一个 `sceneX(g, lt)`**。用 `?scene=g_x.sceneX` 静帧逐个审查。
3. `sh demo/build.sh` 重建一切：TTS → 剪裁 → whisper → 配乐 → 事件 → 提示点检查 → 混音 → srt → 渲染（1436 帧约 25 s）→ 封装（−14 LUFS，grain 0），总共约 1.5 分钟。
4. 用 `bash demo/tools/review.sh out/revN 6 $(seq 0.5 1 59.5)` 至少审查两遍，外加每个关键动作的帧条。

### 我们踩过的坑

- 用亮度阶梯生成的 ASCII 主角是一团无法辨认的糊。改用手工模板加结构性字符，天线球用反白的 `@`。
- 水墨伞盖一开始读起来像黑烟或暴风云。让墨迹阶段短而圆，用渐变和缝线把伞衣扇形展开，加上扇贝形伞边，并让边缘保持浅淡。
- 瑞士风格的"敬礼失败"读起来像是举手。手臂必须*过冲并打中*红球，而且在 140 BPM 下，这次失败需要一个即时回放才能被看懂。
- alpha 模式的蜡笔图层会从蜡的缝隙中透出背景。在它必须是实心的地方，垫一层全压力的纸白底（或者不透明渲染再裁切）。
- 保留全局上下文（`K.g`）的卡通绘图辅助函数，在场景渲染到离屏缓冲（电视屏幕、老虎机滚轴、方片）时会画到错误的画布上。前后都要调用 `setCtx`。
- `flat` 在 GLSL ES 3 中是保留字。
- 上传 2D 画布时不设 `UNPACK_FLIP_Y`，v = 0 就是画布顶部；用 `p/R` 采样。
- 指令标签会堆起来（LAND IT! 和 PULL! 挤在同一个角落）。次要指令应该飞出，而不是变成标签。
- 100 % 的白色撞击闪光读起来像空白帧；上限设为 60 %。
- 在密集的混音中，即使信噪比 +16 dB，whisper 也经常听错 0.2 s 的指令词。逐段核验，并在 300–4 kHz 频段测量混音的信噪比。
