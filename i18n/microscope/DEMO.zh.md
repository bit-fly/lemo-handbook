# 显微叙事 — 我们的示范片

这只是众多可能中的一个例子。不要照搬它的故事、结构、镜头、道具或时间安排。

示范片：*Measured Blue*《量出来的蓝》（39.5 s）· `microscope.mp4` · 源文件在 [`demo/`](demo/)

一个连续的镜头，把一片染色的人肝组织切片从手中的玻片一路推到单个细胞核，再拉回来。途中它数出两个相距 1.4 mm 的 1 mm 圆圈内的蓝色（胶原）：13.5 % 和 32.6 %。屏幕上是中文，英文旁白，双语字幕（中文在上，英文在下）。使用一份公开的全切片扫描（Ventana-1.bif，PathAI，CC0）；每个数字都是从文件中测量得到的，并连同测量方法列在 [`demo/FACTS.md`](demo/FACTS.md) 中。影片只描述测量结果；不做任何诊断。

## 故事与结构

一句话梗概：一片指甲盖大小的染色切片；同一种染色，两个相距 1.4 mm 的圆，13.5 % 的蓝对 32.6 %，每个数字都是从扫描本身数出来的。

弧线：物件（石墨色工作台上的玻片、它的标签、一小片组织：*一张玻片，一片人肝组织*）→ 尺寸（推进到组织，一条尺寸线，4.80 mm）→ 第一次计数（大结节内的圆 A，一道扫描前沿点亮每个被计数的像素，13.5 %）→ 第二次计数（横移 1.4 mm 到圆 B，一个被厚纤维间隔包围的小结节，32.6 %）→ 转折（静默，然后两个圆同框并停留：*蓝色是 2.4 倍*）→ 最小尺度（推进到一个肝细胞核，焦平面扫过，一个圆环，8.5 µm）→ 爬升回到玻片，片名写在上面。

用到的原生手法：*推进* 作为招牌镜头（两次：玻片 → 组织 → 结节，以及结节 → 细胞核），对两个圆都用了 *给颜色计数*，转折处用 *两个圆，一个结论*，细胞核处用 *焦平面扫过与圆环*，以 *爬升回来* 进入片尾卡。

## 镜头

一镜到底；摄影机是一个相似变换，在关键帧之间以对数螺线插值。时间以秒计；放大倍率的切换发生在屏幕上金字塔层级真正切换的地方（推进时为 4.04、4.56、9.94、10.42、21.02、27.52、27.94、28.22；拉出时在 33.53 和 34.46 之间有六次）。

## 声音结构

90 BPM，4/4，每小节一个和弦：Dsus2 – Bm7 – Gmaj7 – Asus4（两遍），结论下用 Bm，Gmaj7，推进时用 Em9，细胞核落定时 D 大调，爬升时 Gmaj7，片尾卡用 Dsus2 – D。每个设计好的卡点都在网格上（`demo/tools/cuecheck.py`：0 ms）；转换器咔嗒声是配合画面层级变化的拟音。

| 段落 | 时间 | 音色 | 备注 |
|---|---|---|---|
| 开场 | 0–2.67 | 弓奏颤音琴铺底，柔和的颤音琴琶音，长音脉冲贝斯，移动光线下一层高音玻璃闪烁声，柔和的定音鼓 | |
| 推进 | 2.67–5.33 | 硬槌颤音琴十六分音符，八分音符脉冲贝斯，上升音效 | 每个层级一次转换器咔嗒 + 伺服声 |
| 组织 | 5.33–9.33 | 铺底，四分音符脉冲 | 画尺寸线时笔在玻璃上的声音 |
| 测量 | 9.33–20.67 | 颤音琴八分音符，马林巴反拍嘀嗒，四分音符脉冲 | 每个圆：画弧线的笔声，一道带通滤波的扫描声从左到右移动，伴随越来越快的计数嘀嗒；读数落定时钟琴 + 定音鼓（A 12.67，B 18.0）；横移时一声呼啸 |
| 静默 1 | 21.8–22.67 | 只有房间底噪 | |
| 结论 | 22.67 | 定音鼓 + 大鼓 + 钟琴 B5 + 贝斯低音 B | 静默之后的第一个声音 |
| 推进 | 26.67–29.33 | 再次十六分音符，上升音效，三次咔嗒 | |
| 落定 | 29.33–32.3 | 水杯玻璃动机 D5–A4–F♯5–E5–D5 带回声，D 大调铺底，一道随焦平面横扫立体声场的滤波扫频，读数落定时钟琴 F♯6 | 全片唯一的解决 |

混音（在 `mix.py` 中）：各分轨按有效 RMS 相对人声设定（音乐 −11 dB，脉冲 −14，拟音 −12，卡点 −6，房间 −30），有语音时音乐闪避约 4 dB，只对音乐、脉冲、拟音和房间做轻度总线压缩；除人声外所有声音都做 38 Hz 高通和 62 Hz 以下 −4 dB 的搁架衰减。成片测得 −14.0 LUFS，LRA 5.8 LU，峰值 −1.8 dBFS。

## 色板与道具

- 玻璃 #F4F1EC（玻片照片和扫描都归一化到此色），工作台石墨色 #0B0D0F → #2A3036，墨色 #181B1F，磨砂面板 rgba(12,14,17,0.74) 带 1 px 亮边，强调色薄荷绿：在染色上为 rgb(120,240,205)，在玻璃上为 rgb(0,122,99)。
- 染色保持原色：三色染色的红（肝细胞胞质）和蓝（胶原）。
- 道具：玻片照片（标签和条形码保持原样，制造商标志被填掉），尺寸线，两个 1 mm 圆及其计数像素遮罩，结论面板，细胞核圆环，仪器面板（比例尺、视野、带转动物镜转换器图标的放大倍率，每次新倍率大字闪现一次），来源面板。
- 旁白：Kokoro `af_heart`，语速 0.95。

## 片尾卡

摄影机一路爬升，直到玻璃填满画面；在空白的盖玻片上用墨色写着：量出来的蓝（Noto Serif SC 600），*Measured Blue*，一条从左向右画出的线，`MICROSCOPE STORY · 显微叙事`，`LemoLab × Claude Opus 5.5`，`数据：Ventana-1 · PathAI · CC0`；那一小片组织在右边。4.2 s。“LemoLab × Claude Opus 5.5”署名只属于本库的示范片；用户的影片不带 LemoLab 署名，也不复制这张卡。

## 制作说明

```
demo/
  build.sh          one command: (plates if missing) -> voice -> speech check -> cues -> events -> video -> mix -> master -> .srt -> checks -> poster
  index.html        one canvas, fonts
  film.js           render(t): similarity camera keys + log-spiral interpolation, plate selection, objective events,
                    focus, frosted panels, every mark and reading, subtitles, end card, TEXTS, SUBCHECK, EV
  timeline.js       90 BPM grid, key moments, narration with zh/en lines and the numbers it states (checked)
  mix.py            score, foley, room, voice, mix -> out/mix.wav + out/stems/
  config.json       circle centres, nucleus guess, the roll the scan direction is computed for
  tools/            plates.py (registration, cleaning, plates, collagen masks and counts, tissue axis), nucleus.py,
                    fonts.py (all fonts), export.mjs (voice lines, cues, number check), subcheck.mjs, cuecheck.py, finalasr.py
  assets/           raw/Ventana-1.bif (227 MB, gitignored), plates/ (plates, ROI overlays, plates.json, nucleus.json)
  FACTS.md, CREDITS, stills/styleframe.jpg
```

- `sh demo/build.sh` 在 Apple silicon 上大约需要 5 分钟（画面用 4 个 worker 渲染约 20–90 s；最后的语音检查是最慢的一步）。在全新克隆的仓库中，它会先下载玻片（227 MB），重建图层和测量（约一分钟），并抓取字体（Barlow Condensed 和 IBM Plex Mono 来自 github.com/google/fonts，Noto Sans SC / Noto Serif SC 子集来自 Google Fonts API）；`FETCH=1` 会强制重新执行所有这些步骤。玻片读取器在它自己的 `demo/.venv` 中运行（tifffile、imagecodecs）。
- 它运行的检查：用 `small.en` 跑 `asr_check.py`（小数按 Whisper 的写法写在每句的 `asr` 中），稿子中的数字对照测量值（`export.mjs` 遇到不一致就失败），卡点网格，用真实字体检查字幕单行宽度（最宽 642 px，上限 960），`readcheck.mjs`，对最终混音做语音识别，黑帧检查。
- 图层：玻片照片 1251 × 3685（21.2 µm/px），扫描第 5/4/3 层整幅并带 0.3 mm 羽化，第 2 层整幅（6144 × 5376，1 µm/px），第 1 层和第 0 层为细胞核周围 5120 × 3584 的裁切。每个渲染 worker 约 400 MB 的解码图像。
- 本示范片特有的坑：扫描仪托盘在玻片远端的夹子只能粗略填补，所以那一端在每个镜头中都不入画；玻片照片的分辨率标签，只有在组织的质心通过 AOI0 与扫描对齐（19 µm）之后才被采信；视野在 2.6 到 2.8 mm 之间时第 2 层图层会反复切进切出，所以两个圆保持在 2.6–2.7 mm，让转换器在读数期间保持安静；计数遮罩的扫描方向是按 `config.json` 中的滚转角计算的，如果滚转角改变，必须跟着摄影机一起改。
