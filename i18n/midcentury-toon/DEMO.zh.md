# 50s 扁平卡通 — 我们的示范片

这只是众多例子之一。不要照搬它的故事、结构、镜头、道具或时长。

示范片：*Meet Pip*（认识 Pip，40.0 s）· `midcentury-toon.mp4` · 源文件在 [`demo/`](demo/)


## 故事与结构

一部为虚构扫地机器人 Pip 制作的产品安装指南（即 STYLE.md §11 中的第一种用途）。它适合放在产品页面上、印成包装盒上的二维码，或者放进帮助中心。旧版指南把这个风格的每部片子都定义为"一部 30–40 秒的场景片：用户给你东西和步骤；镜头、时长、声音和配乐由你决定"；这一定义现在写在 STYLE.md 里。

结构：开场揭示（"Meet Pip."，盒子在芥末黄底色上打开）→ 每个步骤一个场景（全景 + 圆形细节标注）：① 把充电座靠墙放好（两侧各留 50 cm 空间），② 手机配对（2.4 GHz），③ 按住启动键（一秒）→ 高潮（扫地机的路线画在户型平面图上）→ 小贴士 → 海报式收尾版式（三个步骤化作三枚圆章）→ 光圈收拢结尾卡。

讲解人 **June**，一位新房主：蛋形脑袋，长而尖的鼻子是脸部轮廓的一部分；波波头配芥末黄发带，珊瑚色高领毛衣，藏青色烟管裤（创作方案里解释了她为什么不是 1950 年代的"家庭主妇"）。她的身体是一张保持不动的画；双手是四指手套，共四种手形：张开、平摊、指点、抓握。场景由一块色面、一条地面色带、一条有缺口的地平线，以及墙角、插座、手机之类的道具构成。

示范片中运镜如何服务于信息的参考：

**原生手法如何服务于信息（而非故事）：**
- **错版套色**让一张平面信息卡显得像手工制作，也足够温暖，可以放在产品页上。所有元素都保持错版，文字也不例外。
- **有限动画**引导视线。身体静止时，手是唯一在动的东西，而那只手*就是*步骤本身。每个步骤给一个手部动作，包含预备 → 动作 → 跟随，并落在节拍上。
- **圆形标注**（说明书里的放大镜）就是特写。全景保留语境，手在圆圈里变大。步骤的数据（50 cm、2.4 GHz、一秒）在动作节拍上落进圆圈内或圆圈边上，绝不做成幻灯片式的切换。
- **带编号的圆章**既是层级标记，也是一扇门。它盖印在即将离场的场景主体上，镜头穿过它进入下一步。
- **高潮把功能变成纹样。**在示范片中，扫地机的真实路线（先沿墙走，再走绕开家具流动的往返折线，每个转弯处有个小卷曲，线与线之间点缀星星和圆点）一个房间接一个房间地自己画出来，每个节拍一个房间。退远一看，它就像一块原子时代的印花布。

## 镜头

镜头永远是"拍摄台"：推、横移、俯仰、后拉，从不手持。示范片只用了一种转场语法——**圆形**：

| 运镜 | 示范片中的位置 | 原因 |
|---|---|---|
| 慢推 1.00 → 1.07 | 开场 | 把视线收拢到舞台上的产品 |
| **穿过圆章的光圈**（圆从印章扩展到全画面，0.9 拍） | 每次换步骤 | 步骤编号*就是*那扇门 |
| 向右横移 + 轻推 | 步骤 1 全景 | 跟随向墙推去的动作 |
| 圆形细节标注（画中画，带一条虚线引线指向主体） | 每个步骤 | 特写尺度下线宽不变；语境始终可见 |
| 推进手机，再沿信号环摇镜 | 步骤 2 | 从人 → 界面 → 设备 |
| 随手指向下俯仰 | 步骤 3 | 按键是最重要的动作；手指带着画面走 |
| **按钮 → 光圈 → 俯视图** | 步骤 3 → 高潮 | 启动键打开成平面图；从圆到圆 |
| **后拉 + 反向旋转，5.4× → 1.0×，−6° → 0°**（标志性运镜） | 高潮 | 尺度揭示：一条路线 → 一整套像印花布一样的公寓 |
| 色块划像（小贴士从侧面，收尾版式从下往上） | 小贴士、收尾版式 | 翻过说明书的一"页" |
| 完全静止 ≥ 3 s | 收尾版式 | 告诉观众：这一帧就是该截图的那一帧 |
| **光圈收拢到产品上**，结尾卡在圆圈内 | 结尾 | 经典的卡通结尾，也是最后一个圆 |

为什么为这个任务选这条路线：每次换步骤都穿过它自己的编号，所以层级本身就是剪辑；按钮 → 俯视图的光圈把最重要的动作和它的结果连在一起；后拉把全片唯一的"哇"时刻交给了产品的真实行为；完全静止的收尾版式就是那张截图。每一项都是从 STYLE.md §6 中做出的一个选择，而不是这个风格的默认开场或结尾。

时间线（由内容生成）：在 132 BPM 下，开场 4 小节，每个步骤 ≥ 3 小节（由其旁白长度决定），最后一个步骤 2 小节，然后高潮 3 小节、小贴士 2 小节、收尾版式 3 小节、结尾 2 小节。三个步骤 = 22 小节 = 40.0 s。关键主体 ≥ 画面高度的 1/3，且避开底部 140 px（字幕卡区域）。

## 配乐结构

- **音乐：**一支原创的西海岸冷爵士小编制乐队，**132 BPM**：颤音琴（和弦、琶音、滑奏、马达颤音）、长笛（旋律）、拨奏低音提琴（行走低音）、鼓刷（一个扫刷加第 2、4 拍，高潮时改用鼓棒敲叮叮镲）、钢片琴点缀。**每个步骤都落在它自己的颤音琴和弦上**（F6、B♭maj7、C9），收尾版式时这些和弦移调后再次出现，每枚圆章一个。在高潮段，颤音琴"每绕一圈弹一个音"，由 `events.json` 中导出的圈时驱动。
- **节奏弧线：**常速 → 高潮时加倍速（升高一个全音）→ 小贴士时半速（喘口气）→ 收尾版式回到常速。
- **静默：**A（0–1.36 s）：没有音乐，只有盒子。B（按键前最后一拍）：*全部*关掉，包括环境声，这样静默后的第一个声音就是启动的咔嗒声。C（收尾版式之前）：只有房间底噪。静默 C 之后的第一个声音是第一枚圆章的盖印声。
- **J/L 剪辑：**音乐在揭示之前进入；每个步骤的旁白在其光圈前半拍开始；马达声在高潮前 0.2 s 响起；最后一声 Wi-Fi 提示音延续到步骤 3；高潮的滑奏尾音延续到小贴士。
- **环境声：**温暖的房间底噪（低通的布朗噪声，约 −42 dB）和一个非常轻的壁炉钟滴答声，落在二分音符网格上。高潮时由 Pip 的马达嗡鸣（带通锯齿波加慢速 LFO，再加鼓刷的嘶嘶声）接管。
- **本片的拟音：**盒子（吱呀声、盒盖相差一个半音的两下闷响、一声呼地划过接一声啪）、插头咔嗒声、充电座在地面上的摩擦声、每枚圆章的盖印声、50 cm 箭头的滑音哨、表示"已连接"的上行提示音、每个房间路线画出时的笔尖沙沙声、墨线从纸上剥离的声音、光圈的"刷"声。
- **混音：**旁白压缩后置于最上层，音乐在其下压低 8 dB，拟音不压低，−14 LUFS，真峰值 −1.2。`tools/cuecheck.py` 检查出 0 处偏离半拍网格。
- **旁白：**沉稳的课堂权威感。示范片使用 Kokoro `am_michael`，语速 0.94。试过 `bm_george`：whisper 在他的英式元音里把 "dock" 听成了 "dark"。每句只保留一个分句："Step one. Set the dock against a wall."

## 色板与道具

**色板（示范片；每个值都是 content.json 中的一个字段）：**

| 角色 | Hex |
|---|---|
| 纸张 | `#F4EAD5`（暗部 `#E6D8BC`、`#D4C29F`） |
| 墨色（暖黑） | `#2B2420` |
| 珊瑚色（强调色，June 的毛衣） | `#E4613F` / 深 `#B8452B` |
| 芥末黄（开场底色、腰带、圆点） | `#E8B43A` / 浅 `#F3D37F` |
| 青绿色（产品） | `#3FA7A0` / 深 `#257A74` |
| 灰蓝 / 牛油果绿 / 粉 / 梅紫（各步骤底色） | `#7F9CC0` · `#A7AE5B` · `#F0B4A8` · `#6E4A6B` |
| 藏青（裤子）· 头发 · 皮肤 | `#3B4766` · `#3A2621` · `#F2C7A0` |
| 牛皮纸（盒子） | `#C9955D` / `#A2713F` / `#DDB47F` |

- **每个场景一种底色**，墙面用更浅的色调（`tint(col, .45)`），地面用更深的暗色（`shade(col, .16)`）。绝不把产品放在它自己的颜色上，也不把 June 放在珊瑚色或粉色上。
- **线条：**3–5 px 的墨线带，宽度有 ±40 % 的呼吸变化和 12–25 % 的断口。角色：4 px。道具：3–4.5 px。平面图中的墙：6–7 px，带断口。手：手掌和手指合并后的外轮廓用一条 6 px 的线，手指之间的分隔线 2.4 px。
- **明暗：**在形状内部裁切出一块平涂的深色面（绝不用渐变）。投影是形状的一个副本，偏移 (12, 12)，用 50 % 的纸张暗色。
- **装饰：**四角原子闪光、8–18 角的星爆、太阳放射线（30 条楔形，55 % 透明度）、回旋镖和肾形、波点。
- **字体：**Oleo Script Bold 用于引语（"Meet Pip."）；Alfa Slab One 用于标题、数字和步骤标题（墨色字，配奶油色或彩色的底版，偏移 4–7 px）；Jost 500/600 用于正文、细节、标签和字幕（小标签用加字距的大写字母）。
- **颗粒：**轻度（mux grain 4）加纸张叠层；质感是印刷品，不是胶片。
- **角色设定图：**[`demo/stills/modelsheet_v2.jpg`](demo/stills/modelsheet_v2.jpg)（`?test=sheet`）：June 的转面图、五种表情、关键姿势和手形，以及产品在关机 / 开机 / 平面视图 / 充电座四种状态下的样子。

STYLE.md 中各条规则背后的示范片数值：套色偏移 `(6, 4)` px，以 12 fps 重新随机 ±1.6 px；平面图中的墙 6–7 px，带断口；手为一条 6 px 外轮廓，手指分隔线 2.4 px；投影偏移 (12, 12)；太阳放射线 30 条楔形，55 % 透明度；mux grain 4；墙 `tint(col, .45)`，地面 `shade(col, .16)`；弹出动画 0.24–0.3 s，过冲 1.9；手部预备动作 20–60 px，回弹 6–10 px；跪姿让臀部下降 150 单位（`kneel: true`，`kneelPose()`）；字幕卡用 Jost 500 42 px，距底部 60 px，淡入 0.16 s 并上升 10 px，色版偏移 5 px，珊瑚色八角星；步骤标题 Alfa Slab 64 px；细节标签 Jost 36 px。

**高潮：**扫地机的真实路线（先沿墙走，再走绕开家具流动的往返折线，每个转弯处有个小卷曲，线与线之间点缀星星和圆点）一个房间接一个房间地自己画出来，每个节拍一个房间，同时镜头从 5.4× 后拉到 1.0×，并伴随 −6° → 0° 的反向旋转。退远一看，它就像一块原子时代的印花布。

## 结尾卡

收尾版式之后，在光圈圆圈内：片名、风格名、`Lemo-Opuscar`、`LemoLab × Claude Opus 5.5`、素材署名。LemoLab 的署名只属于本库的示范片；用户的影片不带 LemoLab 署名，也不复制这张卡。

## 制作说明

1. `demo/content.json` 存放每一个字、数字、颜色、旁白声音和高潮的平面图方案。`python3 demo/tools/lines.py` 把它转换成 `lines.json`。
2. Kokoro（`core/tts/tts.py`）→ `voices/` + `dur.json`；反复运行 `asr_check.py`，直到每句都 OK（步骤编号按数字比对）。
3. 时间线由内容生成（见"镜头"）：在 132 BPM 下，开场 4 小节，每个步骤 ≥ 3 小节（由其旁白长度决定），最后一个步骤 2 小节，然后高潮 3 小节、小贴士 2 小节、收尾版式 3 小节、结尾 2 小节。三个步骤 = 22 小节 = 40.0 s。
4. 配乐（`music/score.py`，连同提示点表一起交给一个子代理）→ `score.wav`、分轨和 `hits.json`。
5. `core/render/events.mjs` 导出与画面使用的相同的事件时间。`tools/cuecheck.py` 把每个击点与半拍网格和配乐对照检查（示范片中 0 处偏离）。`mix.py` 构建拟音、旁白、闪避压缩和三段静默。
6. `tools/cues.mjs` → `.srt`；用 `core/render/video.mjs` 渲染（960 帧，2 个 worker 约 30 s，通过 `core/render/slot.mjs`）；`mux.sh … 24 4`。
7. `sh demo/build.sh` 完成以上全部；`sh demo/build.sh stills` 渲染内容替换测试。

与本示范片道具相关的陷阱（通用规则在 STYLE.md 中）：

1. **路线必须符合产品逻辑。**我们第一版高潮的路线从沙发上绕了过去。修复：先沿墙走，再让往返折线作为**势流流线**（`laneY()`）绕开家具：折线之间从不交叉，也从不进入障碍物椭圆（家具 + 30 px）。障碍物要远离墙；被挤在墙边的流线会让多条折线叠在一起。
2. **不要一次铺满整个图案。**一个房间接一个房间地画，每拍一个房间，同时镜头后拉。最后沿一条同样避开家具的虚线回到起点。
3. **鼻子要在轮廓之内。**单独画成楔形的鼻子看起来像粘上去的纸锥。把头部做成一条开放样条，从鼻梁绕过头顶到鼻子下方，再在鼻尖处闭合（`chain + tip`）。在 3/4 侧面视角下，把远侧的眼睛放在鼻梁左边，这样它才能露出来。
4. **手臂从肩膀长出来。**肩膀位于躯干的两角（±40–46, −384）。袖子画成一条粗墨线带，上面再叠一条珊瑚色带。细细的墨线手臂看起来像从脖子里伸出来的棍子。
5. **手套手需要缝隙。**把手指画成胖乎乎的团块会让手变成一朵云。先给每个部分描边，再给每个部分填色（一条合并的外轮廓），手指要纤细（rx 12–13，ry 5），并加分隔线。
6. **够到地面。**站立人物的手大约停在肩膀下方 190 单位处。让人物跪下，用 IK 解算手臂，而不是把手臂拉长。
7. **特写中的线宽。**把世界镜头放大 3× 会让墨线也变粗 3 倍。把特写放进按原生尺度绘制的标注圆圈里。
8. **细节文字需要阅读时间。**"Against a wall, 50 cm clear each side" 塞不进它的 3 s 窗口。于是数据移到了 `detail`（"50 cm clear on each side"），"墙"则移到标题和旁白里。
9. **高潮路线 + 字幕箭头可能与标签冲突。**把房间标签放在平面图*下方*，字幕放在上方页边。
10. **光圈内容处于负的本地时间。**当转场在下一场景开始之前就绘制它时，把 `t` 钳制到刚过开始的时刻（否则姿势和弹出动画是未定义的）。

## content.json 字段

所有可读文字和每一种颜色都来自 `demo/content.json`。页面读取 `?content=<file>` 用于测试。

| 字段 | 类型 | 范围 | 超出范围时 |
|---|---|---|---|
| `product` | string | 1–12 个字符 | 挤压以适应盒子标签（`maxW`） |
| `kind` | string | 自由 | 仅供你自己参考 |
| `title` / `subtitle` | string | ≤ 36 / ≤ 24 个字符 | 标题在开场换成 2 行，在收尾版式中缩小到 50 px |
| `hook.kicker` / `hook.line` | string | ≤ 14 个字符 / 一句话 | 引语挤压到 760 px；这句成为第一条字幕 |
| `steps[]` | array | **2–5** | 每个步骤增加 ≥ 3 小节（5.45 s）；收尾版式那一行重新排距（超过 3 步时 R 从 104 → 88 px）。4 个步骤 ≈ 45 s：如果需要 ≤ 40 s，就削减小贴士或结尾卡 |
| `steps[].title` | string | ≤ 22 个字符 | 缩小到 40 px（步骤标题），换成 2 行（收尾版式） |
| `steps[].detail` | string | ≤ 30 个字符 | 换成 2 行；必须能在它的窗口内读完（字符数/12 + 1 s） |
| `steps[].icon` | enum | 18 个图标名 | 未知 → `spark` |
| `steps[].action` | enum | `place`（推到墙边 + 间距示意图；使用 `measure`）、`tap`（手机配对，信号环指向产品）、`press`（手指 + 长按圆环）；其他任何值 → `show`（图标在手里，手指在标注中点击它） | — |
| `steps[].measure` | string | 例如 "50 cm" | 仅用于 `place`；为空 = 箭头不带标签 |
| `steps[].line` | string | 一个短句 | 旁白 + 字幕；句子太长会拉长它所在的步骤 |
| `payoff.caption` | string | ≤ 40 个字符 | 缩小到 26 px |
| `payoff.plan` | object | `y0,y1`、`dock[x,y]`、`zones[]`（name、x0、x1、color、checks）、`rug`、`items[]`（shape：sofa、kidney、boomerang、chair、plant、table、bed；x、y、s、rot、color、accent），以 1920×1080 平面图 px 为单位 | 窄于 400 px 的区域只走沿墙一圈；物品会自动成为流场障碍物 |
| `tip.label/text/icon/line` | strings | 文字 ≤ 40 个字符 | 标题缩小；色带加宽 |
| `outro.line` / `outro.cta` | string | cta ≤ 48 个字符 | CTA 缩小到 20 px |
| `palette` | object | `paper, ink, product, productDark, accent, hook, steps[], tip` | 缺失的键回退到示范片色板 |
| `voice` | object | Kokoro `id`、`speed` | — |
| `film` | object | `name, style, credits` | 结尾卡 |

## 引擎参考

`demo/engine/toon.js`（风格本身）、`demo/engine/chars.js`（讲解人、手和产品）、`demo/engine/icons.js`（18 个图标）。所有函数都在当前画布变换下绘制。

**最小示例：本风格下一个带光标尾迹的暖橙色四角闪光**（"唯一颜色"槽位：场景换色时保持 `fill` 不变）：
```js
import { setClock, shape, ink, sparkle, starPts, spline, PAL } from './engine/toon.js';
setClock(t);                                   // register jitter on twos
ctx.fillStyle = PAL.paper; ctx.fillRect(0, 0, 1920, 1080);
// the tail: a broken ink stroke that draws on
ink(ctx, spline([[520, 700], [700, 640], [860, 560]], false, 10), 6, { upto: Math.min(1, t / 0.6), breaks: 0.2 });
// the spark: any closed path -> off-register fill + breathing ink line
const pts = [];
for (let i = 0; i < 8; i++) { const a = i * Math.PI / 4 - Math.PI / 2, r = i % 2 ? 26 : 110; pts.push([960 + Math.cos(a) * r, 520 + Math.sin(a) * r]); }
shape(ctx, pts, { fill: '#D97757', line: 4.5, grain: 0.3, breaks: 0.15 });
sparkle(ctx, 1040, 440, 28, { fill: PAL.white });
```
