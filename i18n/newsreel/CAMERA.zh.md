## 6. 静态照片与档案素材上的摄影机

| 运镜 | 作用 | 典型用法 |
|---|---|---|
| 旋转后砸定 | 报纸作为新闻到来 | 一条头条；一封电报；一张海报 |
| 缓慢推镜后在节拍上急推 | 从整个版面到唯一的细节 | 一条头条 → 其中的一张照片 |
| 沿宽幅照片摇镜 | 人群、游行、天际线 | 全景照、合影 |
| 俯仰揭示 | 主体身后的地标 | 一座建筑、一座纪念碑 |
| 地图推镜 | 从国家到一座城市，进入下一个故事 | 旅行、扩散、运动/宣传活动 |
| 网格发牌 | 许多相关的静态照片每拍落下一张 | 分步骤、合集、"全都是" |
| 翻页书 | 一组静态照片按节拍播放，变成动态 | 舞步、组装阶段、前后对比 |
| 定格 + 一震 | 让档案停在最能说明问题的那一帧 | 笑点、证据 |
| 分屏 / 四宫格 | 两个或四个地方同时并排呈现 | 比较、"人人都在跳" |

档案影像不用超过约 6 % 的假运镜来重新构图（它已经有自己的摄影机运动）；静态照片则总要配一个有目的的运镜。



## 8. 原生动作

一份菜单；按故事需要选用，每个只用一次。

- **片头标识仪式。** 探照灯在前 0.2 s 内伴着闪光啪地亮起，地球仪变大并转动，名称带过冲效果落定，光圈在地球仪上合拢。代码：`sceneLogo()` — `sunburst()`、`beams()`、`globe()`、`decoTitle()`。*适合：*任何新闻形态影片的开场；它的重现就是结束语。
- **旋转报纸。** 按 `u^2.3` 变大，旋转按 `(1−u)^1.25` 在 2.5 圈内衰减，三个相隔 18 ms 的残影副本作为运动模糊，砸定时有一个竖向震动（阻尼正弦，16 px）和 3 % 的回弹，然后在下一拍推镜并急推。*适合：*一条头条、一项法令、一份新闻稿。
- **地图扩散。** 一个投影轮廓（Natural Earth，Albers），从源城市出发的虚线弧线按节拍画出并伴有电报嗒嗒声，到达时星标脉动，地名标签放在屏幕空间，角落里一个年份计数器；推镜进入下一个故事所在的城市。*适合：*一股热潮、一次产品发布、一次迁徙、一场运动。
- **网格发牌 → 翻页书。** 静态照片每拍落下一张（每张一声快门），然后摄影机扎进第一格，整组照片按节拍以定格动画播放。*适合：*一个教程、一个流程的各个阶段、一个合集。
- **文件下划线。** 砸下一本书或一封信，翻页，推镜到段落，用软铅笔逐字精确地画出下划线（位置取自扫描件的 OCR 框，例如 archive.org 的 hOCR）。*适合：*一句引语、一条规定、一项合同条款。
- **油性笔定格。** 定格在最能说明问题的那一帧，让它一震，用手绘圈圈出细节（`pencil()` + `ring()`），加一个箭头。*适合：*证据、笑点、"看这里"。
- **分屏对决 → 推出。** 两个面板滑入，各有标签，各自在自己的声道里有自己的音乐，轮流交替小节；获胜的一方把输的一方推出画面。*适合：*新旧对比、竞争产品、两座城市。
- **落针。** 乐队戛然而止，一张 78 转唱片在角落里旋转，那个年代的唱片在档案画面下播放，并在定格处以它自己的和弦结束。*适合：*任何拥有公有领域录音的年代。
- **乐队停顿 + 收尾。** 一个戳击和弦，只有放映机声的静默，播音员的一句短话。*适合：*任何故事的最后一句话。
