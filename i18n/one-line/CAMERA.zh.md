## 5. 动作质感

- **全部逐帧（on ones）**（24 fps）：魅力在于连续的作画过程；跳帧会破坏它。
- **时间 = 章节时间窗 + 曲率**：在时间窗内，每个点的时间按 `1 + K·turn` 加权（急转弯分到更多时间，并经过平滑，使速度永不突变）。用标记钉住音乐节拍：按弧长比例，或按位置（“笔第二次经过这里时”）。一次停顿就是同一位置上的两个标记。
- 拐角（转弯大处的速度极小值）可以导出给配乐，作为候选的音符起点。
- 速度：行进中的线约 300–700 单位/s，小细节约 50–150。最重要的那一笔通常是最慢的。
- 沿已有的线**重描**是允许的，且看不见（只会稍微变粗）。



## 6. 镜头语法

这是一套词汇，而不是一条路线。镜头是一个连续的运动：构图中心、缩放、几度的滚转，以及一个跟随权重（0 = 构图固定，1 = 锁定笔尖）；跟随点是笔尖在大约 −0.55…+0.4 s 区间的平均位置（滞后与预判），并有一个软限位把笔尖保持在画面中央约 70 % 的范围内。开场和结尾由题材决定。

| 运镜 | 表达什么 | 可用于 |
|---|---|---|
| 跟随笔尖（高跟随权重） | 行进；动势；一条时间之线 | 一段旅程；一个过程；一条时间线 |
| 构图固定，低跟随权重 | 一个必须整体读懂的场景 | 一个小场景；一个笑点；一张图解 |
| 笔尖微距 | 亲密；创作的动作本身 | 第一次落笔；一个签名；一个细节 |
| 停留加缓慢推镜 | 分量；一次停顿 | 失去；怀疑；抉择 |
| 镜像取景 | 跨越时间的呼应 | 父母与孩子；前后对比 |
| 连续拉镜 | 一切原来是同一幅画 | 揭示；一张地图；一个字 |
| 横向卷动，线在前方奔跑 | 地平线；一张图表；一场赛跑 | 股价走势图；心跳；一条路 |
| 随线滚转 | 眩晕；嬉戏 | 翻跟头；坠落；一支舞 |

不剪切。转场就是变形：上一幅画的最后一笔就是下一幅画的第一笔。



## 8. 招牌手法

一份菜单：按故事需要选用。

- **笔从不离纸。** 任何一以贯之的东西。*适合这类内容：* 一条河从源头到大海；一场接力赛；一条生产线。
- **线就是时间。** 笔触的性格随年龄、情绪或压力变化。*适合这类内容：* 一座建筑的老去；一个跑者逐渐疲惫；一台机器的磨损。
- **变形。** 一幅画变形为下一幅。*适合这类内容：* 种子长成树、树做成桌子；草图变成产品；一个字变成它所指的东西。
- **停顿就是事件。** 笔尖停下，墨迹聚积，音乐骤然静默（1.5–3 s）。*适合这类内容：* 一次停电；默哀一分钟；签字前的一瞬犹豫。
- **逆向设计的尺度揭示。** 每个小场景暗中都是结尾才看到的一幅大画的一部分。*适合这类内容：* 城市地标组成天际线；公司里程碑组成它的标志；菜谱步骤组成这道菜。
- **交接。** 笔传到另一只手里（以影子形式），一根新线开始。*适合这类内容：* 老师与学生；创始人与继任者；一代人传给下一代。
- **线即图表。** 线变成图表，同时仍然是一幅画。*适合这类内容：* 心跳；一份气温记录；一场足球比赛的攻势起伏。
