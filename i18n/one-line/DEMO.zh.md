# 一笔画 —— 我们的示例片

这只是众多可能中的一个例子。不要照搬它的故事、结构、镜头、道具或时间安排。

示例片：*The Line That Never Lifted*（47.5 s）· `one-line.mp4` · 源文件在 [`demo/`](demo/)


一部 30–60 秒的影片：一个男人的一生被画成一根线，而在最后的拉镜中，这根线原来是他自己年老时的脸。

## 故事与结构

一部由**一根连续的线**在暖白色纸上构成的影片。笔从不离纸：在代码里，整部影片字面上就是一个点数组，从笔尖第一次触纸到最后一帧。没有剪切。镜头像跟拍一样跟着笔尖，带一点滞后、一点预判，让观众始终看着这根线*正在被画出来*。

一切都是线：人物、地点、物件，甚至时间。没有填色，没有明暗，没有第二种线宽，没有背景画。屏幕上除了墨线，只有纸本身和一道柔和的**笔影**（纸面上方的真实世界）。最多一种强调色，只用一次。

从 Osvaldo Cavandoli 的 *La Linea*（1971）学习语法——一根线既是世界也是角色，线的变形就是笑点和转场；从 Gjon Mili 1949 年拍摄毕加索用光作画的照片学习——单一手势的自信与速度；从 Norman McLaren 的 *Begone Dull Care* 和 *Boogie-Doodle* 学习——*随着*音乐画出的线。不要照搬 La Linea 的角色、它那种叽里咕噜的配音，或任何具体的连续线插画。

选择**线的连续性本身就是意义**的故事。示例片用上了全部五种招牌能力，并把最强的一种（尺度揭示）放在高潮：

| 招牌能力 | 故事用法 |
|---|---|
| **笔从不离纸** | 一生、一段旅程、一个过程、一段历史：任何*一以贯之*的东西。永远不剪切；镜头跟着笔尖走。 |
| **线就是时间** | 笔触的性格随年龄或情绪变化：年少时轻快，成年时饱满稳健，年老时颤抖并带着枯笔断墨。某一段可以变色（爱情、危险），再变回来。 |
| **变形** | 风筝线变成自行车车架，微笑变成一条路。场景不剪切，而是*变形*：上一幅画的最后一笔就是下一幅画的第一笔。 |
| **停顿就是事件** | 笔尖一停，墨就聚积晕开。1.5–3 s 的停顿，配合音乐骤然静默，是这种媒介里最强的节拍（失去、怀疑、抉择）。 |
| **逆向设计的尺度揭示** | 每一个以特写画出的小场景，暗中都是一幅大画的一部分。最后镜头拉远，观众才看到整个故事*原来是*一张脸（一棵树、一张地图、一个字）。 |

改编任何题材：找到故事可以收尾的**那一幅画**，以及能各自成为其一部分的 6–8 个瞬间。一家公司的历史 → 创始人的第一张书桌、第一个产品、第一间办公室……就是标志的各个部件。一座城市 → 它的地标是其创建者肖像的线条。一个爱情故事 → 两段分开画的人生，最终合成一颗心。

**40–50 s 的情绪弧线：** 白纸上的一次落笔（前 3 s 的钩子）→ 快速、轻盈的早期章节 → 唯一着色的那一章 → 一次停顿（静默，墨迹晕开）→ 线重新开始，已经改变 → 最后缓慢的几笔，同时镜头拉远 → 整幅画面，停留 → 一段把笔传下去的尾声。

## 镜头

镜头是一个连续的运动：构图中心、缩放、几度的滚转，以及一个跟随权重 `f`（0 = 构图固定，1 = 锁定笔尖）的关键帧。跟随点是笔尖位置在 −0.55…+0.4 s 区间的加权平均，由此产生滞后和预判。一个软限位把笔尖保持在画面 72 % × 66 % 的范围内。

| 节拍 | 镜头 |
|---|---|
| 开场 | 在笔即将落下的白纸上做微距（z ≈ 4.3）；第一个小场景采用构图固定，f ≈ 0.1 |
| 行进中的线 | 跟随（f 0.6–0.85），拉远到 ≈ 2.4 |
| 每个小场景 | 构图固定（f 0.15–0.35），取景让画完的图居中 |
| 停顿 | 停留，在整段静默中极慢地推镜（4.6 → 5.4） |
| 镜像章节 | 与它所呼应的章节取景相同，左右镜像 |
| 揭示 | 在画最后几笔的同时，用 5 s 从 ≈ 3 连续拉镜到 1，然后停留 ≈ 1 s |
| 尾声 | 推镜到笔停下等待交接的位置；新线条跑起来时再次拉镜；片尾卡落在空白纸面上 |

- **全部逐帧（on ones）**（24 fps）。魅力在于连续的作画过程；跳帧会打破这种错觉。
- **时间 = 章节时间窗 + 曲率。** 每个章节有一个时间窗；在窗内，每个点的时间按 `1 + K·turn` 加权（急转弯分到更多时间，并经过平滑，使速度永不突变）。用标记钉住音乐节拍：按弧长比例 `f`，或按位置 `at:[x,y]`（“笔第二次经过鼻子时”）。一次停顿就是同一位置上的两个标记。
- 拐角（转弯大处的局部速度极小值）会导出给配乐，作为候选的音符起点。
- 典型速度：行进中的线 300–700 单位/s，小细节（手指、睫毛）50–150。一生的最后一笔应是全片最慢的一笔。

## 配乐结构

- **音乐：一件独奏乐器，一条不间断的旋律线**——相当于画面的声音版本。示例片使用大提琴（`cellos`，低力度，单声道，略偏左，连奏，重叠 0.14 s），童年部分用 `cellos_pizz`，下一代开始时用一个 `hand_chimes` 音。不用钢琴，不用弦乐铺底。
- 照着画面写配乐：关键音落在标记和拐角上（握住手指时回到主音，风筝的每个角是一次拨弦，最高音是两个鼻尖第一次相触，最后一只眼睛的睫毛是最后三个音）。线快 = 短音；线停 = 一个长音渐弱到静默。
- **静默就是字面意义的静默**：停顿期间把音乐总线连同混响尾音一起归零；房间底噪降到 15 %。
- **笔在纸上的声音是最重要的声音**：根据笔速轨合成——带通噪声（快时明亮 2.2–7.5 kHz，慢时沉闷 0.7–2.4 kHz），随机的纸纤维咔哒声，密度 ∝ 速度，振幅 ∝ (v/520)^0.5，声像随笔尖在屏幕上的位置移动；年老时被枯笔断墨打断；孩子的部分更轻、更跳。再加上第一次落笔时的一声木质轻叩、墨迹晕开时几乎听不见的湿润涌声、交接时一声细小的摩擦。
- **人声**：温暖、回望式的男声旁白（Kokoro `am_liam`，速度 0.84；85 Hz 高通、7.2 kHz 低通以柔化）。5–6 句短台词，给线条留出空间。按 whisper 的词级时间戳放置，让关键词落在画面节拍上（“holding **on**”落在握手指时，“**goes** on”落在笔重新开始时）。人声下音乐压低 ≈ 5 dB、笔声压低 ≈ 4 dB。响度 −14 LUFS，**颗粒 0**（纸张纹理已在渲染中）。

## 色板、道具与逆向设计的脸

**逆向设计是核心技法。** 先画出最终画面，再把它切成章节，然后设计每个章节，让它在特写中读作一个独立场景，*同时*又是最终画面的一个部件。在示例片中奏效的规则：
- **最终画面的每个区域只画一次。** 章节之间的连接线必须落在最终画面的自然线条上：镜框边缘、法令纹、鱼尾纹、下颌轮廓、一根头发。每一根“多余”的连接线，在揭示时都会变成一道杂乱的皱纹、一块赘肉或一把胡子。
- **像规划欧拉路径一样规划拓扑。** 一个闭合母题，比如嘴（微笑 + 上唇 + 两个侧脸），是一个回路：从哪里进就从哪里出。要么让下一章从同一点出发（重描的褶纹是看不见的），要么调整章节顺序。我们把“失去”挪到“孩子”之前纯粹是出于拓扑考虑，然后把它变成了情感重点（“and then it goes on”）。
- **重描是允许的，且看不见：**沿已有的线走回去只会让它稍微变粗。在示例片中，笔通过重描风筝尾巴和风筝线回到头顶，把风筝“收”了回来。
- **尽早、经常测试揭示效果：**每次改动后，以最终尺度一次性渲染整条路径（`?all=1&cam=0,-170,1`）。

**示例片使用的映射**（老人的脸）：左耳 = 他的出生（一只婴儿拳头蜷成耳朵的 C 形，握着一根成人的手指，那手指同时也是他眼镜的镜腿）；光秃的头顶 = 风筝线，风筝 = 他唯一的一根头发；眼镜 = 自行车（车轮 = 镜片，车座 = 左眉，车把 = 右眉，车架 = 鼻梁两侧）；嘴 = 初恋（两个侧脸鼻尖相对；他们的头顶构成上唇的 M 形，下方是红色的微笑）；鼻子 = 房子（戒指和一扇圆窗是鼻孔）；右眼 + 泪滴 = 失去；右耳 = 他自己的孩子（他出生那一章的镜像）；下颌轮廓 = 老年；左眼闭上 = 最后一笔。

**纸**：暖白 `#F4EFE4`；程序化的斑驳纹理（1400 单位平铺，柔光混合），长纤维（260 单位平铺，拉远时渐隐，以免闪烁），近距离缩放时在墨线上方叠一层稀疏的“纸纹齿”斑点；暗角 0.13 正片叠底。所有纹理都固定在纸上，随镜头一起移动。

**墨**：暖黑 `#1D1A17`，渲染为围绕路径的填充多边形（不是 `ctx.stroke`），按每个点与纸色混合成不透明色调。
- 宽度 = 年龄基础宽度 × 笔压 × 细微噪声（±8 %）。笔压由速度决定：`0.66 + 0.8·exp(−v/300)`（快 = 细，慢 = 粗）。
- 基础宽度（纸面单位）：孩子 2.4（alpha .82），少年 2.5，成年 2.9（.96），老年 2.7（.93），下一代 2.0（.76）。在章节边界的 ±60 单位内混合过渡。
- 洇墨：同一个多边形稍微加宽，画到离屏图层，模糊（≈0.9 × zoom px），以 22 % 合成。
- 墨聚：速度 < 45 单位/s 处额外加圆点。
- 老年：垂直方向的颤抖（两个八度的噪声，振幅最高 ≈1.1 单位），由长尺度噪声产生的枯笔断墨，加三根细细的笔毛丝；**最后几笔再把枯涩感减弱**，让最后的手势清晰。
- 停顿：泪滴形墨迹（尖端在停住的笔尖处，晕开时肚子往下坠，边缘有一圈深色水线）。
- **保持屏幕空间的最小线宽。** 线宽随缩放变化，就像微距镜头下的真实线条，但在拉镜过程中，用于计算线宽的缩放值要限制在 ≥ 1.3（揭示时 ≈ 3–4 px）。否则最终画面看起来像铅笔速写，失去分量。

**颜色**：最多一种强调色，只用一次，并保留在最终画面中有意义的位置。示例片的红色 `#B3332B` 恰好从嘴角开始，到下一章又回到墨色，所以老人身上唯一的颜色就是他的微笑。

**笔**：从不画出来。只有一道柔和的影子（从笔尖向右下方延伸的模糊楔形，长度 ≈ 560 × zoom px，alpha .15）和一个 1–4 px 的接触点。手只在交接时以影子形式出现（每只手作为一个整体的平涂影子合成，这样重叠处不会变得更暗）。

## 标题、字幕与片尾卡

- 字幕：Caveat 500，46 px，84 % 墨色，无底框，居中，基线距底部 100 px；字幕从左到右**书写出现**（0.2 s + 每字 17 ms），背后有一圈柔和的纸色光晕，让经过的墨线永远不会穿过字母；0.45 s 淡出。停留时长 ≥ 人声 + 0.6 s 且 ≥ 1.8 s。
- 标题：Sacramento（一种单线连写体——本身就是一笔画）76 px，在远离当前小场景的空白纸面上用 1.6 s 书写出现，下面配一行小号 Caveat 副标题。要足够短，在镜头移过去之前就消失。
- 片尾卡：两行 Sacramento 标题，“ONE-LINE DRAWING”用宽字距的 Caveat 600，下方是署名行，在新线条仍在画的时候写在最终画面旁边的空白纸面上。其中的“LemoLab × Claude Opus 5.5”一行（`subs.js`）只属于本库的示例片：用户的影片不带 LemoLab 署名，也不复制这张卡。

## 我们踩过的坑（示例片记录）

- **多余的连接线会毁掉揭示。** 每个早期版本都有被看成胡子、双下巴、围兜或面具的线。要修拓扑（哪一章从哪里进、从哪里出），而不是修画。
- **从头顶直直往上画的风筝，变成了一个尖尖的洋葱顶。** 让风筝线就是那唯一的一根头发，并重描（收线）回到头顶，让头顶保持一条干净的弧线。
- **从太阳穴横伸出去的手被看成了螺栓。** 把婴儿拳头蜷进耳朵竖直的 C 形里，指尖藏在里面，指节画成四个短而圆的凸起（长圈会被看成弹簧）。
- **用一道弧线在头顶闭合的两个侧脸，被看成了高脚杯**（鲁宾花瓶）。改为让他们的头顶构成上唇的 M 形，脖子在一点汇入微笑。
- **侧脸靠得太近**，加上线宽后会缠在一起；嘴唇之间保持 ≥ 5 单位，只在鼻尖相触。
- **眼睛**：带眼袋的杏仁形会被看成露牙的嘴；闭着的眼睑（‿）加三根短睫毛效果最好。
- **圆形墨迹被看成痣。** 把它做成晕开时下坠的泪滴形。
- **揭示时线太细。** 限制线宽用的缩放值（见“色板、道具与逆向设计的脸”）。
- **手影做成分开的半透明形状**，在手指重叠处会加倍变暗——把每只手合成为一个图层。
- **镜头移动时标题和小场景撞在一起。** 要在标题时间窗内的每一帧都检查，而不只是第一帧。
- **Whisper 听错**：“Sometimes it stops”被听成“But sometimes it stops”，“Your turn.”被听成“Your turns”——与其较劲，不如改写台词（“Sometimes the line stops.”、“Your turn now.”）。
- **zsh**：作为 echo 分隔符的 `=====` 会被展开；机器负载高时 `still.mjs` 很慢——页面支持 `?cams=` / `?camt=`，可以在一次浏览器会话中渲染多个视角。

## 构建说明

```
styles/one-line/demo/
  face.js    THE drawing: every chapter as SVG path strings + transforms, and the chapter table (time windows, marks, holds)
  geom.js    samples SVG paths by arc length (browser SVGPathElement), adds tangent-continuous connectors, assigns time (curvature-weighted, marks, holds)
  ink.js     line renderer (pressure, bleed, pooling, tremble, dry brush, red stretch, teardrop blot, min screen width)
  paper.js   procedural paper, fibres, tooth, vignette          cam.js    composition keys + nib follow + soft clamp
  shots.js   camera keyframes                                    hands.js  pen shadow and hand shadows
  story.js   single source of truth for voice/subtitle/title/handoff times
  subs.js    written-on subtitles, title, end card               main.js   render(t), debug modes, events for the mix
  lines.json voice script   music/score.py  solo cello score   mix.py  pen-scratch foley + voice + music   build.sh
```

1. 在 `face.js` 中设计最终画面，并用 `node core/render/still.mjs styles/one-line/demo 0 --q 'all=1&nopen=1&nosub=1&cams=0,-170,1.0'` 反复迭代（再加几个 `;x,y,z` 视角，可在同一次运行中检查各个小场景）。
2. 人声：`core/tts/tts.py lines.json voices` → `asr_check.py`；读取 `voices/words.json`，在 `story.js` 中放置台词。
3. 在 `face.js` 中设置章节时间窗和标记；`node demo/tools/probe.mjs 0.5` 会打印各部分边界和笔尖轨迹，用于编写镜头关键帧。
4. `node core/render/events.mjs styles/one-line/demo` → `music/score.py` → `mix.py`。
5. `node core/render/video.mjs styles/one-line/demo --fps 24 --workers 3`（1140 帧 ≈ 30–45 s）→ `sh core/render/mux.sh out/video24.mp4 mix.wav one-line.mp4 24 0`。
6. 或者直接运行 `sh styles/one-line/demo/build.sh`。
