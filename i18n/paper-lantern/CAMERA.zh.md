## 5. 运动质感

- **一切都像插在小棍上的纸那样运动**：各层滑动（x/y）、绕支点旋转、沿一个轴从 0 缩放出来（“写出来”），或者亮起来。没有挤压拉伸，没有变形，没有弯折。
- **带关节的人物**：一张身体纸片 + 若干单独的肢体纸片，锚定在关节处；只动画旋转。
- **光的变化是最大的运动**：先是光源，然后每层的透光度以约 0.4 s 依次错开亮起，然后是窗户，然后是闪烁（`1 + .06·sin(7.3t)·sin(3.1t)`）。
- **硬动作落在口播字词上**（使用 whisper 词时间）：一件东西砸下、一个字闪亮、一道光弧生长，都踩在对应的字词上。
- 摄影机上的手持式微漂移（约 0.6 mm）让固定画面保持生气。以 30 fps 逐帧渲染（on ones）；绝不跳帧。



## 6. 镜头语法

这是一套词汇，不是一条路线。镜头很小，灯箱很浅：运动幅度都短。开场和结尾由题材决定。

| 运动 | 表达什么 | 可用于 |
|---|---|---|
| 缓慢的移动镜头推进，几乎正面 | 亲密；被吸引进一个地方 | 一段回忆；一个重要的细节；一扇亮着的窗 |
| 缓慢的移动镜头拉出 | 环境；孤独；尺度 | 一个孤身的人物；前后对比；一次看清整个地方 |
| 在层与层之间转移焦点 | 注意力在纵深中移动 | 一远一近的两个人；藏在后面的线索；现在与过去 |
| 带纵深视差的横向移动 | 旅途；时间流逝 | 一次公路旅行；分阶段的过程；一条时间线 |
| 俯拍层叠 | 以手艺人的眼光看一件做好的东西 | 一份食谱；一封信；一张地图；一件正在组装的产品 |
| 拉出 / 推进灯箱 | 画框即物件；“这是一个被讲述的故事” | 一件纪念物；一个框架叙事手法；回到当下 |
| 固定画面，只有光在变化 | 等待；一天或一夜的流逝 | 守夜；四季；一座入睡的城市 |
| 沿层叠向上 / 向下俯仰 | 攀登；坠落；天空与大地 | 一座山；一口井；希望与沉重 |
| 近景平面遮挡物划像 | 场景之间的一道幕布 | 换章节；梦境；揭开一个秘密 |

构图：故事层在焦内，前景和远景层虚化；在箱内时灯箱边缘完全出画，在箱外时清楚入画，绝不只露一半。转场：叠化（0.5–1.2 s）、圆形划像、灯灭/灯亮、两半精确相接的近景平面幕布。不用甩镜，不用数码变焦。



## 8. 天然招式

一份菜单：按故事需要挑选。

- **灯亮起来。**先是光源，然后远景层，然后窗户一扇扇亮起。*适合的内容：*一家清晨开门的小店；一家初创公司迎来第一位客户；比赛开始前的体育场。
- **两扇窗，一束光。**两个亮着的地方共享同一个光源（月亮、灯塔、卫星）。*适合的内容：*一段异地友谊；两个攻克同一难题的实验室；一对友好城市。
- **纵深即距离。**层叠的山脉或街道让“远方”可见；行进时各层以与深度成比例的速度移动。*适合的内容：*一条迁徙路线；寄一个包裹；一条河的历史。
- **自己书写的纸。**一张纸条在念到某个字词时从边缘生长出来。*适合的内容：*一份食谱；一份条约的条款；一个孩子说出的第一个词。
- **灯箱即纪念物。**摄影机在房间里找到这盏真实的灯，真实的物件被它的溢光照亮。*适合的内容：*一个结婚纪念日；一次产品开箱；一件博物馆藏品的故事。
- **从打开的东西里迸出的光。**盖子掀起，解析式辉光溢出。*适合的内容：*一份礼物；一个发现；一个新点子。
- **窗中剪影。**一个带关节的人物站在一扇亮着的窗框里。*适合的内容：*深夜加班的人；一位手艺人的肖像；一位等待中的病人。
