## 5. 运动质感

- 一拍一（60 fps 适合流畅的微距摄影机），全部是 `t` 的纯函数。纸片的动作是僵硬的；生命感来自缓动：立体件用 `back()` 的回弹过冲，吊在线上的东西用弹簧，角色用挤压与拉伸。
- **立体件从后往前弹起**（延迟随着与读者距离的增加而增加），远处的块向后躺倒，近处的块正面朝下向前折倒；折回去时也按同样的顺序。
- 植物和轻巧的道具绕底部摇摆零点零几弧度。
- **角色是扁平的卡片，按量化后的姿态重绘**（行走相位、手臂、眼睛、嘴巴、视线、眨眼）；行走相位跟随实际走过的距离，所以脚不会打滑。
- **转身 = 正面与背面图之间的 `scale.x` 翻转**；绝不用 `rotation.y`。跳跃：抛物线轨迹，两端挤压，落地时冒一团纸屑烟。
- **翻页**：一条多段的条带，弯曲沿长度方向积分，所以卷起来像纸。
- 永远不动的：房间。



## 6. 镜头语法

单一的虚拟微距摄影机，以位置 / 目标点 / fov / 光圈 / 对焦设关键帧，用单调三次插值；新的关键帧列表 = 一次硬切。这是一套词汇，不是一条固定路线。开场和结尾由题材决定。

| 运镜 | 表达什么 | 可用于 |
|---|---|---|
| 平视微距跟拍，浅景深 | 以演员的尺寸置身故事之中 | 一段行走；一段对话；一场追逐 |
| 向上拉到跨页的 3/4 视角 | 机关本身、地图 | 一次翻页；一个新场景；一个计划 |
| 从人眼高度下降的移动镜头 | 进入书的尺度 | 一次抵达；放大到系统的某一部分 |
| 推镜到脸部 | 情感 | 一个愿望；一份恐惧；一个决定 |
| 从书内向虚化房间的反打镜头 | 书页之外的世界很大 | 好奇心；来自外部的威胁；一位正在观看的读者 |
| 纸片 ↔ 真实物体之间转焦 | 纸与现实相互触碰 | 因果关系；纸片故事里的真实产品 |
| 俯拍打开的跨页 | 一张棋盘游戏、一张图解 | 一条路线；书缝两侧的对比 |
| 固定画面对准一个拉条 | 机关本身就是事件 | 前后对比；一次计数 |
| 上升的升降镜头，让书变小 | 尺度、距离 | 余波；一段总结；时间流逝 |

演员在焦内，房间里的物件作为柔和的前景或背景；让靠近镜头的立体件避开镜头的路径。转场：翻页、书合上再打开、在一声纸张响声上硬切；书内绝不使用视频叠化。



## 8. 原生手法

这是一份菜单：按你的故事需要挑选。

- **书本打开**：吱呀一声，书板掀起，世界从后往前弹立起来。*适合的内容：* 项目发布；开学第一天；一本菜谱。
- **翻页 = 换场**：旧的立体件折倒，新的弹起。*适合的内容：* 一个流程的各个阶段；农场的四季；一部传记的各个章节。
- **拉条机关**：翻转的百叶、小棍上的太阳、滑动的纸条、带铰链的门、吊在线上的物件。*适合的内容：* 一次预报；旧方法/新方法；一把锁被打开。
- **纸就是角色**：揉皱、抚平、重新折叠、撕开、贴上胶带。*适合的内容：* 一个错误变成一堂课；回收利用；被否掉的草稿变成最终设计。
- **书页的边缘**：在纸与房间之间穿越，双向皆可。*适合的内容：* 角色走进书桌上的手机；一个真实物体进入故事；一幅画变成现实。
- **真实物体参与演出**：台灯当太阳，马克杯当塔楼。*适合的内容：* 家里的一件产品；读者的在场；真实的时钟时间。
- **打字气泡和评分**。*适合的内容：* 一个教程；一次小测验；一次小小的胜利。
