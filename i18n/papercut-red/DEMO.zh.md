# 红色窗花剪纸 — 我们的示范片

这只是众多可能中的一个例子。不要照搬它的故事、结构、镜头、道具或时间安排。

示范片：*Nian Comes to Town*（年兽进村）（49 s）· `papercut-red.mp4` · 源文件见 [`demo/`](demo/)


## 故事与结构

除夕夜：年兽进了村，家家户户都熄了灯。一个小女孩把一张红纸折了三折，剪了一刀；展开的团花贴上她的窗户，点亮一支蜡烛，八盏剪出的灯笼飞向八扇黑着的窗，整个村子重新亮了起来；她剪下来的碎纸变成了鞭炮，年兽在红光和巨响中逃走。天亮时镜头拉远：整部片子原来是一张贴在真实窗户上的窗花。

这部片子所依据的创作要求（也是它给自己定下的规则）：选一个**剪纸这门手艺本身就是情节**的故事，用上几种原生手法，并让其中一种成为结局的*原因*，而不是装饰。这里，折 – 剪 – 展开就是原因：在折好的楔形里剪一盏灯笼 = 团花里有八盏灯笼 = 八户人家亮灯。

示范片是这样理解"改编任何题材"的：找到**那一样被剪的东西**，让它*展开*后的形态成为答案（把一个产品的剪影折进楔形，展开后呈现它的所有用途；从一张折纸上剪出一对恋人；在折叠的纸条上剪一栋房子，展开成一整条街）。把这些当作折纸手法的例子，而不是必须遵循的结构。

结构（计划 40–55 s，成片 49 s）：以剪刀冷开场（0–3 s）→ 片名 → 平静的世界 → 威胁（世界陷入黑暗与寂静）→ 一个安静的决定 → 在强拍上**折–剪–展开** → 图案化作光，修复了世界 → 黎明 → 尺度揭示。

用到的原生手法：折 – 剪 – 展开（高潮）、镂空就是光（窗上背光的团花，其图案越过雪地投射到年兽脸上）、对称即复制（团花上的灯笼飞出去；小团花展开成烟花）、碎纸有未来（剪下的边角料变回鞭炮）、一切都是同一张平纸（远山的锯齿山脊立起来，原来是年兽的脊背；最后拉回到窗户）。

## 配乐结构

原创配乐（`demo/music/score.py`），D 宫五声调式（D E F# A B），2/4 拍，120 BPM，一个 4 小节的原创主题。乐器：`pluck:pipa`（旋律 + 轮指）、`dan_tranh` / `dan_tranh_trem`（作为筝 / 扬琴：分解和弦、刮奏、轮指）、`erhu`（副旋律、滑音）、`flute` 当作笛子、`woodblock`（节拍、折纸）、`gong2:small`（乐句的开头和结尾）、`gong2:big`（只用一次，在 31.0）、`frame_drum`。不用钢琴，不用弦乐组，不用戏曲锣鼓或唢呐（以便与皮影戏和水墨风格区分开）。

| 提示 | 时间 | 速度 | 内容 | 重音 |
|---|---|---|---|---|
| C0 剪纸 | 0–3 | 自由 | 只有剪刀；琵琶滑音进入 | 剪声 0.25 / 1.0 / 1.75；2.5 |
| C1 片名 | 3–7 | 120 | 主题 A：琵琶、筝、高八度的笛子，每拍一声木鱼 | 3.0 小锣；6.5 折纸（筝的上行刮奏） |
| C2 夜晚村庄 | 7–12 | 120 | 主题 A 轻奏，木鱼在反拍 | 在人声下压低 |
| C3 年兽 | 12–17 | 60 的感觉 | 手鼓心跳，二胡缓慢滑音 D4→A3，低音筝 | 12.0 一击；每扇窗一声鼓 |
| C4 寂静 | 17–19.5 | — | **无音乐**（风声、呼吸） | 18.3 眨眼（一声极轻的木鱼） |
| C5 决心 | 19.5–24 | 120 | 筝轮指，琵琶 ×3，二胡上行 | 23.5 琵琶终止式 |
| C6 折与剪 | 24–30 | 120 | 折纸时木鱼；琵琶轮指 + 筝固定音型，每小节升高一级 | 每剪一刀一声；29.5 全部停止 |
| C7 展开 | 30–31 | 120 | 三次筝的刮奏 | **31.0 全奏 + 大锣** |
| C8 全村亮灯 | 31–38 | 120 | 主题 A 全奏 + 手鼓 + 小锣 + 鞭炮；八个筝音 | 32.0–33.75 窗户；35.0 年兽转身；37.5 小锣 |
| C9 黎明 | 38–42.5 | 90 | 笛子独奏，筝泛音，二胡长音 | |
| C10 揭示 | 42.5–46 | 90 | 最后一个乐句齐奏，终止在 D | 44.0 和弦 + 小锣 |
| C11 结尾 | 46–49 | — | 锣的余音 + 两声木鱼 | 46.5 / 47.0 |

音乐在人声下压低约 8–9 dB；强拍避开每句台词的第一个字。

本片特有的拟音：年兽的硬纸板脚步声（55 Hz + 低频噪声，每步带约 6 px 的画面震动）、它的呼吸（低通噪声）、被晃得睁不开眼时的呜咽（一段降调并低通处理的二胡采样）；蜡烛熄灭（"噗"）和点亮（火柴声 + "呼"）；烟花 = 上升的哨音 + 爆炸 + 噼啪声 + 纸屑飘落；黎明时一段长长的揭纸声；两声鸟鸣。

人声：一位温暖的奶奶在除夕夜讲故事，Kokoro `af_sarah`，语速 0.9，五句台词：

| id | 开始 | 文本 |
|---|---|---|
| L1 | 7.6 | 每到除夕夜，年兽就会从山里下来。 |
| L2 | 13.6 | 村子里的灯，一盏接一盏地熄灭了。 |
| L3 | 19.8 | 可年兽怕三样东西：红色、亮光，还有响声。 |
| L5 | 35.2 | 噼里啪啦，砰！年兽就逃走了。 |
| L6 | 38.6 | 所以直到今天，每逢过年，我们还会在窗上贴红纸。 |

whisper 会把 "Nian" 听成 "Nyan"/"Nion"，而这正是 nián 的正确发音，所以它在 `lines.json` 中被登记为 `asr` 别名。

## 色板与道具

- 主角和窗花 `#d2201f`；年兽深一级 `#b00f26`；近侧肢体亮一级 `#c4162c`，远侧肢体更暗（`#8a0c20`，女孩为 `#b8191b`）；折纸背面颜色 `#de3b30`。
- 宣纸 `#f2e8d0`，夜晚的靛蓝纸 `#1c2446`，墨色天空 `#0f142a`，金箔 `#d9a93f` 只在结尾使用（太阳、片名上的金点）。
- 夜晚：远山 `#1f2a55`、近山 `#29356e`、房屋 `#35457f`、树 `#28346c`、雪 `#7a88ba`，全是靛蓝色纸；只有窗花、灯笼、女孩和年兽是红色的（背景也用红色会让剪影不再突出）。白天：宣纸色天空、红色房屋、远山 `#e0877f`、中景山 `#cf4f4a`。
- 纸张投影：偏移 2.6/3.6 px，模糊 5 px × 缩放，`rgba(52,6,10,.38)`。内轮廓：在外轮廓内 3.5 单位处一条 1.5 单位宽的细缝。夜间环境光约 `rgb(214,214,236)`；辉光 10 px / 40 px，强度约 0.55。
- 背光窗花：径向光 `#fff6d6 → #ffc46e → #ec782e`，宣纸纤维以 50 % 正片叠底，团花的透光贴图为 `#b51d18`。投影图案用 `[1.25,0,-0.9,0.3]` 压扁到地面上。
- 团花：中圈为*阳*刻（灯笼、折线上的如意纹、圈边的锯齿纹），内圈和外圈为*阴*刻。
- 女孩：头、棉袄、2 ×（上臂、前臂 + 手）、2 ×（大腿、小腿 + 鞋）、剪刀（两片刀刃装在一个铆钉上）；脸部零件有微笑 ∩、惊讶、害怕、坚定的杏眼、熟睡 ∪；脸颊上的小团花。
- 年兽：身体、头（大，×1.32）、可开合的下颌、鬃毛、尾巴、4 ×（大腿、小腿 + 爪）；粗壮的腿，有四个弯曲的爪尖和涡纹膝关节（第一版带月牙条纹的小腿被弃用了）。光照到它时，图案和一块实心暖色光斑被加进它的图层里，这样眯起的眼睛和大颗泪珠就是在亮面上读得出的镂空（笑点）；未受光的部分暗成剪影。
- 剪纸：显现圆半径 r ≈ 62 单位；刀刃每 0.25 s 开合一次（每一剪 = 一个八分音符）；镜头让刀尖保持在约 32 % 的位置。每一折约 0.55 s，配一声木鱼；三次展开相隔 0.25 s。

## 片尾卡

对联纸条从窗户两侧滑入，上方落下一条红色横幅，上面是奶油色剪纸字 "RED PAPER-CUT"，点缀金箔碎点，下方是墨色的署名 "LemoLab × Claude Opus 5.5"。"LemoLab × Claude Opus 5.5" 的署名只属于本库的示范片；用户的影片不带任何 LemoLab 署名，也不要照搬这张片尾卡。

片名和字幕的实际做法：宣纸上用 Fraunces 800 剪出的字，配锯齿纹边框条，一枚把"年"字镂空剪出的红色印章，一行斜体副标题。字幕横幅 `#a8111f`，金色碎点，Fraunces SemiBold 44 px，奶油色 `#fff1d6`，居中，距底部 70 px，停留 ≥ 语音时长 + 0.7 s 且 ≥ 1.8 s。

## 构建说明

```

  paper.js    paper textures, piece builder (fill, cut, inset, edge, grain), shadows, transmission
  motifs.js   folk pattern library          rig.js      2D affine rig helpers
  girl.js     jointed girl + face pieces     nian.js     jointed monster + eye pieces + poses
  tuanhua.js  8-fold rosette (one wedge × D4) village.js  houses, hills, plum tree, snow, lanterns
  light.js    night lightmap, backlit windows, bloom, rays, masked projected light
  world.js    village layout (night/day palettes) + lighting pass
  fold.js     fold – cut – unfold sequence   hud.js      subtitle banner, cut-letter text
  story.js    timeline (single source of truth, 120 BPM)   main.js  shots, cameras, events
  sheet.js / climax.js / test.js   model sheets and style frame (?test=sheet_girl | sheet_nian | frame)
  lines.json  voice script   music/score.py  original score   mix.py  foley + voice + music   subs.py  srt
```

1. `node core/render/still.mjs styles/papercut-red/demo <t…> [--q nosub=1]`：审看静帧；用 `?test=sheet_girl` 等查看角色设定图。
2. `.venv/bin/python core/tts/tts.py lines.json voices` → `core/tts/asr_check.py`，直到全部 OK。
3. `node core/render/events.mjs` → `music/score.py` → `mix.py` → `subs.py`。
4. `node core/render/video.mjs styles/papercut-red/demo --fps 24 --workers 3`（1176 帧，约 30 s）。
5. `sh core/render/mux.sh out/video24.mp4 mix.wav papercut-red.mp4 24 0`，然后运行 `check_final.py`（在最终混音上逐句 whisper 校验 + blackdetect 黑场检测）。
或者直接运行 `sh styles/papercut-red/demo/build.sh`。

引擎陷阱：`put()` 使用 `setTransform`，因此它会忽略外层的 `translate`：要传入绝对矩阵。测试模式的页面不能靠抛出异常来终止模块（渲染框架遇到任何页面错误都会退出）：应改为对 `window.render` 的赋值加保护。实际使用的引擎参数：纸张颗粒斑驳 ±7 %，尺度约 130 px；边缘抖动约 0.35 单位；`motifs.js` 中有 `sawRow`、`sawEdge`、`crescent` / `crescentRows`、`swirl` / `doubleSwirl`、`cloudCut`、`rosette`、`plum`、`coin`；辉光模糊用半分辨率；平滑处理曾把房子变成了面包。

与本示范片道具相关的坑：
- 把墙高存进房屋零件的 `p.h` 会把房子拉伸（`x0,y0,w,h` 是绘制框）。
- 通过光照贴图压暗雪地图层，会让幽灵般的腿透过雪地显现出来。
- 折纸时的剪刀一开始是朝后指的。
- 投影图案以年兽的眼睛为中心时把眼睛遮住了；后来改为以口鼻为中心并加一块实心暖色光斑，眯眼和泪珠才读得出来。
- 冷开场里飞走的纸与片名卡重叠，以避免出现空白帧。
