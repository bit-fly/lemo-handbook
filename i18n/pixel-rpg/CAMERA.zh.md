## 5. 运动质感

- 输出 24 fps。精灵以 **8 fps**（行走）到 **12 fps**（火焰、闪烁）步进；摄影机和视差逐帧以整像素移动。
- **游戏原生表演**：向前跳一步再行动、施法姿势、受击后退、下跪、KO 闪烁（12 fps 亮/灭）并消失；呼吸 = 肩膀上抬 1 px。
- **UI 运动**：窗口在约 0.3 s 内滑入（缓出，整像素）；手形光标以 4 fps 上下浮动 1 px，**在角色犹豫时停止**。
- **转场**：缩略图展开 + 马赛克，峰值处切换色板的马赛克交叉，遇敌漩涡（极坐标扭曲 + 马赛克 + Bayer 溶解到白），屏幕震动（3–2–1 px，历时 8 帧），色板分级淡变（4 级）。绝不用 alpha 淡变。



## 6. 镜头语法

这是一套词汇，不是一条路线。游戏摄影机简单而清晰。开场和结尾由题材决定。

| 运镜 | 表达什么 | 可用于 |
|---|---|---|
| 带视差层的横向卷轴 | 旅程；孤独；进展 | 通勤；一次冒险；一条时间线 |
| UI 占三分之一的固定画面 | 一个选择；系统在说话 | 菜单抉择；属性揭示 |
| 战斗侧视（敌人 / 队伍 / 窗口） | 把冲突表现为系统 | 一场考试；一次谈判；一场疾病 |
| 俯视大地图摇镜 | 整个世界；东西都在哪里 | 一座城市；一家公司的地图；一次旅行 |
| 沿高大物体按整像素向上俯仰 | 敬畏；尺度 | 一座塔；一扇门；一座山 |
| 色板变化时停留 | 不动声色的失去或改变 | 悲伤；褪去的记忆；夜幕降临 |
| 门槛处的背影 | 决心；前方的未知 | 第一天；一次发布；一次离别 |
| 以马赛克缩放进缩略图 | 进入一段记忆或一个文件 | 闪回；一个存档位；一张照片 |

构图：角色保持在对话框上方（地面线高于对话框顶边）；菜单要让动作保持可见。



## 8. 原生动作

一份菜单：按故事需要选用。

- **色板崩塌 / 涌回。** 色深每个节拍下降一级，或全彩通过一道抖动波涌回。*适合的内容：*城市停电与恢复；陷入危机的公司；倦怠与休整。
- **受保护颜色的匹配剪辑。** 一种豁免的颜色在同一画面位置连接两个时代。*适合的内容：*一件传家宝；跨越数十年的品牌色；一件球队球衣。
- **存档即记忆。** 一份文件列表；选择 NEW FILE 就是拒绝覆盖。*适合的内容：*产品的历代版本；职业生涯的各个篇章；相册。
- **游戏 UI 作为叙述。** 一个变灰的名字、一段道具说明、一个属性界面。*适合的内容：*一位团队成员离开；学会一项技能；一份预算。
- **升级。** 属性伴着凯旋音效上升。*适合的内容：*一个学生的一年；一家创业公司的融资轮；学一门语言。
- **遇敌漩涡。** 一头撞进危险。*适合的内容：*截止日期；一份诊断；一场风暴。
- **时代切换。** 同样的角色用更老的硬件重绘。*适合的内容：*一座小镇的历史；祖父母的青春；一种设备的演变。
