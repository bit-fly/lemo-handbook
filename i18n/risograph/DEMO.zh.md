# Risograph 孔版印刷 — 我们的示范片

这只是众多例子之一。不要照搬它的故事、结构、镜头、道具或时长。

示范片：*Sunday Ride*（周日骑行，40 s）· `risograph.mp4` · 源文件在 [`demo/`](demo/)


## 故事与结构

一个戴圆眼镜的瘦高男人，在一个周日早晨骑车穿过城市，去河边吃早餐。城市一开始只用蓝版印出；他每经过一个地方就多加一版：面包店带来黄色（一根法棍递过来，他没减速就接住了），公园带来粉色（一群鸽子扑腾飞起，其中一只搭上了法棍的便车），到了河边，三个版全部叠印。他和鸽子分享面包；镜头拉远，原来整部片是一张从印刷机里滑出来、落在一摞早先印品上的纸。主题句："Same ride every Sunday. Never quite the same print."（每个周日骑同一条路。每一张印出来都不太一样。）

弧线（40 s = 20 小节，每小节 2 s）：安静的单色开场，3 s 内出钩子（油墨正在铺上去）→ 每个地点增加一个版和一件乐器 → 一个小转折（鸽子乘客）→ 全叠印高潮，配一个停住的静默小节 → 温暖的收束（分享）→ 揭示纸张的尺度。一个角色，一个目标，一个转折。

这个故事的分版配方：第一版 = "之前"的状态（沉睡的城市），每增加一版 = 一个转折点，全叠印 = 高潮。用到的原生手法：以版叙事（蓝 → 黄 → 粉），叠印转场（一个粉色圆盘吞没公园，变成河上的太阳），以套准作节奏（在标题、每个版到来和鸽群飞起时跳动；静默小节里漂移，在强拍上弹回），倒影作为分离的版（河），每一帧都是一张印品（颗粒翻腾），它是一张纸（最后的拉镜）。

## 配乐结构

原创轻快的 **bossa nova**，D 大调，120 BPM（1 小节 = 2 s，所以剪切落在偶数秒上），`demo/music/score.py`（numpy）+ `demo/music/bell.py`。**音乐像印版一样分层**：单色 = 只有尼龙弦吉他；+ 黄 = 沙锤、鼓边响棒、轻柔的鼓刷（以及作为打击乐的自行车铃）；+ 粉 = 低音提琴和一段口哨旋律；全叠印 = + 颤音琴。第 1 小节没有音乐（进纸、滚筒、车铃）。在高潮漂移（26–28）之下是一个完全静默的小节（切掉混响尾音），只有水声、鸟鸣，以及 26.3 处远处教堂的钟声（这是周日）；28.0 弹回时全乐队回归。拉镜过程中乐器一件件退场（颤音琴 → 口哨 → 贝斯 → 打击乐），拉镜每退一步走一件；结尾卡上只剩吉他和一个持续的 Dmaj9。

拟音：每个版到来时都有孔版印刷机的声音（进纸的"刷"+ 滚筒的"咔嚓"；结尾是马达和纸张摩擦声；39.5 一声轻轻的纸张落下声）。自行车铃（两个非谐波分音，约 2.1 / 3.4 kHz，每次响铃 5 下快速敲击），飞轮的滴答声，刹车的尖啸。面包皮的脆响（密集的细小带通咔嗒声）。鸽子振翅（短促的带通噪声爆发），咕咕声（300–400 Hz 滑音）。水波拍岸声。

人声：放松的男声旁白，Kokoro `am_adam`，语速 0.95，5 句短台词，分别在 5.6、9.0、21.7、28.3、32.8，每句都用 whisper 核验。人声之下音乐压低 −8 dB；−14 LUFS；mux grain 0。

## 色板与道具

- 油墨：Riso Blue `#0078BF`（网角 15°）、Yellow `#FFE800`（0°）、Fluorescent Pink `#FF48B0`（75°），印在纸张 `#F6F1E6` 上。混色：蓝 + 黄 = 绿，蓝 + 粉 = 紫/靛，黄 + 粉 = 橙红，三色全叠 = 接近黑；60 % 蓝色网点叠在实地粉上 = 紫。
- 着色器数值：旋转 ±0.0005 rad；网点周期 **1080p 下 7 px**，阈值 smoothstep ±0.07；≥ 0.9 为实地；阈值上的颗粒 ±0.08；噪声 > 0.93 处出现针孔（×0.75）；油墨密度 `k = 0.80 + 0.14·streak + 0.08·blot`（streak = 沿进纸方向拉伸 ×10 的噪声）；纸张纤维 ±1.5 %；颗粒翻腾 35 %。
- 天空色带 20 / 38 / 62 / 100 %。纸白光晕 4–5 px，一圈 12 次压印。
- 骑车人（各版密度）：皮肤 黄 26 %（奶油色；在单色场景中是纸色）；毛衣 蓝 40 + 粉 100（浅蓝网点 → 莓果紫）；裤子 蓝 75 + 黄 100（→ 橄榄绿）；头发 蓝 100 + 粉 22；鞋 蓝 100。粗针织围巾只有黄 + 粉，所以在黄版到来之前它是**空白的纸**，也是第一个亮起来的东西。在河边，他的头正好衬在太阳圆盘前。
- 蹬车：曲柄角度由车轮行进距离算出（`crank = distance / wheelRadius / 2.2`），腿部用双骨骼 IK 连到踏板，围巾是一条行进的正弦波。
- 鸽子：约为他头部的 1.2×，圆胸脯，小碎步配点头，"思考"时歪头，**4 帧振翅循环**（上 / 半 / 下 / 收），一拍二；鸽群混合 1.2–2.4× 的不同大小，起飞时间错开最多 0.35 s。

## 结尾卡

字幕：纸白色挖空条，6 px 圆角，居中于 1000 px 高度，蓝色文字，Jost 500 42 px，字距 0.5 px。标题卡："SUNDAY RIDE"，Bricolage 800 190 px，印在天空中的蓝版上，在第一个和弦上从左 → 右划出，在一个节拍上撤走。

结尾卡：空白的纸，标题以粉 + 蓝双重压印（偏移 10 px），"RISOGRAPH PRINT"，署名行，四角的套准十字线，车铃响起时一个小小的骑车人沿基线骑过。"LemoLab × Claude Opus 5.5" 的署名只属于本库的示范片；用户的影片不带 LemoLab 署名，也不复制这张卡。

## 制作说明

```
styles/risograph/demo/
  riso.js     WebGL2 print shader (plates, halftone, grain, registration, sweeps, water reflection)
  draw.js     plate-canvas helpers: ink(b,y,p), over() overprint, layer() paper-halo, IK, limbs
  rider.js    rider, bike, pigeon, baguette (all colours as plate densities)
  scenes.js   river, street + bakery      scenes2.js  park, top-down quay, printer, bell ECU
  film.js     timeline (120 BPM), shots, registration kicks/drift, plate gates, subtitles, sound events
  sheet.js    model sheet (?sheet=1)      lines.json  narration
  music/score.py  original bossa nova (numpy)   music/bell.py  bicycle bell
  mix.py      foley + ambience + ducked voice + score → mix.wav
  tools/      video_png.mjs (PNG frames, lossless intermediate), mux.sh (crf16 -tune grain), subs.py
```

1. 先设计各个版：单色画面是什么样子，每个版增加什么。角色设定图（`?sheet=1&v=2`，[`demo/stills/modelsheet_v2.jpg`](demo/stills/modelsheet_v2.jpg)）有一行"版 = 故事"：同一个角色通过 `S.mask` 分别以 1、2、3 个版呈现。
2. `sh styles/risograph/demo/build.sh` 重建一切：TTS → whisper → 配乐 → 事件 → 混音 → SRT → 渲染（960 帧，3 个 worker 约 2–4 分钟）→ 封装 → 风格帧、海报、角色设定图。
3. 审查：`node core/render/still.mjs styles/risograph/demo --range 0:40:1.5` + `core/render/sheet.py`；关键动作以 0.2 s 为步长检查；编码后的影片在 100 % 和 50 % 下检查摩尔纹。

编码：PNG 帧 → 无损中间文件（qp 0，yuv444）→ 一次以 crf 16 `-tune grain` 编码（40 s 约 280 MB）；不加 `-tune grain` 的 crf 20 约 120 MB，在 1080p 和 50 % 下仍然干净。逐帧抖动 + 逐帧条纹曾把 x264 推到 900 MB。

与本示范片道具相关的陷阱：
- 交接：面包师的手臂在背景平面上，消失在骑车人身后 → 把交接安排在他前方和上方。
- 桥拱被 `evenodd` 填成实心 → 用 `arc(..., true)` 描出拱底。
- 最初的设计（瘦高、圆眼镜、横条纹）读起来像一个著名的绘本角色 → 改为纯色针织衫，并换一个标志性特征（粗针织围巾）。
- 不含蓝色的毛衣和裤子，在单色开场里显得像一颗漂浮的脑袋。
- 皮肤上的粉色网点看起来像出了麻疹 → 皮肤只用黄色。
