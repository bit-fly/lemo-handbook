# 卫星简报 —— 我们的示例片

这只是众多可能中的一个例子。不要照搬它的故事、结构、镜头、道具或时间安排。

示例片：*The Map Still Says Sea* 《地图上还写着海》（37.8 s）· `satellite-briefing.mp4` · 源文件在 [`demo/`](demo/)

一颗卫星照着地图去找一片海，找到的却是沙漠；唯一回来的那一块，是有人筑了坝的那一块。咸海，1977–2025，使用公有领域的 Landsat 影像。屏幕文字为中文，英文旁白，双语字幕（中文在上，英文在下）。这是一部用公有领域影像制作的非官方影片；美国地质调查局（U.S. Geological Survey）和 NASA 未参与制作，也未为其背书。

## 故事与结构

一句话梗概：在地图上它仍然是咸海；从轨道上看，它是盐和沙；它唯一回来的那一部分——北咸海——是靠一道 13 km 的堤坝保住的。

弧线：一个说法（一页印刷地图集上 1960 年的海，衬线体的名字“咸海”）→ 核查（俯冲进地图直到它填满画面，扫描条把它撕开：盐壳，然后是静默）→ 证据（时间倒回 1977 年，在一个锁定画面中正向播放，每一年都把它的岸线留成一圈环，环来得越来越快）→ 人的尺度（从木伊纳克旧港口到今天海面的一条测距线，95 km）→ 转折（静默，然后先闻水声、后见水面，一个甩镜向北摇到 Kok-Aral 堤坝，环向外生长，水的真实颜色回来了）→ 结尾（“咸海”这个标签离开空荡的湖盆，钉到北咸海上；回到轨道）。

用上的招牌手法：揭示时用*地图对照片*；招牌镜头用*锁定画面中的时间环*；人的尺度用*测距线*；北咸海用*故事转折处颜色回归*；首尾用*俯冲与爬升*；片尾卡用*准星变成画框*。

实测数值在屏幕上标注为实测；每个数字及其来源都在 [`demo/FACTS.md`](demo/FACTS.md) 中。

## 配乐结构

100 BPM，4/4；每个关键动作都落在拍子或半拍上（`demo/tools/cuecheck.py`：26 个提示点误差 0 ms）。D 小调，到大坝处转为 D 大调。

| 段落 | 时间 | 音色 | 说明 |
|---|---|---|---|
| 轨道 | 0–1.8 | D 持续音（带二、三次谐波的脉冲贝斯），Dm 铺底，八分音符的 FM 遥测拨弦，轨道嗡鸣，无线电嘶声，数据杂音 | 0.6 锁定提示音 D6，1.2 地图提示音 A5 |
| 俯冲 | 1.8–4.95 | 拨弦变成十六分音符，滤波器打开，踩镲滴答，噪声上升音，大鼓渐强，上行音调，高度计数器咔哒声 | 4.95–5.36 一切被抽空 |
| 撕开 | 5.4 | 地图被撕掉：底鼓、大鼓、定音鼓、极强的低音铜管短促和弦（长号、大号、圆号，D 小调）、碎音镲、随扫描条扫过的噼啪撕纸声 | 全片三个最重的时刻之一 |
| 静默 1 | ~5.9–6.6 | 细细的风声；撕裂声衰减进其中 | |
| 倒带 | 6.6–7.8 | 影片自身配乐的最后 1.8 s 倒放并加速，倒放的大锣，计数器滴答 | 转入招牌镜头 |
| 环 | 7.8–13.2 | 贝斯以 D–C–B♭–A–G 下行，和弦为 Dm–C–B♭–A–Gm（两层铺底）；大号奏每个根音，长号奏五度；每拍一个超低频脉冲，从 2000 年起每半拍一个；滴答声从八分变成十六分；每个环：定音鼓奏根音 + 底鼓 + 非谐波金属环声 + 笔尖嘶声；倒放的镲声涌起，进入 0.24 s 的抽空 | 靠细分节奏加速，而不是靠改变速度 |
| 停住 | 13.2–15.3 | 重击（底鼓、定音鼓、大鼓、锣、金属撞击声），然后是低音 D、弓拉镲、细细的持续音 | 全片最响的时刻 |
| 木伊纳克 | 15.3–21.9 | 远处的船笛（两个失谐锯齿波，长混响空间）带一声吱嘎，每两拍一次定音鼓心跳，一个低音 D/A 持续音，其滤波器随测距线打开，干燥的沙粒声，每 2 km 一下棘轮滴答（每 10 km 一个重音），读数落定时一声空洞的咚 + 提示音 | |
| 静默 2 | 21.9–22.8 | 只有风声 | 之后的第一个声音：22.8 一下水波拍岸声，先于画面转向北方 |
| 北方 | 22.8–28.8 | 甩鞭声和嗖声；0.22 s 抽空，然后是大坝重击（底鼓、定音鼓、敲击声、撞击声、低沉的金属闸门声）；D 大调：大号、长号、圆号、温暖铺底、弓拉颤音琴，镲声涌起并在水到来时落下，玻璃琴动机 D5–A4–C♯5–F♯5–E5–D5 加回声，颤音琴脉冲；水声底层 | 全片唯一湿润的音色 |
| 爬升 | 28.8–34.2 | 圆号 D3/A3/F♯4，大号，弓拉颤音琴，D 大调铺底；动机由玻璃声和 FM 提示音一起奏出（干与湿合一）；轻快的脉冲 | 31.2 钉标签提示音 |
| 结束 | 34.2–37.8 | 低音 D 一击，锁定提示音的回声，最后一次过境的柔和扫掠声，长尾音 | |

混音（在 `mix.py` 中）：分轨增益固定（旁白说话时音乐低于人声 10 dB 并再压低约 5 dB，脉冲 −8 dB，拟音 −6 dB，环境底层 −17 dB）；总线压缩只作用于音乐、脉冲、拟音和环境底层，让重击保持分量；母带级（−14.4 LUFS，真峰值限制器 −4.6 dBTP，作用于 4× 过采样峰值；AAC 会再加回约 3 dB）。超低频：除人声外所有声音做 38 Hz 高通（重击上为 46 Hz、4 阶）以及 62 Hz 以下 −5 dB 搁架；冲击感的分量在 60–120 Hz（`punch()`）：20–60 Hz 比全频段低 16 dB，与数据可视化示例片相同。影片实测 −13.8 LUFS，真峰值 −1.6 dBTP，LRA 5.3 LU。`tools/impactcheck.py`：硬停是全片瞬时响度最高的时刻，大坝重击比它低 −0.5 dB，地图撕开低 −2.6 dB（各自都在全片最响的 4 s 之列），它们之前分别有 −4、−3 和 −14 dB 的下陷。静默段比节目整体低约 20 dB。

## 色板与道具

- 地面：轨道高度用 Landsat 真彩色；分析级调色从 #070B0E 到 #A1A7A9，色度只保留五分之一。
- 标记 #F2F5F6 带深色光晕；读数琥珀色 #FFBE55；印刷地图：纸 #ECE2CB，海 #8CB5DB，海岸墨线 #1A3B6B，经纬网用褪色的红棕色，衬线体名字在纸面上为 #1F3F6B，在沙地上方为 #D6EAFF。
- 北咸海的水在一个 0.75° 的圆内恢复为提亮的真彩色；分析图层中其他东西都不着色。
- 道具：印刷地图（Natural Earth 历史湖泊多边形做成的距离场、河流、两个城镇圆点）、六条实测岸线（1977–2025）、北咸海的环（2001、2009）、在 2025 年影像上描出的 Kok-Aral 堤坝、木伊纳克测距线。
- 旁白：Kokoro `bf_emma`，速度 0.9–1.0。

## 片尾卡

锁定框从北咸海张开，在左侧成为一个画框：地图上还写着海（Noto Serif SC，地图的声音）、*The Map Still Says Sea*、一条横线、`SATELLITE BRIEFING · 卫星简报`、`LemoLab × Claude Opus 5.5`，下方是压暗后转动的地球；最后一次卫星过境从它后面向下扫过。3.6 s。“LemoLab × Claude Opus 5.5”署名只属于本库的示例片；用户的影片不带 LemoLab 署名，也不复制这张卡。

## 构建说明

```
demo/
  build.sh          one command: voice → checks → events → video → mix → master → .srt → checks → poster
  index.html        two canvases (WebGL2 imagery, 2D marks), fonts
  film.js           render(t): camera keys, plate/scan state, every mark, readouts, subtitles, end card, EV
  engine.js         camera, project/unproject, plate shader (grade, soft scans, growth, printed map, water colour, whip blur)
  overlay.js        hairlines, brackets, readouts, transcript strip, text registry for readcheck
  timeline.js       beats, cues, ring schedule, narration (single source; tools/export.mjs → timeline.json, cues.json, voice/lines.json)
  mix.py            score, foley, beds, voice, mix → out/mix.wav + out/stems/
  tools/            fetch_landsat.py, fetch_gibs.py, plates.py, bmng.py, vectors.py, mapfield.py, growth.py, fonts.py (data); lowcheck.py (sub-bass share);
                    export.mjs, voicefix.py (voice); cuecheck.py, subcheck.mjs, motioncheck.py, audiocheck.py, impactcheck.py, finalasr.py (checks)
  assets/           plates/ (JPEG plates, water masks, mapfield.png, ko_grow.png, plates.json), vectors.json, raw/ (downloads + manifest.jsonl)
  FACTS.md, CREDITS, stills/styleframe.jpg
```

- `sh demo/build.sh` 在 Apple silicon 上大约需要 2 分钟（画面用 3 个 worker 约 20 s 渲染完）。在全新克隆中，影像板、原始场景和字体都不在 git 里：首次运行会下载并重建影像（约 25 分钟，`assets/raw/` 中约 3.5 GB），并下载字体（`tools/fonts.py`：来自 github.com/google/fonts 的 Barlow Condensed 和 IBM Plex Mono，以及 Noto SC 子集）；`FETCH=1` 会强制重新执行。配乐需要用 `sh tools/fetch.sh instruments <lib>` 获取 vsco2ce、vcsl 和 freepats，人声需要 `setup.sh deps voice`。
- 它会运行的检查：用 `small.en` 跑 `asr_check.py`（base 模型会把 “sea” 听成 “C”）、提示点网格、用真实字体测量的字幕单行宽度（最宽一行 578 px，上限 1100 px）、`readcheck.mjs`、每秒运动量（不允许超过 1 s 的段落平均像素变化低于 0.6；全片最慢的一秒为 1.06）、冲击排名。
- 影像板：六个年份的区域镶嵌图 3917 × 2652，约 190 m 分辨率；着陆、木伊纳克和 Kok-Aral 用约 32–40 m 的细节板；Blue Marble 世界图（4096 × 2048）和中亚图。全部在一个着色器 pass 中采样；每个渲染 worker 约占 1 GB 纹理内存。
- 示例片特有的坑：1977 年的 Landsat 2 镶嵌图需要最近邻重采样、修复丢失行、在陆地上按 12° 清除条纹，并用一个 L1GS 场景补上西北湾的一个洞；8 月 16 日 path 161 的 1989 年场景有一团横穿海面的沙尘，已被排除（`tools/plates_spec.json` 中的 `exclude`）；木伊纳克以西 10–15 km 一处被堤坝围起的圩田有一条直边，可能被看成拼缝：港口居中时把它压暗，并在测距线出现前让它滑出画面；水体掩膜需要删除沿影像板边界的轮廓片段，否则北咸海里会出现一条直线；地图上除“咸海”之外的地名都去掉了，因为俯冲给它们的时间不够阅读。
- Kokoro 会在 “Someone kept it.” 之后多加一个带气声的音节；`tools/voicefix.py` 会在语音检查之前把它剪掉。
