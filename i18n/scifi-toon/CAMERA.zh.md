## 5. 运动质感

- **角色一拍二（12 fps）**：姿势、嘴型、眨眼、行走循环和线条抖动都以 12 fps 步进。**摄影机运动、传送门漩涡、飞行道具和划像一拍一（24 fps）**。
- **表演胜于移动**：停留的姿势加细微变化（眼皮抽动、瞳孔滑动、咽口水、汗珠）。待机时的生气：呼吸（±1 % 挤压）、由说话响度驱动的点头。
- 每个手势之前都有**预备 → 动作**。
- **挤压与拉伸**用于落地（衰减余弦挤压约 22 %），从传送门飞出时拉伸；“被吸进去” = 一边拉伸一边朝传送门中心缩小。
- **由音频驱动口型**：逐句以 24 Hz 计算 RMS（张开程度）和频谱质心（宽扁 vs 圆），在 12 fps 的画稿时刻采样。尖叫时夸张处理（嘴 ×1.5–1.9）。
- **紧张的抖动**：12 fps 的 3–6 px 随机偏移，加上颤抖的瞳孔；幅度随惊慌程度增大。
- 冷场停顿中永远不动的：除了线条抖动之外的一切。



## 6. 镜头语法

这是一套词汇，而不是一条路线。开场和结尾由题材决定。

| 运镜 | 表达什么 | 可用于 |
|---|---|---|
| 中景双人镜头 | 人物关系；谁作何反应 | 对话；对峙；一笔交易 |
| 硬切到特写 | 一次打断，一张崩溃的脸 | 被打断的台词；恍然大悟；一句谎话 |
| 物体的插入大特写 | 荒谬的细节 | 揭示；问题本身；错误的结果 |
| 反应特写 | 笑点就在脸上 | 每个荒谬画面之后 |
| 紧凑特写 + 在一个词上短暂震动 | 惊慌 | 关键词；警报；尖叫 |
| 冲刺式变焦冲进传送门 → 漩涡划像 | 离开一个世界 | 在地点、时间或版本之间的任何跳跃 |
| 各个世界重复同样的构图 | 只有世界在变 | 蒙太奇；对比；清单 |
| 对静止的双人镜头非常缓慢地推镜 | 冷场的寂静 | 反转之后的停顿；一次坦白 |
| 装置和两位主角同在画面中的全景 | 一次看清整个局面 | 回扣；陷阱；重新开始 |
| 越肩看向屏幕 | 读到坏消息 | 一条消息；一个读数 |
| 在两张脸之间急速横摇 | 互相抢话的争吵 | 吵架；打赌；愣了一下再回头看 |

规则：每个荒谬画面之后都要跟一个**反应特写**。转场要么经过穿越装置（漩涡划像），要么硬切；不用叠化。



## 8. 原生招式

这是一份菜单：按故事需要取用。

- **平行世界。** 每次跳跃 = 新的调色板、新的提示曲、新的生物。*适合的内容：* 一个产品的不同版本；你本可以拥有的各种职业；同一座城市的五个时代。
- **二人组反差。** 面无表情 vs 惊慌失措：笑点在于两人反应的差异。*适合的内容：* 老员工和新人；父母和青少年；AI 和它的用户。
- **三的法则 → 机关枪。** 两个慢节奏的错误答案，然后是一秒一个的世界，剪辑落在拍点上，拒绝词每次相同。*适合的内容：* 失败的原型；糟糕的约会点子；报税表格。
- **正常得可疑的世界。** 模式被打破；平静本身就是笑点。*适合的内容：* 唯一一个无聊但管用的答案；混乱过后安静的办公室；真正的客户。
- **死寂反转。** 反转之后一段长长的沉默，然后用一句话揭示角色的价值观。*适合的内容：* 价格揭晓；小字条款；一份不想要的礼物。
- **把高科技当破烂。** 能扭曲世界的科技被用来做琐碎小事。*适合的内容：* 用量子计算机列购物清单；用火箭送一个三明治；用时光机改一个错别字。
- **回扣式收尾笑点。** 最后一句重复第一句，让故事形成循环。*适合的内容：* 品牌的口头禅；早晨的例行公事；一句反复出现的抱怨。
