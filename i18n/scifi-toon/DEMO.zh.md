# Sci-Fi Sitcom Toon — 我们的示范片

这只是众多可能中的一个例子。不要照搬它的故事、情节走向、镜头、道具或时间安排。

示范片：*Coffee Run*（咖啡跑腿）（57.5 s）· `scifi-toon.mp4` · 源码在 [`demo/`](demo/)


原始需求：一部 30–60 秒的这种风格短片；前提设定、笑料、角色、镜头、节奏、音乐和声音都由导演决定，无需请示即可交付。

## 故事与结构

实验室没咖啡了。一位穿着浴袍、看什么都腻味的天才带着他紧张兮兮的跟班 Gary 穿越宇宙去续杯；每个宇宙的咖啡都更糟；最后带回来的却是低因咖啡。微不足道的日常目标 + 大得荒谬的科幻手段。

我们构思过的把其他题材变成一次跑腿的方法（仅供参考）：
- 产品发布 → 天才穿越维度寻找这个产品能用的版本；每个宇宙的版本都更糟；最后带回来的那个藏着一个反转。
- 一堂课 / 一段讲解 → 跟班问了一个简单的问题；每个宇宙都是一个被字面理解的错误答案；最后一个是对的，但要付出代价。
- 一个节日 / 一场活动 → “派对上的 X 没了” → 一个比一个更离谱的 X 宇宙。

**示范片的节拍表（57.5 s）：**
1. **冷开场（8–12 s）**：日常的问题，用画面展示而不是说出来（一个空咖啡壶，最后一滴）。跟班解释过头，天才用一个词打断他。没有音乐，还没有片名。
2. **传送门 + 片名重击（2–3 s）**，落在音乐的强拍上。
3. **第 1 次跳跃（6–8 s）**，果冻世界：慢节奏：抵达、尝试、用插入特写揭示哪里不对、**切断音乐**、反应镜头、一个词的拒绝。
4. **第 2 次跳跃（6–8 s）**，马克杯世界：更快也更糟；跟班崩溃了；同一个拒绝词。
5. **蒙太奇（3 × 1 s）**：牙齿、鸽子和克隆人世界；每个宇宙一秒，每次同一个词，剪辑点落在拍点上。
6. **打破（4–5 s）**：一个*正常得可疑*的宇宙。模式被打破；平静本身就是笑点。
7. **回家（12–16 s）**：松了口气 → 反转（是低因的）→ **2 秒以上的死寂** → 天才用一句话暴露了他的价值观 → 收尾笑点。
8. **收尾笑点**：回扣开场的台词，让故事形成循环。
9. **片尾卡（4–5 s）。**

## 镜头

| 节拍 | 摄影机 |
|---|---|
| 冷开场 | 空咖啡壶的静止插入特写，缓慢推镜 |
| 对话 | 中景双人镜头；**被打断时硬切到特写** |
| 揭示荒谬 | 插入大特写，然后剪切到反应特写 |
| 惊慌 | 紧凑特写，在关键词上加一次短暂的镜头震动 |
| 跳跃 | “冲刺”式变焦冲进传送门 → 全屏漩涡划像 → 下一个世界从漩涡中展开 |
| 蒙太奇 | 每个世界都用同样的构图（二人组在左，生物在右），只有世界在变 |
| 冷场寂静 | 对峙的双人镜头，非常缓慢的推镜，除了线条抖动什么都不动 |
| 收尾笑点 / 结尾 | 全景，让传送门和两个角色都在画面中；随后是片尾卡 |

## 配乐结构

- 120 BPM，让剪辑点卡在半秒的拍点上。特雷门琴主奏，配模拟贝斯、十六分音符方波琶音和复古鼓机。主题为 D 小调，半音下行 D–A–B♭–A–E–F–E–E♭–D。
- **每个宇宙一个动机**，每个都是独立的提示曲，且**第一拍就是剪辑点**：弹跳的大号 + 摇晃的主奏 + 滑哨（果冻），带颤音琴的鼓刷摇摆爵士（马克杯），四拍底鼓律动上的 1 秒短乐句（蒙太奇），用 Karplus–Strong 尼龙吉他的电梯波萨诺瓦（“正常”世界），温暖的 Rhodes + 特雷门琴的“啊——”（松了口气），上行的弦乐震音（惊慌）。
- 静默：在果冻揭示的插入镜头上，以及“decaf”之后 2 秒以上的冷场停顿中，音乐（连同混响尾音）被硬切；只剩日光灯的嗡嗡声 + 时钟滴答声。
- 使用的拟音：传送门打开/嗡鸣/关闭、每次划像的漩涡呼啸、吐出和落地时的“啵/嘣”、黏液生物的“咕噜/吧唧/眨眼”、吸管嘬吸声、牙齿咬合声、鸽子咕咕声、店铺门铃、气泡“噗噜”、眨眼“哔”、遥控器咔嗒-嘀声。
- 人声：面无表情的天才 = Kokoro `am_onyx`，语速 0.82–0.9，轻度饱和 + 180 Hz 提升；跟班 = Kokoro `am_eric`，语速 1.1–1.15，提升临场感；一个小生物 = Kokoro `af_sky` 升高 +7 个半音，只说一两个词。选角方式：生成试读台词，测量 f0 中位数 / 音高方差。音乐在对白下闪避约 −7 dB；母带 −14 LUFS。
- 最后一个贝斯音落在 D2：持续的 D1（37 Hz）在笔记本扬声器上只剩隆隆声。

## 调色板与道具

- 线条：`#1b1422`，角色和道具 7 px。
- 家里的实验室：灰绿色 `#a7c3b1`、橄榄色地板、暖色木头、一处橙色点缀。
- 果冻世界：品红天空色带 `#ff4f9a→#ff9bcb`，青柠果冻 `#b8f03c`，青色 `#52e0e0`。
- 马克杯世界：橙色天空 `#ff7a2f→#ffb862`，蓝绿色山丘 `#2b9c98`，奶油色。
- 牙齿世界：红色 `#c3122f`，牙龈粉 `#ff8fa6`，牙齿白。鸽子世界：石板蓝 `#5f78a8`，灰色系。克隆人世界：反相紫 `#3b1f66` + 黄色 `#e8d84a`。
- “正常”世界：刻意乏味的米色 `#f1e3c6` 和棕色。
- 角色：穿浴袍 + 毛绒拖鞋 + 护目镜的天才；戴自行车头盔 + 超大圆眼镜的跟班 Gary。
- 传送门：竖向椭圆（x 方向缩放约 0.74），凹凸不平的黏液边缘 `#3fd93a`，7–8 px 描边，5 条螺旋臂在 `#b8ff5a`/`#21b33c` 间交替，**一拍一**旋转，淡色的核心，环绕的火花，底部往下滴，打开时整个场景笼罩一层平涂的绿色；约 12 % 过冲，0.32 s 回弹缓动。用遥控器打开。
- 宇宙读数：左上角的 VT323 标签，打字机式出现，每个世界不同颜色。
- 咖啡：拉花爱心、溢出杯沿的液滴和热气（一团纯棕色看起来像土豆）。

## 片名与片尾卡

- 片名：1950 年代原子时代电视片名风格：奶油色的粗壮方块字母（Bungee），带硬朗的品红偏移阴影和粗墨线描边，外面环绕一条倾斜的青色轨道环，一颗咖啡豆绕着它飞，还有几颗闪烁的四角星；在音乐强拍上以 12 fps 的步进弹出。
- 片尾卡：深紫色、一个缓慢旋转的暗淡传送门、片名、用终端字体写的风格名、"LemoLab × Claude Opus 5.5"、署名；传送门里还有一个小小的片尾彩蛋笑料。这一落款只属于本库的示范片；用户的影片不带任何 LemoLab 署名，也不要复制这张卡。

## 构建说明

```
styles/scifi-toon/demo/
  toon.js     vector engine: matrix stack, screen-space boil, constant line width, flat shading
  chars.js    the cast (parametric eyes, mouths, hands, noodle limbs) + props
  worlds.js   one function per universe + creatures + the portal
  story.js    single source of truth: VO start times, shots, wipes, tags, key beats, music cues
  main.js     acting per shot, cameras, wipes, tags, subtitles, title, end card, window.EV
  lines.json  script (tts text, subtitle text, speaker, voice, pitch, cut)
  voice.py    per-character processing + lip-sync envelopes   asr.py   padded whisper check
  music/score.py  synthesized score from the cue list        mix.py   foley + voices + ducking + ambience
  srt.mjs  build.sh  sheet.sh (contact sheets)  strip.sh (consecutive-frame strips)  levels.py (stem meters)
```

1. 写处理方案。选角方式：生成试读台词，测量 f0 中位数 / 音高方差。
2. `core/tts/tts.py lines.json out/raw` → `voice.py` → `asr.py`，直到每句台词都通过。
3. 把旁白时间、镜头和提示曲放进 `story.js`；在 `main.js` 中调度镜头；用 `sheet.sh`（每秒 1 帧）和 `strip.sh`（连续帧）审看，至少两轮。
4. `core/render/events.mjs` → `music/score.py` → `mix.py`（检查 `levels.py` 和频谱图）。
5. `sh demo/build.sh` 会重现全部内容：TTS → 人声 → 事件 → 配乐 → 混音 → SRT → 渲染（1380 帧，4 个 worker 约 15 s）→ 以 −14 LUFS 混流。在 M 系列 Mac 上完整重建约 1 分钟。

与本示范片相关的坑：
- Kokoro + whisper：名字 "Pim" 用低沉嗓音读出来被识别成 "Pam"；"Gary" 没问题。"b-broken" 被读成 "be broken"；"buh, buh-broken"、"Wh, wh, why" 可行。"decaf" 读出来像 "D-cuff"；"dee-caf" 很可靠。
- 有弹性的传送门（lib `spring`）过冲到约 135 %，把演员吞了进去。
- 放在店铺柜台后面的生物消失了；后来把它们挪了位置，让脸和上半身露出来。
