## 5. 运动质感

- 皮影和镜头都以 **24 fps 连续运动**；只有替换式的特效部件（火、水）以 12 fps 步进。
- 每个皮影都有**手部抖动**（几个像素，约 0.02 rad，低频），紧张时更强。
- 身体随主操纵杆滑动；**腿、翎子、流苏都是模拟的**（由身体加速度驱动的阻尼摆锤 / 弹簧链，以固定频率预先模拟，保证结果确定）。
- 戏曲式的动作分句：碎步跑 → 一跳 → 蹲身 → **在打击乐重音上亮相**（约 1 s，只有松动的部件在颤）→ 转头。
- 脸永远不变；情绪 = 头部角度 + 身体倾斜（向上 = 决心，向下 = 悲伤）。
- **贴上 / 揭离**：入场时又大又模糊地贴到幕布上，再猛地变清晰（约 0.5 s）；退场时变大、变模糊并淡出（约 1 s）。
- 新点亮的灯带着过冲闪亮；熄灭的灯以急促的闪烁摇曳着灭掉。
- 永远不动的：幕布、台框。没有任何变形：部件只绕铆钉旋转、沿操纵杆滑动，或被替换。



## 6. 镜头语法

这是一套词汇，而不是一条路线。开场和结尾由题材决定。

| 运镜 | 表达什么 | 可用于 |
|---|---|---|
| 观众席视角（整个戏台，下方是观众的头） | "这是一场演出" | 一段传说；一堂课；一段被框起来的回忆 |
| 推镜穿过台框到幕布上 | 进入故事 | 故事中的故事；聚焦 |
| 横向摇镜扫过宽阔的幕布 | 广度，一个铺开的地方 | 一段旅程；灾难波及的范围；一支队伍 |
| 跟拍一个皮影，轻微变焦 | 与一个人物同在 | 一场追逐；一个工作日 |
| 在一记打击乐上几帧的**急推变焦** | 鼓点变成了镜头 | 登场；亮相；揭示 |
| 沿一个运动部件甩镜 | 因 → 果 | 一条消息发出；一次出击 |
| **锁定全景** | 变化的每一步都被看见 | 计数；重复；阶段 |
| 中近景，两个部件之间是空幕布 | 距离，犹豫 | 一个抉择；一次分别 |
| 雕刻细节的近景 | 手艺即意义 | 一个誓言；一件工具；一条线索 |
| 从地面长条俯仰到幕布顶部 | 高度，等级 | 一座塔；天与地 |
| 横移绕到背面（镜像视角） | 揭开戏法 | 幕后故事；谁在背后操纵 |
| 从幕布拉回到黑暗的房间 | 故事变成一件物品 | 余波；一晚的故事讲完了 |

皮影以侧面示人；幕布的大部分保持空着。放大时，把镜头限制在影窗矩形内（不出现黑边）；除非扎进一盏灯，否则都以画面中心推镜。转场：灯光变暗、一根模糊的前景柱子扫过、一个部件在光中揭离、闪成暖白色；绝不用普通的交叉淡化或数字擦除。



## 8. 原生手法

一份菜单：按故事需要挑选；把最强的放在高潮处。

- **光就是世界。** 灯的数量决定热度和色彩。*适合的内容：* 夜里城市灯火蔓延；高烧起起落落；服务器一台台开机。
- **离开影窗 = 变大变模糊。** 被拉向灯的部件会变大、变模糊。*适合的内容：* 谣言越传越大；记忆逐渐模糊；截止日期逼近，压到幕布上猛然清晰。
- **转到幕后。** 灯、手、操纵杆。*适合的内容：* 一件产品真正是怎么做出来的；谁在操控一个市场；老师揭示方法。
- **镂刻与透光。** 镂空处发光，重叠处变暗，空脸与实脸对照。*适合的内容：* 一个系统的 X 光透视；寓言中的好人与坏人；一座城市的层次。
- **手持操纵。** 抖动和摇摆的部件。*适合的内容：* 一场紧张的面试；走钢丝；幼儿迈出第一步。
- **部件替换。** 操纵杆上的一个雕刻部件被另一个替换。*适合的内容：* 四季；一台机器的不同状态；收获季节里的天气。
- **长条揭离。** 揭起一条布景，露出另一条。*适合的内容：* 地质分层；洪水前后；新城之下的老城。
