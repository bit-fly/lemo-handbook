# 皮影戏 — 我们的示范片

这只是众多可能中的一个例子。不要照搬它的故事、结构、镜头、道具或时间安排。

示范片：*Hou Yi Shoots the Suns*（后羿射日）（54 s）· `shadow-puppet.mp4` · 源文件见 [`demo/`](demo/)


## 故事与结构

十盏油灯燃作十个太阳；神射手后羿每射下一个，幕后就熄灭一盏灯，直到只剩最后一盏，而这一盏正是照亮整出戏的那盏灯。一个角色，一个目标（射下炙烤大地的太阳），一个转折（第十支箭已经搭上弦，他却停了手，留下一个太阳）。

核心创意：*每个太阳都是一盏灯*，每一箭熄灭一盏，所以画面真的一级一级地变暗。开场一盏灯（演出开始）；说到"十个太阳"时，幕布后又亮起九盏，影窗发白、过曝，颜色被漂淡；每射下一个太阳就熄灭一盏灯，色彩便退回一级暖金。结尾转到幕后：原来"太阳"是一盏灯，"天空"是一块一米宽的布，于是故事的结局（一个太阳就够了）和媒介的真相（皮影戏只需要一盏灯）在同一个镜头里合拢。呼应：1 盏灯 → 10 盏 → 1 盏；开场的梆子 ↔ 结尾的梆子；片名牌匾 ↔ 片尾牌匾。

示范片如何改编它的题材：灯就是太阳，而离开影窗的，是每一只死去的金乌。（同样的问题适用于任何题材：一次产品发布 → 产品就是最后点亮影窗的那盏灯；一段回忆 → 人物从幕布上浮起，随着被遗忘而变得模糊。）

结构（54 s）：黑暗中一盏灯亮起 → 幕布上出现一个世界 → 麻烦降临（十盏灯：光变了）→ 英雄登场并亮相 → 伴着锣鼓射日 → 一个无声的抉择 → 世界复原 → 转到幕后 → 幕布上的片尾卡。

用到的原生手法：光就是世界（灯的数量 = 太阳的数量）、离开影窗（金乌翻落，化入光中）、镂刻与透光（后羿的空脸）、手持操纵（翎子和腿挂在摆锤上）、转到幕后（在高潮之后，作为呼应）。

## 镜头

| 节拍 | 镜头 |
|---|---|
| 开场 | 观众席视角：整个戏台框，下方是孩子们的后脑勺。黑场，直到幕后一根火柴擦亮。极慢的推镜。 |
| 进入故事 | 推镜穿过台框，直到幕布填满屏幕。 |
| 灾难 | 1.5× 横向摇镜扫过燃烧的大地（给灾难留出范围）。 |
| 英雄登场 | 1.15× 跟拍；在亮相的锣声上，5 帧的**急推变焦**（打击乐重音变成了一次运镜）。 |
| 第一个动作 | 手 / 弓 / 脸的近景，然后沿着箭甩镜到目标。 |
| 重复 | **锁定全景**，让观众看到变化的每一步（九级灯光变暗）。 |
| 抉择 | 中近景，目标在画面远端：英雄在左，中间是空旷的天空，最后一个太阳在右。音乐停止。 |
| 呼应 | 拉镜重新露出戏台框，**向右横移，一根模糊的前景柱子扫过画面**，从幕后出来。缓慢推镜，然后快速扎进火焰，闪成暖白色后接片尾卡。 |

为什么这个故事走这条路线：观众席视角让它成为一段被讲述的传说；锁定全景让九级变暗可以被数清；无声的中近景撑住了那次拒绝；幕后横移兑现了"太阳就是一盏灯"。每一个都是从 STYLE.md §6 中做出的一个选择，而不是这种风格默认的开场或结尾。

时间线要点（`story.js`）：片名牌匾 2.4 s 进入，3.6 s 就位，6.6 s 退出；1306 帧，24 fps。

## 配乐结构

原创锣鼓配乐（`demo/music/score.py`）。锣鼓点按以下顺序对应剧情：开场滚奏 → 每盏灯一击，逐渐加快 → 灾难段下面的心跳鼓 → *急急风*滚奏加速进入登场 → 亮相时一声大锣 → 每一击配一锣的快速击打 → **戛然而止**（≤ 30 ms，包括混响尾音）进入无声的抉择 → 下决定时一声极轻的小锣 → 温柔的胡琴主题 → 锣的刮擦声转到幕后 → 最后一声大锣的余音。

胡琴：灾难段用**苦音**，英雄与疗愈段用**欢音**。类似唢呐的簧管只在高潮处出现。

本片特有的拟音：开场和散场的木梆子、擦火柴、点灯、操纵杆的敲击声、金乌飞起时的皮革拍打声、皮革脚步声、拉弓的吱嘎声（随拉满音高上升）、弓弦的嗡响、箭的呼啸、命中时的皮革"啪"声、灯熄灭（"噗"+ 嘶嘶声）、振翅声、噼啪声、热浪的低鸣（在寂静处硬切）、水声、安静的幕后房间底噪和一次呼吸。

人声：一位说书人，Kokoro `am_michael`，语速 0.86–0.88，5–6 句短台词，经过压缩，再加小剧场混响。音乐压低约 12 dB，拟音约 4 dB。一句单独通过 whisper 校验的台词在音乐下变得模糊（"shadow play still" 变成了 "shadow place"）：改写台词，而不是跟混音较劲。

## 色板与道具

- **渲染常数**：灯光主瓣 σ ≈ 700 px + 热点 σ ≈ 120 px；闪烁 ≈ ±6 % 的 7 Hz 值噪声加一个很小的 23 Hz 正弦；光色 `(1, .77, .46)`；曝光 `1.75 / √(lamps lit)`（十盏灯 ≈ 一盏灯的 3×）；幕布织纹约 2.6 rad/px；辉光来自 3 级金字塔，阈值 0.72，色调 `(1,.82,.6)`；暖色暗角趋向 `(.7,.47,.25)`；饱和度 ×1.1；可平铺的 512² 兽皮纹理；ffmpeg 中胶片颗粒 2。
- **染色**：朱红 `#b8211a`、火焰色 `#d9541c`、赭黄 `#dc9d1e`、金色 `#c98a26`、孔雀石绿 `#236e3a`、玉绿 `#2f8a5c`、靛蓝 `#22647e`、生皮色 `#e2bd80`、墨色 `#1a100a`（轮廓、头发、靴子）。
- **后羿**（11 个部件）：头 + 头盔、胸、裙、两个上臂、两个前臂、两只手、两条腿，外加箭囊、弓、雉鸡翎。头约为自然比例的 1.2×，头盔约占全身的四分之一。铠甲 = 成排的粗月牙孔（"开口鱼鳞纹"），裤子 = 菱形格纹，腰带 = 钱孔，四瓣云肩带云卷纹镂刻，袖子与躯干用不同颜色。朝靴：高高的黑色靴筒带镂刻云卷，靴尖上翘，厚厚的白色靴底一体雕成（刻槽 + 一排椭圆孔）。空脸（镂空面部）。
- **弓**以程序方式绘制：弓臂随拉弓弯曲，弓弦连到扣弦的手，**箭尾扣在瞄准线上**：握把 = 肩 + u·118，箭尾 = 握把 − u·(40 + 72·pull)。箭杆深色 `#4a2612`，3 px。
- **太阳**：一个镂刻的圆形部件：火舌边缘（交替卷曲，火舌之间有泪滴形孔，火舌长约 40 px × 弧距的 0.78）、珠圈、半透明的橙红色圆盘，上面单独放一只深色的三足金乌，以便它能掉落下来。
- **布景**：每座山是一个部件，带沿山脊走向的宽阔地层刻纹，近山顶处有云孔；树 = 一个树干部件加一整片布满叶形孔的镂空树冠；地面是一条窄窄的雕刻长条（回纹带 + 钱孔），裂缝刻成逐渐变细的缝隙，随着大地被烧透而变宽变长。水是一条单独的靛蓝色波浪条，可以被揭起。火是一个由 S 形卷曲火舌组成的雕刻部件（红 → 橙 → 黄的色带，尖端带螺旋钩），装在操纵杆上，以 12 fps 替换和抖动。一间茅屋。
- **戏台**：红黑漆框，雕花门楣上有金色云卷，立柱；在开场和片尾卡的全景中，底部是模糊的孩子们的后脑勺。
- **幕后**：灯是灯盘 + 绳索，一盏亮着，其余九盏刚刚熄灭，拖着青烟。
- **运动参数**：抖动约 3 px / 0.018 rad，紧张时 ×1.8；摆锤以 120 Hz 预先模拟；入场时缩放 2.6 → 1、模糊 34 → 0，用时 0.55 s；退场时缩放 ×1.9、模糊 +30 px、约 0.9 s 内淡出；灯火亮起时过冲到 1.5×，0.35 s 内熄灭；在大锣上的亮相停留约 1 s。
- **字幕牌**：深棕色渐变，不透明度 0.93，一条细细的金色内线，左侧一枚小小的朱红印章，刻"说"字（Ma Shan Zheng 字体），Cormorant Garamond 600，46 px，奶油色 `#f3e2bf`，居中，距底部 58 px；在 0.22 s 内上滑 18 px；从台词开始显示到语音结束 + 0.8 s（≥ 1.8 s），在下一句前 0.3 s 切掉。
- **片名牌匾**："HOU YI / SHOOTS THE SUNS / a shadow puppet tale"（后羿射日 / 一出皮影戏）从深色兽皮上镂刻出来，红色边框带回纹带，绿色云卷纹角花，一枚刻字的红色印章，由两根操纵杆举起，退场时从幕布上揭离。

## 片尾卡

幕布上的一块剪刻字牌匾："SHADOW PUPPETRY" / "Hou Yi Shoots the Suns" / "LemoLab × Claude Opus 5.5"（`stage.js` `buildStage().end`），出现在扎进幕后火焰并闪成暖白色之后；海报帧上也带同样的署名行（`main.js`）。"LemoLab × Claude Opus 5.5" 的署名只属于本库的示范片；用户的影片不带任何 LemoLab 署名，也不要照搬这张片尾卡。

版权（见 [`demo/CREDITS`](demo/CREDITS)）：后羿传说是公有领域的民间故事；皮影、布景、镂刻纹样、舞台调度和旋律均为原创，由代码生成；传统纹样（鱼鳞铠甲、云卷、回纹、钱纹和格纹、火舌）均为通用使用，没有复制任何历史上的皮影。字体 Cormorant Garamond 和 Ma Shan Zheng（OFL 1.1）；人声 Kokoro TTS（Apache-2.0）；音乐采样 CC0（Karoryfer 二胡、Versilian Studios 音色库）；音效为合成。

## 构建说明

```
styles/shadow-puppet/demo/
  carve.js     cutting toolkit: piece sprites, cut/cutLine/cutTaper, pattern library, hide texture, rivets
  gl.js        WebGL2 screen compositor (lamp field × transmission × cloth, mirror, bloom, haze, warm fade)
  houyi.js     jointed puppet (11 pieces, IK arms, bow, plumes, rods)    poses.js  key poses
  suns.js      carved suns + crow                     scenery.js  mountains, ground strip, river, tree, hut, fire pieces
  stage.js     lacquer frame, audience, pillar wipe, cut-letter plaques
  backstage.js rim-lit silhouettes (hands, lamps), lamp flame, smoke
  story.js     timeline (single source of truth)      main.js  shots, acting, lamps, events
  hud.js       subtitle placard    test.js  ?test=model | frame | hands | (main) poster
  lines.json   narration   mix.py  foley + voice + music ducking   music/score.py  original gong-and-drum score
  tools/       cues.py (SRT), mux.sh (CRF 22), probe.mjs (render timing)
```

1. `node core/render/still.mjs styles/shadow-puppet/demo 0 --q test=model`：先做角色设定图（角色风险排在第一位）。然后是 `--q test=frame&f=ten|one` 风格样帧和 `--q test=hands`。
2. `.venv/bin/python core/tts/tts.py lines.json voices` → `core/tts/asr_check.py`（同音词用 `asr` 字段处理）。
3. 在 `story.js` 中写时间线。用 `still.mjs --range 0.5:54:1.5` + `core/render/sheet.py` 审看（两轮，错开半个步长），然后从 mp4 中截取关键动作的帧条。
4. `node core/render/events.mjs` → `music/score.py` → `mix.py`。
5. `node core/render/video.mjs … --fps 24 --workers 3`（1306 帧，在 M 系列 Mac 上 3 个 worker 约 80 s）。
6. `sh demo/tools/mux.sh out/video24.mp4 mix.wav shadow-puppet.mp4 24 2`。或者直接运行 `sh demo/build.sh`。

与本示范片道具相关的坑：
- 后羿最初看起来像踩着高跷的腿、蛋形的躯干，手臂淹没在躯干里 → 放大头部、加长裙摆、加宽裤子、加上云肩、袖子与胸部用不同颜色。
- 太阳的光芒先是像锯片，后来又像花瓣 → 改成底部粗壮、带钩的火舌，尺寸如上所述。
- 生皮色的箭在十盏灯的影窗上消失了 → 改用深色箭杆；箭一直斜着指向一边，直到箭尾扣在瞄准线上才对。
- 幕后镜像辅助函数用 `C[0]` 构建两个轴的旋转，把部件上下颠倒了 → x 项用 `C[0]`，y 项用 `C[3]`。
- 对顶部边缘的幕后灯推镜时，把手挤出了画面 → 以画面中心推镜，只在最后扎进火焰时才把固定点移到火焰上。
- 热浪低鸣和噼啪声漏进了无声的抉择段 → 在停顿处硬切。
- 当另外 14 个渲染共用 GPU 时，无头 Chrome 截图偶尔超时 → 重试。
