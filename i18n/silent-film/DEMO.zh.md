# 1920s 默片 — 我们的演示片

这只是众多可能中的一个示例。请勿照搬它的故事、结构、镜头、道具或时间安排。

演示片：*The Runaway Loaf*（逃跑的面包）（54.2 s）· `silent-film.mp4` · 源文件见 [`demo/`](demo/)


一部 40–60 秒的单本喜剧：面包师那只完美的圆面包逃跑了，最后落到了一个饥饿的小女孩手里。它最倚重的参考是：Keaton 的固定机位连锁笑料和 Lloyd 的千钧一发；配乐遵循默片伴奏提示单（Maestoso / Andante / Hurry / Misterioso / Agitato / Tenderly）。

## 故事与结构

一部短小的单本喜剧，呈现出它被*放映*时的样子：画面是片门中的一份 4:3 拷贝，夹在剧院的幕布之间；图像是一幅带灰色淡彩和排线的墨线画，印在会闪烁、晃动、划伤、边缘烧焦的银盐胶片上。没有人说话。故事节拍由**全景中的动作**和**字幕卡**讲述。唯一的声音是影院钢琴（以及放映间里的放映机）。

喜剧引擎来自 Keaton：一个普通人怀着一个小目标，一个不听话的物理世界，一张毫无反应的脸——以及一个由因果链条构成的笑料，观众在同一个画面里看着它发生。

演示片如何运用这一媒介：

| 原生能力 | 故事中的用法 |
|---|---|
| **固定机位全景** | 机械式笑料：A 触发 B，B 离开画面，观众等待，B 回来砸中 C。等待本身就是笑点。 |
| **字幕卡** | 三到五张卡承载动作无法表达的内容：前提的反转（"The loaf had other plans."，面包另有打算），一声叫喊（"STOP THAT BAKER!"，拦住那个面包师！），一句对白（"Is it yours, mister?"，先生，这是你的吗？）。每张卡只写几个词。 |
| **放映速度** | 追逐戏欠速摇片（动作以 18 fps 采样，1.3× 速度，更快的闪烁）；温情戏回到 16 fps 和更平静的拷贝。速度就是情绪。 |
| **光圈** | 在故事的主角物件上打开，在最后一瞥上合拢。停在一半的光圈能让角色看向观众（眨眼）。 |
| **老化即情绪** | 出岔子时损伤更多；影片转向温情时，深褐色更暖、拷贝更干净。 |

**故事形状（已在演示片中验证）：**骄傲（面包师把他完美的圆面包高高举起）→ 物件逃跑（它在窗台上晃了晃，滚下去，一路滚下山坡——是*圆*面包，所以真的能滚）→ 带一次千钧一发的追逐（他一抓，面包从他手上跳过，他盯着自己空空的拳头）→ 一镜到底的连锁笑料（跷跷板 → 一个甜瓜飞出画面 → 警察踱步走进来 → 甜瓜落在他的头盔上）→ 面包停在一个更需要它的人脚边（一个饥饿的小女孩）→ 静默 → 一个小小的举动（他把面包掰成两半）→ 呼应（她把她那一半高高举起，就像他当初那样）→ 光圈在她的眨眼上合拢。**宁删勿加**：早先的版本有电车、雾中追逐、屋顶悬挂和一个八步的市场连锁，在缩略图里完全看不懂。一条清晰可读的链条胜过三条热闹的链条。

改编任何题材：找到那个逃跑的物件、它最终应该归属的人、一条能在单个全景画面里发生的机械链条，以及一个能在结尾以新含义重复的动作。

## 镜头

| 节拍 | 摄影机 |
|---|---|
| 开场 | 放映机启动时幕布在黑屏前拉开；片名卡；**光圈打开**在被举起的面包上。 |
| 铺垫 | 固定全景：整个前提（骄傲 → 窗台 → 滚落 → 愣了一下再回头看）在一个画面里演完。 |
| 追逐 | **跟拍镜头**：小镇以 0.8 滚动，路灯杆以 1.35 从前景扫过，主角和物件始终在画内。 |
| 连锁笑料（标志性镜头） | 固定机位大远景，**不剪切**：跷跷板 → 甜瓜飞出画面顶部 → 2.5 s 的等待 → 警察走进来停在他的位置 → 甜瓜落下。 |
| 喘息 | 固定全景，然后是真正的静默。 |
| 温情 | 一个有动机的缓慢**推镜**：主角跪下时，摄影机降到孩子的高度（缩放 1.6 → 2.1）。 |
| 结尾 | **光圈合拢**到孩子身上，停住，她对观众眨眼，光圈关闭；"The End"；幕布合上。 |

- **手摇采样**：角色和摄影机的运动以 16 fps 采样（追逐时 18）；拷贝的闪烁、晃动、颗粒和划痕每个输出帧（24 fps）都变化。正是这种混合让它看起来像在放映，而不只是低帧率。
- **冷面表演**：主角的脸几乎不变；由身体来表演——举起前的下蹲、骄傲地保持举起、愣一下再回头看时两帧的突变加一个小跳、弯腰一扫、边跑边看着空拳头、双手撑膝、下跪。
- **物件也会表演**：面包离开前在窗台上晃动，恰好在最糟的时刻跳过一块鹅卵石，随着音乐减速（渐慢），最后摇晃着靠在一只鞋边停下。
- **抬手臂要避开脸。** 在这套绑定上，前屈会让抬起的手臂横扫过脸；庆祝时的抬臂用外展（向两侧，像开合跳那样），或者先让角色转向摄影机。

## 配乐结构

- **没有拟音，没有人声。** 钢琴*就是*声音设计，就像 1920 年代的电影院：晃动用紧张的颤音，坠落用下行刮奏，弹跳用低沉的"嘣"，愣一下再回头看用减和弦突强，抓取用一声高音戳击和一段上行快速音阶，空拳头用"叮……咚"，跷跷板用前臂音簇，甜瓜用上行刮奏，等待用渐强的减和弦震音，落地用下行刮奏接一个撞击和弦，面包掰开时用清脆的小二度，眨眼用一个倚音。
- **配乐**：原创的默片配乐，用一台老式**立式钢琴**演奏（VSCO 2 CE，CC0），左手跨步伴奏，遵循提示单：Maestoso 片名 → Andante"面包主题"（F 大调）→ 滑稽的"糟了"+ 渐快快速音阶 → Hurry（a 小调，十六分音符快速音阶，144 BPM）→ 停顿式悬念 + Misterioso 行走 → Agitato 震音 → 渐慢（88）→ 静默 → **簧风琴**（FreePats accordion，CC0）以 pp 进入 → Tenderly（面包主题，72 BPM）→ 终曲。主题在开头听来骄傲，在结尾听来温柔。
- **放映机就是环境声**：幕布拉开前一声灯泡咔嗒和电机启动，整卷胶片下方是轻柔的抓片爪与电机嗡鸣，在静默中被推到前面成为*唯一*的声音，结尾是胶片尾端在收片盘上拍打。
- **静默**：(1) 连锁笑料中的停顿，甜瓜在画外时（只有一个微弱的渐强震音）；(2) 面包停下，只有放映机声两秒钟——下一个声音是簧风琴。
- 在响度标准化（−14 LUFS）之前，用轻度压缩驯服钢琴的击弦瞬态。颗粒放在画面里；mux 时 grain 设为 1。

## 色板与道具

- **本库风格 = 色调绘画 + Redraw。** 场景只用灰度值绘制（拷贝密度：墨 0.07，深色布料 0.15–0.3，中间色木头 0.45–0.6，皮肤 0.8，衬衫和围裙 0.9–0.95），带柔和的光线渐变和一条细分隔线。然后 **Redraw** 处理（WebGL2）为整个画面上墨：在每条边缘的暗侧用高斯差分描出轮廓，亮度色调分离为五级柔和淡彩，暗部加 45° 排线（然后交叉），每两帧重绘一次，就像手工重绘的动画。真实视频帧也经过同样的处理（"redraw mode"，见 `stills/frame_redraw.jpg`），所以实拍素材和绘画出自同一只手。
- **拷贝**（`FilmPost`）：银色调加 0.10–0.36 的深褐色，拷贝黑 0.055 / 白 0.93，S 曲线，高光处的光晕，不均匀的密度，闪烁，片门晃动加偶尔的齿孔跳动，断续的竖向划痕（白色 = 刮掉的乳剂，深色 = 底片上的灰尘），从边缘蔓延的褐色烧痕，暗角，两个倍频程的银盐颗粒。然后 `damage()` 加上灰尘、片门里的一根头发和偶尔的污斑。
- **画框**：1440×1080 置于 1920×1080 中央，22 px 圆角片窗带柔和的暗边；两侧是剧院——天鹅绒帷幔被银幕的溢光和脚灯照亮。幕布在开头拉开，在结尾合上。
- **角色**：写实的 7.5 头身成人和 5 头身的孩子，用 2.5D 绑定（关节在 3D 中求解，带偏航投影），默片时代的妆容（苍白的皮肤，深色的眼睑和嘴唇）。演示片主角的剪影标志：褶皱的面包师帽，白衬衫外一件深色马甲，一条白色长围裙。
  主角的模型表，灰度值即拷贝密度，四种表情和关键姿势：[`demo/stills/modelsheet_v2.jpg`](demo/stills/modelsheet_v2.jpg)。一张经过完整管线（Redraw、深褐色、光圈、剧院）的温情戏风格帧：[`demo/stills/frame_v2_tender.jpg`](demo/stills/frame_v2_tender.jpg)。
- **字幕卡**：黑色手绘卡片配装饰艺术边框，纹饰随情绪变化——叫喊用一条粗线（文字抖动），叙述用带阶梯角和扇形的双线，温情用藤蔓和小花。片名和叫喊用 Playfair Display SC，叙述和对白用 Old Standard TT Italic。
  四种卡片并排：[`demo/stills/frame_cards.jpg`](demo/stills/frame_cards.jpg)。

## 片名、字幕卡与片尾卡

- 字幕卡*就是*字幕；`.srt` 列出它们的文字。每张卡停留 2.5–3.75 s。
- 片名：THE RUNAWAY LOAF / *a photoplay in one reel*（一卷默片）。
- 片尾卡（温情边框）：The End · 片名和风格名称 · LEMO-OPUSCAR · LemoLab × Claude Opus 5.5 · 素材署名；幕布在它上面合拢。LemoLab 落款只属于本库的演示片：用户的影片不带 LemoLab 署名，也不复制这张卡片。

## 我们踩过的坑（演示片记录）

- **木偶手臂**（第一版剪辑）：每条手臂都是一根单独的管子，完整轮廓压在衬衫上，肩部支点从不移动，而且外展是在前屈之后施加的——所以一条"张开"的举过头顶的手臂实际上向内摆，举起的动作变成了一个 X。`engine/figure.js` 中的修复：先外展，再前屈；手臂上抬时肩关节升高并向前摆（锁骨）；抬起一侧躯干的肩角变窄；手臂带有三角肌和二头肌/前臂的轮廓；手臂靠近肩部压在躯干上的那段轮廓被隐藏。
- **姿势跳变**：在 `if` 分支里切换姿势会让角色跳动。每个角色都由关键帧列表驱动（`shots.js` 中的 `poseAt`、`numAt`），所以姿势、位置和朝向总是平滑过渡的；只有刻意的笑料（愣一下再回头看）才突变。
- **漂浮的道具**：一个"握"在双手平均位置、画在所有东西上面的道具会漂浮。要把它握在两掌*之间*，深度位于两臂之间（`props.between`），尺寸与两掌间距相符，交接时在给予者和接受者的手掌位置之间插值（`palmsAt`）。长面包无法沿长度方向滚动——用圆面包，并把它的旋转与距离挂钩（角度 = 距离 / 半径）。

- **内容太多会毁掉一部默片。** 一个八步的连锁笑料，在每个头 64 px 的尺寸下，在缩略图里就是噪点；第一个版本连第一次审看都没撑到。一条链条，中间带一个停顿，才看得懂。
- 绑定的脸在大特写里看起来像人体模型：保持在全景和中景（这本来就是 Keaton 的语法），唯一的特写放在光圈里。
- 一条抬起的手臂横过女孩的脸，挡住了眨眼：让她转向摄影机，用外展抬臂。
- 眉毛角度会随朝向翻转："担忧"（内侧眉毛上扬）在朝左的女孩脸上读成了生气；要在最终尺寸的裁切中检查表情。
- 光圈中心必须在摄影机缩放之后，以*影片*坐标跟踪脸部（`girlFace()` 把世界坐标映射到影片坐标）。
- 追逐中主角起初从未进入面包的一臂之内，所以抓取没被看懂：在那个节拍上把手正好放在物件所在的位置，身体弯下，让跳跃足够大（210 px）。
- 只被黑屏照亮的合拢幕布是纯黑的（blackdetect）：加上脚灯。
- 重颗粒会产生大文件（CRF 19 时 170 MB）；用 `-tune grain -crf 25` 重新编码（≈ 77 MB）。

## 构建说明

```
styles/silent-film/demo/
  timeline.js    cue-sheet sections (bpm, beats) + named hits — the single source of truth → tools/dump_timeline.mjs → timeline.json
  engine/        ink.js (tonal forms, ink line, wash, hatch, drawShape) · redraw.js (Redraw: frame → ink drawing, WebGL2)
                 film.js (FilmPost print + damage) · cards.js (intertitles, deco borders, iris, theatre) · figure.js + heads.js (2.5D rig)
  chars.js poses.js sets.js   the cast, key poses, town set pieces
  shots.js       one function per section: bakery · chase · market · roll · sil · tender · irisShot (tonal paintings)
  film.js        assembly: shot → Redraw → iris → FilmPost → gate + curtains; per-section look (damage, sepia, sampling fps, crank)
  cardspecs.js   the intertitles        frames.js   model sheet, card sheet, redraw sample, one-colour example
  sheets.js      rig check scenes, not in the film: ?scene=sheets.test (turnaround + run pose) · heads · redrawFig · armTest · loafTest
  stage.js       the small scene → FilmPost → gate helper that sheets.js draws through
  music/score.py  photoplay score from timeline.json      mix.py   score + projector
  tools/         cuecheck.py · subs.py · dump_timeline.mjs
```
1. 先写提示单（`timeline.js`）：段落、速度，以及每个笑料节拍作为命名的击点。配乐由同一个文件生成，所以每个击点都精准落拍（0 ms）。
2. 用灰度绘制每个镜头（用 `?scene=` 静帧审看），然后通过整条管线去看它——Redraw 处理会改变哪些东西能被看懂。
3. `sh demo/build.sh`：时间线 → 配乐 → 提示点校验 → 混音 → srt → 渲染（1301 帧，2 个 worker 约 55 s）→ mux（−14 LUFS）→ 颗粒重新编码 → 静帧。总共约 2.5 分钟。
4. 每秒审看 1 帧，然后以 0.1–0.2 s 间隔为每个笑料审看帧条。

## 引擎参考

四个模块，可以单独使用：

| 模块 | 主要 API |
|---|---|
| `engine/ink.js`（色调绘画） | `setFrame(t, {boil})` · `form(g, pts, {v, line, grad, shade, cyl})`（一个灰度值为 `v` 的填充、带阴影、带轮廓的形状）· `stroke(g, pts, w)` · `drawShape(g, shape, style)`（**以本风格绘制任意路径**；`style.color` 用某个色相把它画进颜色蒙版）· `sparkPts(cx, cy, r, tail)` · `catmull`、`ellipsePts`、`rectPts`、`mottle`、`shade`、`grey(v)` |
| `engine/redraw.js` | `new Redraw(w, h).render(canvasOrImageOrVideo, {frame, lines, tone, hatch, levels, gap, sigma, p, eps, phi, bilateral, src})` → canvas。把色调绘画*或真实视频帧*变成墨线画（照片用 redraw mode：`bilateral: 3, p: 34, eps: .24`）。 |
| `engine/film.js` | `new FilmPost(w, h).render(src, {frame, strength, sepia, crank, grain, flicker, weave, scratches, burn, vignette, halation, exposure, jump}, colorMask?)` → canvas · `damage(g, x, y, w, h, frame, strength)`（灰尘、头发、污斑）。可以叠加在**任何** 2D canvas 上。 |
| `engine/cards.js` | `intertitle(g, W, H, {level, lines:[{text, font, size, italic, weight, spacing}], shake}, t)` · `decoBorder(g, x, y, w, h, level)` · `iris(g, W, H, cx, cy, r)` · `theatre(g, W, H, gate, spill, curtainOpen)` |
| `engine/figure.js` + `heads.js` | `drawFigure(g, character, {x, ground, scale, yaw, pose, t, props})` · `P0()`、`mixPose`、`runPose(ph)`、`walkPose(ph)`、`runBob` · 角色在 `chars.js`，姿势在 `poses.js` |

**唯一的颜色。** 拷贝是单色的；要让某个元素保留自己的色相，把它画进一个单独的蒙版 canvas（颜色 + alpha），再传给 `FilmPost.render`：蒙版有 alpha 的地方保留色相，但仍然带有颗粒、闪烁和暗角。

```js
import { drawShape, sparkPts, grey, setFrame } from './engine/ink.js';
import { Redraw } from './engine/redraw.js';
import { FilmPost, damage } from './engine/film.js';

setFrame(t);
const W = 1440, H = 1080, mk = () => Object.assign(document.createElement('canvas'), { width: W, height: H });
const frame = mk(), f = frame.getContext('2d'), mask = mk(), m = mask.getContext('2d');
f.fillStyle = grey(.9); f.fillRect(0, 0, W, H);
const sp = sparkPts(720, 460, 220, 260);                 // a four-point light with a short tail
drawShape(f, sp.star, { v: .6, shade: 12 });            // tonal version (gets inked + hatched)
drawShape(f, { pts: sp.tail, closed: false }, { line: 10 });
drawShape(m, sp.star, { color: '#D97757' });            // the one colour
const inked = new Redraw(W, H).render(frame, { frame: Math.round(t * 24) });
const print = new FilmPost(W, H).render(inked, { frame: Math.round(t * 24), strength: .6, sepia: .15 }, mask);
g.drawImage(print, 240, 0); damage(g, 240, 0, W, H, Math.round(t * 24), .6);
```
（`?scene=frames.oneColour` 渲染这个示例。）
