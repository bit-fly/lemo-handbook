## 5. 运动质感

- **刮印是线性而匀速的**（刮板不做缓动）。强调色油墨比所在色层的主油墨晚半拍开始。
- **信息条目**按节拍细分从左到右印出。**任何地方都没有淡入淡出。**
- **网版抬起**：网框绕铰链翻起（垂直压扁 + 投影变大），约 0.4 s。
- **换色板重印**：一把宽刮板在约 0.35 s 内斜向划过纸面；刀片两侧几何完全相同，只有油墨改变。只露出刀片、墨珠和一小截手柄。
- **松散的色层**：在多层运镜中，各平面按深度产生视差，带有纸缝和厚度投影，然后随一个重音**咔地对准套版**。



## 6. 镜头语法

这是一套词汇，而不是一条路线。开场和结尾由题材决定。

| 运镜 | 表达什么 | 可用于 |
|---|---|---|
| 随刮板横移，轻微滚转，网框边缘入画 | 印刷这个动作；颜色的到来 | 开场钩子；分色喷泉的天空 |
| 锁定的俯拍整张纸 | 色层叠加成一幅画面 | 看一张海报成形；对比 |
| 网版抬起时快速拉镜 | 揭示完成的一个色层 | 一个场景完成；片名 |
| 推镜 + 俯仰到信息条 | 阅读 | 事实信息；日期；价格 |
| 在屏幕空间中横移穿过前景剪影（树、路灯杆、船帆） | 进入下一张海报 | 海报到海报的转场 |
| 升降镜头穿过松散的平面（多层视差） | 纵深，印品内部的一段旅程 | 一条路线；一次攀登；一条街道 |
| 沿一排印品缓慢横向移动镜头 | 一套、一个系列 | 系列墙；多种配色 |
| 推镜到丝网直至看见网纹 | 手艺，媒介的肌理 | 一个亲密的节拍；一处细节 |
| 对数缩放拉回到墙面或橱窗 | 海报置身于真实世界 | 最终定版（停留 ≥ 3 s） |

纸张特写要保留纸边在画面内；横穿特写的刮板要倾斜并藏起手柄，以免把画面一分为二。色层靠刮板切换，海报靠前景剪影或移动印台切换。不用叠化，不用硬切。



## 8. 原生手法

每一种都服务于信息顺序。一份菜单：按影片需要挑选。

- **一色一拍。** 信息最后印出，正是它被阅读的时刻。*适合的内容：* 博物馆开放时间；渡轮时刻表；品鉴笔记。
- **分色喷泉。** 一次刮印带出多种油墨，让画面充满色彩。*适合的内容：* 节庆的夜空；日落海滩酒吧；一整排彩虹配色。
- **换色板重印。** 同一张海报、另一套色板 = 时间流逝、一个季节、一个变体。*适合的内容：* 夏季与冬季营业时间；夹克的三种配色；集市的白天与夜晚。
- **套版错位 → 咬合。** 松散的色层随一个重音对准套版，紧接着是关键信息。*适合的内容：* 一场比赛的日期；发布价格；开票时间。
- **纸也是一种颜色。** 未印刷的纸是最亮的元素。*适合的内容：* 滑雪坡道；灯塔的光束；屋顶上的新雪。
- **路线作为印刷层。** 一条强调色虚线逐段压印出来。*适合的内容：* 一条公交线路；马拉松赛道；配送路径。
- **系列墙。** 所有印品最后挂在一起作为最终定版。*适合的内容：* 一座城市的四个街区；乐队的巡演日期；一个产品家族。
