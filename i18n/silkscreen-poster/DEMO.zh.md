# 丝印旅行海报 — 我们的示范片

这只是众多可能中的一个例子。不要照搬它的故事、结构、镜头、道具或时间安排。

示范片：*Three Trails*（三条步道）（38.4 s）· `silkscreen-poster.mp4` · 源文件见 [`demo/`](demo/)


## 故事与结构

一个虚构公园的步道导览：三张步道海报依次被印出来，一张比一张快，第三张以一个长镜头一路攀爬，最后三张都挂上了游客中心的墙。没有旁白。

这是 STYLE.md §11 中的第一个用例（步道 / 景点导览）。镜头结构：片名横幅刮印 → 海报 1 一层层印出 → 海报 2 按八分音符印出 → 最后一张海报一镜到底攀爬 → 拉回到墙面。信息顺序：公园名 → 场景 → 步道名 → 难度 → 距离 → 时间 → 爬升 → 页脚。停留时长：片名 3.2 s；步道名 ≥ 字符数/12+1 s；数据行在最后一项落下后 ≥ 2.2–3.0 s；3 条步道共 30–40 s。

STYLE.md §11 中的其他用例使用同一个引擎：一个场景就是一组平面，信息条模板可容纳任意 1–4 条信息，`swap` 可以把整张海报换成另一套色板重新上墨。

**原生手法如何服务于信息**（而非故事）：
- *一色一拍*：每一次刮印就是一个音乐重音，于是视线被按顺序引导穿过各个色层，而信息最后才印出来，恰好就是它被阅读的时刻。
- *分色喷泉（split fountain）*：一次刮印带出多种油墨。它用来开场，因为一刮就让整个画面充满色彩。
- *换色板重印*：整张海报以下一个时段的色板再刮一遍。在示范片中，这就是"7 h"这个数据点：镜头攀爬的同时，一天过去了。
- *套版错位 → 咬合*：攀爬过程中，各色层松散地悬着（露出白缝，有纸张厚度的投影），然后随一个重音咔地对准套版。这是全片唯一一次在最重要的信息出现前停顿。
- *纸也是一种颜色*：瀑布就是未印刷的纸，是整张纸上最亮的东西。
- *步道作为一个印刷层*：路线是一条用 sun 油墨印的虚线，镜头沿着它跟拍时一段一段地压印出来。

## 镜头

| 运镜 | 用途 | 示范片 |
|---|---|---|
| 随刮板横移，轻微滚转（−1.7°），网框边缘和刮板手柄两端入画 | 开场钩子：刮板在画面中保持位置，色带从旁流过 | 0–1.0 s |
| 快速拉镜（缓出 0.65 s） | 网版抬起时揭示整张印品 | 1.0–1.65 s |
| 在印台上俯仰 | 从一张纸到下一张 | 4.8 s |
| 锁定的俯拍全景 | 看色层层层叠加 | 5.4–7.8 s |
| 推镜 + 俯仰到信息条 | 阅读 | 7.8–9.0 s |
| 横移穿过前景树木（屏幕空间剪影，用上一张海报的 `near` 油墨，遮满画面约 1 帧） | 海报到海报的转场 | 13.2 s、19.2 s |
| 从细节拉回整张纸 | "白色就是瀑布" | 14.4 s |
| **沿步道升降镜头，多层视差**（标志性镜头） | 最难的步道，一镜到底 | 19.2–23.4 s |
| 从山顶俯仰向下到信息条 | 攀爬结束于数据 | 24.0 s |
| 对数缩放拉回到墙面 | 最终定版，停留 ≥ 3 s | 29.4–30.6 s |

统一的转场语法：色层的切换靠刮板；海报的切换靠前景树木；全片以刮板刮出片尾卡的油墨结束。不用叠化，也不用硬切。

示范片的运动参数：信息条每项 0.18 s，落在八分音符上；强调色油墨 `sub: 1`（晚半拍）；网版抬起 0.4 s；换色板刮刀倾斜 −12°，用时 0.35 s；攀爬视差 `(camTopY − camY) × (depth − 1) × 0.42`，每条山脊支脉横向滑动（高斯凸起，190 u × depth）；纸缝 3 u，厚度投影 9 u、不透明度 28 %，按"松散度"缩放，套版咬合时归零。开场横移滚转 −1.7°。

## 配乐结构

- **音乐**：美式户外民谣，100 BPM，D 大调，开放 D 调弦吉他扫弦（物理建模）、滑棒吉他（numpy）、VCSL 口琴、卡洪鼓底鼓、鼓刷、立式贝斯。**每次刮印是一次扫弦**，随着色层由远及近，和弦依次爬升 D – D/F# – G – A。海报 2 加倍到八分音符（加速）。攀爬段逐件乐器叠加。套版咬合是全片最响的强拍。
- **按材质分类的拟音**：刮板刮过丝网（带通噪声，带有丝网产生的 220–280 Hz 振幅颗粒感；刮得越快越亮）、湿油墨的"咕叽"声（下行正弦加黏稠噪声）、铝制网框的咔嗒声加铰链吱呀声、数据的纸张盖印声、步道虚线的十六分音符滴答声、色层滑动的纸张嘶嘶声，以及木头与金属的套版夹具声。
- **环境声**：工作室房间底噪；网版抬起时，海报 1 里的湖水声渐入（印品"醒来"）；瀑布（提前 0.9 s 的 J-cut）；山风（J-cut 进入寂静，L-cut 延续到墙面）；游客中心的低语、一扇门、脚步声。
- **寂静**：18.0–19.2 s（音乐停止；瀑布尾音淡到约 −59 dBFS；之后的第一个声音是一段长长的上滑音）和 23.4–24.0 s（只有风声；之后的第一个声音是夹具声加全乐队）。
- 音乐在拟音下压低 2.5 dB。母带：−14 LUFS。

## 色板与道具

- **色板纪律**：每张海报一套色板，6 种油墨：`sky1`（浅色天空）、`sky2`（深色天空 / 色带）、`far`、`mid`、`near`（最深，也用于信息条）、`sun`（唯一的亮色强调：太阳、步道、难度、爬升）。可选的 `glow` 是山体的受光面。一张海报最多用其中 ≤ 6 种。示范片的色板：
  - 黎明 `#F6CD98 #EE9A73 #9A7FA8 #3E7079 #1E3B3F #FBE6B4`
  - 正午 `#E4EEDC #86BCD0 #C2AE92 #4C8753 #1D4331 #F2C14A`
  - 金色时刻 `#F7D787 #E9A94F #A57C68 #5E7A45 #2B3A28 #FFF1C4`
  - 黄昏 `#F4B461 #D8613F #7C3E5F #43325A #1B1B2F #FBE3A6`
  - 纸张 `#F2E8D2`。片名横幅 `#F7C66B #E4683F #2F6F73 #1C2A33`。
- **对比度自动处理**：文字油墨按与下方油墨的 WCAG 对比度来挑选（`pickInk`）。夜间色板不会让标题消失。
- **形状**：山是中点位移生成的山脊，带锯齿状的受光面；松树是一个由下垂层叠组成的轮廓加一截短树干；水是一块平面，带水平的反光条；森林是立在实心底座上的成排松树。一切都用硬边绘制。
- **海报模板**（单位 1000×1500）：纸边 26 u；画面区域到 y = 1140；场景整体上移 50 u，裁掉一点天空为信息条腾出位置。信息条（y 1148–1474，`near` 油墨）包含步道名（Big Shoulders Display 900，最大 122 u，自动适配）、用 `sun` 印的编号 `01`–`04`、一条 6 u 的 `sun` 线，以及一行数据：标签 34–38 u（Outfit 600，加字距），数值 48–68 u（Big Shoulders 800）。各列宽度按内容决定。在墙面上以 0.49 比例显示时，标签约 18 px，数值约 31 px。
- **页眉**：公园名以 62 u 大字距排开，印在天空里。
- **纹理预算**：纸张贴图每纹素 0.6 u，斑驳正片叠底 55 %，针孔 75 %，再加 ffmpeg 颗粒 3。超过这个量就开始像孔版印刷（risograph）了。

## 片名与文字

没有旁白，也没有字幕：海报上的文字*就是*信息。片名卡是一张印出来的 4:1 横幅（1800×440 u，片名平衡地分成两行），构图撑满宽度（约 5 % 边距，约占画面高度 40 %），它后来成为最终墙面的页眉（挂出时宽 1150 px，让海报上的数值保持 ≥30 px）。示范片用的阅读规则：每段文字在其**最后**一项落下后停留 ≥ 字符数/12 + 1 s（至少 1.5 s）。时间线根据 `content.json` 计算这一时长，并向上取整到节拍。

## 片尾卡

片尾卡被印成最后一张横版小海报，分两次刮印：一次分色喷泉刮印出画面（天空色带、太阳圆环、山脊、步道虚线、片名），再一次 `near` 刮印出信息条（风格名、`Lemo-Opuscar`、`LemoLab × Claude Opus 5.5`、字体与采样素材署名）。"LemoLab × Claude Opus 5.5" 的署名只属于本库的示范片；用户的影片不带任何 LemoLab 署名，也不要照搬这张片尾卡。

## 构建说明

`sh styles/silkscreen-poster/demo/build.sh` 重建全部内容：
1. `tools/timeline.mjs` 打印由 `content.json` 推导出的时间线。
2. `core/render/events.mjs` → `events.json`（每一次刮印、抬起、色带、名称、条目、擦除、换色、分件、寂静、咔嗒）。
3. `music/compose.py` 读取 `events.json` → `score.wav` 及分轨。
4. `mix.py` → `mix.wav`（环境声、拟音、闪避压低、寂静窗口）。
5. `tools/cuecheck.py` 将混音中的起音与事件对照检查：中位误差 4 ms；33 个中 30 个在 1 帧以内。其余是重叠事件和起音较慢的口琴。
6. 渲染（`--workers 2`，如果你的机器有渲染限流器就通过它）→ `mux.sh … 24 3`。

文件：`engine/silk.js`（印刷引擎）、`engine/scenes.js`（5 个内置场景）、`engine/poster.js`（模板、横幅、对比度）、`film.js`（时间线和镜头）、`mix.py`、`music/compose.py`。每帧大约 0.1 s；完整渲染不到一分钟。

### 我们踩过的坑

- **基于描边的边缘效果会在合并路径上画出内部线条。** 用松树合并画成的森林显示出了每棵树的轮廓。光泽和陷印只用填充来做：先填充形状，再在裁剪区域内把它偏移后再填充一次。
- **网框投影让整张印品变暗。** 网框的投影必须是一个环形（奇偶规则），而不是整个矩形，否则丝网下的一切都显得浑浊。
- **花岗岩上的蓝色阴影面会被读成水。** 阴影面保持用 `near`，并放在紧邻瀑布的内侧面上。
- **一把粗刮板横穿特写会把画面切成"两张图"。** 让刀片倾斜，藏起大部分手柄，并让几何在刮板两侧保持连续。
- **锯齿三角形的油墨珠会被读成纸张边缘。** 墨珠需要圆润感：受光的半边、暗的底面、高光和拉丝。
- **只有视差会被读成"山在移动"。** 在色层松散时展示纸缝和厚度投影，并配一个声音让它们咔地归零。
- **夜间色板让页眉和标签消失了。** 按对比度选择文字油墨（`pickInk`），永远不要用固定的键。
- **湿光泽渐变卡在刮印结尾**（条件 `p < 1.02` 永远为真）。按时间让它淡出。
- **树木擦除遮住画面 0.4 s**（一片暗色空白）。把剪影居中对准切换时刻，让完全遮挡只持续约 1 帧。
- 按这样的阅读时长，四条步道要约 45 s。压缩方法见下文"40 s 内放四条步道"。
- **7:1 的片名横幅在 16:9 画面中只是一条细缝**（约占高度 1/5，印台大片空着）。把横幅做成约 4:1，才能撑满宽度并占约 40 % 的高度。
- **印台上随机的彩色圆点会被读成彩纸屑或占位符。** 做一张真实的工作台：木板、木纹、木节、几块大而柔和的油墨污渍和撕开的胶带。
- **信息条特写必须让整条信息条都在画面内**，两侧边距 ≥5 %（对 1000 u 的海报，z ≤ 1.75）。正在印刷的纸张特写必须保留纸张边缘在画面内，否则观众只会看到一片纯色。

## 引擎参考

`engine/silk.js` 能以这种风格印出**任意形状**：它只需要一个 `Path2D`，单位与当前变换所用的一致即可。

| 函数 | 作用 |
|---|---|
| `makeTextures(paperHex, seed)` | 纸张、斑驳和针孔贴图（生成一次） |
| `paperSheet(ctx, T, x, y, w, h)` | 纸张底材 |
| `ink(ctx, part, o)` | 一个油墨层。`part = { path, knock?, paint? }`（`knock` = 镂空的孔，`paint(ctx)` = 自定义填充，例如文字）。`o = { color, reg:[dx,dy], clip, sheen, trap }` |
| `wipeRegion(box, dir, p, seed)` / `wipeFront(...)` | 以裁剪路径表示的参差刮印前沿，以及刀片所在位置 |
| `squeegee(ctx, a, b, lead, o)` | 从 `a` 到 `b` 的刀片，沿 `lead` 移动；`o.beads=[{t0,t1,color}]`（分色喷泉）、`roll`、`handle` 0–1、`scale` |
| `screenFrame(ctx, box, o)` | 带丝网、感光胶和胶带的铰链网框；`lift` 0–1 |
| `inkFinish(ctx, T, x, y, w, h)` | 纸面上的斑驳和针孔 |
| `bandSteps(x, w, y0, y1, n)` | 阶梯色带（渐变的替代品） |
| `ridgeLine`、`polyPath`、`circlePath`、`ringPath` | 形状辅助函数 |

`engine/poster.js`：`buildPoster(content, trail, i, n)`、`drawPoster(ctx, P, { pal, T, prog, off, reg, sep, swap, items, … })`、`drawBanner`、`pickInk`。`engine/scenes.js`：`buildScene('lake'|'waterfall'|'ridge'|'forest'|'coast')` 返回可以重新排序或扩展的平面。

最小示例：一个暖橙色 `#D97757` 四角星芒，带一条光标尾巴，用两种油墨印刷，从天空中镂空出来，再由刮板刮入：
```js
import { makeTextures, paperSheet, ink, wipeRegion, wipeFront, squeegee, inkFinish, polyPath, rectPath, circlePath } from './engine/silk.js';
const T = makeTextures('#F2E8D2');
paperSheet(ctx, T, 0, 0, 800, 600);
const spark = polyPath([[400,180],[430,270],[520,300],[430,330],[400,420],[370,330],[280,300],[370,270]]);
const tail = rectPath(540, 285, 160, 30);
const p = 0.7;                                                    // 70 % of the pull done
const clip = wipeRegion([0, 0, 800, 600], 'right', p, 3);
ink(ctx, { path: rectPath(0, 0, 800, 600), knock: circlePath(400, 300, 150) }, { color: '#1C2A33', clip, sheen: 1 });   // sky with a knocked-out halo
ink(ctx, { path: spark }, { color: '#D97757', reg: [2, -1], clip, sheen: 1, trap: 1 });
ink(ctx, { path: tail }, { color: '#D97757', reg: [2, -1], clip, sheen: 1 });
const x = wipeFront([0, 0, 800, 600], 'right', p);
squeegee(ctx, [x + 10, -20], [x + 10, 620], [1, 0], { color: '#D97757', roll: x / 30 });
inkFinish(ctx, T, 0, 0, 800, 600);
```
单色海报：只保留一个色板键（通常是 `sun`）作为唯一的颜色，其余油墨设为同一色相的不同深浅。`pickInk` 会保证文字清晰可读。

## content.json 字段

所有文字、数据和颜色都来自 `demo/content.json`；`film.js` 里不含任何文案。

| 字段 | 类型 | 范围 | 超出范围时 |
|---|---|---|---|
| `park` | string | ≤ 22 个字符 | 页眉以 62 u 加字距排列；更长的名称会超出天空宽度（缩短或减小字距） |
| `title` | string | ≤ 34 个字符 | 在横幅上自动适配 132 → 60 u；低于 60 u 就小到难以阅读 |
| `footer` | string | ≤ 45 个字符 | 在横幅条中占一行；墙面停留时间随其阅读时长增加 |
| `trails[]` | array | **1–4** | 1 = 只有印刷（无攀爬）；2 = 印刷 + 攀爬；3 = 印刷、快速、攀爬；4 = 印刷、快速、快速、攀爬（约 45 s，见下文）。超过 4 条，墙上的海报会小到无法阅读 |
| `trails[].name` | string | ≤ 22 个字符 | 自动适配 122 → 60 u |
| `trails[].difficulty` | `easy` \| `moderate` \| `hard` \| `expert` | — | 未知值显示 1 个实心三角 |
| `trails[].distance` | number | 任意 | 印为 `3.2 KM`（单位取自 `units.distance`） |
| `trails[].time` | string | ≤ 7 个字符（`1 h`、`45 min`） | 该列变宽，所有数值一起缩小（最小 48 u） |
| `trails[].elevation` | number \| null | null 隐藏 CLIMB 列 | 以 `sun` 油墨显示为 `↑1,100 M` |
| `trails[].scene` | `lake` \| `waterfall` \| `ridge` \| `forest` \| `coast` | 内置 | 未知 → `lake` |
| `trails[].time_of_day` | `palette` 中的键 | `dawn`、`noon`、`golden`、`dusk`、`night` | 缺失 → `noon`。攀爬段从上一条步道的色板经 `golden` 重印到这一套 |
| `palette.<time>` | `{sky1, sky2, far, mid, near, sun, glow?}` | hex | 文字对比度自动检查 |
| `palette.paper`、`palette.wall`、`banner_time` | hex / object / key | — | — |

**步骤**：编辑 `content.json` → `sh demo/build.sh`。没有 TTS；音乐和混音会根据 `events.json` 自动重新对时。要预览另一个文件而不覆盖原文件：`node core/render/still.mjs styles/silkscreen-poster/demo 30 --q content=content_alt.json`。

**40 s 内放四条步道**：按阅读规则，每张中间海报约 6 s。可选做法，按推荐顺序：
1. 把两张中间海报**并排放在同一张印台上，用同样的几次刮印印出**（一个快速段落、两条信息条、一起阅读）。
2. 中间海报的逐项盖印间隔从八分音符降到十六分音符。
3. 中间海报跳过信息条特写，让它们在最终墙面上被阅读（墙面停留延长 2 s）。

`content_alt.json`（4 条步行路线，黎明/金色时刻/正午/夜晚，一个新公园、墙面和横幅色板）是经过测试的示例。其静帧在 `demo/stills/alt_*.jpg`。

最小内容：
