## 5. 运动质感

- **木偶以一拍二制作**（12 fps）：人物、手、落定的字母、交通工具的姿态和位置。**镜头、字幕滑动和网格生长以一拍一制作**（24 fps）：阶梯式的镜头运动会抖。
- 跑步循环约 8 张画，每拍一步，强烈前倾，强调色的部件向后飘。走路每拍一步，外套摆动。
- 字幕沿网格线滑入，**在拍点上骤然停住**（短促缓出）；字母落定时伴随一声纸片拍打声。
- **时间定格**：在一记强奏上，整个画面（包括背景滚动）在完全静默中定格几拍，然后继续。
- 碎裂：一个场景被切成平行于切线的条带，沿对角线交替滑出。



## 6. 镜头语法

这是一套词汇，不是一条路线。图形化、平面、果断。开场和结尾由题材决定。

| 运动 | 表达什么 | 可用于 |
|---|---|---|
| 先宽景展示整行字幕，再横移推进 | 先阅读，再行动 | 任何由文字搭成的场景 |
| 横向跟拍，保持单一屏幕方向 | 追逐；冲劲 | 一场追逐；一场比赛；一次投递 |
| 在铜管强奏上硬切 | 冲击；新场景 | 蒙太奇；一次揭晓；一个笑点 |
| 图形匹配剪辑（相同形状，相同位置） | 押韵；加速 | 车轮 → 硬币 → 瞳孔 → 月亮 |
| 平涂底色上锁定的单一形状 | 神秘；一个图标 | 冷开场；一条线索；一个标志 |
| 巨大圆形前的剪影 | 主角时刻 | 一次抓捕；一场胜利；一场对峙 |
| 对角线裂开成网格 | 碎片化；众多同时出现 | 分屏；一场阴谋；一个团队 |
| 沿一列文字竖直下摇 | 下降；一份清单 | 一栋建筑；一份名单；倒计时 |
| 推镜进一个字母直到它填满画面 | 字母变成一个地方 | 一扇门；一条隧道；一扇窗 |

构图：强烈的对角线（约 30°），大块平涂底色，人物在文字面前显得很小。匹配剪辑在剪切前后保持圆心和尺寸完全一致。不用叠化。



## 8. 原生手法

这是一份菜单：按故事需要选用。

- **字体就是布景。** 每个场景是一行演职员字幕，这一行字就是它的建筑（字母当柱子，单词当车厢，一个字母当一把锁）。*适合的内容：* 把会议议程变成一座城市；把菜单变成一家餐厅；把队名变成一座体育场。
- **字幕即节奏。** 字幕踩在拍点上落定；强奏就是剪切。*适合的内容：* 产品的功能点；音乐节阵容；奖项的提名名单。
- **图形匹配剪辑。** 形状押韵，随着张力上升间隔不断缩短。*适合的内容：* 硬币 → 行星 → 时钟；齿轮 → 车轮 → 太阳。
- **对角网格。** 一条对角切口倍增成网格，碎片之后沿它飞回拼成某样东西。*适合的内容：* 解开的谜题；组建中的团队；拼合的标志。
- **剪影木偶。** 侧面剪纸人物，表演全靠轮廓和节奏。*适合的内容：* 一场劫案；赶截止时间的信使；一名侦探。
- **时间定格笑点。** 在强奏上定格、静默、继续。*适合的内容：* 千钧一发；一次惊愕回头；一次价格揭晓。
- **追逐的对象就是片名。** 所有人追逐的东西成为最后拼合出的画面。*适合的内容：* 产品发布；一本书的书名；生日主角的名字。
