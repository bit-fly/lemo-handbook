# 60 年代谍战片头 — 我们的示范片

这只是众多示例之一。不要照搬它的故事、结构、镜头、道具或时间安排。

示范片：*The Velvet Cipher*（44 s）· `spy-titles.mp4` · 源码见 [`demo/`](demo/)


一部 30–60 秒的短片：一名特工追逐一名信使和一把被偷走的钥匙，穿过由演职员字幕搭成的布景，而这把钥匙最终打开的正是影片的片名。

## 故事与结构

1950 年代末 / 1960 年代片头设计的图形语法（Saul Bass 的 *North by Northwest*、*Anatomy of a Murder*、*Vertigo*；以及 Kuntzel + Deygas 2002 年为 *Catch Me If You Can* 所做的致敬片头）：**纸上平涂的不透明油墨、手工剪出的边缘、抽象到只剩剪影，以及作为画面结构一部分的字体排印**。片头本身就是一个故事：一个目标、一场追逐、几个场景、一次揭晓——而揭晓的就是片名。

它**不是**枪管式开场，不是踮着脚走路的卡通豹子，也不是复制任何真实片头的标志、字体、角色或镜头。字幕中只出现虚构的职位（"A LEMOLAB PICTURE"、"STARRING THE AGENT"、"MUSIC BY THE SAMPLER"）——绝不出现真实姓名。

选择那种**追逐某样东西、而它最终就是影片本身**的故事。示范片用上了全部五种媒介本色，最强的一种（对角网格拼出片名）放在高潮：

| 媒介本色 | 在故事中的用法 |
|---|---|
| **字体就是布景** | 每个场景恰好是一行演职员字幕，而这一行字*就是*建筑：字母是柱廊的柱子（主角躲在 **I** 后面），单词是火车车厢（他跳过单词之间的空隙），名字中的 **O** 是轮盘赌的转盘，一道长破折号是屋檐，一个字母是一把锁。每一行字都必须在某一刻能被完整读出。 |
| **字幕即节奏** | 字幕踩在拍点上落定。铜管强奏 = 硬切。每条字幕停留的时间要足够让人在读字幕条的同时读完它。 |
| **图形匹配剪辑** | 抽象让形状押韵变得廉价而有力：车轮 → 轮盘 → 瞳孔 → 月亮 → 锁孔。在铜管上剪切，并随着追逐加速缩短间隔（2 小节 → 1.5 小节 → 2 拍）。 |
| **对角网格** | 开场沿一条 30° 的对角线裂开，裂缝倍增成一张网格；高潮时每块碎片沿同样的对角线飞回，拼成片名；片名再沿同一条切线合上。开场的伤口 → 结尾的缝合。 |
| **剪影木偶** | 人物是平面剪纸，永远是侧影，以一拍二制作动画。所有表演都靠轮廓和节奏：奔跑、贴平、回头、定格。 |

改编任何题材：把题材变成**麦高芬**，把片名变成它的终点。产品发布 → 产品就是被偷的东西，碎片最终拼成它的标志。一场讲座 → 核心观点在四个以字幕为布景的"章节"中被追逐。一场生日 → 追逐以名字拼合收尾。

**情绪弧线（35–45 s）：** 冷开场只有一个形状 + 一句任务简报（3 s 内抓住观众）→ 偷窃 → 穿过 3–4 个场景的追逐，每个比上一个更短 → 一个笑点（主角半藏半露；时间定格）→ 形状匹配剪辑组成的加速蒙太奇 → 在巨大圆形前以剪影完成抓捕 → 世界沿网格碎裂并拼成片名 → 一个安静的收尾小节：一拍静默、一记邦戈鼓、一句面无表情的台词。

## 镜头

| 节拍 | 镜头 |
|---|---|
| 冷开场 | 锁定，黑底上居中的单一形状（锁孔）。它其实是片名中 **I** 的大特写。 |
| 每个由字幕搭成的场景 | 开头**足够宽，能读到整行字幕**，然后推镜/横移进入动作。 |
| 追逐 | 横向跟拍（*Catch Me* 的语法）：屏幕方向始终从左到右，被追者在前，追者在后。 |
| 蒙太奇 | 在铜管强奏上硬切；圆形在剪切前后保持相同的屏幕位置和大小。 |
| 主角时刻 | 剪影立在一轮巨大的奶油色月亮前。 |
| 结尾 | 推镜到片名的锁上，直到画面与冷开场完全一致，然后在最后一记邦戈鼓上硬切回完整片名。 |

- **木偶以一拍二制作**（12 fps）：人物、手、落定的字母、飞机的姿态*和*位置。**镜头、字幕滑动、网格生长以一拍一制作**（24 fps）——阶梯式的镜头运动看起来会抖。
- 跑步循环：8 张画，每拍一步（132 BPM 下一个循环 = 2 拍），前倾 0.3 rad，领带以约 65° 向后飘。走路：每拍一步，外套摆动。
- 字幕沿网格线滑入，在拍点上骤然停住（缓出，0.2 s），字母落定时伴随一声纸片拍打声。
- **时间定格**：在一记铜管强奏上，整个画面（包括背景滚动）定格 2 拍，同时音乐完全静默，然后继续——这是大乐队手法的视觉化，也是一个无声的笑点。
- 高潮：前一场景被切成平行于切线的条带，沿对角线（N×NW）交替滑出，同时片名字形沿同一条对角线飞入，在连续的十六分音符上落定。

## 声音结构

- **音乐：1960 年代谍战大乐队**（不是冷峻的黑色爵士，也不是拉格泰姆），小调，约 132 BPM。原创动机：从五度音开始半音下行，然后跳进到主音（B–A♯–A–G | E），附点节奏。**避免**那段著名的 E–F–F♯–F 爬行音型和 Em(maj9) 结束和弦；以 Em6/9 结束。
- **铜管强奏 = 剪辑点**：`trumpet_stac` + `trombone_stac` 按八度叠加 + 吊镲，约 0.25 s，提前 8 ms 放置，让采样峰值正好落在那一帧上。冲浪吉他低音弦的拨弦声（`electric_guitar`）经过一个自制弹簧混响（色散啁啾回声，往返约 41 ms，衰减 2 s）。`jazz_bass` 走路贝斯。前段用鼓刷（轻柔小军鼓 + 蛋形沙锤），火车段用鼓棒（十六分音符的"铁轨"小军鼓）。赌场段用 `world_perc` 的邦戈鼓/沙锤。片名处一个大和弦，然后一个短促的收尾，**一拍数字静音**，一记干涩的邦戈鼓。
- **静默是一种工具**：冷开场只有一声磁带咔嗒；时间定格和最后一拍是真正的零（包括混响尾音）；最后一句台词只垫着磁带嘶声。
- **拟音跟随材质**：纸（剪切的"嘶"声、滑动、每个字母落定时的卡片拍打声、百叶翻转、碎裂时的撕纸声）、金属（钥匙叮当、链条断开、钥匙插入锁中、锁的咔哒声）、磁带（咔嗒、嘶声）。环境声只做暗示：喷气机掠过（声像从左到右）、火车隆隆声加上合拍的车轮"咔—咚"、轮盘小球的滴答声逐渐变慢、屋顶的风声。
- **人声**：英式任务简报男声（Kokoro `bm_george`，语速 0.9–0.97），经过一条磁带链路：220–5200 Hz 带通、轻度饱和、0.9 Hz 的抖晃、在人声下升起的嘶声。4–6 句非常短的台词；最后一句呼应第一句（"Nobody knows what it opens." → "Now you know what it opens."）。人声出现时音乐闪避约 −7 dB。响度 −14 LUFS。

## 色板与道具

- **四种油墨，没有渐变**：墨黑 `#1b1714`、纸奶油色 `#efe4c9`、信号红 `#d23a22`、芥末黄 `#e2a52a`。只允许用"更深的纸"变体来表现纵深/阴影：`#9a2a18`（深红）、`#b07e1c`、`#3a322b`（远处的城市）。每个场景有一个主导底色：黑（冷开场、屋顶）、红（网格、火车、赌场）、奶油色（天鹅绒、片名）、芥末黄（机场）。
- **剪刀剪出的边缘**：每个多边形每隔约 9–10 px 重新采样，并沿法线方向按低频噪声位移（幅度 1.2–2.2 px，形状越大幅度越大），偶尔加一个 1–2 px 的小缺口。**在部件的局部空间中只剪一次边缘并缓存**——移动的剪纸保持同样的边缘，就像真正的剪纸动画一样。（在屏幕空间计算的边缘会在部件移动时"蠕动"。）
- **纸张叠层**：分开的部件之间有一条**底色的 2.4 px 剪切缝隙**，并投下一点纸片阴影（偏移 2.5/3.5 px，模糊 5，透明度约 0.3）。整个人物以这条缝隙作为外轮廓，所以黑色人物站在黑色字母前也能被看清。
- **纸张纹理**：一张全画面纹理以正片叠底覆盖在最上层（低频斑驳 + 淡淡的纤维），再以滤色方式叠一层稀疏的"墨点空洞"斑点（只在深色油墨上显现），加上淡淡的水平刮板条纹。在合成封装时加约 6 的胶片颗粒。不用网点（那属于其他风格）。
- **剪影人物**（见 `demo/stills/modelsheet.jpg`）：七头身的特工，戴窄檐帽（帽带是一道剪开的缝），宽肩外套，尖头鞋，**一条红领带是他唯一的颜色**（奔跑时向后飘——这是运动的指示）。反派高 1.2 倍：宽而平的帽檐，A 字型大衣，红色内衬只在奔跑时露出，一把芥末黄的钥匙用链子锁在手腕上，因此每个镜头里都能找到麦高芬。人物内部的部件**合并成一个轮廓**；只在肩、肘、臀/下摆和膝处留出细（1.7 px）缝。手是尖锐的楔形。没有面孔，只在特写中有一道奶油色的眼缝。
- **麦高芬**始终放在黑色衬底上（= 墨色轮廓线），所以在任何底色上都看得清；它是画面中最亮的东西。
- **字体**：字幕用 League Gothic（OFL），用 opentype.js 提取字形轮廓，并逐字**重新剪切**（边缘噪声、±0.8° 旋转、±1.5 px 基线抖动）。影片片名使用定制的几何剪纸字形（直线切口 + 弧线、粗细不均、俏皮错落的基线）——绝不使用真实片名的字体。字幕条用 League Spartan 600。

## 标题、字幕与片尾卡

- **字幕条**：一条窄纸条（两端剪刀剪切，倾斜 −1°），位于左下角 (96, 958)，用一个小红锁孔字形作为项目符号，League Spartan 600 44 px。深色场景用奶油色纸条配墨色文字；奶油色场景用墨色纸条配奶油色文字。在 0.18 s 内从左侧滑入 60 px。显示时间 ≥ max(1.8 s, 人声 + 0.6 s)。
- **演职员字幕存在于布景之中**，绝不放在字幕条区域。每个场景一行。
- **片名**：定制剪纸字形；麦高芬的位置就是一个字母（这里 CIPHER 中的 I 是一块带红色锁孔的黑色"锁板"；钥匙的轮廓正好填满它）。
- **片尾卡**：小片名，用剪切过的 League Gothic 写的"60s SPY TITLE SEQUENCE"，红色 Spartan 字体的"LemoLab × Claude Opus 5.5"，一个小小的特工抬帽致意。LemoLab 署名（以及"A LEMOLAB PICTURE"字幕）只属于本库的示范片：用户的影片不带 LemoLab 署名，也不要复制这张卡片；其虚构字幕应写用户自己的职位。

## 我们踩过的坑（示范片记录）

- 给每个内部部件都加缝隙轮廓，让人物看起来像木制人体模型的示意图。把每个人物画进一个离屏图层，让部件合并，只剪出关节缝（`destination-out`），然后再以 8 个方向的底色外轮廓 + 一层阴影合成。
- 会重置变换的 `clear()` 会悄无声息地让镜头失效 → 在填充背景时保留镜头矩阵。
- 主角完全藏在 I 后面，看起来就像"那里没人"：挪动他，让帽檐、鼻子、领带结和飘动的领带露出柱子。领带必须飘动（多段色带，带行进的正弦波 + 宽度抖动），否则看起来像一条舌头。
- 一行字幕如果始终只露出一部分（"R R I N"），读起来很别扭：永远先以宽景展示整行。
- 单词车厢之间的黑色电线杆会被读成字母 I——把背景道具改成底色的更深版本。
- 芥末黄的钥匙放在芥末黄底上会消失——给它加一块黑色衬底。
- 放进空格字符里的轮盘会盖住相邻的字母；把单词的两半排在一个 2.2 × 半径的空隙两侧。
- 一只画在最上层的近侧手臂会破坏车轮/瞳孔/月亮的匹配：剪切前后保持圆心完全一致，否则匹配无法成立。
- 铜管断奏采样需要约 8 ms 才到峰值——把它们提前放置，让重击落在剪切点上。
- 峰值很尖的混音（大强奏叠在轻柔的鼓刷上）在 −1.2 dBTP 上限下只能停在 −14.4 LUFS；在 loudnorm 之前先往限制器里推约 4 dB。

## 构建说明

```
styles/spy-titles/demo/
  paper.js   four inks, scissor edges (cached), cut gaps, paper shadow, texture, silhouette layer + joint slits
  glyph.js   League Gothic → opentype.js outlines → re-cut letters
  chars.js   agent / courier rigs (side, front, back), poses, run/walk cycles, key + keyhole
  title.js   custom title glyphs, lock-plate I, diagonal split
  scenes.js  keyhole, grid, velvet, intro, airport, train, wheel, casino, pupil, rooftop, title background
  film.js    timeline, acting, cameras, subtitles, sound events     story.js  132-BPM grid (single source of truth)
  sheet.js / frames.js   model sheet and style frames
  music/score.py   original big-band score (sampler)      mix.py  foley + tape voice + ducking
```

1. `node core/render/still.mjs styles/spy-titles/demo 12 20.8 --q nosub=1` — 查看静帧（`?sheet=1&v=1`、`?frame=airport|train|title`）。
2. `core/tts/tts.py lines.json voices` → `core/tts/asr_check.py`（6/6）。
3. `python music/score.py` → `node core/render/events.mjs` → `python mix.py`。
4. `node core/render/video.mjs styles/spy-titles/demo --fps 24 --workers 3`（1058 帧 ≈ 17 s，Canvas2D）。
5. `CRF=24 sh demo/tools/mux.sh out/video24.mp4 mix.wav spy-titles.mp4 24 6`（核心 mux + 一个 CRF 调节项：平涂油墨 + 颗粒在 crf19 下 = 270 MB，在 crf24 下 = 18.5 MB，肉眼看不出差别）。或者直接运行 `sh demo/build.sh`。
