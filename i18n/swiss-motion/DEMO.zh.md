# 瑞士动态排版 — 我们的示例片

这只是众多可能中的一个例子。不要照搬它的故事、结构、镜头、道具或时间安排。

示例片：*Five Rules for a Poster*（44 s）· `swiss-motion.mp4` · 源文件见 [`demo/`](demo/)


一部 30–60 秒的影片：五条规则在网格上搭建起一张音乐会海报；一个红色圆形打破了网格，而这张海报原来就是这段音乐的乐谱。示例片只用 Archivo 这一个字体家族。

## 故事与结构

在网格上做动画的纯 2D 平面设计：平整的白纸、黑色文字和色条、极浅的灰色，以及**一种**饱和的红色。这是 1950–70 年代苏黎世音乐会海报（Müller-Brockmann、Hofmann、Gerstner、Crouwel）的语言，以现代视觉识别系统的运动方式（Experimental Jetset、Pentagram）动起来：**每个元素都吸附到网格，每个动作都落在节拍上，没有任何回弹**。

它的魅力在于**严谨，外加一个例外**。整个画面服从一套系统，所以那唯一不服从的元素就成了角色。

绝不照抄某张具体历史海报的构图（不要搬用 Müller-Brockmann 的同心圆或扇形构图）。不要使用 Helvetica 或 Akzidenz 的字体文件。选一款 OFL 授权的新怪诞体（Archivo、Inter、Schibsted Grotesk、Instrument Sans……）。绝不在海报上出现真实机构的名字。

挑选那些**由系统本身讲故事**的题材。示例片用上了全部五种原生能力，最强的那个（网格有含义）放在高潮：

| 原生能力 | 叙事用法 |
|---|---|
| **模块化网格** | 网格既是舞台也是规则手册。展示它被搭建出来（线条踩着节拍画出），在段落间隙短暂露出，并在高潮处**让网格具有含义**：在示例片中，7 列 = A 多利亚调式的 7 个音，16 行 = 16 个八分音符，所以海报*就是*乐谱。 |
| **吸附 = 节拍** | 每个元素的到位都是一次打击乐：铅字咔哒、裁刀、鸭嘴笔。画面和音乐共用一套坐标系统，而不是事后再对齐。 |
| **规则生成设计（程序）** | 情节就是一组规则，一条一条地作用于同一件作品。结尾展示同一套程序生成许多作品（Gerstner 式揭示）。 |
| **极端的尺度对比** | 一个 700 px 的数字旁边是 19 px 的技术注释。巨大的元素是章节卡，微小的元素是质感。 |
| **一种信号色** | 只有一样东西是红色的，所以红色 = 主角。当它打破规则时，它是屏幕上唯一不精确的东西。 |

**改编任何话题：** 把它变成**一套系统加一个例外**。一次产品发布：产品规格表在网格上组装起来，然后某个功能突破了网格。一家公司的历史：每个十年是添加到同一张海报上的一条规则。一个爱情故事：两个红色元素分别在两套不同的网格上，当其中一个离开自己的网格时，影片结束。

**情感弧线（30–60s）：** 秩序被搭建（好奇、利落）→ 秩序完成（正确但有点乏味，*要说出来*）→ 犹豫（红色元素抽动一下又吸附回去）→ 打破（片中唯一不吸附的线性运动；鼓声退出）→ 其他一切围绕它重新排布，变得更好（全乐队回归）→ 揭示（网格有含义）→ 规模揭示（同一套系统，许多产出）→ 片尾卡回到主作品。

## 镜头

"摄像机"是一个 2D 矩阵（中心、缩放、旋转）。它只用那条精确缓动运动，并且只在节拍上运动。

| 节拍 | 摄像机 |
|---|---|
| 开场 | 锁定全画面。一个动作：一条红线横扫而过，网格的列在十六分音符上从它里面长出来 |
| 搭建（规则） | 锁定跨页，让观众读出原因（规则，左）→ 结果（作品，右） |
| 打破 | 左页滑出，作品移到中间偏左，网格线延伸到整个画面（网格比页面大） |
| 揭示 | **把作品在 1.5 拍内旋转 90° 并停住。** 之后标签（音名、小节号）才擦入，然后播放头扫过两个小节。每个小节在它起音的那一帧准确变红：把起音放在整帧上（24 fps 时为 0.25 s 的倍数） |
| 规模揭示 | 一边转回来，一边拉远，露出一整面由同一套系统生成的作品墙 |
| 结尾 | 红线再次横扫，把其他作品切掉。推回开场的跨页，片尾卡在左页，主海报在右页 |

- **只用两条曲线。** 吸附用精确缓动 `cubic-bezier(.7,0,.2,1)`，正在画出的线条、播放头和打破规则者用线性。没有过冲，没有弹簧，没有回弹。
- **时长就是音符时值**，按影片的 BPM 计算（120：1/8 = 0.25 s，1/16 = 0.125 s）。一次吸附提前一个音符时值开始，并**落在节拍上**。
- **入场用擦除或裁切揭示，绝不淡入。** 文字从基线下方的裁切矩形中升起（1/16 音符），向上离开（1/8 音符）。线条沿长度方向生长。纸张通过垂直擦除出现。大数字分 **4 个缓动步骤**爬升（"一次一个模块"）。
- **删除用裁刀切。** 一条 2 px 的线在 1/16 内横穿元素，然后元素在 1/8 内垂直塌缩到它的中线。
- **涟漪按与起因的距离排序。** 红色圆形落定后，各单元在十六分音符上每次两个地重新排布，最近的先动。
- **例外的运动方式不同。** 它是线性的，不吸附，飞行途中停顿一个八分音符（回头一瞥）。它边走边变大。旁边的坐标读数从 `col 5.00 row 0.00 · on grid` 变成红色的 `off grid`，数值变成非整数（甚至负数）。
- 一切都以流畅的 24 fps 渲染。没有一拍两帧的步进：这种风格是数字式的精确，不是手工感。

## 配乐结构

- **音乐**：Motorik / 德国泡菜摇滚，120 BPM，A 多利亚调式（不是通用的钢琴加弦乐铺底）。每条规则叠加一种乐器：
  1. 只有踩镲；
  2. + 完整的 motorik 鼓组（`drum_kit`：底鼓在 1、3、3&；军鼓在 2、4；闭镲八分音符）；
  3. + `electric_bass` 八分音符根音脉动；
  4. + numpy 锯齿波十六分音符琶音，滤波器逐渐打开；
  5. + `glockenspiel`，由一个柔和的 numpy 方波主音加倍。

  **在打破的那一小节撤掉鼓**，落定时回归。揭示之前加一小节近乎静默（贝斯持续音 + 四分音符滴答）。揭示期间只保留底鼓 + 贝斯 + 旋律，让每个音都听得清。
- **旋律和画面来自同一个 JSON**（`score.json`：列 → 音高，行 → 起音，长度 → 时值）。"海报就是乐谱"在代码里是真的，不是假装的。
- **拟音跟随材质**，干、近，不加混响：
  - 凸版印刷的咔哒声（金属瞬态 + 3.3 / 5.1 kHz 共振 + 木质字盘）；
  - 鸭嘴笔的"嘶"声；
  - 裁纸刀（带通扫频 + 金属咔嚓）；
  - 纸张拍下 / 滑动；
  - 数字每走一步一声"咚"；
  - 方块吸附；
  - 圆形落地（58 Hz 毛毡闷响）。

  打破规则者是唯一会*唱*的元素：一个跟随它位置的正弦滑音。
- **人声**：冷静、干脆的女声旁白，Kokoro `af_sarah`，语速 1.0。它在 3–8 kHz 的辅音能量约为 `af_kore` 的 7 倍。台词要像规则一样："Rule one. Build a grid."用 whisper 检查每一句（数字写成 `"asr": "Rule 1, …"`）。
- **混音**：人声压缩，有人声时音乐闪避约 −10 dB（人声比音乐高 ≥ 6 dB），−14 LUFS。

## 配色与道具

- **画面网格**：1920×1080，12 列，96 px 侧边距，24 px 栏间距（列宽 122 px），24 px 基线。把画面当成一个**跨页**：左页（第 1–6 列）= "程序"（数字、规则文本、注释）；右页（第 8–12 列）= 作品（海报 706×1008，比例 0.70 ≈ 瑞士世界格式）。
- **作品网格**：从内容推导出来（Gerstner 的方法）。示例片中海报为 7 列 × 91 px 和 16 行 × 40 px，文字区有 26 px 的基线网格。我最初试过 12 个半音列：色条只有 43 px 宽，海报看起来像一张数据图表。**选择能让色条有分量的模块尺寸。**
- **配色**：页面 `#EAE9E5`，纸张 `#FFFFFF`，墨色 `#111111`，信号红 `#E30613`，网格线在页面上为 `#CFCEC9` / 搭建时为 `#C9C8C2` / 在纸上为 `#E2E1DC`，次要色条 `#CFCEC9`。没有渐变，没有阴影，没有粒子，没有颗粒（mux 颗粒为 0）。
- **字体**：整部片子一个字体家族（示例片：**Archivo** 可变字体，字重 400–800）。≥ 90 px 时字距 −2.2%。标题用小写（`neue musik`）。规则数字约 980 px（数字高度 700 px），底部与海报下边缘对齐，**视觉上**左对齐（减去字形的左侧留白）。注释用 19 px Medium。绘制前始终用 `document.fonts.load` 加载每个字重。
- **构图**：左对齐，右边参差。一切都在网格线上。大片留白是版式的一部分。最终构图必须比"正确"的那版**明显更大胆**：
  - 一条主对角线，带强烈的长短节奏；
  - 红色元素约 2× 大小；
  - 元素从纸张边缘**出血**；
  - 文字叠印在红色圆形上（红底黑字）。
  仅仅把正确的版式倾斜一下是不够的。
- **色条即音符**：色条宽度 = 列宽减 8 px；同一个音的连续格子合并成一根色条（接缝处多画 1 px，否则抗锯齿会露出细线，旋转时尤其明显）。
- **次要声部**（贝斯）是黑色色条下方的浅灰色条。它们读起来像一条阴影对角线，不用第二种颜色就带来纵深。

## 标题、字幕与片尾卡

- **字幕是版式的一部分**，不是底部的一条字幕栏。每一句位于跨页左页的第 1 列：第一句作为 30 px Medium 灰色引语，其余作为 76 px Bold 的陈述。每个词按它的 whisper 时间戳裁切揭示。非规则的台词用 Regular 字重（"Perfect. And a little dull."）。在其他镜头中，台词位于该镜头的第 1 列，放在作品标题的基线上，或者像博物馆标签一样放在作品墙下方。
- **标题卡**：`Five Rules / for a Poster`，120 px Bold，两行左对齐，坐在开场的红线上。一行 19 px 的说明文字，上方有一条 1 px 细线（`A programme in five steps · 1961 · ♩ = 120`）。
- **说明行 + 注释**：左页顶部（标题 / `Rule 0n / 05` / 关键词）；第 5 列底部：每条规则 2–3 条技术注释（`Columns 7 · Rows 16 · Module 91 × 40`）。第 7 列底部：一个小节计数器 `bar 04.3`。
- **片尾卡**：再次回到开场跨页。`Swiss Motion / Graphics` 120 px，下方一条红线，`LemoLab × Claude Opus 5.5` 36 px，底部是注释，右侧是主海报。LemoLab 署名只属于本库的示例片：用户的影片不带 LemoLab 署名，也不复制这张卡片。

## 我们踩过的坑（示例片记录）

- **12 列看起来像图表。** 网格模块必须让图形元素有分量。我们为作品用了更少、更宽的列，画面保持标准的 12 列。
- **"更好"的构图并没有明显更好。** 四个小阶梯 → 一个分散的版式，说服力不够。解决：一条带长短节奏的主对角线、2× 的红色元素、出血、文字压在红色上。
- **旋转揭示需要一个停顿。** 一边旋转一边加标签，读起来就是噪音。排好顺序：旋转（1.5 拍）→ 停留 → 网格线 → 标签 → 播放头 → 扫过。
- **合并的色条在旋转和缩放后露出接缝**（相邻矩形之间的抗锯齿）。在格子相接处多画 1 px。
- **标签与表头重叠**：在旋转镜头之前隐藏说明行。
- **词的时间**：whisper 会拆分或合并单词（"type face"），`asr_check` 报告第一个词在 −0.6 s（填充导致）。按字母对齐并钳制到 0（`tools/words.py`）。
- **字幕规则**（≥ 语音 + 0.6 s 且 ≥ 1.8 s）：有两句差了 2 ms。`tools/subs.py` 会做断言检查，所以通过微调起始时间修正。
- **作品墙的切割必须跟随线条**：在屏幕空间中，从红线进入的那一侧收缩墙板。
- 墙上的其他海报共用摄像机矩阵，所以**只**在作品墙镜头中绘制它们。否则它们会在 ±786 px 处漏进其他镜头。
- Canvas 的 `letterSpacing` 也会影响 `measureText`，所以设置字体之后再计算宽度。

## 构建说明

```
styles/swiss-motion/demo/
  score.json  grid = score: stiff / final melody, bass, circle, bleeds, timeline
  ease.js     cubic-bezier(.7,0,.2,1), snap(t, t_arrive, dur), steps(), track()
  film.js     layout system, rules, poster, circle, reveal, wall, end card, foley events
  main.js     loads fonts, score, lines, whisper word times; ?nosub=1, ?poster=1
  lines.json  voice script (af_sarah)          tools/words.py  word timings → subtitle reveal
  music/score.py  motorik score from score.json   mix.py  foley + ducked voice + music
  tools/subs.py   subtitle intervals (asserted) → srt     build.sh  one-shot rebuild
```

1. 先设计版式系统：画面网格、作品网格，以及列和行*代表*什么。写好 `score.json`。
2. `node core/render/still.mjs styles/swiss-motion/demo --range 0.5:43.5:1 --out …`，然后 `sheet.py`。审看 1 s 间隔的总览，以及打破和每个转场附近 0.25 s 间隔的密集条带。
3. `tts.py` → `asr_check.py`（0 处不匹配）→ `tools/words.py`。
4. `music/score.py`（起音来自 `score.json`；检查扫过时的起音误差 ≤ 5 ms）→ `events.mjs` → `mix.py`（逐句打印人声/音乐/拟音的 dB）。
5. `video.mjs --workers 3`（1056 帧约 12 s）→ `mux.sh … 24 0`。或者直接 `sh styles/swiss-motion/demo/build.sh`（从零开始约 55 s）。
