## 5. 运动质感

- **延时的顿挫是这种风格的灵魂。**快进时整个世界（车辆、人、灯光、太阳）以较低的频率更新，每个位置保持若干帧（8 Hz = 24 fps 下的 3 帧）；选择更新频率，让每次跳动都落在音乐的节拍网格上。**摄影机在每一帧都保持平滑。**速度适中时用中等频率步进；低于约 ×2 时顿挫消失，运动变得丝滑，这让骤降到真实时间更有冲击力。
- 系统由每个片段预先计算的简单模拟驱动（跟车模型、信号灯周期、人群聚集和涌出），周期偏移经过选择，使变化落在小节线上。
- 主角由美术指定时间（脚本路径穿过节拍时间点拟合），绝不指望模拟碰巧踩中节拍。
- 近景表演：预备压扁 → 拉伸 → 落地压扁 → 稳定；成功之前的一次失败是喜剧的引擎。



## 6. 镜头语法

这是一套词汇，不是一条路线。开场和结尾由题材决定。

| 运动 | 表达什么 | 可用于 |
|---|---|---|
| 高机位斜角全景，极慢的平移 | 一眼看尽整个系统 | 交代地点；日常；许多小角色 |
| 模糊带在全景中跟随一个主体 | “就是这一个” | 一个通勤者；一次配送；一个走失的孩子 |
| 模糊带从一个主体转到另一个 | 注意力易手 | 因果；一次交接；一次比较 |
| 对一个路口、车站或货场缓慢推镜 | 一个系统在升温 | 高峰时段；节日布置；一条队伍 |
| 正俯视，缓慢旋转 | 世界如同棋盘或机器 | 图案；物流；编排 |
| 从高处连续俯冲到角色高度，同时速度渐变 | 那一件要紧的小事 | 一次转折；一个笑点；一次相遇 |
| 模糊带收窄成一条细缝 | 亲密 | 一次告白；一次重逢；一个决定 |
| 以对数高度垂直上升 | 尺度，放手 | 余波；一个总结；系统变成图案 |
| 沿一条线（铁轨、河流、道路）横向跟拍 | 按顺序进行的过程 | 一条供应链；一场游行；一场比赛 |
| 跨越数小时的固定画面 | 时间就是主角 | 一项建造；一个集市日；潮汐 |

构图：保持高机位；清晰的模糊带承载主体；除近景外，车辆和人都保持很小。转场：踩在节拍上的剪切、速度渐变、俯冲和上升；避免会暴露假镜头的叠化。



## 8. 天然招式

一份菜单：按故事需要挑选。

- **速度骤降（×40 → ×1）。**时间在一个细节上骤降到真实速度。*适合的内容：*一个工人结束了一个班次；一个孩子掉了冰淇淋；拥挤码头上的一次求婚。
- **模糊带即指针。**滑动或收窄清晰带来引导视线。*适合的内容：*一个穿过市场的快递员；一个逆向滑行的滑雪者；一艘离港的船。
- **上帝视角的系统。**把地方当作音序器或机器。*适合的内容：*一个正在卸船的港口；机场的航班周转；农场的收割。
- **长曝光光轨。**黄昏时，灯光留下在世界上作画的轨迹。*适合的内容：*横渡海湾的渡轮；戴头灯的跑者；沿河的灯笼。
- **尺度揭示。**不断上升，直到地方变成图案。*适合的内容：*一个节日从布置到人潮；课间的学校；夜晚的城市网格。
- **掠过的云影。**天气掠过模型。*适合的内容：*季节转换；情绪变化；一个新闻周期。
