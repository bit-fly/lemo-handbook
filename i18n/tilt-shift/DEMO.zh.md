# 移轴微缩 — 我们的演示片

这只是众多可能中的一个例子。不要照搬它的故事、结构、镜头、道具或时间安排。

演示片：*Toy Town Rush Hour*（38 s）· `tilt-shift.mp4` · 源码在 [`demo/`](demo/)


## 故事与结构

一座原创的程序化小镇在黎明醒来，逐渐发展到早高峰的大堵车；在顶点处，时间骤降到真实速度，落在一窝在一辆主角车前横穿主干道的鸭子身上，然后释放并上升，直到小镇变成一块电路板。

旧版指南的改编配方，作为一个例子保留：把题材做成一个*由许多小角色组成的系统*，然后找到系统围绕其弯折的那*一个小角色*（产品发布 → 城市的车流都流向一家店；爱情故事 → 两个通勤者每天早上在同一条斑马线上擦肩；历史课 → 一条街在一个世纪中的延时）。

结构（38 s）：安静（黎明时一道光轨）→ 系统苏醒（角色倍增，节奏加强）→ 最大密度 → **在一个细节上硬降到真实时间**（鸭子，成功前先失败一次跳跃作为喜剧节拍）→ 释放回快进 → 上升到尺度揭示。一个主体，一个目标，一次转折。

用到的天然能力：长曝光光轨（黎明的车灯轨迹就是整个开场）、模糊带（跟随汽车；在鸭子上最窄）、延时速度（×24–×40，顶点处从 ×40 → ×1 骤降）、上帝视角的尺度（最大密度时旋转的正俯视，最后的上升）。

## 镜头

| 节拍 | 摄影机 |
|---|---|
| 开场 | 黎明时的高机位斜角全景，极慢的平移；模糊带跟随唯一一辆主角车的光轨，这辆车被安排在离摄影机最近的车道上 |
| 标题 | 斜角掠过屋顶，落到一块面向宽阔大道的建筑上的**场景内霓虹招牌**，字母每个八分音符亮起一个；路牌式标签 "A TILT-SHIFT MINIATURE" |
| 系统苏醒 | 中高机位斜角对着一个路口和一个车站，缓慢推镜；模糊带落在停车线 / 站台边缘上；通勤列车 |
| 最大密度 | **正俯视，缓慢旋转**，大堵车 |
| 真实时间的细节 | 一个连续的**俯冲**，从正俯视降到主角车引擎盖上方的低机位中近景，车头和车灯作为虚化前景。视线先于机身落到鸭子身上（注视目标的缓出比位置更快）。俯冲过程中速度从 ×40 → ×1 渐变；落在最窄的模糊带上。正俯视镜头事先旋转好，使其结束时正对近景镜头的方向 |
| 结尾 | 以对数高度**垂直上升**（40 m → 820 m），穿过一层薄云，直到小镇变成电路板图案；片尾卡 |

近景使用的数值：摄影机离地约 1.7 m，距离 6–8 m，俯仰约 12°，FOV 17°，近裁剪面 0.08 m；鸭子占画面高度约 1/4–1/3。斜角镜头：俯仰 45–55°，距主体 110–200 m，垂直 FOV 27–30°。

## 配乐与声音结构

采样的极简主义马林巴合奏（`demo/music/score.py`），120 BPM，因此 8 Hz 的延时顿挫正好是一个十六分音符。**固定的乐句骨架；城市事件决定哪些音发声**：车辆越过停车线触发马林巴 A，绿灯奏响木鱼重音，人群触发钟琴，列车车厢演奏低音；每个段落有一个基础填充率。

- 最大密度时骨架是满的，加入相位错开的马林巴 B 和调过音的汽车喇叭和弦（采样铜管断奏，八分音符脉动）。
- 真实时间的骤降是一次**磁带停转**：变速 1 → 0.22，各声部逐一退出，然后是真正的寂静。休止期间每个故事事件只奏一个轻柔的音，鸭子每跳一次就沿音阶上一级。
- 影片的第一个音是最后一个和弦的最高音。

声音设计：延时 = 音乐为主，加一层微弱的颗粒化快放城市嘶声、铁轨咔嗒声、继电器咔哒声；真实时间 = 发动机怠速、远处的城市、麻雀、细小的嘎嘎声和啾啾声、蹼足拍打柏油路面的声音；释放 = 发动机加速轰鸣，上升时风声扫上来。

人声：放松的美国男声，Kokoro `am_adam`，speed 0.9–0.95，5–6 句短台词，音乐闪避约 8 dB。

## 色板与道具

- 立面：暖白、奶油色、赤陶、砖红、淡黄、薄荷绿、天蓝。汽车：白、银、黑、红、蓝、黄色出租车。公园绿 `#6fa24a`。柏油 `#4b4e53`。人：0.5 m 的彩色胶囊体。
- 调色：NeutralToneMapping，饱和度 ×1.55，柔和对比度 +0.42，高光略暖，暗角 0.3。
- 模糊带参数：半宽 `w` 0.055（鸭子上为 0.035），`amp` 30，`mix` 0.55–0.7，`aper` 5000–9000（米），CoC 上限 30 px；128 个螺旋采样点。
- 光照：每个镜头拟合一张 4096 阴影贴图，半球补光约 0.6。黎明：太阳在地平线下约 3.5°，东方粉橙色补光 `#ffb48c`，约 9 % 的窗户亮着，钠灯路灯的光池。
- 立面着色器：冲孔窗 / 带形窗 / 幕墙 / 砖墙几种窗型，玻璃粗糙度 0.08–0.22，金属度 0.35；井盖、柏油补丁、油渍；GTAO。
- 交通：每个片段预先计算 IDM 跟车模型，信号灯 96 s 一个周期，“不要堵塞路口”逻辑，一条让所有车道都停下的人行横道；大量车流涌入加上路口堵塞，形成真实的大堵车。人群用闭式解：红灯时聚集在路口，绿灯时涌出。步进：快进时 8 Hz，×2 到 ×6 之间 12 Hz，低于 ×2 时平滑。
- 主角：一辆沿脚本路径行驶的黎明汽车，一列运动学曲线穿过节拍时间点拟合的通勤列车，车削成型的鸭子配绒毛光泽材质（`MeshPhysicalMaterial`，sheen 1，sheenRoughness 0.55），跳跃 = 预备压扁（0.28 s）→ 拉伸跳起 → 落地压扁 → 稳定，成功前先失败一次。

## 标题、字幕与片尾卡

- 字幕：绿色 `#0f5e3c` 圆角路牌面板，内嵌白色细边线，Overpass 600 44 px 白字，左侧一个亮绿灯的小红绿灯图标，距底部 118 px，位于下方模糊带内。
- 左上角的延时时钟（Overpass Mono）：`07:12` 带小号秒数，琥珀色 `×24 TIME-LAPSE`，绿色 `×1 REAL TIME`。
- 片尾卡：同样的路牌语言，叠在正俯视的小镇上：标题、风格名称和 `LemoLab × Claude Opus 5.5`。"LemoLab × Claude Opus 5.5" 署名只属于本库的演示片；用户的影片不带 LemoLab 署名，也不要复制这张片尾卡。

## 构建说明

```
styles/tilt-shift/demo/
  post.js    tilt-shift DOF (band + physical), grade      city.js   procedural town, facade shader, sign
  geo.js     merged-geometry builder                      sky.js    clock → sun/sky/fog/env, dawn glow
  traffic.js lanes, lights, IDM sim, fleet, trails, walkers   train.js commuter train
  ducks.js   lathe ducks + hop choreography               story.js  120 BPM timeline, time windows, rate curves
  main.js    cameras, stepping, crowds, HUD, events       mix.py    ambience + foley + VO + score
  music/score.py  sampled marimba score (skeleton + event gating)   subs.mjs  subtitle export
```

1. `sh styles/tilt-shift/demo/build.sh` 从头重建一切：TTS → whisper → 事件 → 字幕 → 配乐 → 混音 → 912 帧渲染（在 M 系列 GPU 上用 3 个进程约 60–80 s）→ 封装（−14 LUFS，grain 1）→ 风格帧和海报帧。
2. 用 `node core/render/still.mjs styles/tilt-shift/demo <t…> --q noev` 迭代（`noev` 跳过事件扫描）。调试参数：`nohud`、`nodof`、`nostep`、`az=<deg>`、`cam=x,y,z,lx,ly,lz,fov`、`aper=`、`bamp=`、`bmix=`。

与本演示片道具相关的坑：
- 第一版是一片摩天楼森林，看不到任何街道。
- 黎明的那辆车一直藏在街道峡谷里，直到把它安排到靠摄影机一侧的车道上。
- 霓虹招牌一直被遮挡，直到把它移到面向宽阔大道的位置。
- 实例数上限（1,400 对比 2,800 辆在场车辆）悄无声息地把主角车丢掉了。
- 车辆在离鸭子过马路处还有 2 m 时就停下了（IDM 堵车间距）：把停车线挪近，并减去了堵车间距。
- 大堵车让故事车道空了：路口堵塞让人行横道前的路段断了车流，于是把主干道豁免，让队伍在主角车后面形成。
- 从正俯视到斜角的俯冲起初扭转了 180°。
- 顶点处起初用的是高机位长焦，鸭子只占画面的 1/15。把车头灯移到车头顶部前缘，使其从上方也能看清，并让主角车保持不动，直到上升的摄影机完全离开它。
- 云把结尾冲淡了；路灯光池看起来像气泡；街道设施让近景区域显得杂乱，于是被移除。
- 固定的太阳让半部影片逆光发灰；第一版黎明看起来像半夜（通过东方粉色补光和把亮灯窗户减少约 3 倍来修正）。
