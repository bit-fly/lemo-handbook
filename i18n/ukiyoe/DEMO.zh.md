# 浮世绘 — 我们的演示片

这只是众多可能中的一个例子。不要照搬它的故事、结构、镜头、道具或时间安排。

演示片：*Toward the Mountain · 山へ五景*（44 s）· `ukiyoe.mp4` · 源码在 [`demo/`](demo/)


## 故事与结构

一位戴草笠的旅人从稻田出发，走向远处的一座山：雨中过桥，经过一家茶屋——山就在圆窗里等着——来到一片在他和山之间立起来的海。巨浪把版画冲回一张白纸；下一幅版画就是那座山，他摘下了斗笠。五景，一个恒定的主体；故事靠的是*每次山在画面中的位置*来讲述（地平线上的一个小点 → 被窗框住 → 被巨浪压得渺小 → 占满整张纸）。一个人物，一个目标，一次转折。

结构：序破急（jo-ha-kyū），缓慢、开阔、静止（序）→ 逐渐聚集的脉动（破）→ 急速冲向顶点（急）→ 硬切到寂静（間，ma）→ 安静的收束与尺度揭示。旧版指南要求每部片至少依托五个天然招式中的三个，并把最强的那个放在高潮；那是这部演示片的选择，不是规则。

用到的天然招式：一组景（整部片）、手卷（每次转场）、逐版套印（开场和巨浪之后的重生）、纸即是白（抹去版画的泡沫）、画框即物件（巨浪冲出边框）。旧版指南建议这类故事这样改编题材：把它做成一段旅程或一个系列，有一个恒定的主体（产品发布 → 产品在五个地方的五景；一座城市 → 五幅版画里的一天；一生 → 五个年龄，每幅里都是同一棵树）。

五景：一 田毎の朝（黎明的稻田）· 二 雨の橋（雨中的桥）· 三 茶屋の窓（茶屋的窗）· 四 海立つ（海立起来）· 五 山（山）。

## 镜头

| 节拍 | 摄影机 |
|---|---|
| 开场 | 固定在一张白纸上；第一幅版画在我们眼前逐版套印出来 |
| 前几景 | 固定画面，就像看墙上的一幅版画。主体很小 |
| 中间一景 | 极慢地推镜（1.00 → 1.065）向一个框景元素（圆窗） |
| 转场 | 手卷式从右向左滑过裱装间隙，越来越快：1.0 s → 0.9 s → 0.6 s |
| 高潮 | 第一次大幅运动：向上俯仰越过上边框进入裱纸，推镜；然后急推进泡沫 |
| 高潮之后 | 硬切到一张白纸，停留（間），然后重新印 |
| 结尾 | 从最后一幅版画拉镜，揭示整幅卷轴：所有景并排（尺度揭示）；片尾卡在卷轴上 |

高潮获得了全片**唯一一次大幅摄影机运动**，分四个节拍演出（共约 4.5 s；成片中为 25.4–30.4 s）：

1. **升起**（约 1.9 s）：海水涌成一堵墙；摄影机向上俯仰越过上边框，并略微放宽，让人物变小。
2. **悬停 / 亮相**（约 1.2 s）：浪峰立在边框之外的裱纸上，浪爪张开、几乎凝固（抖动 ×0.25）；整幅版画作为一件物件完整可见。滚奏鼓声达到顶点，然后是 80 ms 无声的吸气。
3. **落下**（约 1.2 s）：浪唇伸长并向镜头方向旋转下压，浪爪放大 ×2.5，摄影机推进到 3× 并带一点滚转。
4. **泡沫**（约 0.7 s）：分形浪爪从浪唇迸出铺满屏幕，淡成素纸 → 硬切到寂静（間，30.4–32.2 s）。

然后是四次重印（32.2 / 32.7 / 33.2 / 33.7 s），最后一句台词在 34.4 s，最终版画在 38.4 s，拉镜 38.9–40.9 s，片尾卡从 40.3 s 开始。初剪的高潮只有 0.7 s，看起来就像“闪过一些泡沫”；正是因为四节拍版本的效果，STYLE.md 才要求一个约一秒的停留节拍。

字幕避开人物：底部字幕带距边缘约 80 px；必要时把人物上移。

## 配乐与声音结构

原创配乐（`demo/music/score.py`），使用三味线、尺八、太鼓和拍子木，遵循序破急：

- 拍子木的击打声在开场套印过程中逐渐加速（每块版一击），即歌舞伎的开幕信号。
- 尺八自由节奏，*都节*音阶（D E♭ G A B♭），带气息的长音，每个音滑入，乐句末尾用 *meri* 下沉。
- 三味线：缓慢的脉动（72 BPM），然后是一段固定音型（96 BPM）配一面小而紧的鼓；最快的一次卷轴滑动配一段快速上行音阶。
- 太鼓心跳从 0.9 s 的间隔加速到高潮的滚奏；浪砸下时一记全力击打；然后是**绝对的寂静**（混响尾音也切掉）。四记重太鼓重印最后一景。开场的尺八动机回归并解决；片尾卡下一个带 sawari 的三味线长音回响。

乐器配方（可复用）：
- 用采样做尺八：`flute` / `recorder`，拉平振幅和音高颤音（除以 60 ms 包络；跟踪 f0 并反向变形），加入与包络锁定的 1–4 kHz 气息噪声，起音处加一段 *muraiki* 爆发气息。
- 用采样做太鼓：`gran_cassa` + `toms:low_mallet` + `frame_drum:large` + 一层合成鼓皮（音高从约 120 降到 58 Hz）和一声鼓槌闷响。

本片特有的拟音：带约 9 Hz 圆周调制的马连（baren）摩擦声、空心的桥上脚步声、风铃泛音 2.36 / 5.15 / 7.98 kHz、田间涓流、带雨滴的雨声底、约每 4 s 一次的海浪涌动、云雀啁啾、雁鸣，最后一景里一只鸢的 *pii-hyoro* 鸣叫。

人声：平静的男性讲述者，第一人称，5 句短台词（Kokoro `am_adam`，speed 0.84–0.88）。人声下音乐闪避约 −8 dB（最后一句 −10 dB），环境声约 −4 dB。本演示片的字幕停留：≥ max(1.8 s, 人声 + 0.75 s)。

## 色板与道具

**画布与纸张。**1920×1080 的纸张 = 缩放为 1 时的屏幕。墨色边框在 `x 44–1876, y 38–1042`（3.4 px），外侧 9 px 处还有一条细线；再往外是纸边。纸张裱在一条长卷轴上（`#c9b690`，间隙 260 px），左端有一根木轴。

**色板**（本片的颜料组合）：

| 名称 | 十六进制 | 用途 |
|---|---|---|
| 纸 | `#eee2c6` | 和纸底色（带 ±3 % 斑驳，纤维 `#fbf6e9` / `#c7b893`） |
| 普鲁士蓝 | `#1d3a66` · 深 `#13284a` · 浅 `#4d6f98` | 天空、水、山、浪 |
| 深浪谷 | `#0f2344` | 浪的内侧 |
| 淡蓝 | `#8db0c6` · `#bcd0d6` | 水中倒影、下部天空 |
| 墨（主版） | `#231f1c` | 所有主线 |
| 红 | `#b8412f` · 淡 `#e3a08a` · 桃 `#efc4a8` | 太阳、毛毡长凳、印章、黎明的晕染、题签标签 |
| 赭 / 稻草色 | `#cf9f4a` · `#c9a45c` | 斗笠、道路、腰带 |
| 绿 | `#8aa152` · 深 `#50703c` · 松 `#3e5a3a` | 田地、树木 |
| 靛蓝布 | `#2c4a70` · 绑腿 `#1d2c44` | 服装 |

**版块。**`g0` 主线 · `g1` 蓝色 · `g2` 绿色 / 次要色 · `g3` 红色 / 人物，以固定的套准偏移合成：`g1 (2.2,−1.3)`、`g2 (−1.8,1.9)`、`g3 (1.5,2.2)`。套印显现：每块版约 0.34 s。

**纹理配方。**每个色版上按此顺序：木纹 `source-atop` α ≈ 0.1–0.17（天空/水最强），马连刷痕 `destination-out` α ≈ 0.38（深色木纹上 0.2），胡麻摺（goma-zuri）斑点 `destination-out` α ≈ 0.3。主版：只有斑点（α 0.12）。完成的纸张上覆盖浅色纤维（α ≈ 0.09）。**木纹** = 扭曲噪声场的等值线（`u = y·0.035 + fbm·9 + knots`），在 `|frac(u)−0.5| > 0.4` 处画细暗线，加上宽的色调带。**马连** = 约 260 道模糊的圆弧 + 之字形刷痕。动态的大面积填色（浪）在其裁切区内加木纹 + 纸色马连叠层。**晕染（bokashi）**：逐像素，上边缘每列游移 ±20–30 px。

**道具：**
- *山*：不对称的凹形山坡（左 `y = s^1.55`，右 `s^1.8`），带缺口的山顶，雪顶做成**顺着沟壑淌下的雪痕**：12 道深度随机（有些很长）、细而尖的雪指，由一条轻微起伏的雪线相连；右侧有阴影带；黎明时雪上有淡红色的光晕。原创轮廓，不是富士山。
- *浪*：归一化轮廓（后坡 → 浪峰 → 前唇 → 卷曲 → 中空的前部）。一堵垂直的水墙，浪峰朝镜头方向倒下，旅人站在岩石海岬上，刻意避开 *The Great Wave*（神奈川冲浪里）的船与浪构图。浪身是**三条蓝色带，之间有晕染**（浪峰附近浅蓝 → 普鲁士蓝 → 深浪谷），由后坡曲线向内偏移的粗笔触构成；**成组的白色流线**（每组 3 条，断成长弧）。沿浪峰有泡沫边；**分形浪爪**：每只大爪分成 3 根爪指，每根再分叉，所有尖端向内钩；一层淡蓝背层偏移在白色前层之后；水花**成簇**（一个大点、几个中点、许多小点）。
- *浪爪根部*从泡沫**里面**长出来：根部收窄到约 40 % 宽度，然后埋进不规则的白色泡沫团里（先描所有泡沫团的边，再全部填色 → 得到一条合并的轮廓）。直接插在浪峰上的浪爪看起来像木板。
- *桥*：侧视的拱形（太鼓）桥，而不是斜跨河面的桥构图。
- *旅人*（80–130 px）：侧视，低矮的圆锥形斗笠遮住上半张脸，和服下摆掖起、后角塞进腰带，深色绑腿，草鞋，手杖，胸前打结的包袱。近景：剃过的头顶（淡蓝灰），折起的发髻，一笔画成的眼睛。姿势：行走 / 站立 / 扶斗笠 / 披蓑衣 / 坐着喝茶 / 背影 / 摘下斗笠。
- *题签*：奶油色 `#f3e7c6`，淡红色标签上写着系列标题。

## 构建说明

```
styles/ukiyoe/demo/
  print.js     paper, woodgrain, baren, specks, blocks, bokashi, carved lines, reveal masks, cartouche, seals
  nature.js    mountain + snow drips, pines, rocks, rain, geese, simple claws
  traveler.js  the traveler (walk / stand / hold hat / straw cape / sit & drink / back view / hat off)
  views.js     the five prints: cached blocks (g0–g3) + per-frame paint()
  wave.js      sea rows, wave geometry, banded body, fractal claws, spray clusters
  story.js     the timeline (single source of truth)     main.js  camera, scroll, sheets, reveal, titles, subtitles, events
  lines.json   voice   music/score.py  original score   mix.py  foley + voice + ducking + the silent ma   subs.py  cues → srt
  build.sh     one-command rebuild
```

1. `node core/render/still.mjs styles/ukiyoe/demo <t…>`（`--q nosub=1`，`--q test=trav` 输出角色设定图，`--q poster=1`）。
2. `core/tts/tts.py lines.json voices` → `core/tts/asr_check.py`。
3. `node core/render/events.mjs styles/ukiyoe/demo` → `music/score.py` → `mix.py`。
4. `node core/render/video.mjs styles/ukiyoe/demo --fps 24 --workers 3`（1056 帧 ≈ 45 s，Canvas2D）。
5. `core/render/mux.sh out/video24.mp4 mix.wav ukiyoe.mp4 24 0` → `check_asr.py ukiyoe.mp4`。

或者直接运行 `sh styles/ukiyoe/demo/build.sh`。

与本演示片道具相关的坑：
- 之字形的雪线看起来像皇冠；平滑的波浪线看起来像糖霜。要用细而尖、长度随机的雪痕，并强制控制点在 x 方向单调（否则会出现微小的自相交圈）。
- 第一版的浪看起来像一道瀑布帘子（流线从底部呈扇形展开）。流线必须沿后坡轮廓走；浪身需要分层的蓝色带；浪爪必须分叉并向内钩：单独一条卷曲的条带看起来像丝带。
- 偏移曲线在收紧的浪唇处会自相交 → 内部流线只用后坡。
- 冲出边框的浪必须同时逃出纸张裁切**和**画框裁切；它的两侧仍被画框裁切，只有顶部冲出去。
- `mountain()` 只在传入纯色时才填充，因此渐变的山体是透明的：注意选项标志。
- 用 `multiply` 绘制的印章在深色片尾卡和浪上消失了 → 在这些地方改用 `source-over`。
- 旅人从前景树旁走过时看起来像是在树“前面”；让低矮的树枝避开行走路径。
- 字幕带会盖住底部 150 px 内的任何东西：地面线和人物都被抬高了。
