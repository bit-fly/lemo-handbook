# Urban Sketch · Pen & Wash — 我们的示范片

这只是众多可能中的一个例子。不要照搬它的故事、情节走向、镜头、道具或时间安排。

示范片：*Where the Wind Went*（风去了哪里）（32.4 s，1920×1080，24 fps，无旁白）· `urban-sketch.mp4` · 源码在 [`demo/`](demo/)


原始的开头描述：一张在公园长椅上画的速写本页面：细细的深褐色针管笔线条，微微抖动、出头、从不完全闭合，上面随手点染透明水彩。颜色略微偏离线条，溢出线外，并在页面边缘消融进奶油色的冷压水彩纸里。

## 故事与结构

一座公园只以钢笔速写的形式存在，页面上唯一的颜色是一顶草帽。一阵风卷走了草帽，**风把它带到哪里，页面就被上色到哪里**。

原始的“这种风格是什么”笔记，附示范片的精确颜色：纸 `#f5eede`，墨 `#2b2520`。

现场报道式绘画，几分钟内在现场完成。两个始终明显分开的层：
1. **墨线。** 一根细而几乎粗细不变的线（0.3–0.5 mm 针管笔），深褐色 `#2b2520`。它轻微抖动，在转角处出头几个像素，笔画中途断开，重在暗示而非描述：几笔窗户的记号代替整齐的网格，几段扇贝状的碎线代替整棵树的轮廓。
2. **水彩。** 透明水彩罩染在上面。它与线条**错位** 1–3 px，有时溢出线外，并为高光和人物留出纸白（留白）。干透的边缘更深（颜料在边缘积聚），颜料在纸纹中沉淀出颗粒。

页面本身就是画面的一部分。暖奶油色 `#f5eede` 的冷压纸有大尺度的斑驳和细密的纸纹。没有任何东西是满版涂色的：画面边缘散成叶片大小的色点和白色空洞，留下空白的页边用来手写。

这种风格当初瞄准的故事，以及示范片用到的原生招式（速写跨页与天际线的“先线后色”；由阵风驱动的“颜色作为到来”；唯一有颜色的东西 = 草帽；以页面作为结尾的画框）：

适合：旅行日记、城市肖像、某地的一天、“我注意到的那一刻……”、生活切片、带小人物的温和喜剧，以及任何因“被观察、手工制作”的感觉而增色的内容。

**原生招式（只有这种媒介才能做到）：**
- **先线后色。** 展示钢笔一笔一笔地画出主体（按真实的笔顺），然后点上水彩。绘画过程本身就是看点。
- **颜色作为到来。** 每个像素都有一个*颜色到达时间*。水彩从一个源头向外扩散，带着参差的湿润前沿和一条深色的水渍线，于是你可以用一个事件来上色（风、一个奔跑的人、音乐、日出）。人物在颜色触及之前一直是凝固的线稿，被颜色触到后才开始动。
- **唯一有颜色的东西。** 以一张无色的速写开场，只有一件物体带色；它就成了主角。
- **页面作为画框。** 拉远直到整张页面可见，边缘消融，页边有手写的标题和笔记。这同时充当片尾卡和尺度揭示。

## 镜头

一台 2D 摄影机在一张 5120×2880 的页面上移动（最后的拉镜以 0.375× 的比例 1:1 显示整页）。
- 设计好的运镜用三次缓动。跟拍镜头用临界阻尼弹簧追随一个前瞻目标，让摄影机像手持跟拍一样滞后（刚度 28，坠落时为 70）。
- 示范片用到了推镜、拉镜、横向跟拍、升降镜头上升、带轻微滚转的急速俯仰、撞击时带 0.35 s 震动的冲击推近、长拉镜，以及向下俯仰进入页边。
- 在故事节拍处让主体至少占画面高度的三分之一；草帽带一圈淡淡的纸白光晕（留白），让它在繁茂的枝叶上也能看清。

## 示范片中实际使用的运动

- 人物以 12 fps **抖动（boil）**：线条抖动和水彩种子每 1/12 s 变化一次。静态页面不抖动（它是一张真实的纸）；摄影机每帧平滑移动。
- 人物保留预备、动作和跟随动作：站起前先蹲，扑空时前冲并踉跄，鱼跃后趴着滑行。脚步落在拍点上（奔跑循环 = 2 拍）。
- 风是画出来的：每一拍都在草帽后面生成墨线“~@”卷曲，0.4 s 内画出，然后从尾部擦除；叶片色点拖在草帽后面。
- 颜色从不突然出现。它要么带着有噪声的圆形裁切从一个点绽开（人物），要么通过到达场铺开（世界）。

## 配乐结构

三层；无旁白。
- **环境声：** 纸张房间底噪 → 公园鸟鸣（颜色到来之后）→ 低沉的城市嗡鸣，在天际线出现前一小节进入（J 剪辑）。在静默小节里一切声音都消失。
- **拟音：** 笔在冷压纸上的声音（带通噪声，1.6–7.5 kHz，带纤维振幅纹理和颗粒咔嗒声，每个真实笔画一阵；速写跨页时成千上万叠成一片嘶嘶声；天际线的笔画更亮，听起来像踩镲）；每次大面积晕染配一声湿笔刷的“嘘”；风声从右声道 J 剪辑切入；草帽像纸张扑动，扑动频率和音量跟随它的速度，声像跟随它在屏幕上的 x 位置；脚步落在拍点上；自行车铃；鱼跃、滑行、接住时的拍击声和落水的扑通声。
- **音乐：** F 调 150 BPM 爵士华尔兹：Sneakybass 以三拍子行走，合成的鼓刷加踏板踩镲，立式钢琴落在第 2–3 拍，单簧管主奏，城市段用加弱音器的小号，拨奏固定音型，树木绽开处用颤音琴和马林巴的短促重击，在顶点处一个漂浮的 D♭maj7♯11，随后是**一小节真正的静默**。静默后的第一个声音是单簧管的半音下行加定音鼓；接住草帽的瞬间落在全奏的强拍上。
- 混音：接住时音乐闪避；拟音做 90 Hz 高通；−14 LUFS，LRA 7。

## 片名与片尾卡

不需要字幕。所有文字都是**页面上的手写字**，以从左到右的显现方式写出，并配有笔声：
- 角落笔记用 Reenie Beanie（`Sun. 3:40 pm — windy`）；
- 片名和版权说明用 Caveat（字重 500–600），左对齐写在页面空白边距里。

文字始终留在世界之中，随摄影机移动，绝不作为叠加层。

片尾卡（`demo/film.js`，`notes()`）：片名 "Where the wind went." 用 Caveat 500、190 px 写在左下页边（28.2–29.5 s），然后在同一栏写版权说明："Urban Sketch · Pen & Wash — a Lemo-Opuscar style"（30.1–30.8 s），"LemoLab × Claude Opus 5.5" 用 Caveat 600（30.6–31.2 s），以及音乐、采样和字体署名（31.0–31.8 s）。"LemoLab × Claude Opus 5.5" 这一落款只属于本库的示范片；用户的影片不带任何 LemoLab 署名，也不要复制这张卡（复用代码时删掉那几行 `handwrite()`）。

### 我们踩过的坑

- **颜色场里出现直边。** 源头的包围盒忽略了它的纵向拉伸（`sy`），而超出影响半径的缓慢“蔓延”被一个方盒截断。按实际的（带噪声的）距离裁切，而不是按包围盒。
- **退台式高楼周围的矩形遮罩**在天空中留下白色缺口。用真实的阶梯剪影做遮罩（层台、尖顶、金字塔顶、水塔）。
- **角色跑进未上色区域时失去颜色。** 只在角色的起点采样一次到达时间（或把它绑定到给角色上色的那个事件），绝不在当前位置采样。
- **静态墨线无法被后来的水彩遮挡。** 因此远处人群用“胡萝卜小人”（一团水彩、两笔腿、一个头部圆点）代替完整骨架；在绘制之前，先把建筑墨线在更近的建筑和树冠内部擦除。
- **混合坐 → 站时 IK 脚被钉住**，会把双腿叉开。把脚的目标位置向髋部正下方混合。
- **正面朝向的头变成了秃头。** 始终先画头发块面，再从其下部挖出脸。
- 无头 Chrome 与大画布：墨线、时间、颜色和页面用 5120² 画布没问题，但要自己把墨线和时间打包进 RGBA 字节纹理（`getImageData`），并把到达场以 `R16F`（可过滤）上传。

## 引擎参考

所有函数都在 `demo/engine.js` 里，并且是确定性的（相同种子，相同笔迹）。

| 函数 | 作用 |
|---|---|
| `penStroke(pts, {w, wob, over, gap, seed, smooth})` | 沿任意折线准备一条针管笔笔画（抖动、出头、渐细、断口） |
| `drawPen(ctx, stroke, p=1, col=INK, alpha=1, from=0)` | 将它绘制到比例 `p`（逐步画出）；`from` 从尾部擦除 |
| `rasterPen(inkCtx, timeCtx, stroke, t0, dur, win)` | 把一条笔画烘焙进静态墨线层，**同时**记录每个像素的到达时间（在着色器中按笔顺回放） |
| `wash(ctx, poly, [r,g,b], {a, j, layers, edge, dx, dy, seed})` | 在任意多边形上做一层水彩（粗糙边缘、罩染、深色水渍线、偏移） |
| `reserve(ctx, poly, a)` | 把颜色洗回纸白（留白、前景遮挡） |
| `dab(ctx, x, y, r, angle, col, a, seed)` / `foliage(ctx, crown[], opts)` | 叶片色点 / 整个树冠 |
| `arrivalField(W, H, gw, gh, sources, {amp, creep})` | 每个格子的颜色到达时间；`sources = [{x, y, t, v, R, sy, mask, hard}]` |
| `compositor(canvas, layers)` → `draw(cam, t)` | WebGL 页面：纸 × 水彩（按到达时间显现，带湿润前沿）× 墨线（按笔画时间显现） |
| `figure(look, pose, place, {seed, boil})` → prims | 一个速写人物（挖空 / 水彩 / 墨线图元）；`prims.head`、`prims.hand` 用于挂载附件 |
| `hat(c, r, [rx, ry, rz])`, `bike(place, phase, col)` | 具有真实 3D 朝向的道具 |
| `drawPrims(ctx, prims, {color, ink, clip})` | 绘制图元；`color` 0..1 = 水彩已到达的程度；`ink` = 描绘进度（数字或按图元的函数） |
| `sketchShape(ctx, poly, col, {ink, wash, offset, color, p})` | 一次调用画出**这种风格的任意形状** |
| `handwrite(ctx, text, x, y, size, p, {font})` | 从左到右写出的手写字 |

**“唯一颜色”钩子。** 让其他一切保持 `color: 0`（纯墨线），只给保留颜色的那个元素传 `color: 1`，就像示范片中的草帽。或者给那个元素一个 t = 0 的到达源，其他一切更晚到达。

最小示例：一个暖橙色 `#D97757` 的四角闪光，带一条短短的光标尾巴。
```js
import { sketchShape, sparkle, penStroke, drawPen, hex } from './engine.js';
const star = sparkle(960, 540, 120, .24);                       // 4-point star polygon
sketchShape(ctx, star, hex('#D97757'), { ink: 3, wash: .7, offset: 3, seed: 7 });
drawPen(ctx, penStroke([[1040, 610], [1180, 640], [1300, 646]], { w: 3, wob: 1.2, over: 6, seed: 8 }), 1);   // the tail
```
