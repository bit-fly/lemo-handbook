## 5. 运动质感

- **绘制进入是主要的运动**：物体的进度是它在屏幕上的位置或某个提示点的函数；一组笔触中的每一笔各占进度的一段，所以结构最先出现。
- **摇曳**只在物体画完之后发生：一个小幅的水平错切（`sin(1.15t+φ) + .4 sin(2.7t+2φ)`），树木约 0.006，草为 0.01–0.03。
- **笔刷边缘擦除**：一条波浪形的垂直裁剪揭开整个场景；线条随笔触进度生长；标签以从左到右的裁剪打开。
- **雾气**负责擦除：带波浪形上升边缘的纸色图层。
- 动画中的生物和事件可以按音乐的节拍网格定相，让落地踩在拍点上。
- 平滑缓动（`ss`、`eio`、`eo`、`ei`）；60 fps 适合缓慢流畅的笔刷；没有任何抖动。



## 6. 镜头语法

这是一套词汇，不是一条路线。画面是一张手绘的纸；很少剪切。开场和结尾由题材决定。

| 运动 | 表达什么 | 可用于 |
|---|---|---|
| 在连续世界上的长距离横向移动镜头 | 梯度；旅程；因果 | 一条样带；一条路线；一条时间线 |
| 沿一个物体的垂直俯仰 | 尺度；测量 | 一棵高树；一栋建筑；一个深度 |
| 锁定画纸，东西逐一画出 | 研究；专注 | 一张标本图版；一份食谱；一张示意图 |
| 缓慢推镜到一个细节 | 观察者凑近细看 | 一粒种子；一只昆虫；一条手写笔记 |
| 拉镜到地图或示意图 | 重新框定全局 | 一切发生的地方；一个系统 |
| 雾气洗回空白纸面 | 章节结束；时间流逝 | 一个季节；遗忘；一个新地方 |
| 翻页 / 新的纸页滑入覆盖 | 笔记里的新条目 | 新的一天；新的物种；新的案例 |
| 锁定视角下的时间变化 | 生长；衰败；历史 | 季节循环；前后对比；地质深时 |

构图：留出宽裕的纸边；每个视图一个主角主体及其注释；标签永远不遮挡主体。转场：笔刷边缘擦除、雾气、翻页或连续的镜头运动；不用硬切，也不在不相关的画面之间叠化。



## 8. 原生手法

这是一份菜单：按故事需要选用。

- **以绘制作为揭示。** 新东西进入时一笔一笔地出现。*适合的内容：* 一栋建筑的建造阶段；一道菜的食材；人体的器官。
- **迸发。** 一整组东西在 ≤ 1 s 内同时画出，制造高潮。*适合的内容：* 节日人群；一片花田盛开；一座城市亮起灯火。
- **色板即数据。** 天空、地面和背景按一个测量值混合。*适合的内容：* 沿河的污染；随海拔变化的温度；城市各处的噪声。
- **标本 + 注释。** 一个主角物体，配手写标签和引线。*适合的内容：* 一套工具；一个葡萄酒产区的葡萄品种；自行车的零件。
- **雾气擦除。** 世界被洗回白纸。*适合的内容：* 遗忘；梦的结束；一处被拆除的场地。
- **随时间变化的地图。** 一幅手绘地图，其填色随年份连续变化。*适合的内容：* 一种语言的传播；一段海岸线的侵蚀；一张铁路网的扩张。
- **绘制的变形。** 物体交叉淡变为烧焦、湿透或老化的精灵图，然后重新生长。*适合的内容：* 山火与恢复；一场洪水；一次修复。
