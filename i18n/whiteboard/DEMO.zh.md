# 白板讲解 — 我们的示范片

这只是众多例子之一。不要照搬它的故事、结构、镜头、道具或时长。

示范片：*Einstein in Your Pocket*（口袋里的爱因斯坦，111 s）· `whiteboard.mp4` · 源文件在 [`demo/`](demo/)


示范片最初的一句话提案：一部在一块光亮的白板上现场绘制的科普讲解片：单线手写字真的是一笔一画*写*出来的，马克笔悬浮着、没有手，一块可以移动的磁铁，一块能让时间倒流的板擦——镜头始终不离开白板，直到最后的拉镜让人看到整堂课挂在墙上。

## 故事与结构

为什么 GPS 需要相对论，从你手机上的地图图钉讲起。这是一部非官方的科普影片：Albert Einstein 仅以历史科学家的身份、以名字出现，他的遗产管理方以及其姓名和肖像权利的持有人并未制作或认可这部影片；GPS 的运营方也没有。为这部示范片写下的原始风格笔记如下：

在**一块实体白板**上的一堂课。观众学到的一切都在他们眼前用白板笔画出来，按照真实的书写顺序。白板是一张*地图*：每个想法占据自己的区域，镜头在区域之间移动，通常**由笔带领**（笔画出一条线，镜头沿着它走）。最后镜头拉远，观众看到整个讲解原来是一幅完整的画面。

让它感觉真实而不是"动画文字"的关键：笔尖落下处墨水淤积，干笔条纹和斑点，笔画冲过头、收不拢，从未擦干净的旧课残影，一层比白板移动得更慢的光泽反光，以及**每一笔**都有声音。

**这个版本没有手。**马克笔悬浮着（带着真实的投影，抬起时投影会变大），在两句话之间停到画外，再飞回来。实体道具（磁铁、板擦）自己移动。不要画手、手臂或光标。

| 原生能力 | 示范片如何使用 |
|---|---|
| **按笔顺书写** | 揭示*就是*讲解：旁白念到哪一项，方程就恰好在那一刻逐项出现。 |
| **一块白板，一个镜头** | 白板上的距离 = 论证中的距离。回到之前的图是免费的呼应（示范片回到第一个方程，算出 38 μs × c ≈ 11 km）。 |
| **笔带领镜头** | 转场是画出来的：一条轨道、一条信号线、一道轨迹。镜头沿着线走到下一个想法。 |
| **磁铁** | 白板上唯一被允许*移动*的物体。把主角（"你在这里"的图钉）交给一块磁铁；它可以被拿起、放下、滑动、下沉。 |
| **板擦让时间倒流** | 倒着擦掉一条轨迹，读起来就是撤销时间。示范片只用了一次，就在笑点之后。 |
| **两支笔同时画** | 二重奏：现场比较两个量（示范片中：地面时钟和轨道时钟以两种速度滴答）。 |
| **全板揭示** | 示范片的结尾：拉镜越过白板边框，看到墙和笔槽。之前的每个场景一下子全部重新出现。 |

**示范片的故事形态：**以一个微小物体（图钉）开场 → 尺度揭示 → 在第一个强拍上出标题 → 用 3 步讲清机制 → **静默 + "But, there's a catch."（但是，有个问题。）**→ 用视觉二重奏解释转折 → 一个展示后果的笑点（图钉每拍漂移一天，最后漂进大海）→ 板擦倒带 → 修正，二者同步 → 拉镜看到整块白板 → 结尾卡写在标题下方。

我们如何找到主题的抓手（同样的配方适用于其他主题）：找到**一个观众拥有的物体**（手机、一条面包、一个灯泡），一个令人意外的数字，以及一个你能在白板上*走*过去的后果。把意外放在中间，在一段静默之后。

## 镜头

- 一个在 8000 × 4500 白板上方的 2D 镜头：位置、缩放（以 1/z 插值，使推镜感觉像移动镜头）、少量横滚。
- **语法**：(1) 拉镜揭示尺度；(2) 沿着笔正在画的线走；(3) 每当观众需要阅读时保持静止；(4) 静默之后一次甩镜进入新想法；(5) 最后一次越过边框的拉镜。
- 真实的 180° **运动模糊**：当镜头每帧移动超过 14 px 时，渲染最多 12 个子帧并取平均。
- 每个镜头都留出画面底部 12 % 给字幕。

在示范片中，镜头始终没有离开白板，直到最后的拉镜，展示了整堂课挂在墙上，连同铝框和笔槽。

示范片的运动数值：笔跳跃的抬起高度最多为窗口的 35 %；间隔 > 0.75 s 时笔会去停靠，在下一笔之前 0.42 s 返回；磁铁落下 0.3 s，下沉 = 倾斜 0.5 rad 并下降 40 px；板擦带宽 90–230 px，强度 90 %；标题 3 s，一个标签 0.3–0.8 s，一颗完整的卫星约 1 s。原始的运动部分：

- **手速**：每一笔都遵循 `u − sin(2πu)/2π × 0.8`——慢落笔、快中段、慢抬笔。笔画被安排进一个**时间窗口**（由引擎求解速度），所以书写总是恰好在那个词上完成。
- 笔画之间的**笔跳跃**：抬起高度与距离成正比（投影滑开并变模糊），最多为窗口的 35 %。间隔 > 0.75 s：笔飞到画外的停靠点，在下一笔之前 0.42 s 返回。
- **磁铁**：落下 = 0.3 s，抬起高度 → 0，一个大投影逐渐缩小；滑动 = 每一步用 smoothstep 加少量抬起；下沉 = 倾斜 0.5 rad 并下降 40 px。
- **板擦**：沿路径匀速移动，以 90 % 的强度擦掉一条 90–230 px 的带（始终留下 10 % 的残影）。
- **速度**：标题 3 s，一个标签 0.3–0.8 s，一颗完整的卫星约 1 s。比真人手快——这是一堂加速的课——但绝不快到丢失笔顺。

## 配乐结构

- **每一笔都有声音**：带通的毡头在光面上的噪声（2.2–7.5 kHz 嘶声 + 0.5–1.5 kHz 主体），以笔画自身的速度曲线作为包络，开头一个 4 ms 的笔尖滴答声，随机的粘滑颗粒，约 28 % 的长笔画带有**白板笔的吱吱声**（1.5–2.6 kHz 正弦波，7–13 Hz 颤音）。蓝笔略暗，橙笔略亮。声像 = 笔画在屏幕上的 x 位置；镜头越近越响。
- **道具**：磁铁在钢制白板上 = 咔嗒声 + 金属振动模态（830/1370/2210/3120 Hz）+ 140 Hz 的白板闷响；板擦 = 250–2600 Hz 的毡布摩擦声，由它的之字形运动调制；笔槽 = 塑料弹跳声 + 铝的余响；拔笔帽 / 盖笔帽。
- **房间**：低沉的房间底噪，以及一个**按地面时钟的秒数滴答的挂钟**——它是静默期间唯一的声音。
- **配乐**：120 BPM 的发条式极简主义，D 大调 / B 小调：马林巴八分音符琶音、大提琴 + 低音提琴拨奏、每拍一声木鱼、钢片琴主题，沙锤/拍手只在响亮的段落出现。信号配钢片琴的叮声，下落的信号配一段竖琴刮奏，漂移的物体配一段断奏进行曲（大号 + 巴松，半音下行）。在任何"两个量出现分歧"的时刻，让**同一个音型以两种速度**演奏（相位偏移），然后在修正时一下子回到齐奏。倒带 = 把前一段提示音乐倒放并压缩。
- **混音**：旁白在最上层（压缩，轻微的房间感），配乐比旁白 RMS 低 6.5 dB，说话时再额外压低 9 dB，拟音比旁白低约 11 dB；−14 LUFS。

## 色板与道具

- **白板**：暖白色 `#fbfbf9 → #eeede9` 渐变，一层淡淡的磨痕/细微划痕贴图，约 46 个**残影痕迹**（旧的字、圆圈、箭头），透明度 5–10 %，颜色为灰 `#9aa0a8` / 浅蓝 `#8aa0c8`。一道柔和的斜向**窗户反光**（白色，10–16 %），以镜头 0.35× 的速度移动——正是这个细节让人信服"光亮"。
- **墨水**：黑 `#23262c`、蓝 `#2a5cb3`、橙 `#d97757`，alpha 0.94，用 **multiply** 合成，这样重叠处会像真的马克笔一样变暗。绘图线宽 6–11 px，写字线宽为大写字高的 13 %。
  - 颜色语义：**黑** = 事物和结构，**蓝** = 信号、光、测量，**橙** = 你 / 时间 / 最要紧的东西（每个场景一个强调色）。单色变体：只保留一个橙色元素（"唯一颜色"）。
- **笔画特征**：每约 0.6 × 线宽重新采样；沿法线方向的低频手部抖动（±2.6 px，波长约 220 px）加更细的颤动；凿形笔尖的线宽随方向变化（0.8–1.0）；开头有压力渐变（0.72 → 1），结尾有 12 % 的收尖；圆从某个角度起笔，并**闭合后再多画一段**；矩形是 4 笔，转角处略微冲出；每条长笔画起点内侧有一个颜色更深的淤墨点。
- **干笔质感**：一张 512 px 的斑点和短条纹贴图，从墨水层中减去（destination-out），锁定在白板空间，镜头拉远时淡出。
- **字体**：单线字体 **EMS Tech**（OFL，Architects Daughter 的单笔画版本），每个字形有 ±2° 旋转、±3.5 % 的基线和缩放抖动。缺失的字形（μ ≈ → × − ✓ ² ↓ ° ± .）在引擎中手工定义。标题大写字高 200 / 120 px，标签 30–70 px。
- **道具**：白板笔（白色笔杆、与墨色一致的色环和插在尾部的笔帽、毡头笔尖），一块带橙色小标签的炭灰色毡布板擦，一枚光亮的橙色**地图图钉磁铁**（径向渐变、白点、高光、柔和投影）。铝框和笔槽只在最后的全景中出现，挂在一面暖灰色的墙上 `#d8d3ca`。

## 字幕与结尾卡

- 标题和结尾卡都用同一种单线手写字**写在白板上**；结尾卡写在标题下方，于是影片在它开始的地方结束。
- 烧录字幕：米白色圆角标签（90 %），Architects Daughter 44 px，深墨色文字，左下角一小段橙色马克笔短划。在分句处断开，每行 ≤ 44 个字符，短分句合并，超过 1250 px 时分两行。

示范片的结尾卡用同一种手写字写在标题下方（`demo/film.js`，代码块 `END CARD`，从 103.3 s 开始）："Whiteboard Explainer"，橙色的 "Lemo-Opuscar"，"LemoLab × Claude Opus 5.5"，然后是用小字写的旁白、字体和采样署名；笔在 107.3 s 盖上笔帽。"LemoLab × Claude Opus 5.5" 的署名只属于本库的示范片；用户的影片不带 LemoLab 署名，也不复制这张卡（复用代码时请删掉那些 `credit()` 行）。

## 制作说明

1. 把脚本写成短句（`demo/lines.json`），用 `core/tts/tts.py` 合成（声音 `bm_george`，`lang: en-gb`），用 `demo/tools/asr_check.py`（`WM=medium.en`）检查 → 得到 `voices/words.json` 的逐词时间。
2. 规划白板布局（每个想法一个区域），然后编写 `demo/film.js`：旁白开始时间、用 `at(id, word)` 挂在说出的词上的图、笔、镜头关键帧。
3. `node core/render/events.mjs demo` → `events.json`（每一笔、每次擦除、每块磁铁、提示锚点）。
4. `music.py`（读取同样的事件）→ `mix.py`（由事件生成拟音 + 旁白 + 闪避压缩后的配乐）。
5. `node core/render/video.mjs demo --fps 24` → `core/render/mux.sh … 24 2`。整部片渲染约 30 s。
6. `demo/build.sh` 完成第 3–5 步，外加字幕、海报和静帧；`--vo` 会把第 1 步也重做一遍。

### 我们踩过的坑

- **一支笔，活太多**：一支笔被背靠背地安排任务，会越拖越晚（卫星晚到了 12 s）。给每张图一个窗口（`by:`），让重叠的任务交给另一支笔。
- **最短笔画时长 × 虚线**：一条 60 段的虚线，每段下限 0.09 s，就要花 6 s。虚线需要自己很小的下限。
- **淤墨点比笔画起点还大** → 每个字母周围都出现灰色光晕。让墨点保持在笔画之内。
- **标点消失了**：字体里的句号是一条 1 px 的笔画。把小于线宽的笔画渲染成点。
- **被推镜切掉一半的标签**看起来很邋遢：一个标签在它出现的每个镜头里，要么完整在画内，要么完全在画外。
- **子帧太少的运动模糊**会让文字频闪。子帧之间的步长 ≤ 4 px。
- **英式嗓音 + 美式音素**：Kokoro `bm_george` 用 `lang: en-us` 时把 "clocks" 念得像 "Clarks"。英式嗓音用 `en-gb`；用 `medium.en` 检查。
- 让板擦的路径避开你想保留的标签（它有一次擦掉了半个 "orbit"）。

## 引擎参考

| 函数 | 作用 |
|---|---|
| `loadFont(name, url)` | 加载由 `demo/tools/svgfont2json.py` 转换的单线字体（`'tech'` = EMS Tech） |
| `line / curve / poly / arc / circle / rect / roundRect / arrow / dashed / hatch` | 手绘形状 → `Stroke` / `Stroke[]`。选项：`w`、`color`、`jitter`、`over`（冲出）、`bow`、`lap`（圆的重叠）、`clip`（圆角矩形）、`alpha` |
| `text(str, x, y, {h, align, w, color, font})` | 按书写顺序生成笔画的手写文字（`h` = 大写字高） |
| `new Stroke(points, opts)` | 任意路径（扁平的 `[x,y,…]`），马克笔风格 |
| `new Pen(id, color, {park})` | 一支悬浮的马克笔；`park` = 它在画外的停靠点，以屏幕 px 计 |
| `Timeline.draw(pen, shapes, t, {by, speed, minGap, maxGap})` | 安排笔画；有 `by` 时会求解手速以按时完成 |
| `Timeline.erase(path, t, dur, {width, strength})` | 沿路径移动的毡布板擦（留下残影） |
| `Timeline.cue(t, type, extra)` | 导出到 `events.json` 的额外声音/音乐锚点 |
| `new Camera([[t, x, y, zoom, roll, ease], …])` | 带关键帧的 2D 镜头；缓动 `io` `i` `o` `l` `s` |
| `new Board(tl, {ghosts})` · `board.render(ctx, t, cam)` | 白板、墨水（multiply + 干笔质感 + 板擦）、反光、`objs`（世界空间道具）和 `overlays`（屏幕空间） |
| `penPose / drawMarker / drawEraser / drawPinMagnet` | 实体道具 |

最小调用——用马克笔画一个带短光标尾巴的暖橙色四角闪光：

```js
import * as W from './engine/wb.js';
await W.loadFont('tech', 'fonts/EMSTech.json');
const tl = new W.Timeline(), O = new W.Pen('orange', '#D97757');
const star = [], cx = 960, cy = 540, R = 120, r = 26;
for (let i = 0; i <= 8; i++) { const a = i * Math.PI / 4 - Math.PI / 2, q = i % 2 ? r : R; star.push([cx + Math.cos(a) * q, cy + Math.sin(a) * q]); }
tl.draw(O, [W.poly(star, { w: 10 }), W.line(cx + 150, cy + 60, cx + 150, cy + 150, { w: 10 })], 0.5, { by: 1.6 });
tl.draw(O, W.text('ready', cx + 190, cy + 150, { h: 60 }), 1.7, { by: 2.4 });
tl.end();
const board = new W.Board(tl), cam = new W.Camera([[0, 960, 540, 1]]);
board.objs.push({ draw: (ctx, t, c) => W.drawMarker(ctx, O, W.penPose(O, t, cam), c, t) });
window.render = t => board.render(ctx, t, cam);           // ctx = your 1920×1080 canvas 2D context
```
单色变体：所有东西都用黑笔画，只给最要紧的那个元素 `{ color: '#D97757' }`。
