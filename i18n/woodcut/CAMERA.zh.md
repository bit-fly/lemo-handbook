## 5. 动态质量

- **角色一拍二（12 fps）**；镜头、粒子、火和光一拍一（24 fps）。排线存在于每个身体部件的局部空间里，所以刻痕随肢体移动、不会抖动；只有火和液体每 2 帧重新刻一次，作为刻意的抖动效果。
- 每个关键动作都有**预备 / 动作 / 跟随**：后撤几帧 → 2 帧的击打 → 落定 + 短暂震动。
- **雕刻揭示**：每一笔都有自己的开始时间和速度（0.08–0.35 s）。揭示依据：`light`（亮部先出，由粗到细）、`radial`（从一点向外：光芒、浇铸）、`down`，或任意函数。
- **硬切 = 一次新的印刷**：两帧套印偏差（偏几个像素，再回位）。
- **纸张转场**（唯一的转场语法）：滚筒上墨（一道湿润高光扫过）→ 铺纸 → 马连螺旋拓印，图像渗透出来 → 纸张绕着一个圆柱朝镜头揭起，先沉后快，背面露出镜像的透印。
- 永远不动的：纸边。



## 6. 镜头语法

镜头在纸面上移动；纸边保持固定。焦点是刀尖，或最亮的那道刻痕。

| 运镜 | 表达 | 可用于 |
|---|---|---|
| 跟随刀尖移动 | 制作；线条就是故事 | 第一笔；在地图上画出的路线；一个签名 |
| 随刻痕扩展连续拉镜 | 一条线变成一个世界；尺度 | 从一条街到一座城；一棵家谱树；声音或消息传播的范围 |
| 固定机位的一幅版画 | 无字小说的一页；阅读时间 | 一个决定；一幅肖像；事后 |
| 在雕塑特写上缓慢微距推镜 | 耐心、触感、劳动 | 劳作的双手；一件工具；一封正在读的信 |
| 急速变焦并停留 | 震惊；断裂的那个细节 | 一道裂缝；一个错的数字；一张转过来的脸 |
| 画中画（门、窗、拱） | 距离、隔绝、等待 | 门外的人群；病房；边界 |
| 踩着节拍的硬切，每次都是一次新印刷 | 堆积，一组系列版画 | 献礼；日子流逝；一串名字 |
| 从细节升镜到全貌 | 后果 | 洪水漫到村庄；光照到人们脸上 |
| 通过揭纸在两幅版画间切换 | 一个状态印在另一个之上 | 前后对比；兑现的承诺；几代人 |

开场和结尾由题材决定。构图：黑色块面落在刻出的白底上，或白色落在未刻的黑底上，绝不灰对灰；文字只出现在纸边上。转场：硬切（新的印刷）或揭纸；绝不用叠化。



## 8. 原生动作

这是一份菜单：只用你的故事需要的。

- **光是刻出来的。**从一点迸发的一簇放射状刻痕。*适合的内容：*接通的电网；一次科学顿悟；修复的灯塔。
- **雕刻 = 时间。**屏幕上一刀一刀的耐心劳作。*适合的内容：*一年的训练；一座拔地而起的建筑；一段手艺学徒生涯。
- **镜像版块 → 正向印刷品。**纸被揭起时，反写的字读正了。*适合的内容：*投票结果；洗清的名字；纠正的误会。
- **戳刀刻痕作为纹理。**白点可以停在半空，也可以被重新上墨填回，直到黑色干净。*适合的内容：*城市上空熄灭的星星；停下的雨；地图上消退的疫病。
- **唯一的色版铺开又收回。***适合的内容：*一次献血；丰收上空的日出；停电中唯一亮着的窗。
- **对雕塑或画面使用滤镜**，变成顺着形体走向的刻痕。*适合的内容：*根据照片绘制的真人肖像；一个机械零件；重新刻制的档案图片。
- **无字小说式的编排。**各自独立的版画，台词很少或没有；空白处可以无声。*适合的内容：*一次迁徙；一场罢工；七幅版画里的一生。
